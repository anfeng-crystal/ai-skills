# 属性适用性与取值

## 先判断适用，再决定是否写入

按目标版本、实体字段类型、实际控件类型、页面模型和容器区分属性。文本、金额、复选框、分录列不能共用一套“必录/锁定/可见”补齐规则。复制结构时只保留适用于目标且符合本次需求的业务属性。

- 不支持的属性不写入；已有且非本次修改的属性保持原状。目标未配置的可选属性保留缺省，不为了“完整”补 `false`、空串或默认状态列表。
- 属性存在与属性值合法分开核验。优先使用目标版本的属性定义、当前设计器选项、可信同类导出及已验证行为；不因 XML 可解析或别的控件有该属性就判定可用。
- `observed_properties` 是观察集合，`observed_common_properties` 是样本交集，`examples` 是样本值；它们都不是必填属性清单、默认值或完整枚举。不能遍历这些集合自动补业务属性，也不能把第一个 example 当默认值。
- 设计器没有某属性选项时，不从其他类型补入该属性，也不转写到实体层绕过界面限制。界面缺项本身不证明所有版本都不支持；确需实现该能力时核对目标属性定义/有效配置，只保留有依据的实现。

## 必录与布尔字段

接口键必须出现、值不可为 null、页面要求输入、业务要求必须为 true，是不同要求。接口参数必填不能自动映射成实体或控件 `MustInput=true`。

复选框/开关的 `false` 通常表达“否”，不能按空值处理，也不能为了接口必填把未勾选变成不合法。目标类型没有必录配置时，不添加 `MustInput`，不通过实体字段硬加星号；确有“必须同意/必须勾选”的业务规则才按已确认语义选择受支持校验。

页面、分录列和弹窗的必录语义需一致，但各层只使用自身支持的配置，不能逐层复制同名属性。出现异常星号时检查实际实体 `MustInput`、控件、继承、规则和插件来源；只修正已确认的错误配置，不能因复选框界面缺项就批量清除所有实体字段的必录。

## 锁定性与状态选项

先确认目标控件是否支持 `Lock`，再确认它的序列化形态和可选状态；不支持就不加，支持也只写本次需求需要且有效的选项。

状态列表不能写成布尔值，也不能从单据生命周期推导全集。例如目标锁定选项没有 `view` 时，不因“查看态应只读”就补 `view`；查看态行为由该平台实际机制决定。别的控件或可见性 `Visible` 支持某状态，不证明当前控件的 `Lock` 也支持。设计器显示未翻译的原始值时应核对，不把显示出来当作合法证据。

复用已确认的目标版本取值证据，无需为每个字段重新浏览设计器。缺少枚举依据时保持原配置并记录待核验项，不猜写选项；只有 XML/字符串形态校验通过不能声称枚举合法。

## 单据复制与字段功能控制

单据复制后某字段未带出时，V6.0.1 及以上可核对“开发服务云 → 开发平台 → 对应扩展单据 → 表单字段 → 功能控制 → 允许复制”。此配置用于单据复制时的字段携带；不能据此推断复制按钮权限、单据转换携带或其他记录复制接口的行为。

本地修改仍以目标包的精确节点类型、继承链和序列化形态为准；SDK 的 `Copyable` 仅作检索线索，不能据名称直接添加属性。缺省与显式 `false` 分开处理，不从样本值推导默认值或批量补齐。配置与实际效果不一致时，继续核对有效继承和复制后赋值逻辑，并按已有授权验证目标入口。

## 修改与验收

仅修改本次需求涉及的属性；“接口必填”“只读”“隐藏”分别落实，不能互相推导。需要移除误加属性时先检查直接定义与继承来源，分清删除本层覆盖、恢复继承、显式关闭的区别。

按已有授权验证真实入口：复选框的 true/false 均可保存且符合报文合同；星号、编辑性和锁定状态与目标配置一致。静态脚本只证明其覆盖的检查，不替代设计器选项或运行行为验证。
