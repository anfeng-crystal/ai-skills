## 新增验证模式

### 1. 三级联动标准写法
```java
// 第一级变更 → 清空第二级和第三级 → 重设第二级过滤
private void onCollegeChanged() {
    this.getModel().setValue("edu_major", null);
    this.getModel().setValue("edu_class", null);
    applyMajorFilter();  // 仅重设第二级过滤
}

// 第二级变更 → 清空第三级 → 重设第三级过滤
private void onMajorChanged() {
    this.getModel().setValue("edu_class", null);
    applyClassFilter();
}
```
**关键**：逐级清空下游字段，避免脏数据残留。

### 2. 状态机 Map 映射（优于 if-else）
```java
private static final Map<String, Set<String>> VALID_TRANSITIONS;
static {
    VALID_TRANSITIONS = new HashMap<>();
    VALID_TRANSITIONS.put("A", new HashSet<>(Arrays.asList("B")));
    VALID_TRANSITIONS.put("B", new HashSet<>(Arrays.asList("C", "D", "E")));
    VALID_TRANSITIONS.put("C", new HashSet<>(Arrays.asList("B")));
    VALID_TRANSITIONS.put("D", Collections.emptySet()); // 终态
    VALID_TRANSITIONS.put("E", Collections.emptySet()); // 终态
}
```
**优势**：状态转换一目了然、易于维护、支持任意状态数量。

### 5. IdCardUtil 跨行业复用
医疗行业和教育行业均使用 IdCardUtil，验证了该工具类的通用性：
- `isValid()` — 格式校验
- `calcAge()` — 年龄计算
- `extractBirthDate()` — 出生日期提取
- `mask()` — 脱敏显示

建议将 IdCardUtil 提取到平台级公共包，而非每个行业工程各copy一份。
