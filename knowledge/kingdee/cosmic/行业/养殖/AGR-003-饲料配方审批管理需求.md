## 需求单

### 基本信息
- **需求编号**: AGR-003
- **所属行业**: 养殖
- **业务场景**: 饲料配方审批管理（配方设计→成本核算→审批→生产下发→效果追踪）
- **优先级**: P1(高)
- **迭代轮次**: R4
- **补强目标**: kd-review（转换/报表/工作流审查清单）、kd-data（复杂计算+聚合）

### 核心功能目标
为规模养殖场提供饲料配方全流程管理：技术员设计配方（原料+比例），系统自动核算成本，配方经审批后下推至生产工单，养殖效果数据反向关联配方，形成配方改良闭环。

### 业务角色
| 角色 | 职责 |
|------|------|
| 饲料技术员 | 设计配方、调整比例、查看效果 |
| 场长 | 审批配方、审批成本偏差 |
| 采购员 | 根据配方生成采购需求 |
| 养殖员 | 按配方生产饲料、记录用量 |

### 前置条件与依赖
- 原料基础资料已维护（饲料原料、营养成分、单价）
- 养殖批次已创建（依赖 AGR-001 批次数据）
- 审批流程已配置

### 详细业务规则

#### 1. 配方单（主表+2层分录）
- **单据编号**: `FEED-{品种缩写}-{序号}` (如 FEED-PIG-001)
- **状态机**: 草稿(A) → 待审(B) → 已审(C) → 生产中(D) → 已完结(E) → 作废(F)
- **流转规则**: A→B（自动触发审批流）; B→C/B→A（审批通过/驳回）; C→D（下推生产工单）; D→E（生产批次结束）

#### 2. 配方分录（原料明细）
| 字段标识 | 字段名 | 类型 | 必录 | 校验 |
|---------|--------|------|------|------|
| material | 原料 | BaseData(F7) | ✓ | 必须是有效原料 |
| ratio | 配比(%) | Decimal(5,2) | ✓ | 0.01~100.00 |
| unit_price | 单价(元/kg) | Decimal(8,2) | ✓ | > 0 |
| amount_per_ton | 每吨用量(kg) | Decimal(8,2) | — | = 1000 × ratio/100 |
| cost_per_ton | 每吨成本(元) | Decimal(10,2) | — | = amount_per_ton × unit_price |

- **配比合计**: 所有原料 ratio 之和必须 = 100.00%（精度校验）
- **成本汇总**: 主表"总成本/吨" = Σ(cost_per_ton)

#### 3. 成本偏差审批
- 当总成本/吨超过品种标准成本 10% 时，自动触发二级审批（场长+总经理）
- 偏差率公式: `偏差率 = (实际成本 - 标准成本) / 标准成本 × 100%`
- 偏差率 precision: `Decimal(5,2)`，用 `BigDecimal.divide(standardCost, 4, RoundingMode.HALF_UP)` 计算

#### 4. 配方下推生产工单（转换规则）
- 配方单 → 生产工单的 `AbstractConvertPlugIn` 转换
- 下推映射: 配方分录 → 工单领料分录
- 转换后原单据状态自动变为"生产中(D)"

#### 5. 效果追踪报表
- `AbstractReportFormPlugin` + `AbstractReportListDataPlugin` 联合使用
- 报表维度: 配方 × 批次 × 日增重 × 料肉比 × 成本
- 料肉比公式: `FCR = 总饲料用量(kg) / 总增重(kg)`
- 日增重公式: `ADG = (出栏重 - 入栏重) / 饲养天数`

### 验收标准
- [ ] 原料配比之和精确等于 100.00%
- [ ] 成本/吨自动汇总，BigDecimal 精度正确
- [ ] 成本偏差超 10% 自动触发二级审批
- [ ] 审批驳回后状态回退至草稿
- [ ] 配方下推生产工单转换规则正确
- [ ] 效果追踪报表 FCR/ADG 计算正确
- [ ] 代码通过 kd-review 全类型审查

- 《饲料和饲料添加剂管理条例》：配方原料必须在允许使用目录内
- 《畜禽养殖业污染物排放标准》GB 18596：饲料配方需考虑排放影响
- 可追溯要求：配方版本须完整留痕，不可删除历史版本
