# 表单插件常用事件与方法

> 来源: 联网搜索整理
> 整理时间: 2026-04-12

---

## 1. 常用方法

| 方法 | 说明 |
|------|------|
| `getView()` | 获取动态表单界面视图模型接口 `IFormView` 的实例 |
| `getModel()` | 获取动态表单界面数据模型接口 `IDataModel` 的实例 |
| `getPageCache()` | 获取页面缓存管理器，存取数据到缓存中 |
| `getControl(key)` | 获取界面上的控件 |
| `addClickListeners()` | 注册插件，监听按钮点击事件 |
| `addItemClickListeners()` | 注册插件，监听子菜单项点击事件 |

## 3. 常用事件

### 3.1 preOpenForm

**触发时机：** 系统收到 showForm 指令，显示界面前，准备构建界面显示参数时触发。

**使用场景：**
- 新界面还没有显示出来
- 可以在此事件取消界面的显示
- 或者修改显示参数

```java
@Override
public void preOpenForm(PreOpenFormEventArgs e) {
    super.preOpenForm(e);
    // 可以在此取消界面显示或修改参数
}
```

### 3.2 registerListener

**触发时机：** 用户与界面上的控件进行交互时触发。

**使用场景：** 建议在此事件侦听各个控件的插件事件。

```java
public class RegisterListenerSample extends AbstractFormPlugin
    implements ItemClickListener, ClickListener, RowClickEventListener, TreeNodeClickListener {

    private final static String KEY_MBAR = "tbmain";
    private final static String KEY_BARITEM1 = "baritem1";
    private final static String KEY_BUTTON1 = "buttonap1";
    private final static String KEY_ENTRYENTITY = "entryentity";
    private final static String KEY_TREEVIEW1 = "treeviewap1";

    @Override
    public void registerListener(EventObject e) {
        super.registerListener(e);

        // 侦听主菜单按钮点击
        Toolbar mbar = this.getView().getControl(KEY_MBAR);
        mbar.addItemClickListener(this);

        // 侦听按钮点击
        Button button = this.getView().getControl(KEY_BUTTON1);
        button.addClickListener(this);

        // 侦听单据体行点击
        EntryGrid entryGrid = this.getView().getControl(KEY_ENTRYENTITY);
        entryGrid.addRowClickListener(this);

        // 侦听树型控件点击
        TreeView treeView = this.getView().getControl(KEY_TREEVIEW1);
        treeView.addTreeNodeClickListener(this);
    }

    @Override
    public void itemClick(ItemClickEvent evt) {
        super.itemClick(evt);
        if (StringUtils.equals(KEY_BARITEM1, evt.getItemKey())) {
            // 处理菜单点击
        }
    }

    @Override
    public void click(EventObject evt) {
        super.click(evt);
        Control source = (Control) evt.getSource();
        if (StringUtils.equals(KEY_BUTTON1, source.getKey())) {
            // 处理按钮点击
        }
    }

    @Override
    public void entryRowClick(RowClickEvent evt) {
        Control source = (Control) evt.getSource();
        if (StringUtils.equals(KEY_ENTRYENTITY, source.getKey())) {
            // 处理单据体行点击
        }
    }

    @Override
    public void treeNodeClick(TreeNodeEvent evt) {
        TreeView treeView = (TreeView) evt.getSource();
        if (StringUtils.equals(KEY_TREEVIEW1, treeView.getKey())) {
            // 处理树节点点击
        }
    }
}
```

### 3.3 createNewData

**触发时机：** 界面初始化或刷新，开始新建数据包时触发。

**使用场景：**
1. 需要由外部传入完整的界面数据包
2. 动态添加字段时，系统内置创建的数据包没有新字段的值

### 3.4 afterBindData

**触发时机：** 界面数据包构建完毕，生成指令，刷新前端字段值、控件状态之后触发。

**使用场景：**
- 根据各字段值数据，重新设置控件、字段的可用、可见性
- **注意：** 不要在此事件修改字段值

```java
@Override
public void afterBindData(EventObject e) {
    super.afterBindData(e);
    // 设置控件状态
    this.getView().setVisible(true, "field1");
    this.getView().setEnable(false, "field2");
}
```
