# AGR-002 养殖批次出栏下推销售单

## 基本信息
- **需求编号**: AGR-002
- **所属行业**: 养殖
- **业务场景**: 养殖批次出栏后下推生成销售出库单 + 出栏检疫证打印

## 功能模块

### 模块一：出栏→销售单转换规则
| 源字段（出栏单） | 目标字段（销售出库单） | 规则 |
|--------------|-------------------|------|
| batch_no | src_batch_no | 直接携带 |
| breed | product_name | 品种→产品映射 |
| out_qty | sale_qty | 出栏数量 |
| avg_weight | unit_weight | 均重 |
| (out_qty × avg_weight) | total_weight | 计算:总重 |
| unit_price | sale_price | 出栏单价 |
| (total_weight × unit_price) | sale_amount | 计算:销售金额 |

### 模块二：出栏检疫证打印插件
- 继承 `AbstractPrintServicePlugin`
- 打印前校验检疫证号是否填写
- 打印时自动填充打印日期和打印人
- 打印后记录打印次数
