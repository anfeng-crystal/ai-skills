## 新增验证模式

### 1. 分录加权平均计算（整体进度）
```java
BigDecimal weightedSum = BigDecimal.ZERO;
for (DynamicObject row : entries) {
    BigDecimal progress = row.getBigDecimal("actual_progress");
    BigDecimal weight = row.getBigDecimal("weight");
    weightedSum = weightedSum.add(progress.multiply(weight));
}
BigDecimal overall = weightedSum.divide(new BigDecimal("100"), 2, ROUND_HALF_UP);
```

### 2. 偏差百分比通用公式
```java
public static BigDecimal calcVariancePercent(BigDecimal actual, BigDecimal plan) {
    if (plan == null || plan.compareTo(BigDecimal.ZERO) == 0) return BigDecimal.ZERO;
    return actual.subtract(plan).divide(plan, 4, ROUND_HALF_UP).multiply(new BigDecimal("100"));
}
```
**必须**判断除数不为零。

### 3. 权重合计校验（含精度容差）
```java
BigDecimal diff = weightSum.subtract(new BigDecimal("100")).abs();
if (diff.compareTo(new BigDecimal("0.01")) > 0) {
    addErrorMessage(entity, "权重之和应为 100%");
}
```
**为什么需要容差**：浮点精度问题，用户输入33.33+33.33+33.34=100.00但可能有尾差。

### 4. EntryGrid.lockRow 分录锁行
```java
EntryGrid entryGrid = this.getView().getControl("entryKey");
for (int i = 0; i < entries.size(); i++) {
    entryGrid.lockRow(i);
}
```
用于已审批/已确认状态下禁止编辑分录行。
