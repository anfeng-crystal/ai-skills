# 移动端插件开发指南

> 来源: 基于平台API和社区资料整理
> 日期: 2026-04-12
> 标签: 移动端, AbstractMobFormPlugin, AbstractMobBillPlugin, 移动表单

---

## 摘要
金蝶云苍穹移动端开发基于独立的移动插件体系，通过继承 AbstractMobFormPlugin / AbstractMobBillPlugin / AbstractMobListPlugIn 实现移动表单的业务逻辑控制。移动端与 PC 端共享实体元数据，但拥有独立的表单元数据和页面控件。

## 适用版本
- 金蝶云苍穹 V5.0+

## 核心概念

### 移动端插件基类

| 插件类型 | 基类 | 适用场景 |
|----------|------|----------|
| 移动表单插件 | `AbstractMobFormPlugin` | 移动端动态表单页面 |
| 移动单据插件 | `AbstractMobBillPlugin` | 移动端单据表单 |
| 移动列表插件 | `AbstractMobListPlugIn` | 移动端列表页面 |

### PC端与移动端区别

| 维度 | PC 端 | 移动端 |
|------|-------|--------|
| 实体元数据 | 共享 | 共享 |
| 表单元数据 | 独立 | 独立 |
| 插件基类 | `AbstractFormPlugin` | `AbstractMobFormPlugin` |
| 控件类型 | PC 控件 | 移动控件（卡片、轮播等） |
| 页面参数类 | `FormShowParameter` | `MobileFormShowParameter` |

## 详细内容

### 一、移动表单插件

```java
package com.example.mobile;

import kd.bos.form.plugin.AbstractMobFormPlugin;
import kd.bos.form.events.AfterDoOperationEventArgs;
import kd.bos.dataentity.entity.DynamicObject;

/**
 * 移动端动态表单插件示例
 */
public class MyMobileFormPlugin extends AbstractMobFormPlugin {

    @Override
    public void afterCreateNewData(EventObject e) {
        super.afterCreateNewData(e);
        // 新建数据后的初始化逻辑
    }

    @Override
    public void afterBindData(EventObject e) {
        super.afterBindData(e);
        // 数据绑定后的界面控制
        // 注意：不要在此方法中修改数据对象
    }

    @Override
    public void registerListener(EventObject e) {
        super.registerListener(e);
        // 注册控件事件监听
        this.addItemClickListeners("bar_save");
    }

    @Override
    public void itemClick(ItemClickEvent evt) {
        super.itemClick(evt);
        String itemKey = evt.getItemKey();
        if ("bar_save".equals(itemKey)) {
            // 处理保存按钮点击
            doSave();
        }
    }

    private void doSave() {
        // 保存逻辑
        this.getView().invokeOperation("save");
    }
}
```

### 二、移动单据插件

```java
package com.example.mobile;

import kd.bos.bill.plugin.AbstractMobBillPlugin;
import kd.bos.form.control.events.ItemClickEvent;
import kd.bos.dataentity.entity.DynamicObject;

/**
 * 移动端单据插件示例
 */
public class MyMobileBillPlugin extends AbstractMobBillPlugin {

    @Override
    public void afterCreateNewData(EventObject e) {
        super.afterCreateNewData(e);
        // 新建单据初始化
    }

    @Override
    public void beforeDoOperation(BeforeDoOperationEventArgs args) {
        super.beforeDoOperation(args);
        // 操作执行前校验
        String operateKey = args.getSource().getOperateKey();
        if ("submit".equals(operateKey)) {
            // 提交前检查
            if (!validateBeforeSubmit()) {
                args.setCancel(true);
                this.getView().showTipNotification("请填写必填字段");
            }
        }
    }

    private boolean validateBeforeSubmit() {
        DynamicObject dataEntity = this.getModel().getDataEntity();
        // 校验逻辑
        return dataEntity.get("required_field") != null;
    }
}
```

### 四、移动端页面跳转

```java
// 移动端页面跳转使用 MobileFormShowParameter
import kd.bos.form.MobileFormShowParameter;

MobileFormShowParameter showParam = new MobileFormShowParameter();
showParam.setFormId("mob_target_form");  // 移动端表单标识
showParam.getOpenStyle().setShowType(ShowType.MainNewTabPage);
showParam.setCustomParam("paramKey", "paramValue");

this.getView().showForm(showParam);
```

### 五、插件注册

与 PC 端类似，在设计器中注册：

1. 打开移动端表单设计器
2. 在表单属性中找到"插件"配置
3. 填写完整的插件类名
4. 保存

## 注意事项

1. **页面参数类型**：移动端使用 `MobileFormShowParameter`，不能使用 PC 端的 `FormShowParameter`
2. **F7 过滤**：移动端 F7 控件的过滤方式与 PC 端不同，不支持直接设置 listFilter
3. **控件差异**：移动端的控件与 PC 端不完全对应，需使用移动端专用控件
4. **禁止混用**：PC 端插件（AbstractFormPlugin）不能注册到移动端页面
5. **事件差异**：部分 PC 端事件在移动端不触发，需针对移动端单独测试
