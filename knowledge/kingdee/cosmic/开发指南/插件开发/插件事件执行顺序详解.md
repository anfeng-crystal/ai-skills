## 摘要

本文详细描述了动态表单界面、单据操作插件、单据列表插件、单据转换插件、单据反写插件、报表取数插件、打印插件、引入引出插件中各种事件的执行顺序和触发条件。

- 金蝶云苍穹 V5.0+

## 一、动态表单/单据插件事件顺序

### 1. 界面打开前事件

| 序号 | 事件 | 触发时机 | 用途 |
|-----|------|---------|------|
| 1 | `setPluginName` | 显示界面前，准备构建显示参数之前 | JS 代码触发 |
| 2 | `preOpenForm` | 显示界面前，准备构建显示参数之前 | 设置权限、标题、是否触发事件 |
| 3 | `loadCustomControlMetas` | 显示界面前，构建界面显示参数时 | 动态添加控件 |

### 2. 界面初始化事件

| 序号 | 事件 | 触发时机 | 用途 |
|-----|------|---------|------|
| 4 | `setView` | 表单视图模型初始化，创建插件时 | 传入 IFormView 实例 |
| 5 | `initialize` | 表单视图模型初始化，创建插件后 | 初始化插件 |
| 6 | `registerListener` | 用户与界面交互时 | 注册控件监听 |
| 7 | `getEntityType` | 创建数据包之前 | 获取实体类型 |
| 8 | `createNewData` | 开始新建数据包时 | 自定义创建数据包 |
| 9 | `afterCreateNewData` | 新建数据包完毕后 | **新增模式：设置默认值** |
| 10 | `beforeBindData` | 生成指令，刷新前端之前 | 准备数据 |
| 11 | `afterBindData` | 生成指令，刷新前端之后 | **修改控件锁定性、可见性** |

**重要说明：**
- `afterCreateNewData`：从列表打开/下推/列表引入**不会进入**该事件
- `afterBindData`：**禁止修改**从数据库加载的字段值；可给无字段名的动态控件赋值

### 3. afterLoadData 与 afterCreateNewData 的区别

| 对比项 | afterCreateNewData | afterLoadData |
|-------|-------------------|---------------|
| 触发时机 | 界面数据包准备完毕后 | 界面数据包准备完毕后 |
| 数据包来源 | 全新创建的数据包 | 来自数据库 |
| 适用场景 | 调整默认值 | 根据单据数据执行业务逻辑 |
| 互斥性 | 与 afterLoadData **互斥**，只会触发其中一个 | 与 afterCreateNewData **互斥** |
| 触发条件 | 单据以**新增**模式打开 | 单据以**修改/查看**模式打开 |

### 4. 用户交互事件（无先后顺序）

| 序号 | 事件 | 触发时机 | 用途 |
|-----|------|---------|------|
| 12 | `beforeItemClick` | 点击菜单按钮，执行操作前 | **工具栏点击事件**（注意监听工具栏而不是按钮） |
| 13 | `itemClick` | 点击菜单按钮时 | 处理工具栏点击 |
| 14 | `beforeDoOperation` | 点击按钮/菜单，执行操作前 | **用于校验** |
| 15 | `afterDoOperation` | 执行操作后（不论成功与否） | 后续处理 |
| 16 | `comfirmCallBack` | 前端交互提示确认后 | 确认后处理 |
| 17 | `closedCallBack` | 子页面关闭，回调给父界面 | 子页面关闭处理 |
| 18 | `beforeClick` | 点击按钮/标签，执行操作前 | 用于校验（如判断当前登录人是否为创建人） |
| 19 | `click` | 点击按钮或标签时 | 处理点击 |
| 20 | `flexBeforeClosed` | 弹性域维护界面关闭时 | 弹性域关闭处理 |
| 21 | `onGetControl` | 代码尝试获取控件模型时 | 动态控件处理 |
| 22 | `customEvent` | 触发自定义控件定制事件 | 响应自定义控件前端请求 |
| 23 | `timerElapsed` | 定时触发 | 定时任务 |
| 24 | `afterDeleteRow` | 删除单据体行后 | 删除后处理 |
| 25 | `afterAddRow` | 新增单据体行后 | 新增后处理 |
| 26 | `propertyChanged` | 字段值更新后 | 字段变更处理 |
| 27 | `beforeF7Select` | F7 字段打开时 | F7 弹出前处理 |

### 5. 界面关闭事件

| 序号 | 事件 | 触发时机 |
|-----|------|---------|
| 28 | `beforeClosed` | 界面关闭之前 |
| 29 | `destory` | 界面关闭之后，释放资源时 |
| 30 | `pageRelease` | 界面关闭之后，释放资源时 |

## 二、单据操作插件执行顺序

```
onPreparePropertys（添加需要用到的字段）
  → onAddValidators（系统预置校验器加载完）
  → beforeExecuteOperationTransaction（校验通过，开启事务前）
  → beginOperationTransaction（开启事务后，提交数据库前）
  → endOperationTransaction（提交数据库后，事务未提交前）
  → [事务提交成功/失败]
  → rollbackOperationTransaction（事务提交失败，回滚后）
  → afterExecuteOperationTransaction（事务提交后）
  → setContext（设置上下文）
  → initializeOperationResult（初始化操作结果集）
  → onReturnOperation（操作结束）
```

### 各事件详细说明

| 事件 | 触发时机 | 注意事项 |
|-----|---------|---------|
| `onPreparePropertys` | 添加需要用到的字段 | 声明操作需要用到的字段 |
| `onAddValidators` | 系统预置校验器加载完，执行校验前 | 添加自定义校验器 |
| `beforeExecuteOperationTransaction` | 校验通过后，开启事务前 | 最终业务校验 |
| `beginOperationTransaction` | 开启事务后，提交数据库前 | **不能跨库更新**，跨库需用 KDTX 框架 |
| `endOperationTransaction` | 提交数据库后，事务未提交前 | 单据数据已保存到数据库 |
| `afterExecuteOperationTransaction` | 事务提交后 | 发送通知、触发外部接口 |

**重要限制：**
- `beginOperationTransaction`：**不能**在此事件直接跨库更新数据
- 跨库需采用 **KDTX 框架** 实现数据一致性
- 勿在此事件通过 `e.setCancelOperation(true)` 取消操作（不会回滚已更新的关联数据，会破坏数据一致性）

## 三、单据列表插件事件

### 1. 列表初始化

| 事件 | 触发时机 | 用途 |
|-----|---------|------|
| `createTreeListView` | 树形列表界面初始化 | 仅树形列表触发 |
| `filterContainerInit` | 初始化过滤控件时 | 设置过滤控件默认值 |
| `beforeCreateListColumns` | 构建列表列之前 | **动态添加/删除显示列** |
| `beforeCreateListDataProvider` | 构建列表取数器前 | **自定义获取不同数据库的数据** |
| `setFilter` | 生成过滤条件后，查询前 | **调整/追加过滤条件** |
| `beforePackageData` | 包装数据前 | 格式化数据（**不要修改基础资料引用属性**） |
| `packageData` | 包装数据，单元格填值 | 格式化数据、锁定已审核数据操作项 |

### 2. 用户交互事件

| 事件 | 触发时机 | 用途 |
|-----|---------|------|
| `billListHyperLinkClick` | 点击超链接单元格时 | 取消单据打开，显示其他界面 |
| `filterContainerSearchClick` | 修改过滤条件或点击确定 | 调整过滤条件配置 |
| `filterContainerAfterSearchClick` | 过滤条件解析后 | 联动修改其他过滤字段 |
| `filterContainerBeforeF7Select` | 过滤容器内 F7 弹出前 | F7 弹出前处理 |
| `filterColumnSetFilter` | 过滤字段基础资料条件调整 | 基础资料过滤条件调整 |
| `baseDataColumnDependFieldSet` | 设置常用过滤基础资料依赖字段 | 依赖字段设置 |
| `beforeShowBill` | 打开单据维护界面之前 | 打开前处理 |
| `billClosedCallBack` | 列表打开的单据界面关闭后 | 子单据关闭回调 |
| `listRowClick` | 列表行点击时 | 行点击处理 |
| `listRowDoubleClick` | 列表行双击时 | 行双击处理 |
| `setCellFieldValue` | 设置单元格指令 | 单元格值设置 |

## 四、单据转换插件事件

| 事件 | 触发时机 |
|-----|---------|
| `initVariable` | 初始化变量，增加必要变量 |
| `afterBuildQueryParemeter` | 构建取数参数后，添加额外字段/条件 |
| `beforeBuildRowCondition` | 编译数据筛选条件前，取消或增加自定义条件 |
| `beforeGetSourceData` | 取源单数据前，修改取数语句和条件 |
| `afterGetSourceData` | 取源单数据后，获取其他定制数据 |
| `beforeBuildGroupMode` | 构建分单/行合并模式之前，更改合并策略 |
| `beforeCreateTarget` | **选单时触发**，获取现有目标单数据包定制处理 |
| `afterCreateTarget` | **下推时触发** |
| `afterFieldMapping` | 目标字段赋值完毕后，修订/计算/汇总 |
| `beforeCreateLink` | 记录关联关系前，可取消记录 |
| `afterCreateLink` | 记录关联关系后，计算非转换携带字段 |
| `afterConvert` | **单据转换完毕，最后执行**，最终调整目标单据数据 |

## 五、单据反写插件事件

| 事件 | 触发时机 |
|-----|---------|
| `beforeTrack` | 本关联主实体全部关联记录前，取消关联/反写 |
| `beforeCreateArticulationRow` | 单行数据与源单关联记录前，取消本行关联 |
| `beforeExecWriteBackRule` | 分析反写规则，计算反写量前，取消规则执行 |
| `afterCalcWriteValue` | 反写值计算完毕后，修正反写量 |
| `afterCommitAmount` | 反写量反写到源单行后，连锁更新 |
| `beforeExcesscheck` | 源单反写完毕，超额检查前，取消检查 |
| `afterExcessCheck` | 超额检查完毕后，控制是否中止反写 |
