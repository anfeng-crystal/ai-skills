# 需求单

## 基本信息
- **需求编号**: MFG-001
- **所属行业**: 制造
- **业务场景**: 生产工单管理
- **优先级**: P1(高)
- **提出时间**: 2026-04-12
- **需求来源**: 制造业生产管理 + 苍穹**批量数据操作+自定义服务接口+调度任务+缓存**能力验证

## 核心功能目标
开发一个「生产工单」，管理从计划→投料→生产→入库的全过程。重点验证**BatchHelper 批量操作、自定义查询服务、WebAPI 接口提交、调度任务自动关单**。

## 详细业务规则

### 单据头
| 字段标识 | 字段名 | 类型 | 必录 | 说明 |
|---------|--------|------|------|------|
| billno | 工单号 | 文本 | 是 | 自动生成 |
| billstatus | 工单状态 | 下拉 | 是 | A-计划 B-已投料 C-生产中 D-已入库 E-已关闭 |
| mfg_product | 产品 | 基础资料 | 是 | |
| mfg_bom | BOM 版本 | 基础资料 | 是 | 联动产品 |
| mfg_workshop | 车间 | 基础资料 | 是 | |
| mfg_plan_qty | 计划数量 | 整数 | 是 | |
| mfg_actual_qty | 实际入库数 | 整数 | 否 | 可多次入库累加 |
| mfg_defect_qty | 不良品数 | 整数 | 否 | |
| mfg_yield_rate | 良品率(%) | 小数 | 否 | =实际入库/(实际入库+不良品)×100 |
| mfg_plan_start | 计划开始日期 | 日期 | 是 | |
| mfg_plan_end | 计划结束日期 | 日期 | 是 | |
| mfg_actual_start | 实际开始日期 | 日期 | 否 | |
| mfg_actual_end | 实际结束日期 | 日期 | 否 | |

### 子分录：BOM 用料明细
| 字段标识 | 字段名 | 类型 | 必录 |
|---------|--------|------|------|
| mfg_material | 物料 | 基础资料 | 是 |
| mfg_unit_usage | 单位用量 | 小数 | 是 |
| mfg_plan_usage | 计划用量 | 小数 | 否 | =单位用量×计划数量 |
| mfg_actual_usage | 实际用量 | 小数 | 否 |
| mfg_usage_variance | 用量偏差(%) | 小数 | 否 | =(实际-计划)/计划×100 |

### 业务规则 - 表单交互
1. **产品→BOM联动**：选择产品后过滤BOM版本
2. **BOM展开**：选择BOM后自动展开物料到子分录（批量插入分录行）
3. **计划用量自动计算**：单位用量 × 计划数量
4. **良品率自动计算**：实际入库/(实际入库+不良品)×100
5. **计划日期校验**：结束日期≥开始日期

### 业务规则 - 数据服务
6. **批量投料**：支持选中多个工单批量更新状态为"已投料"（kd-data 批量更新）
7. **工单查询服务**：自定义服务接口，按车间+日期范围查询工单列表（kd-service WebAPI）
8. **调度任务**：每日定时检查超期未完成工单，自动标记为"已关闭"（kd-service 调度）
9. **入库回写**：入库操作时累加 actual_qty 并计算良品率（kd-data 值更新）
