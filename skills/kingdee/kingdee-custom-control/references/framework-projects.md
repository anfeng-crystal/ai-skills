# 框架工程接入

用于用户明确选择或项目已使用 React、Vue3、Vue2 的控件。只读取和处理本次技术栈；KDApi 生命周期、锁定、通信和版本依据仍按 [运行合同](runtime-contract.md)，框架版本不能证明苍穹接口兼容。

## 工程选择与复用

先读现有 `package.json`、锁文件、构建配置、控件入口和测试，确认框架版本、包管理器、挂载方式及运行资源目录。修复已有工程不重新初始化，不为套用示例切换框架、构建器或 UI 库。

新建框架工程优先使用目标环境已确认的模板或项目现有同类工程。用户选用的 CLI 先核对实际版本、帮助和模板来源，再按其支持的命令创建；不默认安装或升级全局 CLI。下载指南中的命令和最低版本只是对应模板的线索，不是所有控件的前置依赖。无外网时先核对本地模板和依赖缓存，不能仅凭“手动配置”承诺框架依赖可用。

项目中的 `AppContext`、`StateManager`、事件总线、`useInvokeAsync`、`getLangMsg` 等可能是脚手架封装。沿定义与调用核对参数、返回值、异步完成和释放方式，存在且符合当前合同才复用；不要为对齐示例创建同名封装，或把封装方法及参数当成 KDApi 原生接口。业务入参仍来自本次事件或数据合同。

## 挂载、更新与释放

外层控件实例持有自己的框架实例与状态，挂载点位于该实例的 `model.dom` 内。平台更新映射到现有组件输入，不在每次更新时重新创建整个应用；页面指令和组件事件仍承接已确认的三条通信链。

| 当前工程 | 接入要点 |
|---|---|
| React，项目版本支持 `createRoot` | 每个挂载点保存自己的 root，初次及后续输入通过 `root.render` 更新；外层 KDApi 销毁时 `root.unmount()`，重建时创建新 root。已有其他版本挂载方式按实际依赖保留。 |
| Vue3 | 保存 `createApp` 返回的 app，挂载一次；平台输入更新到现有响应式状态或组件约定的输入通道，销毁时 `app.unmount()`。不要依赖修改普通对象自动触发刷新。 |
| Vue2 | 保存 Vue 实例，在 `model.dom` 内自有子节点挂载，避免 Vue 替换平台容器；更新既有响应式数据，外层销毁时调用 `$destroy()` 并移除自身 DOM。Vue 的 `destroyed` 不能替代 KDApi 的 `destoryed`。 |

这些框架方法分别依据 [React root API](https://react.dev/reference/react-dom/client/createRoot)、[Vue3 Application API](https://vuejs.org/api/application.html) 和 [Vue2 生命周期 API](https://v2.vuejs.org/v2/api/#vm-destroy)；使用时核对项目实际版本。它们不替代运行合同中的异步资源释放和迟到回调检查。

组件输入和事件处理都使用当前锁定状态；框架示例里的 lock、初始化次数和响应包装不能覆盖目标平台合同。复用的 store、订阅和事件总线应保留控件实例边界，销毁只退订本实例的处理器，不清空其他控件的订阅；不为单个控件新增共享状态服务。

## 构建、预览与验证

优先运行已审查的项目脚本和锁定依赖，先核对其输出目录和静态资源路径。需要接入内置 helper 时复用已有 `build/test.mode: external`、命令数组及 `--run-command`，不增加 framework、preview 或业务配置参数。构建前会清空声明的精确输出目录，该目录须与源目录分离且为项目内至少两层的子目录；常见的 `dist/` 不符合此 helper 限制，不为通过 helper 擅改已有构建布局。

`external` 只承接命令，不代表 helper 支持任意框架源码：当前源码校验仍查找 `sourceDir/index.js` 中的字面量注册和生命周期，build 与 release 都先过源码校验再运行构建。TSX、Vue SFC 或转换后的注册形式可能不符合该合同；沿用项目原生测试和构建，并明确 helper 未覆盖或失败的环节，不能伪造入口、忽略错误或把构建成功写成 release 通过。包格式与完整 release 门禁仍按 [交付合同](delivery-contract.md)。

预览命令取项目实际 scripts；`mock`、`dev:ram`、`dev` 等名称不通用。只在实际路径需要时启动模拟服务，平台预览仍须具有目标平台操作授权。本地宿主和视觉核对按 [验证合同](testing-contract.md)，不复制自动注入业务数据的定时器或凭浏览器打开就宣告通过。

针对本次框架接入验证：同页两个控件只更新各自的数据、锁定状态和事件；销毁其中一个后另一个仍正常，重建无重复订阅；框架组件真正显示更新后的内容。保留已有异步、空态和失败恢复用例。多语言按当前需求复用已确认资源，不因框架选择自动增加语言机制。
