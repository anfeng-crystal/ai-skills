# FIN-001 贷款审批工单

## 基本信息
- **行业**: 金融
- **需求编号**: FIN-001
- **业务场景**: 贷款申请→风控审核→审批→放款，含金额分级审批权限
- **覆盖 Skill 重点**: kd-review（代码审查模式实操）、kd-optimization（性能优化：大数据量分页查询、缓存策略）

## 业务背景
金融机构贷款审批流程严格，按贷款金额分级审批：小额（≤10万）→部门审批，中额（10-100万）→分行审批，大额（>100万）→总行审批。需跟踪每笔贷款的完整审批链路。

## 业务规则
1. 贷款编号自动生成：`LN` + 年月日 + 6位流水号
2. 贷款金额不得为负数，且不超过贷款额度上限
3. 贷款期限：3/6/12/24/36/60 个月（固定选项）
4. 年利率根据期限自动匹配（3月3.5%，6月3.8%，12月4.2%，24月4.5%，36月4.8%，60月5.2%）
5. 每月还款额自动计算（等额本息公式）
6. 审批状态流转：申请中(A) → 风控审核(B) → 审批中(C) → 已放款(D) / 已拒绝(E)
7. 审批分录记录每个审批节点（审批人、意见、时间、结果）
8. 已放款/已拒绝状态不可修改

## 单据结构
| 字段 | 标识 | 类型 | 说明 |
|------|------|------|------|
| 贷款编号 | loan_no | 文本 | 自动生成 |
| 申请人 | applicant | 文本 | 必填 |
| 身份证号 | id_card | 文本 | 必填，18位 |
| 贷款金额 | loan_amount | 金额 | 必填，>0 |
| 贷款期限(月) | loan_term | 整数 | 下拉 3/6/12/24/36/60 |
| 年利率(%) | annual_rate | 小数 | 自动匹配 |
| 每月还款 | monthly_payment | 金额 | 自动计算 |
| 贷款总利息 | total_interest | 金额 | 自动计算 |
| 审批状态 | approval_status | 下拉 | A/B/C/D/E |
| 审批级别 | approval_level | 文本 | 自动判定 |
| 申请日期 | apply_date | 日期 | 默认当天 |

## 技术要求
- 表单插件：期限变更→利率自动匹配→每月还款&总利息实时计算（等额本息公式）
- 操作插件：身份证号校验（18位+校验码）、金额上限校验、状态流转校验
- 列表插件：按审批状态过滤、大金额高亮
- Helper：等额本息计算、审批级别判定
