# 插件挂载规则

`Plugin`、`Plugins` 与 `JsPlugins` 是当前同环境模板知识中观察到的插件相关节点；具体属性、模型、父容器和值形态仍以命中的实际 profile 为准。

- 任何插件挂载变更先取得 `kingdee-metadata-analyzer` 的证据：业务对象、实体或页面入口、操作（如适用）、现有或待挂载插件身份及证据来源。
- 已有挂载只允许对已唯一定位节点做精确属性修改；插件类、操作键、页面或节点类型任一项不确定时停止。
- 新插件节点、插件集合条目、JS 插件或操作插件按实际同类结构在本地构造，遵循 [本地新增](local-addition.md) 的身份与引用规则；不沿用标准节点独立身份，也不从源码类名推导元数据结构。复杂集合须检查所有子节点和绑定，超出脚本范围时单独记录检查与待验证项。
- 删除挂载前确认页面、操作、实体和包外消费者没有剩余引用；业务插件实现、SDK 签名和运行行为分别交 `kingdee-cosmic`、`kingdee-sdk-helper` 与目标环境验证。
