## 需求单

### 基本信息
- **需求编号**: EDU-003
- **所属行业**: 教育
- **业务场景**: 在线考试管理系统（考试安排→考卷分配→监考→成绩录入→成绩审核）
- **优先级**: P1(高)
- **迭代轮次**: R4
- **补强目标**: kd-frontend（F7查找/Tab切换/弹窗回调/beforeClosed/FlexPanel/树形控件）

### 核心功能目标
为高校期末考试管理提供完整线上流程：教务处安排考试科目与考场，教师创建考卷并绑定考场，监考人员确认考场信息，考试结束后批量录入成绩，系绩系由教研组长审核后发布。

### 业务角色
| 角色 | 职责 |
|------|------|
| 教务管理员 | 安排考试计划、分配考场 |
| 教师 | 创建考卷、绑定科目考场、录入成绩 |
| 监考员 | 确认考场名单、提交考场记录 |
| 教研组长 | 审批成绩、发布最终结果 |

### 前置条件与依赖
- 基础数据已维护：院系、专业、班级、学生信息
- 教室/考场资源已维护（基础资料）
- 学期课程已排课（依赖 EDU-001 学籍数据）

### 详细业务规则

#### 1. 考试计划单（主表+分录）
- **单据编号**: 自动生成 `EXAM-{学年}{学期}-{序号}`
- **状态机**: 新增(A) → 已排考(B) → 考试中(C) → 已结束(D) → 已归档(E)
- **状态流转规则**: A→B（必须分配所有考场）; B→C（开考时间到达自动或手动触发）; C→D（交卷截止后触发）; D→E（成绩审核通过后归档）

#### 2. 考场分配规则
- 每教室最大容纳人数不可超标（字段: `capacity`, 类型: Integer, 必录）
- 同一教室同一时段不可安排两场考试（唯一校验: 教室+日期+时段）
- 考生分配: 按学号顺序自动分配座位（可手动调整）

#### 3. 成绩录入规则
- 成绩区间: 0-100（百分制），保留 1 位小数
- 总评公式: `总评 = 平时成绩 × 0.3 + 期末成绩 × 0.7`（比例可配置）
- 录入后状态: 待审核(P) → 已审核(Q) → 已发布(R)
- 审核人: 教研组长，审批驳回需填写原因

#### 4. 前端交互重点需求
- **F7 查找**: 选择学生时用 F7 弹出框从学生基础资料中选择，支持多选
- **Tab 页签**: 主界面分 3 个 Tab: "考试计划"/"考场安排"/"成绩管理"
- **弹窗回调**: 批量导入成绩时弹出文件选择，导入后回调刷新列表
- **关闭前校验**: 成绩录入中关闭表单前提示"未保存的成绩将丢失"
- **FlexPanel**: 根据考试状态动态显示/隐藏"成绩录入"面板
- **树形控件**: 左侧按"院系→专业→班级"树形展示，点击筛选右侧考生

### 标准单据定义
- **单据类型**: 单据(Bill) + 列表
- **关键字段**:
  | 字段标识 | 字段名 | 类型 | 必录 | 默认值 |
  |---------|--------|------|------|--------|
  | exam_plan_no | 考试计划号 | Text(30) | ✓ | 自动生成 |
  | exam_name | 考试名称 | Text(100) | ✓ | — |
  | semester | 学期 | BaseData(F7) | ✓ | 当前学期 |
  | exam_date | 考试日期 | Date | ✓ | — |
  | time_slot | 考试时段 | Combo | ✓ | — |
  | room | 考试教室 | BaseData(F7) | ✓ | — |
  | capacity | 教室容量 | Integer | ✓ | — |
  | status | 状态 | Combo | ✓ | A(新增) |
  | regular_score | 平时成绩 | Decimal(5,1) | — | 0.0 |
  | final_score | 期末成绩 | Decimal(5,1) | — | 0.0 |
  | total_score | 总评成绩 | Decimal(5,1) | — | 自动计算 |
  | score_status | 成绩状态 | Combo | — | P(待审核) |
