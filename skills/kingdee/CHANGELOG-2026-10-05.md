# 金蝶 Skill 与云端知识更新（2026-10-05）

本次修正已核实的检查器、工具和模板缺陷，并将详细的版本说明、官方来源、案例结论与验证边界归入 [金蝶云苍穹知识库](https://chatgpt.com/space/page_7daf34b3f87c8191ae8297513bd09cc8)。知识库当前有 46 个专题；本地 Skill 保留执行流程、关键约束、代码、验证入口及按需读取的短链接。读取云端须有相应 Page 权限；链接可长期引用，但不会自动加载到所有新会话。

## 主要变化

- Java 插件与模板：修正调度停止传播、操作字段准备、BOTP 单源/多目标、MQ 示例、单据数量类型和动态表单请求间状态等已确认问题；保留事件入口、工具 API 和业务能力。
- 静态检查与脚本：改进 KSQL、ISCB、页面脚本的词法边界；SDK 简单类名存在歧义时返回候选；按实际父实现检查生命周期 super 调用；工具替换建议保留 null、精度、舍入和异常语义。
- 工具安全与恢复：完善 Header/响应脱敏、会话有效性判断、日志分类、CLI 失败审计、资源更新预检和回滚、元数据引用与继承证据、UI 页面身份校验。
- 知识与版本：将工作流、事务、锁、ORM、服务、缓存、线程、数据模型、OpenAPI、视图、查询、打印、导入等专题放到云端，分别标注社区说明、本机构件证据和未验证边界。修正 SCENE 历史候选的构件归属记录，保留更正链。

## 验证与限制

各路线保留原始失败、针对性回归、独立复核、能力对照和恢复证据。验证包含本地单元/CLI 测试、纯计算或 mock 探针、真实依赖编译以及静态 SDK 声明/字节码核对；这些证据不等于目标平台业务验收，也不跨版本自动成立。JDK 21 的 `--release 8` 编译与实际 JDK 8 运行分别记录。未执行业务平台写入、生产部署、数据库变更或真实服务重启。

提交前复核全部活动记录、当前源码与云端回读，按路径隔离本次改动。其他任务的全局规则、浏览器、安装器及通用工具改动不属于本次交付。
