# Design Parameters（设计参数）

按实际取舍记录设计值。每项用原语与贴合当前画面的中文含义，用用户在稿面能找到的位置指明影响范围。优先复用项目已有的 Design Tokens（设计变量）和组件标识。

| 参数组 | 记录与试调的对象 |
| --- | --- |
| Layout & Responsive（布局和响应式） | 内容宽度、分栏比例、页边距、区块间距、组件位置或顺序。记录在哪个宽度换布局，以及窄屏下图文、导航和主操作怎样重排。 |
| Color & Surface（颜色和表面材质） | 画布、容器、文字、主次操作、边框和状态的颜色。使用半透明表面时，登记染色、透明度、背景模糊、边缘与阴影，注明叠在什么背景上。 |
| Typography（排版） | 字体、字号层级、字重、行高、行宽与关键换行，记录桌面与窄屏的实际差异。 |
| Media（图像与媒体） | 素材、显示比例、裁切焦点、覆盖关系和目标尺寸。试调时用同版实际素材观察变化。 |
| Components & Content（组件和内容） | 关键组件的文字、变体、尺寸、内边距、间距、对齐、圆角，以及适用的选中、聚焦、禁用等状态。 |
| Interaction & Motion（交互与动效） | 主要动作的触发方式、起止状态和反馈。有动效时记录作用对象、时长、缓动、方向或位移，以及启用减少动态效果时的表现。 |

## 标注与编辑

- 每项记录稳定参数键、显示名称、对应组件或全局作用域、状态及适用尺寸、默认值与单位、可选值或有效范围，以及变化在画面上的表现。共用值、按尺寸或状态的覆盖值、由其他参数计算的值应可追溯。文字等采用内容约束，比例、枚举等使用相应值域。
- 交付试调时，依照用户需要作出的决定，从相关参数组开放有实质影响的值。整页试调应覆盖配色、排版、布局及关键组件的位置或顺序、内容与样式。材质、媒体或动效是本方案的取舍时，也提供相应控制。按关联对象组织控件，编辑和恢复基准值时都更新实际稿面。
- 原型、规范和参数表共用参数键。切换尺寸保留同一方案和编辑值，按约定应用该尺寸的覆盖规则。确认时同步三份材料中的选定值，记录可编辑源的版本。有可导出的源参数时，随稿交接并沿用项目使用的格式。复核试调对标明对象、文字可读性、组件边界和主要操作的影响。
