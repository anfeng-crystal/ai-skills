# Office Polish

为 Word、Excel、PPT 建立清晰的阅读顺序、稳定的版式和能区分内容分组的留白。语言、受众、用途和风格按用户要求及现有材料确定；没有视觉要求时采用专业、克制的默认样式。

## 触发与路由

- 新建文件需要选择模板与版式，或已有文件需要美化、统一风格、改善可读性时使用；不限语言、行业或场景。
- 不主动接管仅取数、仅修改公式、仅转换格式等任务；用户未要求重排时，维持原有结构。公文、法定表单及企业强制版式遵循其既定标准。

## 输入与契约

- 先检查已有文件、模板和当前要求，确定语言、受众、输出格式、用途（屏幕阅读/打印/放映）与视觉约束。缺少非关键偏好时使用本文默认值，不逐项询问；参考文件中的中文字体与企业配色是可替换的默认值，不限制任务范围。
- 新文件可梳理信息层级；纯美化保留文字含义、事实、数据、公式、工作表名称与依赖关系，以及幻灯片页数、顺序、备注和必需对象，不擅自删改记录、重写结论或恢复已删除内容。保留原件，在副本上处理。
- 新建或获准调整计算的 Excel，统计结果由公式或可刷新汇总驱动；数据修改及追加记录后须能更新。保留工作表的正常行列、网格线和编辑能力，不因版式或打印范围限制可编辑区域。

## 与基础技能的关系

本技能负责视觉决策与验收标准；基础技能负责读取、生成、编辑、计算、导出与渲染。二者需要配合，不能只套样式后保存文件。

| 输出 | 应加载的基础能力 | 同时读取 |
| --- | --- | --- |
| Word / `.docx` | 宿主可用的 `docx`、`documents` 或同等文档技能 | [Word 规范](references/word-style-guide.md) |
| Excel / `.xlsx` | 宿主可用的 `xlsx`、`spreadsheets` 或同等表格技能 | [Excel 规范](references/excel-style-guide.md) |
| PowerPoint / `.pptx` | 宿主可用的 `pptx`、`presentations` 或同等演示文稿技能 | [PPT 规范](references/ppt-style-guide.md) |
| 选择或新增模板 | 对应格式的基础能力 | [模板约定](templates/README.md) |

从当前可用技能中选择对应的基础技能，读取并遵循其实际指令，使用它要求的工具完成文件操作。遵守其运行时、文件保真、重算及渲染要求。

相对于本 `SKILL.md` 所在目录解析内置参考文件和模板路径；输入与输出文件的位置按用户要求及当前工作环境确定。

视觉冲突按“用户明确要求 → 指定模板/品牌/适用文种标准 → 现有材料的有效风格 → 本技能默认值”处理。默认值不覆盖基础技能的强制操作或验证要求；不能兼容时说明具体冲突，不默默混合两套版式。

若没有基础技能，使用宿主已提供的等价文件工具，先确认其读写和预览能力。若工具不足，完成可做的部分并指出缺口；不能把 Markdown、CSV、PDF 或静态截图冒充可编辑的 Office 文件。

## 工作流

### 1. 先套模板或确定规范

优先检查用户指定模板；其次选择适合当前用途、已经视觉验收的本地模板；没有适用模板时才按对应规范建立样式。模板必须真实存在且能读取，不能把建议目录中的文件名当成已有模板。

在任务内简要记录：用途、模板来源、字体及实际可用的替代字体、主色、页面方向、标题层级，以及需要保留的原有规则。只加载当前输出格式的参考文件。不要为短文档添加独立封面，不为简单台账强行创建仪表盘。

### 2. 再生成或编辑

通过基础技能落实样式。Word 使用段落/字符/表格样式管理层级；Excel 用一致的表头、数据列类型、数字格式及区域样式管理布局；PPT 继承主题、母版和版式，用对齐基准与字号层级组织每页。优先修复信息密度、对齐与间距，再处理颜色和装饰。

文字、数值与单位完整保留。表格、图表和汇总服务于已有业务问题，不编造指标、阈值、趋势或审批状态。原文件含复杂域、宏、外链、透视表、保护、动画、媒体或特殊对象时，选用能保留这些能力的编辑路径；无法保证保真时不要覆盖原件。

### 3. 再渲染并实际查看

先做内容与结构核对，再查看渲染结果；文件保存成功、文本提取成功或 XML 检查通过都不代表视觉合格。

- Word：用基础技能的渲染器或已配置的 Office/PDF 渲染能力生成逐页预览，查看每一页，并以 100% 比例检查正文、表格、页码和字体。
- Excel：重算后检查每张表的表头、典型数据区、最长文本、异常/空值、底部合计和全部图表；查看所有拟打印区域的分页预览。新建或修改了统计计算时，在验证副本上改一个输入值、追加一条记录，检查统计与相关图表更新，并确认数据区外可编辑。大表允许按区域检查屏幕布局，打印页仍须检查，并记录实际覆盖范围。
- PPT：先看全稿缩略图检查风格与节奏，再查看每一页完整预览，检查文字溢出、遮挡、图表与对齐；按使用场景检查放映或打印效果。可编辑性与动画/媒体另行检查，不能从截图推断。
- 更换字体、渲染引擎或执行环境后，重新渲染并检查最终文件，不沿用原环境的验收结论。

### 4. 修复并复验

按内容遗漏/计算问题 → 裁切重叠/缺字 → 分页与可读性 → 风格一致性的顺序修复。修改后重新生成并重算/渲染；局部样式检查受影响区域，字体、页边距、列宽等全局变化重新检查所有受影响页面或工作表。

## 门禁与失败

- 无新增内容或计算缺陷、无意外截断或遮挡、阅读层级稳定，且符合本次屏幕/打印/放映用途时才记为通过。原有数据异常未修复时明确列出，不能记为计算通过。
- 缺少渲染器时，检查现有工具是否可提供可靠预览。确实不可用则标记“已生成，未完成视觉验收”，列出缺项；静态检查或模型想象的排版不能替代预览。
- 工具持续失败且没有新的修复依据时保留当前副本，说明已完成项与未验收项，不无限重试，也不声称通过。

## 输出

- 默认交付用户要求的可编辑文件，简述采用的模板/风格、检查范围与残余问题；检查图片、临时 PDF 和脚本留在工作目录，除非用户要求一并交付。
