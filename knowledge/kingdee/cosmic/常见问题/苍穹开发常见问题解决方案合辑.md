## 一、TOP 搜索问题（5月）

### 1. 获取当前单据体当前行

**问题描述：** 如何获取单据当前流程节点？

**解决方案：**
```java
// 获取单据体当前行
int rowIndex = this.getModel().getEntryCurrentRowIndex("entryEntityKey");
DynamicObject currentRow = this.getModel().getEntryRow("entryEntityKey", rowIndex);
```

### 2. 获取基础资料列表的数据

**问题描述：** 如何获取基础资料列表的数据？

**解决方案：** 使用 `BusinessDataServiceHelper.load()` 或 `QueryServiceHelper.query()`

### 3. 移动端树形基础资料

**问题描述：** 如何在移动端展示树形基础资料列表界面？

**解决方案：** 参考移动端树形基础资料配置文档

### 4. 列表插件获取单据标识

**问题描述：** 如何通过列表插件获取单据标识？

**解决方案：**
```java
@Override
public void setFilter(SetFilterEvent e) {
    String formId = this.getView().getFormId();
    // formId 即为单据标识
}
```

### 5. 页面未初始化或者已经过期

**错误信息：** "页面未初始化或者已经过期，请重新打开---从缓存读取模型数据失败"

**问题描述：** 在移动端或 PC 端的二开场景中出现的报错。

**解决方案：**
- 清除浏览器缓存
- 重启开发环境
- 检查插件注册是否正确

### 6. 数据库配置或表结构不正确

**错误信息：** "数据库配置或表结构不正确，请联系系统管理员!!"

**问题描述：** 访问 MC 或苍穹登录页，输入用户名密码后提示。

**解决方案：**
- 检查数据库连接配置
- 确认数据中心是否正确配置
- 检查表结构是否完整

### 7. 数据中心升级未配置数据源报错

**问题描述：** 苍穹补丁升级中出现数据中心未配置数据源报错。

**解决方案：** 在 MC 中配置数据源后重新升级

### 8. 没有分配许可或许可已过期

**错误信息：** "没有开发服务运行时独立版分组许可，请联系管理员"

**解决方案：**
- 在【基础服务云】→【安全管理】→【许可管理】中分配许可
- 检查许可是否过期

### 9. 插件功能发生异常

**错误信息：** "插件功能发生异常，程序员正在紧张修复中"

**问题描述：** 页面注册插件后打开页面弹出提示。

**解决方案：**
- 检查插件代码是否有编译错误
- 检查插件是否正确注册到元数据
- 查看 monitor 日志定位具体错误

### 10. 资源不属于当前开发商

**错误信息：** "资源不属于当前开发商，请通过开发平台应用和资源扩展按钮扩展后再进行编辑"

**问题描述：** 开发平台打开非本开发商标识设计的页面（如采购申请单 pm_purapplybill）。

**解决方案：**
1. 点击【扩展】按钮扩展资源
2. 或切换到有权限的开发商账号

### 11. getDynamicObjectCollection 不存在属性

**错误信息：** "PlainObject 不存在名为 XXX 的属性"

**问题描述：**
1. 用 `QueryServiceHelper` 查询数据后，遍历时使用 `DynamicObject.get("xxxx")` 报错
2. 用 `BusinessServiceHelper.load` 出来的数据 `get("xxxx")` 属性时提示不存在

**原因分析：**
- `QueryServiceHelper` 返回的是 `DynamicObject`，但只包含查询时指定的字段
- 如果查询时没有指定该字段，就会报错

**解决方案：**
```java
// 查询时必须指定需要的字段
DynamicObject[] data = QueryServiceHelper.query(
    "entityFormId",
    "id,name,field1,field2",  // 必须包含要获取的字段
    new QFilter[]{...}
);
```

### 12. monitor 日志查看

**问题描述：** 苍穹报错日志在哪里查看？如何快速定位异常问题的原因？

**解决方案：**
- 路径：`苍穹安装目录/monitor/logs/`
- 或登录 MC → 集群管理 → 对应服务 → 日志

### 13. 不能修改非本组织创建的数据

**错误信息：** "不能修改非本组织创建的数据！"

**问题描述：** 修改基础资料后，点击"保存/提交"按钮时提示。

**解决方案：**
- 检查数据规则配置
- 确认当前用户是否有该组织的修改权限
- 检查单据的创建组织字段

### 14. 数据不存在

**错误信息：** "您要读取的资金来源数据在系统中不存在，可能已经被删除"

**原因分析：** 用实体的主键去查询数据库，返回实体数据时，在对应的实体表中不存在。

**解决方案：**
- 检查传入的主键值是否正确
- 确认数据是否被物理删除
- 添加空值判断

## 二、开发服务云 FAQ

### FAQ 1: 如何获取单据体（分录）单选、多选的选中行的数据？

```java
// 获取选中行索引
int[] selectRows = this.getView().getEntryGrid("entryEntityKey").getSelectRows();

// 遍历选中行
for (int rowIndex : selectRows) {
    DynamicObject rowData = this.getModel().getEntryRow("entryEntityKey", rowIndex);
    // 处理行数据
}
```

### FAQ 2: 苍穹插件里面怎么获取到当前用户的 access_token？

```java
// 通过 RequestContext 获取
String accessToken = RequestContext.get().getAccessToken();
```

### FAQ 3: 插件怎么调用保存？

```java
// 方式1：调用操作服务
SaveServiceHelper.saveOperate("formId", new DynamicObject[]{dynamicObject}, null);

// 方式2：触发界面保存操作
this.getView().invokeOperation("save");
```

### FAQ 4: 如何监听单据体工具栏？

```java
@Override
public void registerListener(EventObject e) {
    super.registerListener(e);
    // 获取单据体控件
    EntryGrid entryGrid = this.getView().getControl("entryEntityKey");
    // 监听工具栏
    entryGrid.addItemClickListener(this);
}

@Override
public void itemClick(ItemClickEvent evt) {
    String itemKey = evt.getItemKey();
    if ("addRow".equals(itemKey)) {
        // 处理新增行
    }
}
```

### FAQ 5: 是否可以实现单据下推后自动审核？

**解决方案：** 在转换插件或操作插件中实现

```java
// 转换插件 afterConvert 中
@Override
public void afterConvert(AfterConvertEventArgs e) {
    DynamicObject targetData = e.getTargetData();
    // 设置自动审核标识或调用审核操作
}
```

### FAQ 6: 操作后刷新字段不生效

**问题描述：** 元数据上面的操作有一个配置"操作后刷新字段"，有的字段会刷新有的字段不刷新。

**原因分析：** 字段刷新受多种因素影响，包括字段绑定、操作配置等。

**解决方案：**
- 检查字段是否正确绑定
- 在 `afterDoOperation` 事件中手动刷新字段

### FAQ 7: 列表界面怎么获取选中单据的子单据体的所有数据？

```java
@Override
public void itemClick(ItemClickEvent evt) {
    // 获取选中行
    List<Object> pkIds = this.getSelectedRows();

    // 加载完整数据（包含单据体）
    DynamicObject[] fullData = BusinessDataServiceHelper.load(
        "formId",
        "id,field1,entryEntity,entryEntity.field2",
        new QFilter[]{new QFilter("id", QCP.in, pkIds)}
    );
}
```

### FAQ 8: 怎么获取树形单据体的选中行？

```java
// 获取树形单据体控件
TreeEntryGrid treeGrid = this.getView().getControl("treeEntryKey");
// 获取选中节点
TreeNode selectedNode = treeGrid.getSelectedNode();
```

### FAQ 9: 转换插件里面怎么新增分录？

```java
@Override
public void afterConvert(AfterConvertEventArgs e) {
    DynamicObject targetData = e.getTargetData();

    // 获取目标单据体
    DynamicObjectCollection entries = targetData.getDynamicObjectCollection("entryEntityKey");

    // 新增分录
    DynamicObject newRow = entries.addNew();
    newRow.set("field1", "value1");
    newRow.set("field2", "value2");
}
```

### FAQ 10: Could not initialize class org.apache.poi

**错误信息：** `java.lang.NoClassDefFoundError: Could not initialize class org.apache.poi.ooxml.POIXMLTypeLoader`

**解决方案：**
- 检查 JDK 版本是否为 64 位
- 检查内存配置是否足够
- 清理缓存重启服务

### FAQ 11: 如何通过插件获取当前登录用户的角色？

```java
// 获取用户角色列表
List<RoleInfo> roles = UserServiceHelper.getUserRoles(RequestContext.get().getUserId());
```

### FAQ 12: 表单插件如何获取子单据体字段值？

```java
// 方式1：直接获取当前界面的单据体
DynamicObjectCollection entries = this.getModel().getEntryEntity("entryEntityKey");
for (DynamicObject entry : entries) {
    String value = entry.getString("fieldKey");
}

// 方式2：从 DynamicObject 对象中获取
DynamicObject data = ...;
DynamicObjectCollection entries = data.getDynamicObjectCollection("entryEntityKey");
```

### FAQ 13: 服务插件执行操作后如何显示提示？

```java
// 在服务插件中设置操作结果
OperateResult result = new OperateResult();
result.Message = "操作成功！";
result.Number = billNo;
this.OperationResult.OperateResult.Add(result);
```

### FAQ 14: 移动端如何用代码锁定基础资料不可编辑？

```java
// 设置字段锁定
this.getView().setEnable(false, "fieldKey");
// 设置字段只读
this.getView().setReadOnly(true, "fieldKey");
```

### FAQ 15: PC端附件面板上传的附件如何在移动端显示？

**解决方案：** 检查附件面板的移动端可见性配置，确保移动端字段映射正确。

### FAQ 16: 表单中的基础资料字段在预览时报元数据不存在

**解决方案：**
- 检查基础资料字段引用的实体是否存在
- 确认实体已发布
- 清理缓存重新登录

## 三、系统服务云 FAQ

### FAQ 1: convert.exe 闪退，激活码从哪里获取？

**解决方案：** 联系金蝶销售或技术支持获取正式激活码。

### FAQ 2: 单据中上传附件后无法预览

**解决方案：**
- 检查附件预览服务是否启动
- 确认附件存储配置正确
- 检查文件格式是否支持预览

### FAQ 3: 自定义基础资料新增提示不能修改非本组织创建的数据

**解决方案：**
- 检查基础资料的创建组织字段
- 确认当前用户主业务组织
- 配置数据规则允许跨组织操作
