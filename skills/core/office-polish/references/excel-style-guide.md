# Excel 排版规范

仅在处理工作簿时读取。语言与风格按用户要求及原表确定；先识别输入、公式、来源、状态及打印用途，已有业务配色和格式含义优先保留。

## 结构、字体与配色

- 简单台账保持一张表即可；复杂汇报可按汇总、明细、来源组织，不为美化额外制造封面、空白分隔页或重复数据。
- 字体使用实际可用的微软雅黑，缺失时用思源黑体/Noto Sans CJK SC，必要时统一换为目标环境已安装的中文字体。正文 10–11 pt，表头 10–11 pt 加粗，标题 16–18 pt，备注 9–10 pt。
- 主色深蓝 `#24476A`，浅填充 `#EAF0F5`，正文 `#222222`，次要文字 `#5B6573`，细边线 `#D8DEE5`。普通明细默认白底；条带色只在帮助追踪长行时使用。
- 默认显示屏幕网格线及行号/列标，保留数据区以外的正常行列和编辑空间；用户明确要求无网格展示页时才调整对应工作表。打印默认不显示网格线。边界用表头底线、分组线和合计顶线表达，避免满屏粗边框。
- 样式仅作用于实际内容区及确定需要的输入区，不给整张工作表铺白底或设置满表格式。不隐藏数据区外的全部行列、不把滚动范围锁在现有数据区，也不为美化新增工作表保护。现有文件已隐藏或受保护时先核对用途，纯美化不擅自解除业务控制。
- 一个工作表采用一致的表头风格：浅底深字为默认，品牌需要时深底白字。状态色必须有文字说明；没有已有约定时才建立输入/公式等颜色规则，不覆盖财务模型既定语义色。

## 对齐、数字与日期

| 字段 | 对齐与显示 | 注意事项 |
| --- | --- | --- |
| 项目、部门、说明 | 左对齐，较长文本自动换行 | 不把长说明统一居中 |
| 数量 | 右对齐，`#,##0` 或按业务精度 | 显示精度不改变底层值 |
| 金额 | 右对齐，`#,##0.00` | 在表头注明元/万元及币种；不只改标签而不换算 |
| 百分比 | 右对齐，`0.0%` | 先确认底层值是 0.25 还是 25，不盲目套百分比格式 |
| 日期 | 短日期可居中，`yyyy-mm-dd` | 保留原值与日期类型；字符串转日期须确认解析含义 |
| 日期时间 | 按列统一，`yyyy-mm-dd hh:mm` | 按业务需要显示秒；不推断时区 |
| 状态、序号 | 短值可居中 | 状态保留文字，不能只留颜色 |
| 编码、合同号 | 左对齐、文本格式 | 保留前导零和长编号，避免科学计数法及精度损失 |

同类列保持相同精度和对齐方式，表头跟随列内容。负数默认保留负号；会计格式按既定模板。零、空白和“不适用”含义不同，不为了整洁相互替换；默认零显示为 0。用户要求零显示短横线时只改显示格式，并确保说明不把零与缺失混淆。

不把数值转成带逗号的字符串，不把公式替换成当前结果。禁止用 `IFERROR(...,0)` 等手段掩盖未解决的错误。格式无法修复已有数值精度丢失，须如实指出。

## 列宽、行高、冻结与筛选

以下列宽为 Excel 字符宽度的起点，受字体影响，最终以实际预览为准；一个中文字符通常比一个拉丁字符占宽更多。

| 类型 | 初始列宽 | 行高策略 |
| --- | --- | --- |
| 序号 | 6–8 | 单行约 21–24 pt |
| 日期 | 12–14 | 不折成两行 |
| 数量/金额 | 14–18 | 留出负号、小数、千分位及筛选按钮空间 |
| 编码 | 18–24 | 按实际最长值检查，避免截断 |
| 项目/部门 | 22–32 | 必要时换行 |
| 说明/措施 | 36–52 | 自动换行后自适应行高，手动检查最长记录 |

- 表头通常 28–34 pt；双行表头可更高。正文保持相近行高，但允许长文本自然增高，不以固定行高截字。
- 避免整表“自动列宽”导致说明列占满屏幕。先约束宽度再换行；不要自动缩小字体掩盖问题。工具不能可靠自动行高时，按内容设置后查看预览修正。
- 冻结真实表头及必要标识列，不机械冻结第一行。例如第 4 行为表头、A/B 列需固定时，冻结点为 C5；先确认原布局。
- 对连续明细范围启用筛选或正式表对象；标题、说明、普通合计行不混入筛选数据体。表对象可使用原生总计行。
- 数据体保持矩形，不插空白分隔行，不合并单元格。标题区域确需横跨列时优先跨列居中；不得影响筛选、排序及后续增量记录。
- 修改列宽、筛选或表对象后，核对范围覆盖所有现有记录，没有意外新增隐藏行列、遗漏记录、截掉末行或包含多余空白区域；保留已确认有用途的隐藏设置。

## 合计与条件格式

- 新建或获准调整统计时，以公式驱动合计、差额、占比、进度与条件汇总，不将脚本算出的当前结果写成固定值。原始输入保留为数据，派生结果引用输入；外部事实或一次性快照按其原始属性保留，不能凭空反推公式。纯美化保留现有公式和口径。
- 优先用 Excel 表对象及结构化引用覆盖可追加的明细，并让派生列随新行延续公式。不能使用表对象时，设计有明确扩展机制的命名范围或等价引用；只引用现有末行的固定范围不能声称支持追加更新。预留行需有可识别的边界与扩展说明，不能冒充无限扩展。
- 例如表对象 `明细` 含数值列 `金额` 时，全量合计可用 `SUM(明细[金额])`；分组汇总按实际字段使用 `SUMIFS`、`COUNTIFS` 等函数。公式语法与支持范围以所用基础工具和目标 Excel 环境为准，中文列名、空格及特殊符号须正确引用。
- 已有透视表等可刷新汇总可以保留；新建统计优先选择可自动重算的公式。只有分析需要且刷新路径明确时才采用透视表/查询，并说明新增数据是否自动纳入及实际刷新方式，不承诺不支持的实时更新。
- 合计行用加粗、顶线和可选浅底色标识。求和范围不包含自身或重复小计。金额、数量可求和；比例/单价按业务口径加权计算，不能直接相加或默认平均。
- 筛选后的“可见合计”与全量总计明确区分。若需可见合计，按要求使用 `SUBTOTAL` 等对应函数；例如 `SUBTOTAL(109,范围)` 忽略筛选掉及手动隐藏的行，`9` 会纳入手动隐藏的行。先确认用户口径，纯美化不擅改公式。
- 条件格式只表达业务含义，如已确认的逾期、预算偏差、缺项。没有明确阈值时不凭美学制造红黄绿风险判断。
- 规则覆盖实际数据区，处理空白/错误值，检查相对与绝对引用及规则优先级。不要把表头和合计一起着色。
- 警示浅红 `#FBE9E7` 配深色文字、注意浅黄 `#FFF4D6`、完成浅绿 `#E8F2EA`；同时保留状态标签。可用进度数据条，但负数、超过 100% 或缺失值必须可识别，不能隐藏异常。

统计设计还须确认分母为零、缺失输入、筛选及隐藏行的业务含义；不能统一用零填补。新建工作簿使用自动计算模式，并通过可用计算引擎生成正确结果缓存；设置“打开时重算”不能代替验证公式正确。修改已有工作簿时核对原计算模式及依赖，不因格式调整改变计算行为。

## 图表

- 只有存在可解释的比较、趋势或结构关系时才加图。默认用条形图比较类别、折线图展示连续时间、柱形图比较少量期间；避免 3D、过多饼图切片、无必要双轴和渐变。
- 图表标题说明业务问题；数据足以支持时可写真实结论，例如“本月实际支出低于预算 8%”，否则写中性标题，不编造趋势。
- 标明期间、单位与口径。条形/柱形图通常从零起轴；折线如缩小范围，刻度须清楚且不夸大波动。百分比与金额不得混用单位。
- 仅关键系列用主色，其余用灰阶或同色浅阶；去除外边框、多余网格线与背景填充，保留必要刻度和标识。只标关键数值，检查文字不重叠。
- 图表引用真实数据区域，检查空值与零值呈现、隐藏/筛选数据口径、追加记录后的引用范围。不能用一张静态图片替代用户需要的可编辑图表。

## 打印区域与分页

- 打印区域精确覆盖需要交付的标题、表头、数据、合计和图表，不包含整列整行或历史残留格式。存在多个独立区域时明确顺序。
- 打印区域只控制打印输出，不限制可编辑范围。不要通过隐藏外部行列、铺满白色填充或保护工作表来模拟一张纸；在普通视图仍须能滚动到空白区域、输入数据和插入行列。
- 默认 A4；窄表纵向、宽表横向。边距可从左右 1.0–1.3 cm、上下 1.3–1.5 cm 起调，兼顾打印机可打印边界。页脚按需放页码、报告期间，不编造出具日期。
- 连续明细重复打印表头行；需要横向跨页时可重复标识列。不要把大型封面标题当作每页重复行。
- 优先设为一页宽、高度自动，绝不默认强塞一页高；若缩放导致正文难读（例如低于约 9 pt），调整方向、列宽或按业务分区分页。不能只为一页宽牺牲可读性。
- 分组或合计不宜孤立在新页；必要时设置手动分页。检查所有打印页是否有空白页、最后一列单独成页、合计独页、图表被切开、页脚遮挡。
- 屏幕视图与打印视图分别检查；屏幕冻结不等于打印重复表头，屏幕布局良好不等于打印合格。

## 验收顺序

1. 对照输入核对工作表、记录数、关键字段、公式、单位、空值、合并区域及既有隐藏/保护设置；纯美化应保持内容与计算含义不变。
2. 使用基础技能支持的计算引擎重算并核对关键合计、比例与图表数据。排查 `#REF!`、`#DIV/0!` 等计算错误；不要把预先存在的业务错误标成美化已修复。没有计算引擎时说明缓存值及公式结果未验证。
3. 新建或修改统计逻辑后，在验证副本上修改一个代表性输入、追加一条明细，重算并核对合计/比例、派生列、筛选及图表数据是否正确扩展。采用可刷新汇总时执行其真实刷新路径；检查空值和零分母。验证副本与交付文件分离，不能把测试记录留在交付文件中。
4. 查看每张表的表头、首尾记录、最长文本、最大/负数金额、异常/空值和合计；检查所有图表。向右、向下查看数据区之外的空白区域，核对行列可见、网格线、滚动范围、填充与保护设置；可使用真实 Excel 交互时，在验证副本的空白单元格输入并插入一行确认可用。只有文件属性检查时说明交互未实测。大表按有代表性的区域查看并记录覆盖范围，不能把抽样说成逐单元格验收。
5. 查看全部拟打印页。检查 `####`、科学计数法、日期截断、行高不足、图表重叠及缩放可读性。核对筛选范围和冻结位置的设置；不能从静态图片推断其交互已验证。
6. 修复后重新计算/渲染受影响区域；全局样式或列宽、打印设置变化时检查所有受影响页面。

通过条件：数据与公式正确或原有异常已明确、统计按约定随输入与新记录更新、数据区外保持正常可编辑、无遮挡截字、数字易比较、配色有业务含义、屏幕与打印可读。说明实际使用的预览方式与未覆盖的计算、交互或目标客户端，不把设置检查当作 Excel 内真实操作测试。
