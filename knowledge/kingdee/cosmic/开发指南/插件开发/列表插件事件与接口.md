# 列表插件事件与接口详解

> 来源: https://blog.csdn.net/tanrt/article/details/128915484
> 标签: 列表插件, AbstractListPlugin, 事件, 接口

---

## 摘要

本文详细介绍金蝶云苍穹列表插件的基类选择、事件列表及接口参数，涵盖 BillList、FilterContainer、CommonFilterColumn 等核心组件的事件触发时机和用法。

## 适用版本

- 金蝶云苍穹 V5.0+
- 金蝶云星空（部分兼容）

## 核心概念

### 列表类型与基类对应关系

| 列表类型 | 插件基类 |
|---------|---------|
| PC 普通列表 | `kd.bos.list.plugin.AbstractListPlugin` |
| PC 分组列表 | `kd.bos.list.plugin.StandardTreeListPlugin` |
| PC 树型列表 | `kd.bos.list.plugin.AbstractTreeListPlugin` |
| 移动列表 | `kd.bos.list.plugin.AbstractMobListPlugin` |

## 事件列表

### 1. BillList 事件

| 事件名称 | 监听方法 | 触发时机 |
|---------|---------|---------|
| `billListHyperLinkClick` | `addHyperClickListener` | 超链接点击 |
| `beforeCreateListColumns` | `addCreateListColumnsListener` | 列创建前 |
| `beforeCreateListDataProvider` | `addCreateListDataProviderListener` | 自定义取数（**注意**：不要修改基础资料引用属性，会打乱缓存） |
| `setFilter` | `addSetFilterListener` | 设置过滤条件 |
| `beforePackageData` | `addBeforePackageDataListener` | 包装数据前（**注意**：不要修改基础资料引用属性） |
| `packageData` | `addPackageDataListener` | 包装数据，单元格填值 |
| `chat` | `addChatListener` | 打开云之家 |

### 2. FilterContainer 事件

| 事件名称 | 监听方法 | 触发时机 |
|---------|---------|---------|
| `filterContainerInit` | `addFilterContainerInitListener` | 过滤字段元数据初始化 |
| `filterContainerSearchClick` | `addSearchClickListener` | 查询，过滤条件第一次解析 |
| `filterContainerAfterSearchClick` | `addAfterSearchClickListener` | 最终查询条件解析后，可获取最终过滤条件 |
| `filterContainerBeforeF7Select` | `addBeforeF7SelectListener` | 常用过滤和方案过滤的 F7 监听 |

### 3. CommonFilterColumn 事件

| 事件名称 | 监听方法 | 触发时机 |
|---------|---------|---------|
| `filterColumnSetFilter` | `addSetFilterListeners` | 过滤字段上的基础资料字段过滤条件调整 |

## 事件生命周期

### 页面加载时
```
beforeCreateListDataProvider
  → filterColumnSetFilter
  → filterContainerInit
  → beforeCreateListColumns
  → setFilter
  → packageData
```

### 点击查询时
```
filterColumnSetFilter
  → filterContainerInit
  → filterContainerSearchClick
  → filterContainerAfterSearchClick
  → beforeCreateListColumns
  → beforeCreateListDataProvider
  → setFilter
  → packageData
```

| 方法 | 说明 |

### BeforeFilterF7SelectEvent

| 方法 | 说明 |
|-----|------|
| `getRefEntityId()` | 获取绑定的实体编码 |

| `isCancel()` | 是否取消 |
| `setCancel(cancel)` | 设置是否取消 |

| `isMulti()` | 是否多选 |
| `getFieldName()` | 映射的实体字段名 |

| `addCustomQFilter(filter)` | 添加插件设置的过滤条件 |
| `getMergeQFilters()` | 获取最终合并的所有过滤条件 |

## 注意事项

1. **缓存问题**：`beforeCreateListDataProvider` 和 `beforePackageData` 中**不要修改基础资料的引用属性**，会打乱缓存数据
2. **适用场景**：上述两个事件只适合非基础资料字段的修改
3. **过滤条件**：`filterContainerSearchClick` 获取的是初始过滤值，`filterContainerAfterSearchClick` 获取的是最终解析后的过滤条件

## 代码示例

```java
public class ListPluginSample extends AbstractListPlugin {

    @Override
    public void registerListener(EventObject e) {
        super.registerListener(e);
        // 注册超链接点击监听
        this.addHyperClickListener(this);
    }

    @Override
    public void billListHyperLinkClick(HyperLinkClickArgs e) {
        super.billListHyperLinkClick(e);
        // 处理超链接点击
        String fieldName = e.getHyperLinkClickEvent().getFieldName();
        // ...
    }

    @Override
    public void setFilter(SetFilterEvent e) {
        super.setFilter(e);
        // 添加自定义过滤条件
        e.addFilter(new QFilter("fieldName", QCP.equals, "value"));
    }
}
```
