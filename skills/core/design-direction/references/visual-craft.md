# Visual Craft（视觉设计方法）

用于网页与应用界面的设计取舍、视觉评审和出稿。先遵循用户明确的风格、业务任务、目标平台和已有设计系统；以下方法是未定视觉细节的参考，不是固定模板。已选方向的改动仍按原有确认边界处理。纯文字评审只就可观察的画面和证据给出判断，不强制生成原型或实施。

## 1. Composition & Visual Hierarchy（构图与视觉层级）

- 以首屏应完成的任务决定开场。业务表单、搜索、列表、工具和工作台优先呈现实际内容与操作；品牌、故事或作品展示才考虑 Hero（主视觉首屏）。需要主视觉时，用标题、素材、尺度和留白建立统一构图，不默认套用左文右图各占一半、附加统计条的模板。双栏若服务于配置与结果对照、列表与详情等实际任务则保留。
- 用 Grid（网格）、Alignment（对齐）、Proximity（邻近关系）、Contrast（对比）和 Visual Rhythm（视觉节奏）组织整页；优先确定主要阅读与操作路径，再调整疏密与次要区域。后续区块延续同一视觉语言，而非首屏精致、下方重复等宽卡片。窄屏根据任务重排，不只是缩小桌面稿。
- 依据主题、受众及使用环境选择具体的风格与配色理由。新设计用少量语义色彩建立画布、表面、主次文字与强调关系；额外颜色服务真实状态。避免无依据地复用模型惯用配色，也不禁止某种颜色；既有品牌、状态语义和主题变量优先。

## 2. Typography（排版）

- 优先使用一至两个匹配主题的字体家族。正文、区块标题和辅助信息先用少量稳定字级（通常三个左右），通过字重、行高、留白与颜色区分主次。主标题、品牌字标及高密度数据界面可按实际需要增加层级；沿用项目或平台既有规范，不机械限制字体和字号数量。
- 同一用途的段落、列表、表头和标签使用一致的排版规则。长文行宽与语言和字号匹配（英文长文约 65ch 可作参考）；避免依赖过小文字容纳更多信息，首屏若出现低于 13px 的关键阅读或操作文字，优先检查可读性而非强制改动项目字级。金额、数量等需要纵向比较的数字采用等宽数字特性（如 tabular-nums），不为此另引字体；代码等内容按用途选用等宽字体。
- 检查多语言、长字段值、真实标题换行及数字单位。对齐真实内容，而不是只调好占位数据。

## 3. Functional Restraint（功能性克制）

- 直接呈现有意义的标题与面向受众的内容。不默认添加英文眉题（Eyebrow/Kicker）、复述标题的副标题、营销式说明、装饰编号、虚假实时标记或无作用标签。保留真实范围、状态、统计、操作指引、警告、空态与校验反馈；保留用户原文及规定文案。
- 用留白、对齐、分隔线或表面差异组织相关信息；只有需要明确分组、独立交互、内容边界或平台约定时才增加容器。避免为了装饰反复嵌套卡片及堆叠边框。控件密度、行高和输入框尺寸服务信息量及输入方式，不用大面积空白代替层级。
- 区分 Action（执行动作）、Selection（选择）与 Status（状态）。主次动作应清晰；多模式选择优先考虑有真实语义的页签、分段控件、单选、下拉等。状态标签与真实筛选控件按需保留。不要因追求简洁而删除必要的保存、审核、批量操作或改变平台标准控件行为。

## 4. Imagery & Motion（图像与动效）

- 图像只在叙事、识别或信息表达确有收益时使用；密集工作区不为装饰插入大图。安排素材比例、裁切焦点、图文层次和文字可读区域；使用真实、授权或明确标为示意的素材。缺少生成或素材能力时说明限制，选用户素材或适用的自制图形，不虚构图像链接。
- 动效用于解释状态变化、空间关系或操作反馈。高频操作及列表、导航和工具优先即时反馈与原生滚动。未有项目规范时，简短的状态过渡可从约 140–240ms 试起，按对象与交互调整；检查中断、连续触发及减少动态效果时的结果，不引入无目的循环动画或阻塞任务的滚动效果。

## 5. Visual Critique（视觉审查）

按实际交付类型复核相关问题：开场是否服务任务、视觉重心是否清晰、字级和配色是否一致、边框与文案是否有功能、真实数据是否可读、各区块视觉语言是否贯通。整页可运行稿要查看目标桌面首屏、下滚关键区块与目标窄屏，留意长内容、遮挡、裁切、溢出和关键状态；原型使用同版参数与真实稿面验证修改。只有静态稿或文字评审时按可见证据判断；缺少浏览器、素材或入口时说明未验证项，不将推测称为实测。不以审美规范代替业务与交互验收。
