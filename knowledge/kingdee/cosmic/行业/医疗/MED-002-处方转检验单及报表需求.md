# MED-002 电子处方转检验单 + 用药报表

## 基本信息
- **需求编号**: MED-002
- **所属行业**: 医疗
- **业务场景**: 电子处方下推检验申请单 + 科室用药统计报表

## 需求概述
处方开立后需下推生成检验申请单（转换规则），同时提供科室维度的用药统计报表（报表取数）。

## 功能模块

### 模块一：处方→检验单转换规则

#### 转换映射
| 源字段（处方） | 目标字段（检验单） | 规则 |
|---------------|-------------------|------|
| billno | src_billno | 直接携带 |
| patient_name | patient_name | 直接携带 |
| patient_id | patient_id | 直接携带 |
| doctor_name | request_doctor | 直接携带 |
| dept_name | request_dept | 直接携带 |
| 处方分录.drug_name | 检验分录.test_item | 药品名→检验项映射 |
| 处方分录.dosage | 检验分录.remark | 剂量写入备注 |

#### 转换校验
1. 源单状态必须为"已审核"
2. 处方分录中必须含有需检验的药品（drug_category = "special"）
3. 同一处方不可重复下推

#### 转换插件事件
- `afterConvert`: 自动设置检验单状态为"待采样"
- `afterConvert`: 填充检验单创建时间为当前时间
- `afterConvert`: 过滤非检验类分录（只保留 special 类药品）

### 模块二：科室用药统计报表

#### 查询条件
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start_date | Date | 是 | 统计起始日期 |
| end_date | Date | 是 | 统计截止日期 |
| dept_name | Text | 否 | 科室名称（为空查全部） |

#### 报表列
| 列名 | 类型 | 说明 |
|------|------|------|
| dept_name | Text | 科室 |
| drug_name | Text | 药品名称 |
| total_qty | Decimal | 用量合计 |
| total_amount | Decimal(2) | 金额合计 |
| prescription_count | Integer | 处方数 |
| avg_amount | Decimal(2) | 篇均金额 = total_amount / prescription_count |

#### 排序规则
- 默认按 total_amount DESC 排序
- 支持按科室、药品名排序

## 技术要求
- 转换插件继承 `AbstractConvertPlugIn`
- 报表取数插件继承 `AbstractReportListDataPlugin`
- 报表界面插件继承 `AbstractReportFormPlugin`
