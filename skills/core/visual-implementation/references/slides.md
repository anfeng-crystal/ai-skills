# 幻灯片实现与验收

## 将确认稿做成可编辑演示稿

- 先看交付格式、画幅、观看场景及原稿。沿用已有模板的母版、版式、主题字体和配色，把要复用的元素放在相应层级。按章节、每页的结论和证据核对图文阅读顺序。只改单页时沿用其已有版式。[Microsoft 幻灯片母版说明](https://support.microsoft.com/en-us/powerpoint/training/what-is-a-slide-master-in-powerpoint)
- 标题和正文用原生文本框或占位符，流程与关系用可移动的原生形状、连接线和分组。数据用可编辑图表或表格，保留数值、单位、系列与类别的对应关系。照片、插画、纹理按素材放入，可独立替换，保持确认的裁切与叠放关系。[Microsoft 图表数据编辑说明](https://support.microsoft.com/en-us/powerpoint/change-the-data-in-an-existing-chart)
- 对照原稿还原图片焦点、字号节奏和跨页延续的视觉线索。如果已选方案包含分步讲解或转场，用目标格式能播放的效果表达出现顺序；静态导出也在交付范围内时，核对其最终画面能读懂。

## 从编辑到放映检查实际文件

1. 用支持目标格式的编辑入口打开成品。在副本里修改有代表性的文字，并按交付内容实际修改图表数据、移动分组或替换图片。保存重开，检查更新后的图例、换行、裁切及关联对象。验证用现有兼容工具即可，用户指定编辑环境时按其要求执行。
2. 从放映入口按顺序查看本次涉及的页面，在目标画幅与预计观看距离下核对结论、图例、坐标和数据标签。检查字体替换、溢出、边距和遮挡。有动画或媒体时播放其触发与结束状态。投影场景关注远处观众能否辨认小字、细线和浅色，能使用实际设备时在那里复查。[Microsoft 放映和投影说明](https://support.microsoft.com/en-us/powerpoint/present-your-slide-show)
3. 提供可编辑演示稿。演讲备注只写讲解人要说的内容和播放提示。若某项约定的编辑或放映效果无法验证，在交付回复中指明具体项目。
