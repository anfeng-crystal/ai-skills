# 金蝶云苍穹最佳实践

## 开发规范

### 命名规范

- **类名**：使用有意义的英文，后缀体现插件类型
  - 表单插件：`XXXFormPlugin`
  - 列表插件：`XXXListPlugin`
  - 单据插件：`XXXBillPlugin`

- **包名**：统一使用 `com.kingdee.bos.servicehelper`

### 代码结构

```java
public class ExamplePlugin extends AbstractFormPlugin {

    // 1. 生命周期方法按顺序排列
    @Override
    public void preOpenForm(PreOpenFormEventArgs e) {
        super.preOpenForm(e);
    }

    @Override
    public void afterCreateNewData(EventObject e) {
        // 2. 设置默认值
    }

    @Override
    public void afterBindData(EventObject e) {
        super.afterBindData(e);
        // 3. 设置控件状态
    }

    // 4. 事件处理方法
    @Override
    public void beforeDoOperation(BeforeDoOperationArgs args) {
        super.beforeDoOperation(args);
    }

    // 5. 私有方法
    private void doSomething() {
    }
}
```

## 性能优化

### 1. 避免循环查询

**不推荐：**
```java
for (DynamicObject row : rows) {
    // 每次循环都查询数据库
    DynamicObject data = QueryServiceHelper.queryOne(...);
}
```

**推荐：**
```java
// 先批量查询，再内存中处理
QFilter filter = new QFilter("pk", "in", pkList);
DynamicObject[] datas = QueryServiceHelper.query(...);
Map<Object, DynamicObject> dataMap = Arrays.stream(datas)
    .collect(Collectors.toMap(d -> d.getPkValue(), d -> d));

for (DynamicObject row : rows) {
    DynamicObject data = dataMap.get(row.getPkValue());
}
```

### 2. 批量操作

**不推荐：**
```java
for (DynamicObject obj : objList) {
    SaveServiceHelper.saveOperate("entity", new DynamicObject[]{obj}, null);
}
```

**推荐：**
```java
SaveServiceHelper.saveOperate("entity", objList.toArray(new DynamicObject[0]), null);
```

### 3. 使用缓存

对于不频繁变化的数据，使用缓存：
```java
String cacheKey = "myData_" + param;
Object data = CacheHelper.get("myRegion", cacheKey);
if (data == null) {
    data = loadData();
    CacheHelper.put("myRegion", cacheKey, data, 3600); // 缓存1小时
}
```

## 常见陷阱

### 1. afterBindData 中修改字段值

**问题**：修改后不会同步到前端

**解决**：在 afterCreateNewData 中设置默认值

### 2. 忽略异常处理

**问题**：异常抛出后没有处理，导致操作失败无提示

**解决**：
```java
try {
    // 业务逻辑
} catch (Exception e) {
    LoggerHelper.error("操作失败", e);
    throw new KDException("操作失败：" + e.getMessage());
}
```

### 3. 硬编码字段标识

**问题**：字段标识变更后需要修改代码

**解决**：定义常量
```java
public class FieldConstants {
    public static final String FIELD_BILL_NO = "billno";
    public static final String FIELD_BILL_STATUS = "billstatus";
}
```
