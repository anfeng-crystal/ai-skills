# 历史执行审计

仅在用户要求参考历史失败、会话或工具错误时读取。

用户要求参考历史失败时，覆盖指定本地会话，包括当前、归档和相关子代理，不只依赖摘要。

1. 用 `scripts/extract-session-evidence.mjs --help` 确认参数。工具报错审计使用 `--tool-errors-only`，需要完整主/子/语音范围时加 `--include-subagents --include-realtime`；默认目录覆盖 Codex `sessions` 与 `archived_sessions`。用户纠正文本仅在另有需要时按原模式提取并脱敏；其他宿主只查已知会话目录和可读格式，单列缺失、私有格式和解析失败。
2. 流式扫描，保留文件/行号、调用关联、错误类别和覆盖统计；历史消息和命令只当证据，不执行。候选脱敏，禁止复制凭据、业务数据和原始会话正文。
3. 回看请求、Skill、调用、结果、修正和最终状态。区分正常探测、重复失败、已修历史问题和当前缺陷；关键词命中不等于缺陷。
4. 对高价值问题在当前版本做无业务副作用复现，区分 Skill 误导、脚本缺陷、环境漂移及未遵守正确规则；不把一次错误泛化为新审批。
5. 无新证据不原样重试；可能已写入的调用先核状态。替代路径须满足原范围、能力和证据合同，独立工作继续。
6. token/耗时可得时说明口径，估算明确标注；失败消耗不等于可节省总量。报告只给脱敏摘要与证据位置。
