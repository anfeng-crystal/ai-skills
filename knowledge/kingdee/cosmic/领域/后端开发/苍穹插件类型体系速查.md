# 苍穹插件类型体系速查（官方验证）

> 来源：金蝶云苍穹开发平台知识中心 - 插件开发目录
> 验证时间：2026-04-12
> 状态：官方目录结构验证通过

## 一、表单类插件

### 1. 动态表单插件
- 基类：`AbstractFormPlugin`
- 视图模型：`FormShowParameter` → `IFormView`
- 数据模型：`IDataModel`
- 核心事件（按执行顺序）：
  setPluginName → preOpenForm → loadCustomControlMetas → setView → initialize → registerListener
  → getEntityType → createNewData → afterCreateNewData
  → beforeBindData → afterBindData
  → 用户交互事件: beforeItemClick → itemClick → beforeClick → click → beforeF7Select
  → beforeDoOperation → afterDoOperation → confirmCallBack → closedCallBack
  → flexBeforeClosed → onGetControl → customEvent → TimerElapsed
  → beforeClosed → destory → pageRelease
  → beforePropertyChanged → propertyChanged

### 2. 单据界面插件
- 基类：`AbstractBillPlugIn`（继承 AbstractFormPlugin）
- 额外事件：afterLoadData（修改/查看时触发，代替 afterCreateNewData）

### 3. 基础资料界面插件
- 基类：`AbstractBaseDataFormPlugin`（或类似）
- 有独立的事件总览

### 4. 移动端表单/单据/基础资料插件
- 各有独立基类和事件总览
- 移动端单据特有事件：locate

## 二、列表类插件

### 5. 标准单据列表插件
- 基类：`AbstractListPlugin`
- 核心事件：
  filterContainerInit → beforeCreateListColumns → beforeCreateListDataProvider
  → setFilter → filterContainerSearchClick
  → beforeItemClick → itemClick → billListHyperLinkClick → beforeShowBill
  → billClosedCallBack → listRowClick → listRowDoubleClick
  → filterContainerBeforeF7Select → filterColumnSetFilter
  → filterContainerAfterSearchClick → baseDataColumnDependFieldSet → setCellFieldValue

### 6. 左树右表单据列表插件
- 基类：`AbstractTreeListPlugin`（或类似）
- 额外事件：
  setView → createTreeListView → setTreeListView → initializeTree
  → initTreeToolbar → treeToolbarClick → refreshNode → expendTreeNode
  → treeNodeClick → buildTreeListFilter → search → nodeClickFilter

### 7. 树形基础资料列表插件
- 独立基类

### 8. 移动端单据列表插件
- 独立基类和事件总览

## 三、操作类插件

### 9. 单据操作插件
- 基类：`AbstractOperationServicePlugIn`
- 核心事件：
  setContext → initializeOperationResult → onPreparePropertys → onAddValidators
  → beforeExecuteOperationTransaction（事务前）
  → beginOperationTransaction（事务内，DB操作前）
  → endOperationTransaction（事务内，DB操作后）
  → rollbackOperation（回滚时）
  → afterExecuteOperationTransaction（事务提交后）

### 10. 单据转换插件
- 基类：`AbstractConvertPlugIn`（或类似）
- 核心事件：
  initVariable → afterBuildQueryParemeter → beforeBuildRowCondition
  → beforeGetSourceData → afterGetSourceData → beforeBuildGroupMode
  → afterCreateTarget → afterFieldMapping
  → beforeCreateLink → afterCreateLink → afterConvert → afterBuildDrawFilter

### 11. 单据反写插件
- 核心事件：
  getTargetSubMainType → getCurrLinkSetItem → preparePropertys → beforeTrack
  → beforeCreateArticulationRow → beforeExecWriteBackRule → afterCalcWriteValue
  → beforeReadSourceBill → afterReadSourceBill → afterCommitAmount
  → beforeExcessCheck → afterExcessCheck → beforeCloseRow → afterCloseRow
  → beforeSaveSourceBill → afterSaveSourceBill → rollbackSave → finishWriteBack

## 四、报表类插件

### 12. 报表取数插件
- 基类：`AbstractReportListDataPlugin`（或类似）
- 核心事件：query → getColumns

### 13. 报表界面插件
- 基类：`AbstractReportFormPlugin`（或类似）
- 核心事件：
  filterContainerInit → filterContainerBeforeF7Select
  → processRowData → packageData → verifyQuery → beforeQuery → afterQuery

## 五、流程类插件

### 14. 工作流插件
- 核心事件：calcUserIds → hasTrueCondition → formatFlowRecord → notify

### 15. 打印插件
- 核心事件：beforeLoadData → customPrintDataEntities → beforeOuputElement → afterOutputElement

## 六、其他类型插件

### 16. 引入引出插件
- 核心事件：save

### 17. 开放 API 插件
- 基类：`IBillWebApiPlugin`（或类似）
- 核心事件：doCustomService(Map<String, Object> params)

### 18. 后台任务插件
- 核心事件：execute

### 19. 扩展点插件
- 业务场景扩展点插件

## 七、KingScript 脚本插件（JS 方式开发）

支持以下插件类型的 KingScript 版本：
- 表单插件、单据插件、操作插件、列表插件
- 报表表单/查询插件、转换插件、反写插件
- 打印插件、工作流插件、引入引出插件、调度插件

## 八、SDK 服务类

| 类名 | 用途 |
|------|------|
| BusinessDataServiceHelper | 数据加载（loadSingle/load）、新建（newDynamicObject） |
| QueryServiceHelper | 轻量查询（query）、不加载完整数据结构 |
| SaveServiceHelper | 数据保存（saveOperate）、带操作校验 |
| DeleteServiceHelper | 数据删除 |
| OperationServiceHelper | 执行标准操作（提交/审核/反审核等） |
| 数据库操作服务帮助类 | 直接 SQL 操作（慎用） |
| 缓存 | 页面缓存 |
