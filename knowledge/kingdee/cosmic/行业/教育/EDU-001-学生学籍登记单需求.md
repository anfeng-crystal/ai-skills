# 需求单

## 基本信息
- **需求编号**: EDU-001
- **所属行业**: 教育
- **业务场景**: 学生学籍登记与管理
- **优先级**: P1(高)
- **提出时间**: 2026-04-12
- **需求来源**: 高校/K12学校学籍管理核心流程 + 苍穹单据+分录+BOTP能力验证

## 核心功能目标
开发一个「学生学籍登记单」，实现学生基本信息录入、班级分配、学籍状态流转（入学→在读→休学→退学→毕业）的完整管理。本需求重点验证**单据分录（家庭成员）+ 状态机 + 值更新服务 + 列表树形过滤**能力。

## 业务角色
| 角色 | 职责 |
|------|------|
| 招生办 | 录入新生信息、分配班级 |
| 班主任 | 查看/修改本班学生学籍 |
| 教务主任 | 审批休学/退学、数据统计 |

## 前置条件与依赖
- 基础资料：学院(树形)、专业、班级、学期
- 编码规则：学号自动生成（年份+学院代码+序号）
- 环境：苍穹开发环境 + PostgreSQL

### 业务规则
1. **学院-专业-班级三级联动**：选择学院后过滤专业，选择专业后过滤班级
2. **身份证→出生日期**：录入身份证后自动提取并回写出生日期字段
3. **毕业日期自动计算**：入学日期 + 学制(年) = 预计毕业日期
4. **学制变更联动**：修改学制后重新计算预计毕业日期
5. **班级人数上限校验**：保存时校验班级当前在读人数是否超过上限（默认50人）
6. **身份证唯一性校验**：同一身份证号不允许重复录入（排除已退学状态）
7. **状态流转约束**：
   - 待入学 → 在读（入学确认操作）
   - 在读 → 休学/退学/毕业
   - 休学 → 在读（复学操作）
   - 退学/毕业为终态，不可变更

### 列表页功能
- 支持树形过滤（按学院树展开，点击学院节点过滤对应学生）
- 支持按班级、状态、入学年份快速过滤
- 班主任视图：仅显示本班学生
- 支持导出 Excel
