## 一、AbstractReportListDataPlugin（报表查询插件）

> **基类**：`AbstractReportListDataPlugin`
> **导入路径**：`@cosmic/bos-core/kd/bos/entity/report`
> **作用**：控制报表的取数逻辑，包括查询、导出、动态列等

### 1. query - 查询数据

**方法签名**：`query(queryParam: any, selectedObj: any): any`

**触发时机**：报表刷新/查询时，由 `ReportServiceImpl.doPluginQuery` 调用

**业务场景**：销售订单利润分析报表 —— 按客户维度统计订单金额、成本、利润率

```typescript
import { AbstractReportListDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class SalesProfitReportDataPlugin extends AbstractReportListDataPlugin {

  /**
   * 查询报表数据
   * @param queryParam 报表查询参数，包含过滤面板条件
   * @param selectedObj 左树选中的节点（无左树时为 null）
   */
  query(queryParam: any, selectedObj: any): any {
    // 从过滤面板获取查询条件
    let filters: QFilter[] = [];
    let filterItems = queryParam.getFilter().getFilterItems();
    for (let item of filterItems) {
      let propName = item.getPropName();
      if ("kdec_startdate" === propName) {
        filters.push(new QFilter("bizdate", QCP.ge, item.getValue()));
      } else if ("kdec_enddate" === propName) {
        filters.push(new QFilter("bizdate", QCP.le, item.getValue()));
      } else if ("kdec_customer.id" === propName) {
        filters.push(new QFilter("customer", QCP.in, item.getValue()));
      }
    }

    // 使用 queryDataSet 查询销售订单明细
    let dataSet = QueryServiceHelper.queryDataSet(
      this.getClass().getName(),
      "sm_salorder",
      "customer as kdec_customer, "
        + "customer.name as kdec_customer_name, "
        + "salorderentry.amount as kdec_amount, "
        + "salorderentry.costamount as kdec_cost",
      filters.length > 0 ? filters : null,
      null
    );

    // 按客户分组统计
    let resultDataSet = dataSet.copy()
      .groupBy(["kdec_customer", "kdec_customer_name"])
      .sum("kdec_amount", "kdec_total_amount")
      .sum("kdec_cost", "kdec_total_cost")
      .count("kdec_order_count")
      .finish();

    return resultDataSet;
  }
}

let plugin = new SalesProfitReportDataPlugin();
export { plugin };
```

**要点**：
- `queryParam.getFilter().getFilterItems()` 获取过滤面板的过滤条件
- 使用 `QueryServiceHelper.queryDataSet` 返回 DataSet，便于后续分组/join/union
- DataSet 支持链式操作：`groupBy` → `sum`/`count` → `finish`

### 2. export - 导出查询结果数据

**方法签名**：`export(queryParam: any, selectedObj: any): any`

**触发时机**：报表导出 Excel 时，由 `NormalExcelExport.doQueryExportData` 调用

**业务场景**：库存余额报表导出 —— 分页显示但导出时全量导出，且导出数据需补充批次号信息

```typescript
import { AbstractReportListDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class InventoryBalanceExportPlugin extends AbstractReportListDataPlugin {

  /**
   * 报表页面查询（分页显示）
   */
  query(queryParam: any, selectedObj: any): any {
    let filters = this.buildFilters(queryParam);

    let dataSet = QueryServiceHelper.queryDataSet(
      this.getClass().getName(),
      "im_inventory",
      "material.name as kdec_material_name, "
        + "warehouse.name as kdec_warehouse_name, "
        + "baseqty as kdec_qty, "
        + "baseamount as kdec_amount",
      filters.length > 0 ? filters : null,
      "material.name"
    );

    return dataSet;
  }

  /**
   * 导出时全量查询，补充批次号
   * 分页显示但全量导出的场景
   */
  export(queryParam: any, selectedObj: any): any {
    let filters = this.buildFilters(queryParam);

    // 导出时查询更多字段，包含批次号
    let dataSet = QueryServiceHelper.queryDataSet(
      this.getClass().getName(),
      "im_inventory",
      "material.name as kdec_material_name, "
        + "material.number as kdec_material_number, "
        + "warehouse.name as kdec_warehouse_name, "
        + "lotnumber as kdec_lot_number, "
        + "baseqty as kdec_qty, "
        + "baseamount as kdec_amount",
      filters.length > 0 ? filters : null,
      "material.name"
    );

    return dataSet;
  }

  /**
   * 构造过滤条件（复用逻辑）
   */
  private buildFilters(queryParam: any): QFilter[] {
    let filters: QFilter[] = [];
    let filterItems = queryParam.getFilter().getFilterItems();
    for (let item of filterItems) {
      if ("kdec_warehouse.id" === item.getPropName()) {
        filters.push(new QFilter("warehouse", QCP.in, item.getValue()));
      } else if ("kdec_material.id" === item.getPropName()) {
        filters.push(new QFilter("material", QCP.in, item.getValue()));
      }
    }
    return filters;
  }
}

let plugin = new InventoryBalanceExportPlugin();
export { plugin };
```

**要点**：
- `export` 在导出时调用，`query` 在页面显示时调用
- 导出可返回比页面显示更多的字段或不同的数据结构
- 公共过滤逻辑抽取为 private 方法避免重复

### 3. exportWithSheet - 分 Sheet 页导出数据

**方法签名**：`exportWithSheet(queryParam: ReportQueryParam, selectedObj: object): $.java.util.List`

**消费顺序**：目标 7.0 `NormalExcelExport.doQueryExportData` 先调用 `export`；返回非空 DataSet 就直接采用单表结果，仅返回 `null` 才调用 `exportWithSheet`。本例沿用基类 `export` 的 `null` 实现；不能另外覆盖它并返回查询结果后，还期待本方法优先执行。两者都不提供结果时，导出器可回退既有报表数据，不能据此宣称多 Sheet 已执行。

**业务场景**：按仓库导出库存报表，每个仓库一个独立 Sheet，页面与导出沿用物料筛选。保留原示例的 `im_inventory`、物料/仓库、数量/金额映射；它们是示例数据合同，实际实体、计量单位、组织及权限过滤仍须由目标元数据确认。仓库发现也使用相同物料范围，不能先查全库仓库再声称只导出了当前结果。

**脚本与 Java 边界**：Java 消费者会把每个元素强制转换为 `ReportExportDataResult`，再读取其 DataSet/Sheet 名；普通 JS Object 或 Map 的同名属性不满足此合同。目标实际 7.0 JAR 有该类及二参构造器，但随包脚本声明没有导出该类。本例的 `getReportSheetBridge` 是须由项目显式绑定的函数，不是平台 API；其 `create` 必须调用下方真实 Java 实现，不能用空函数或 JS 对象替代。新增绑定必须在目标 KingScript 环境验收，类型检查不证明桥接可运行。

```typescript
import { AbstractReportListDataPlugin, ReportQueryParam } from "@cosmic/bos-core/kd/bos/entity/report";
import { DataSet, Row } from "@cosmic/bos-core/kd/bos/algo";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";
import { ArrayList } from "@cosmic/bos-script/java/util";

/** 项目桥接只创建真实 Java ReportExportDataResult，不能返回同名属性的 JS 对象。 */
interface ReportSheetBridge {
  create(sheetName: string, data: DataSet): object;
}
declare function getReportSheetBridge(): ReportSheetBridge;

/** 保留可辨认的仓库名；Excel Sheet 名最长31字符，不能包含保留字符或大小写重名。 */
function warehouseSheetName(name: string | null, used: Set<string>): string {
  let base = (name == null ? "" : String(name)).replace(/[\u0000-\u001f\\/?*\[\]:]/g, "_").trim();
  base = base.replace(/^'+|'+$/g, "") || "未命名仓库";
  let candidate = base.slice(0, 31).replace(/'+$/g, "");
  let index = 2;
  while (used.has(candidate.toLowerCase())) {
    const suffix = "_" + index++;
    candidate = base.slice(0, 31 - suffix.length).replace(/'+$/g, "") + suffix;
  }
  used.add(candidate.toLowerCase());
  return candidate;
}

/** 按仓库分Sheet，沿用本示例的物料过滤和库存列；真实实体/权限过滤须按项目元数据接入。 */
class WarehouseInventoryExportPlugin extends AbstractReportListDataPlugin {
  query(queryParam: ReportQueryParam, selectedObj: object): DataSet {
    return this.queryInventoryData(queryParam, null);
  }

  /** 基类 export 返回null，7.0消费者才继续调用此方法；不能同时覆盖export并返回DataSet。 */
  exportWithSheet(queryParam: ReportQueryParam, selectedObj: object): $.java.util.List {
    const bridge = getReportSheetBridge();
    if (bridge == null || typeof bridge.create !== "function") throw new Error("缺少真实Sheet结果桥接");
    const results = new ArrayList();
    const owned: DataSet[] = [];
    const used = new Set<string>();
    const warehouseSource = QueryServiceHelper.queryDataSet(
      "WarehouseInventoryExportPlugin_warehouses", "im_inventory",
      "warehouse as kdec_wh_id, warehouse.name as kdec_wh_name",
      this.inventoryFilters(queryParam, null), "warehouse", -1
    );
    let warehouseRows: DataSet | null = null;
    let closingDiscovery = false;
    try {
      warehouseRows = warehouseSource.groupBy(["kdec_wh_id", "kdec_wh_name"]).finish();
      while (warehouseRows.hasNext()) {
        const row = warehouseRows.next() as Row;
        const warehouseId = row.get("kdec_wh_id");
        if (warehouseId == null) throw new Error("库存行缺少仓库，不能回退为全仓库查询");
        const data = this.queryInventoryData(queryParam, warehouseId);
        owned.push(data);
        const result = bridge.create(warehouseSheetName(row.getString("kdec_wh_name"), used), data);
        if (result == null) throw new Error("Sheet桥接未返回结果");
        results.add(result);
      }
      closingDiscovery = true;
      warehouseRows.close();
    } catch (error) {
      // 尚未交给导出消费者的DataSet由本次调用释放，清理失败不能覆盖原错误。
      if (!closingDiscovery) { try { (warehouseRows == null ? warehouseSource : warehouseRows).close(); } catch (_) {} }
      for (const data of owned) { try { data.close(); } catch (_) {} }
      throw error;
    }
    // 成功返回后的每个DataSet独立交由导出消费者读取/释放，不在这里提前close。
    return results;
  }

  /** 每次新建过滤数组，仓库发现与每个Sheet使用相同物料范围；保留主键原始类型。 */
  private inventoryFilters(queryParam: ReportQueryParam, warehouseId: object | null): QFilter[] {
    const filters: QFilter[] = [];
    if (warehouseId != null) filters.push(new QFilter("warehouse", QCP.equals, warehouseId));
    const filter = queryParam.getFilter();
    if (filter == null) throw new Error("缺少报表过滤上下文");
    const items = filter.getFilterItems();
    for (let i = 0; i < items.size(); i++) {
      const item = items.get(i) as $.kd.bos.entity.report.FilterItemInfo;
      if (item.getPropName() === "kdec_material.id" && item.getValue() != null) {
        filters.push(new QFilter("material", QCP.in, item.getValue()));
      }
    }
    return filters;
  }

  /** 为页面或单个Sheet单独取数；不在不同Sheet复用已消费的DataSet。 */
  private queryInventoryData(queryParam: ReportQueryParam, warehouseId: object | null): DataSet {
    return QueryServiceHelper.queryDataSet(
      "WarehouseInventoryExportPlugin_inventory", "im_inventory",
      "material.name as kdec_material_name, warehouse.name as kdec_warehouse_name, "
        + "baseqty as kdec_qty, baseamount as kdec_amount",
      this.inventoryFilters(queryParam, warehouseId), "material.name", -1
    );
  }
}
const plugin = new WarehouseInventoryExportPlugin();
export { plugin, WarehouseInventoryExportPlugin, warehouseSheetName };
```

项目 Java 桥接的最小实现如下；绑定器把实例的 `create` 暴露给上述 `ReportSheetBridge`，方法返回值必须保持原生 Java 对象：

```java
import kd.bos.algo.DataSet;
import kd.bos.entity.report.ReportExportDataResult;

/** 创建导出消费者要求的原生结果对象，不复制或预消费DataSet。 */
public final class ReportSheetBridge {
    public ReportExportDataResult create(String sheetName, DataSet data) {
        if (sheetName == null || sheetName.isEmpty() || data == null) {
            throw new IllegalArgumentException("Sheet name and DataSet are required");
        }
        return new ReportExportDataResult(sheetName, data);
    }
}
```

**要点**：
- `DataSet.next()` 返回 Row，从 Row 读取仓库；仓库主键保持原始类型，不转成 JS `Number`。每个结果有独立 DataSet，成功返回后由导出消费者读取/释放；返回前出错则释放已创建的数据集。仓库列表无记录返回空 List，不伪造空占位 Sheet。
- Java 五参查询存在，但本目标随包 TS 暴露六参查询；这里明确用 `top=-1`，与实际 `ORMImpl` 五参调用的全量上限一致。独立 AlgoKey 区分仓库发现与明细取数。
- Sheet 名按31字符及禁用字符处理，并按不区分大小写去重；仍须验证目标导出格式、合并列、数据量与完整文件输出。
- 官方 [报表根据条件导出多sheet页签](https://vip.kingdee.com/knowledge/556214886322051840) 使用 `List<ReportExportDataResult>` 和独立 DataSet，但正文环境是 V6.0.1；其中“第二项插空绕过”不能直接移植到 7.0。这里不插入 `null` DataSet，按目标消费者验证所有 Sheet。

### 4. getColumns - 改变列信息

**方法签名**：`getColumns(columns: any): any`

**触发时机**：报表查询时，在 `ReportServiceImpl.doPluginQuery` 中调用，用于动态调整报表列

**业务场景**：按月份动态生成报表列 —— 根据查询的日期范围自动生成月度列

```typescript
import { AbstractReportListDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { ArrayList } from "@cosmic/bos-script/java/util";

class MonthlyAmountReportDataPlugin extends AbstractReportListDataPlugin {

  /**
   * 动态修改报表列
   * 根据查询日期范围，生成对应月份的金额列
   */
  getColumns(columns: any): any {
    let queryParam = this.getQueryParam();
    if (queryParam == null) {
      return columns;
    }

    // 从查询参数获取日期范围
    let filterItems = queryParam.getFilter().getFilterItems();
    let startDate: Date = null;
    let endDate: Date = null;
    for (let item of filterItems) {
      if ("kdec_startdate" === item.getPropName()) {
        startDate = item.getValue() as Date;
      } else if ("kdec_enddate" === item.getPropName()) {
        endDate = item.getValue() as Date;
      }
    }

    if (startDate == null || endDate == null) {
      return columns;
    }

    // 生成每个月的列
    let current = new Date(startDate.getFullYear(), startDate.getMonth(), 1);
    let end = new Date(endDate.getFullYear(), endDate.getMonth(), 1);

    while (current <= end) {
      let year = current.getFullYear();
      let month = String(current.getMonth() + 1).padStart(2, "0");
      let colKey = "kdec_amount_" + year + month;
      let colCaption = year + "年" + month + "月";

      // 创建报表列对象
      let col = new Object();
      col["fieldKey"] = colKey;
      col["fieldName"] = colCaption;
      col["fieldType"] = "java.math.BigDecimal";
      col["scale"] = 2;
      columns.add(col);

      // 下一个月
      current.setMonth(current.getMonth() + 1);
    }

    return columns;
  }

  query(queryParam: any, selectedObj: any): any {
    let dataSet = QueryServiceHelper.queryDataSet(
      this.getClass().getName(),
      "sm_salorder",
      "customer.name as kdec_customer_name, "
        + "substr(bizdate,0,7) as kdec_month, "
        + "salorderentry.amount as kdec_amount",
      null, null
    );

    // 按客户和月份分组统计
    let resultDataSet = dataSet.copy()
      .groupBy(["kdec_customer_name", "kdec_month"])
      .sum("kdec_amount", "kdec_month_amount")
      .finish();

    return resultDataSet;
  }
}

let plugin = new MonthlyAmountReportDataPlugin();
export { plugin };
```

**要点**：
- `getColumns` 在 `query` 之前调用，可根据查询参数动态增删列
- 动态列的 `fieldKey` 需与 `query` 返回的 DataSet 字段名对应
- 常用于交叉表（行转列）场景

### 5. getQueryParam - 获取查询条件

**方法签名**：`getQueryParam(): any`

**说明**：非事件方法，通过反射赋值。插件可调用此方法获取当前报表查询参数对象。

**业务场景**：在 `getColumns` 或其他方法中获取过滤面板的查询条件

```typescript
import { AbstractReportListDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";

class DeptBudgetReportDataPlugin extends AbstractReportListDataPlugin {

  /**
   * 在动态列等场景中使用 getQueryParam 获取查询条件
   */
  getColumns(columns: any): any {
    // 通过 getQueryParam 获取当前查询参数
    let queryParam = this.getQueryParam();
    if (queryParam == null) {
      return columns;
    }

    // 获取过滤面板中的预算类型
    let filterItems = queryParam.getFilter().getFilterItems();
    for (let item of filterItems) {
      if ("kdec_budget_type" === item.getPropName()) {
        let budgetType = item.getValue() as string;

        // 根据预算类型动态添加列
        if ("monthly" === budgetType) {
          for (let i = 1; i <= 12; i++) {
            let col = new Object();
```

### 7. queryBatchBy - 返回分批取数依据

官方[海量数据查询导出](https://vip.kingdee.com/knowledge/321608980914784768)正文依赖V3.0.007_0328，明确分批与分页不同、query需追加当前批过滤；这里的7.0消费链另由本地SDK核验。

**方法签名**：`queryBatchBy(queryParam: ReportQueryParam): DataSet`

**真实消费**：目标 7.0 `ReportServiceImpl.checkLargeData` 接收非空分批依据后建立依据缓存；`prepareCurrentBatch` 更新当前批次索引。框架没有替业务查询追加供应商条件，插件须在每次 `query` 内读取 `queryParam.byBatchInfo().getCurrentBatchRows()`，将这些 ID 与原日期条件 **AND**。如果仍只按日期查询，每一批都会重复读取全量。

**业务场景**：保留供应商对账按日期、供应商分批取数以及应付/已付金额列。本例显式 `setCountPerBatch(1)` 实现每供应商一批；一批可以有多页明细。默认值 `-1` 由框架按依据行数决定批大小，并非固定一供应商，也不是“超过 50,000 行才触发”。

`ap_paybill` 和既有字段仍是原示例合同，接入前须核目标元数据与数据权限。本例过滤映射只有开始/结束日期；项目增加组织、选中供应商、权限或截止版本时，在同一个范围构建函数内按源实体映射并应用到依据与明细，不能只限制其中一个入口，也不能把报表别名条件无证原样转给业务实体。当前批次只收窄已有范围，不替代它。

```typescript
import { AbstractReportListDataPlugin, ReportQueryParam, FilterItemInfo } from "@cosmic/bos-core/kd/bos/entity/report";
import { DataSet, Row } from "@cosmic/bos-core/kd/bos/algo";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";
import { ArrayList } from "@cosmic/bos-script/java/util";

/** 只生成去重键；IN条件保留原对象，禁止将Java Long经过JS Number再装回。 */
function supplierIdentity(value: unknown): string {
  if (value == null || (typeof value === "number" && !Number.isSafeInteger(value))) {
    throw new Error("供应商主键缺失或已经丢失整数精度");
  }
  const key = String(value);
  const max = "9223372036854775807";
  if (!/^[1-9][0-9]*$/.test(key) || key.length > max.length || (key.length === max.length && key > max)) {
    throw new Error("供应商主键不是本例约定的正64位整数");
  }
  return key;
}

/** 每次调用只读取当前切片；缺失缓存、空批次和非法身份均中止，绝不改成全量查询。 */
function currentSupplierIds(queryParam: ReportQueryParam): $.java.util.List {
  const info = queryParam.byBatchInfo();
  if (info == null) throw new Error("缺少分批查询上下文");
  const rows = info.getCurrentBatchRows();
  if (rows == null || rows.size() === 0) throw new Error("当前供应商批次为空");
  const ids = new ArrayList();
  const seen = new Set<string>();
  for (let i = 0; i < rows.size(); i++) {
    const row = rows.get(i) as Row;
    if (row == null) throw new Error("当前批次包含空行");
    const id = row.get("kdec_supplier_id");
    const key = supplierIdentity(id);
    if (!seen.has(key)) { seen.add(key); ids.add(id); }
  }
  return ids;
}

/** 供应商对账：依据与明细复用日期范围，每次query只取当前供应商切片。 */
class SupplierReconciliationReportPlugin extends AbstractReportListDataPlugin {
  queryBatchBy(queryParam: ReportQueryParam): DataSet {
    const filters = this.reconciliationFilters(queryParam);
    const info = queryParam.byBatchInfo();
    if (info == null) throw new Error("缺少分批查询上下文");
    // 本场景明确每供应商一批；一批仍可能含多页明细。
    info.setCountPerBatch(1);
    let result = QueryServiceHelper.queryDataSet(
      "SupplierReconciliationReportPlugin_keys", "ap_paybill",
      "supplier as kdec_supplier_id", filters, "supplier", -1
    );
    try {
      result = result.groupBy(["kdec_supplier_id"]).finish();
      return result.orderBy(["kdec_supplier_id"]);
    } catch (error) {
      try { result.close(); } catch (_) {}
      throw error;
    }
  }

  query(queryParam: ReportQueryParam, selectedObj: object): DataSet {
    const ids = currentSupplierIds(queryParam);
    const filters = this.reconciliationFilters(queryParam);
    filters.push(new QFilter("supplier", QCP.in, ids));
    return QueryServiceHelper.queryDataSet(
      "SupplierReconciliationReportPlugin_batch", "ap_paybill",
      "supplier.name as kdec_supplier_name, billno as kdec_billno, bizdate as kdec_bizdate, "
        + "payableamount as kdec_payable_amount, paidamount as kdec_paid_amount",
      filters, "supplier.name, bizdate", -1
    );
  }

  /** 本例仅映射既有开始/结束日期；扩展组织、供应商或权限范围时必须同时作用于两个查询入口。 */
  private reconciliationFilters(queryParam: ReportQueryParam): QFilter[] {
    const filter = queryParam.getFilter();
    if (filter == null) throw new Error("缺少报表过滤上下文");
    const items = filter.getFilterItems();
    const filters: QFilter[] = [];
    for (let i = 0; i < items.size(); i++) {
      const item = items.get(i) as FilterItemInfo;
      const value = item.getValue();
      if (value == null) continue;
      if (item.getPropName() === "kdec_startdate") filters.push(new QFilter("bizdate", QCP.large_equals, value));
      else if (item.getPropName() === "kdec_enddate") filters.push(new QFilter("bizdate", QCP.less_equals, value));
    }
    return filters;
  }
}
const plugin = new SupplierReconciliationReportPlugin();
export { plugin, SupplierReconciliationReportPlugin, currentSupplierIds, supplierIdentity };
```

**边界**：
- 分组身份仅用供应商 ID，不按可变显示名拆组；本例主键合同为正 Java Long，去重键不改变传给 `QFilter` 的原始值，超过 JS 安全整数范围的数值直接拒绝。字符串或 Java Long 仍需目标桥接支持并验证；不要使用 `Number`、`parseInt` 或按名称去重。
- 所有当前批次变量和过滤数组均为本次调用局部数据，不修改缓存 Row、原 FilterInfo 或共享 QFilter 链。缺缓存、空切片、非法 ID 直接失败，不能用 `IN []`、捕获异常或空 `byBatchInfo` 隐式切换到全量查询。
- 依据缓存固定的是分组键集合，后续明细可能变化；缓存释放后框架还能重跑某批查询。因此它不是数据库一致性快照。财务对账需同一时点时，复用项目已有快照/截止版本合同，并同时约束依据与明细。
- 不把批数当明细页数或总条数。自定义 `export` 若仅返回一次 `query` 的切片，只包含当前批；全量导出须另验全部批次覆盖、过滤和快照口径。这个示例没有声称全量导出或同一个参数对象并发安全。

### 9. query（树形）- 查询树节点数据

**方法签名**：`query(queryParam: any, nodeId: string): any`

**触发时机**：报表左树加载或展开节点时调用

**业务场景**：按组织架构展示部门树 —— 点击部门节点后右侧显示该部门的费用明细

```typescript
import { AbstractReportTreeDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";
import { ArrayList } from "@cosmic/bos-script/java/util";

class OrgTreeDataPlugin extends AbstractReportTreeDataPlugin {

  /**
   * 查询树节点数据
   * @param queryParam 查询参数
   * @param nodeId 当前展开的节点 ID，根节点时为 null 或空
   * @returns TreeNode 列表
   */
  query(queryParam: any, nodeId: string): any {
    let treeNodes = new ArrayList();

    if (nodeId == null || nodeId === "" || nodeId === "0") {
      // 根节点：查询所有一级组织
      let orgData = QueryServiceHelper.query(
        "bos_org",
        "id,name,number",
        [new QFilter("parentorg", QCP.equals, 0)],
        "number"
      );

      for (let org of orgData) {
        let node = new Object();
        node["id"] = org.getString("id");
        node["text"] = org.getString("name");
        node["parentId"] = "0";
        node["isLeaf"] = false;
        treeNodes.add(node);
      }
    } else {
      // 子节点：查询指定组织下的部门
      let deptData = QueryServiceHelper.query(
        "bos_org",
        "id,name,number",
        [new QFilter("parentorg", QCP.equals, nodeId)],
        "number"
      );

      // 判断是否有下级
      for (let dept of deptData) {
        let deptId = dept.getString("id");
        let hasChildren = QueryServiceHelper.exists(
          "bos_org",
          [new QFilter("parentorg", QCP.equals, deptId)]
        );

        let node = new Object();
        node["id"] = deptId;
        node["text"] = dept.getString("name");
        node["parentId"] = nodeId;
        node["isLeaf"] = !hasChildren;
        treeNodes.add(node);
      }
    }

    return treeNodes;
  }
}

let plugin = new OrgTreeDataPlugin();
export { plugin };
```

**要点**：
- `nodeId` 为 null 或空时表示加载根节点
- 每个 TreeNode 需包含 `id`、`text`、`parentId`、`isLeaf` 属性
- `isLeaf = true` 表示叶子节点，不可继续展开
- 树形数据插件与列表数据插件配合使用：选中树节点后触发右侧列表查询

### 13. formatDisplayFilterField - 格式化筛选过滤字段显示

**方法签名**：`formatDisplayFilterField(event: FormatShowFilterEvent): void`。

**触发与消费**：目标7.0 `ReportFilter.updateSearchCondition` 先生成完整摘要，再派发事件，回读 `getFormatedFilterString()` 交前端显示。事件的 `getFilter()` 是完整过滤对象；没有逐字段的 `getFieldName/getValue/setDisplayValue` 合同。

```typescript

import { FormatShowFilterEvent } from "@cosmic/bos-core/kd/bos/report/events";
import { FilterItemInfo } from "@cosmic/bos-core/kd/bos/entity/report";

/** 保留整段原摘要及日期格式，仅为本例单项等值状态补充说明；不修改任何过滤或权限对象。 */
function appendFilterExplanation(event: FormatShowFilterEvent): void {
  const original = event.getFormatedFilterString();
  const filter = event.getFilter();
  if (original == null || original.trim() === "" || filter == null) return;
  // 同字段可有多个条件；getValue只取第一项，不能据此声称整个条件为某一状态。
  const items = filter.getFilterItems("kdec_bill_status");
  if (items == null || items.size() !== 1) return;
  const item = items.get(0) as FilterItemInfo;
  if (item.getCompareType() !== "=") return;
  const value: unknown = item.getValue();
  if (typeof value !== "string") return;
  const names: { [key: string]: string | undefined } = {
    A: "暂存", B: "已提交", C: "已审核", D: "已关闭"
  };
  // 显式白名单避免对象原型键被误当作状态字典条目。
  if (value !== "A" && value !== "B" && value !== "C" && value !== "D") return;
  const suffix = "；状态说明：" + names[value];
  if (!original.endsWith(suffix)) event.setFormatedFilterString(original + suffix);
}

class FormatFilterDisplayPlugin extends AbstractReportFormPlugin {
  /** 同一事件携带所有条件的摘要；父插件处理后再追加本例的只读补充。 */
  formatDisplayFilterField(event: FormatShowFilterEvent): void {
    super.formatDisplayFilterField(event);
    appendFilterExplanation(event);
  }
}

const plugin = new FormatFilterDisplayPlugin();
export { plugin, appendFilterExplanation };
```

**显示与过滤边界**：
- 原摘要逐字保留为前缀，包括未知条件、分号、引号、换行、`<>&` 和前插件正文；不按分号拆分、不替换状态码、不新建FilterInfo。普通过滤项之外还有列头/通用/基础资料权限等条件，不能用少数已知项重建整段范围。
- 同字段多项、非等值、未知状态、null或非字符串值均保持原样；原摘要为空也不另行暴露原本未展示的条件。重复处理同一内容时仅识别本例完整后缀，避免重复追加；条件变化须由平台重新生成本次默认摘要，不能拿旧事件的显示文本作新条件来源。
- 日期继续由平台按实际DateRange起止属性和用户日期格式生成。本例不从 `kdec_daterange` 猜起止字段，也不把日期对象直接转字符串覆盖已有范围。若要新增“查询期间”的特定排版，须先确认真实起止属性、比较语义及业务时区；单边、无效、倒序和复杂条件在合同未确认前保留平台显示。
- 本机前端 `updateSearchCondition` 将整串作为React文本子节点显示，非HTML插入；不要手工转义成HTML实体或拼富文本。该前端包尚未与现场页面版本绑定，不宣称页面验收。

### 14. beforeQuery - 查询前取数事件

**方法签名**：`verifyQuery(queryParam: ReportQueryParam): boolean` 校验并决定取消；`beforeQuery(queryParam: ReportQueryParam): void` 处理通过校验后的取数前置参数。

**真实顺序**：目标7.0代理消费 `verifyQuery` 的false后设置真正QueryEvent的cancel并停止后续校验；通过后才到beforeQuery。ReportQueryParam没有setCancel，不能在beforeQuery调用虚构取消方法。

**业务场景**：保留开始日期必填及既有“管理员/本部门”范围。当前没有证据证明 `bos_user.isadmin/deptid` 与报表部门字段映射成立；授权解析必须接项目现有实现。下例实现确定的校验和范围合并，不查询猜测字段，也不因部门未知回退全量。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { ReportQueryParam, FilterItemInfo } from "@cosmic/bos-core/kd/bos/entity/report";
import { QFilter } from "@cosmic/bos-core/kd/bos/orm/query";
import { DataSet } from "@cosmic/bos-core/kd/bos/algo";

/** 必填开始条件须是本例唯一非空项；日期类型、格式及区间有效性由真实过滤元数据和业务校验负责。 */
function hasRequiredStartDate(queryParam: ReportQueryParam): boolean {
  const filter = queryParam.getFilter();
  if (filter == null) return false;
  const items = filter.getFilterItems("kdec_startdate");
  if (items == null || items.size() !== 1) return false;
  const value: unknown = (items.get(0) as FilterItemInfo).getValue();
  return value != null && !(typeof value === "string" && value.trim() === "");
}

class DataScopeReportPlugin extends AbstractReportFormPlugin {
  /** 返回false由平台取消本次查询；保留父校验，不把ReportQueryParam当QueryEvent。 */
  verifyQuery(queryParam: ReportQueryParam): boolean {
    if (super.verifyQuery != null && !super.verifyQuery(queryParam)) return false;
    if (hasRequiredStartDate(queryParam)) return true;
    this.getView().showTipNotification("请选择唯一且非空的开始日期");
    return false;
  }
}

/** 项目已确认的既有管理员/部门范围结果；不是新角色体系或平台API。 */
type ExistingReportScope =
  | { kind: "administrator" }
  | { kind: "department"; condition: QFilter }
  | { kind: "denied" };

/**
 * 在既有取数端调用：每次重新解析当前用户授权，再把部门条件AND到完整业务条件后执行查询。
 * baseFilters须由项目既有映射生成并包含所有已有业务/权限限制；execute须实际消费传入数组。
 */
function executeAuthorizedReportQuery(
  queryParam: ReportQueryParam,
  baseFilters: QFilter[],
  resolveCurrentScope: () => ExistingReportScope,
  execute: (filters: QFilter[]) => DataSet
): DataSet {
  if (!hasRequiredStartDate(queryParam)) throw new Error("开始日期条件缺失或不唯一");
  if (baseFilters == null) throw new Error("缺少已映射的完整查询条件");
  const scope = resolveCurrentScope();
  if (scope == null) throw new Error("未取得当前用户的数据范围");
  const filters = baseFilters.slice();
  if (scope.kind === "department") {
    if (scope.condition == null) throw new Error("未取得已核字段映射的部门条件");
    filters.push(scope.condition);
  } else if (scope.kind !== "administrator") {
    throw new Error("当前用户无可用报表数据范围");
  }
  return execute(filters);
}

const plugin = new DataScopeReportPlugin();
export { plugin, hasRequiredStartDate, executeAuthorizedReportQuery };
```

**取数接入合同**：
- 表单插件负责可见的日期校验；服务端query也调用 `executeAuthorizedReportQuery`，从可信当前请求上下文重新解析既有授权。不能信任UI传来的部门/管理员标记，不能以表单校验替代数据库范围限制。
- `resolveCurrentScope` 与 `execute` 是项目函数参数，不是平台API；前者须有真实用户/部门/既有管理员判定依据，后者将新数组交已确认实体的真实查询。管理员分支仍保留baseFilters全部限制，部门分支追加AND；解析失败、无部门或无权必须停止，不能返回伪造管理员结果。未接入这两端时不宣称权限功能完成，不提供空实现供复制。
- beforeQuery若追加FilterInfo参数，实际query仍须按原映射消费；`addFilterItem`只写一个命名参数不保证自动变成数据库QFilter。保留原过滤对象、组织、基础资料权限及通用/列头条件，不整体替换FilterInfo，也不复制客户端范围作为服务端授权。
- `kdec_startdate`为本例过滤属性合同，拒绝缺项、重复项、null和空文本；不在缺少元数据时擅自解析日期、猜时区或改写比较符。其他业务校验继续沿用项目实现。

依据：[官方KingScript指南](https://vip.kingdee.com/knowledge/720653325691249152)、[官方beforeQuery事件](https://vip.kingdee.com/knowledge/226033897002083584)及本机7.0 `ReportViewPluginProxy/ReportView` 消费者。真实授权元数据、项目回调接入、数据库与KingScript运行尚未验证。

### 15. afterQuery - 查询取数后事件

**方法签名**：`afterQuery(queryParam: ReportQueryParam): void`。参数没有getDataCount/getQueryTime。

**完成边界**：目标7.0普通报表可异步取数。`ReportView.query` 在Manager提交后调用afterQuery，不能据此即时弹“查询完成”。`ReportView.refresh` 随后还能读取缓存message，所以也不能在beforeQuery提前设置完成消息。真正取数的 `ReportServiceImpl.doQuery` 完成后缓存本次参数，同步视图或异步进度监听器才读取并清空其中message。

**业务场景**：在真正完成时显示结果行数、可选耗时与空结果说明。下面的辅助函数接入既有取数插件的成功出口，在已物化同范围最终结果、后续必要转换已完成且尚未交回平台时调用一次；afterQuery不发即时完成通知。

```typescript
import { ReportQueryParam } from "@cosmic/bos-core/kd/bos/entity/report";
import { CachedDataSet } from "@cosmic/bos-core/kd/bos/algo";

/**
 * 在既有query全部物化成功后调用，缓存仍归原取数端所有；本函数不创建/读取行/关闭缓存。
 * elapsedMs为同请求已核单调时钟测量的物化耗时；未提供则传null，不编造0或包含异步排队时间。
 */
function writeCompletedQueryMessage(
  queryParam: ReportQueryParam, completedCache: CachedDataSet, elapsedMs: number | null
): void {
  if (completedCache == null) throw new Error("缺少本次已完成结果缓存");
  const count = completedCache.getRowCount();
  if (!Number.isSafeInteger(count) || count < 0) throw new Error("结果行数无效");
  if (elapsedMs != null && (!Number.isFinite(elapsedMs) || elapsedMs < 0)) {
    throw new Error("查询耗时无效");
  }
  let message = "本次取数结果共 " + count + " 行";
  if (elapsedMs != null) message += "，物化耗时 " + (elapsedMs / 1000).toFixed(1) + " 秒";
  if (count === 0) message += "；未查询到符合条件的数据，请调整查询条件";
  const original = queryParam.getMessage();
  queryParam.setMessage(original == null || original === "" ? message : original + "\n" + message);
}

export { writeCompletedQueryMessage };
```

**结果、资源与时点合同**：
- 只复用项目已有、属于本次请求的已完成 `CachedDataSet`；`getRowCount()`读缓存元数据，不消费行。本辅助函数不为了提示额外调用cache，也不关闭调用方资源。目标DataSet.cache会物化并关闭原DataSet，不能cache后仍return原流；沿用既有toDataSet/closeAlso等资源所有权，不从此示例猜新的缓存配置。
- 行数是这个缓存的结果行数，分组结果数不是明细数/去重单据数，也不是全库总数。平台后续二次过滤、分页、limit或resetDataCount会形成其他口径；若要最终展示总数，须在该最终消费者另行取证，不能把getData的datacount或一页size冒充同一统计。
- elapsedMs必须来自同请求实际起止测量；null时省略，负值/非有限值拒绝。它不含未纳入测量的排队、网络和页面时间，也不是平台提供的getQueryTime。保留已有message，本例不假称标题栏更新或绑定其他组件。
- `ReportServiceImpl`还会处理返回的结果；若之后失败，完成文本不能充当成功证据。同步异常通常跳过展示；异步监听器先检查ReportException，但异常内容为空有特殊分支。因此项目错误处理必须清理该请求的完成消息，且不能只以progress=100/message非空认定成功。该原生消息按pageId缓存参数，不是已核requestId级回执；调用方必须保证同次param/缓存、不重叠复用，并在失败/重试时清理本例旧摘要而保留其他插件消息。相邻请求、异常、取消和分页时点须按真实环境验收；不要复用旧请求缓存或先写消息再执行可能失败的查询。

依据：[官方事件总览](https://vip.kingdee.com/knowledge/226028022996772096)仅定义afterQuery为后置处理；[官方查询前示例](https://vip.kingdee.com/knowledge/226033897002083584)展示message属性。异步时点、消息缓存/清空和错误分支以本机7.0 `ReportView/ReportListModel/ReportTask/AsynQueryProgressListener/ReportServiceImpl` 为据；不将文档“查询后”泛化为所有异步结果已完成。真实KingScript、异步任务、页面和权限数据未验。

### 16. processRowData - 行数据处理事件

**方法签名**：`processRowData(gridPk: string, rowData: any, queryParam: any): void`

**触发时机**：报表数据返回后、前端渲染前，由 `ReportListModel.processRowData` 调用

**业务场景**：利润分析报表 —— 计算利润率并标记亏损行

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { BusinessDataServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";

class ProfitReportFormPlugin extends AbstractReportFormPlugin {

  /**
   * 处理报表行数据
   * 计算利润率，并将最后一行设置为合计行
   */
  processRowData(gridPK: string, rowData: any, queryParam: any): void {
    if (rowData == null || rowData.size() == 0) {
      return;
    }

    for (let i = 0; i < rowData.size(); i++) {
      let row = rowData.get(i);

      let revenue = row.getBigDecimal("kdec_revenue");
      let cost = row.getBigDecimal("kdec_cost");

      if (revenue != null && cost != null) {
        // 计算利润
        let profit = revenue.subtract(cost);
        row.set("kdec_profit", profit);

        // 计算利润率
        if (revenue.compareTo(BigDecimal.ZERO) != 0) {
          let profitRate = profit.multiply(new BigDecimal("100"))
            .divide(revenue, 2, BigDecimal.ROUND_HALF_UP);
          row.set("kdec_profit_rate", profitRate.toString() + "%");
        } else {
          row.set("kdec_profit_rate", "0%");
        }
      }
    }

    // 将最后一行标记为合计行，设置名称为"合计"
    let lastRow = rowData.get(rowData.size() - 1);
    if (lastRow.get("kdec_customer") == null) {
      let totalObj = BusinessDataServiceHelper.newDynamicObject("bd_customer");
      totalObj.set("name", "合计");
      lastRow.set("kdec_customer", totalObj);
    }

    super.processRowData(gridPK, rowData, queryParam);
  }
}

let plugin = new ProfitReportFormPlugin();
export { plugin };
```

**要点**：
- `processRowData` 在数据返回后、渲染前触发
- 可用于二次计算、数据格式化、合计行处理
- `rowData` 是 `DynamicObjectCollection`，可直接修改

### 17. packageData - 单元格数据打包

**方法签名**：`packageData(event: PackageDataEvent): void`

**触发时机**：报表向前端打包时，按单元格调用；导出不执行此事件。普通报表路径的事件源是 `ReportColumn`，`getRowData()` 是当前行，`getFormatValue()/setFormatValue()` 是当前单元格载荷。不是整张行列表；不能调用不存在的 `getDataList()`，也不能靠 `_link/_pkid/_display` 后缀添加输出列。

**前提**：查询及列定义已提供 `kdec_billno`、`kdec_bill_id` 和普通 BigDecimal 数量列 `kdec_qty`。下面在 `afterCreateColumn` 为单据编号列启用链接，再在 `packageData` 按单元格关闭已启用的链接。主键为 null 时关闭链接，主键存在仍不等于有权访问；点击应沿既有 `hyperLinkClick` 业务处理核对真实业务主键与权限。本例不创建主键或权限解析器。

```typescript
/** 单据编号链接与零数量页面显示；依赖已有查询字段，不修改行数据或业务权限。 */
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { CreateColumnEvent } from "@cosmic/bos-core/kd/bos/report/events";
import { PackageDataEvent } from "@cosmic/bos-core/kd/bos/entity/datamodel/events";
import { ReportColumn } from "@cosmic/bos-core/kd/bos/entity/report";
import { BigDecimal } from "@cosmic/bos-script/java/math";
import { ArrayList } from "@cosmic/bos-script/java/util";

class PackageDataReportPlugin extends AbstractReportFormPlugin {
  /** 只启用本例单据编号列的链接，保留其他列设置。 */
  afterCreateColumn(event: CreateColumnEvent): void {
    super.afterCreateColumn(event);
    const columns = event.getColumns();
    if (columns == null) return;
    for (let i = 0; i < columns.size(); i++) {
      const column = columns.get(i);
      if (column instanceof ReportColumn && column.getFieldKey() === "kdec_billno") {
        column.setHyperlink(true);
      }
    }
  }

  /** 逐单元格处理已核载荷；未知格式保留，缺主键仅关闭链接。 */
  packageData(event: PackageDataEvent): void {
    super.packageData(event);
    const source = event.getSource();
    if (!(source instanceof ReportColumn)) return;
    const key = source.getFieldKey();
    const row = event.getRowData();
    if (row == null) return;

    if (key === "kdec_billno") {
      // 字段由本例查询合同提供；这里只拒绝缺主键，不授予访问权限。
      if (row.get("kdec_bill_id") == null) {
        const noLink = event.getNoLinkKey();
        if (!noLink.contains(key)) noLink.add(key);
      }
      return;
    }
    if (key !== "kdec_qty" ||
        (source.getFieldType() !== "decimal" && source.getFieldType() !== "qty")) return;
    const qty = row.getBigDecimal(key);
    if (qty == null || qty.compareTo(BigDecimal.ZERO) !== 0) return;

    // 本机7.0普通数值载荷：[显示值, 原始值]，前插件可能追加其他槽位。
    // 只处理已核数组合同；未知对象、标量及不足两项的数组保持原样。
    const current = event.getFormatValue();
    if (!Array.isArray(current) || current.length < 2) return;
    const packedRaw = current[1];
    if (!(packedRaw instanceof BigDecimal) || packedRaw.compareTo(qty) !== 0) return;
    const display = current[0];
    const plainZero = display == null || display === "" || display === 0 ||
      (typeof display === "string" && /^[+-]?0+(?:\.0+)?$/.test(display));
    // 前插件的自定义显示、脱敏提示或未知对象不被横线覆盖。
    if (!plainZero) return;
    const copy = new ArrayList();
    for (let i = 0; i < current.length; i++) copy.add(current[i]);
    copy.set(0, "-");
    event.setFormatValue(copy.toArray());
  }
}

let plugin = new PackageDataReportPlugin();
export { plugin };
```

**合同与边界**：
- 数量仅用原始 BigDecimal 比较零，不将 null 当零；不改 `row`，不转 JavaScript Number，不丢小数精度。复制数组后只换显示槽，保留原始值槽及前插件额外槽位，原数组也不改。空串/普通零显示可换横线；已定制显示不覆盖。
- 本机 `NumberColumnDesc.resolveFormat` 产生 `[display, raw]`，`ReportColumn` 的普通数值列带 `isuf=true`，真实 `CommonRenderer` 读取数组第0项显示。`needFormat=false` 可能只有标量，未知/自定义数值载荷需先核合同，本例保持原样；不承诺所有列形态适用。
- KingScript 的Java宿主数组不能据TypeScript的数组声明推定有 `.slice()`；本机Graal探针确认 `Array.isArray` 与索引访问可用，但宿主数组无 `.slice()`。这里用目标声明已导出的 `ArrayList` 复制并返回原生Java数组。
- 当前报表构造路径的 `getColKey()` 不能解析 `ReportColumn`，返回null；三参数事件的 `getRowIndex()` 为-1。使用真实source取fieldKey，不把它们当列键和行号。
- `getNoLinkKey()` 只做幂等增补，保留前插件项目；真实点击送出列ID和报表rowKey，不能把它当 `kdec_bill_id`。权限须在业务钻取处理继续核验。
- `setCancel(true)` 在已核报表打包消费者中未被读取，不能承诺取消该行。本例为页面显示处理，不承诺导出、打印或平台权限验收。

**依据**：[官方报表界面插件基类](https://vip.kingdee.com/knowledge/225997720761664000)说明单元格粒度与导出边界；[单元格链接控制](https://vip.kingdee.com/knowledge/210393247997202944)（BOS_V_4.0.004）使用 `ReportColumn` 与 `getNoLinkKey`。具体数值载荷、列元数据与渲染由本机7.0 JAR、随包声明及前端资源确认；本机资源尚未映射到项目部署补丁，独立Graal/VM验证不等于平台插件运行。

### 18. afterCreateColumn - 表格列创建完成后事件

**方法签名**：`afterCreateColumn(event: any): void`

**触发时机**：报表表格列创建完成后，由 `ReportList.initGrid` 调用

**业务场景**：根据查询条件动态隐藏不需要的列 —— 未选择"显示成本"时隐藏成本列

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";

class DynamicColumnReportPlugin extends AbstractReportFormPlugin {

  /**
   * 表格列创建完成后，根据条件隐藏不需要的列
   */
  afterCreateColumn(event: any): void {
    super.afterCreateColumn(event);

    let columns = event.getColumns();
    if (columns == null) {
      return;
    }

    // 获取过滤面板中"是否显示成本"选项
    let showCost = this.getModel().getValue("kdec_show_cost") as boolean;
    let showProfit = this.getModel().getValue("kdec_show_profit") as boolean;

    // 遍历列，根据条件隐藏
    for (let i = columns.size() - 1; i >= 0; i--) {
      let column = columns.get(i);
      let fieldKey = column.getFieldKey();

      // 不显示成本时，隐藏成本相关列
      if (!showCost) {
        if ("kdec_cost" === fieldKey || "kdec_unit_cost" === fieldKey) {
          columns.remove(i);
        }
      }

      // 不显示利润时，隐藏利润相关列
      if (!showProfit) {
        if ("kdec_profit" === fieldKey || "kdec_profit_rate" === fieldKey) {
          columns.remove(i);
        }
      }
    }
  }
}

let plugin = new DynamicColumnReportPlugin();
export { plugin };
```

**要点**：
- `afterCreateColumn` 在列创建完成后触发
- 通过 `event.getColumns()` 获取列列表，可以增删改列
- 从后往前遍历删除，避免索引越界
- 适合根据用户选项动态控制列的显隐

### 19. filterContainerSearchClick - 过滤容器搜索点击事件

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";

   * 过滤面板"查询"按钮点击时校验

    super.filterContainerSearchClick(args);

    let endDate: Date = null;

    let filterItems = filterInfo.getFilterItems();

      if (diffDays < 0) {
        this.getView().showTipNotification("开始日期不能晚于结束日期");
        args.setCancel(true);
        return;
      }
    }

    // 校验必选条件
    if (startDate == null || endDate == null) {
      this.getView().showTipNotification("请选择完整的日期范围");
      args.setCancel(true);
    }
  }
}
```

### 20. setOtherEntryFilter - 为保存方案的校验补充条件

**方法签名**：`setOtherEntryFilter(filterInfo: FilterInfo): void`

**触发与保存合同**：本机 7.0 的 `verifyAndPutSchemeToMap` 先从过滤控件生成 `FilterInfo`，触发本事件，再交给 `verifyScheme`。校验通过后，方案的 `custfilters` 来自当前模型 `DynamicObject` 的序列化，`commfilters` 来自通用过滤控件；传入本事件的 `FilterInfo` 不是方案保存载荷。因此 `addFilterItem` 只追加本次校验条件，不能替代把控件值写入已有模型字段。产品分类 `kdec_product_category` 与最小金额 `kdec_min_amount` 若已在模型中，原本就可能随模型保存，不能判为必丢。

**业务能力与适配前提**：保留产品分类、最小金额两个过滤值；两个标识是原示例的适配目标，不证明项目中存在或属于哪种类型。先核实它们的模型字段、控件绑定及自动过滤责任。标准过滤控件已产生的条件交平台处理；只有已确认由插件独占、未由标准控件生成条件的自定义标量，才把实际字段 key 加入 `ownedScalarKeys`。界面值必须已同步到模型，单纯显示在自定义控件内的值不会因追加 `FilterInfo` 而进入方案。基础资料引用、多选资料、实际单据体行集合须另按真实元数据与权限合同实现，下面两个标量的适配不等于完整“产品明细单据体”。

```typescript
/** 方案校验条件适配；仅供已核实为插件独占的模型标量使用，不执行持久化。 */
import { FilterInfo } from "@cosmic/bos-core/kd/bos/entity/report";
import { IDataModel } from "@cosmic/bos-core/kd/bos/entity/datamodel";

/**
 * 为本次方案校验补充缺少的自定义条件，保存载荷仍来自 model。
 * 跳过模型缺字段及 null；0 和空字符串保持原值。同名条件归原生产者，
 * 不覆盖比较符、不重复追加、不清空其他插件条件。
 */
export function appendOwnedSchemeFilters(
  filterInfo: FilterInfo,
  model: IDataModel,
  ownedScalarKeys: string[]
): void {
  let properties = model.getDataEntityType().getProperties();
  for (let i = 0; i < ownedScalarKeys.length; i++) {
    let key = ownedScalarKeys[i];
    if (!properties.containsKey(key) || filterInfo.getFilterItem(key) != null) {
      continue;
    }
    let value = model.getValue(key);
    if (value != null) {
      filterInfo.addFilterItem(key, value);
    }
  }
}
```

在 `setOtherEntryFilter` 中将事件参数、当前模型和已核实的自定义标量 key 集合传入此 helper；不要把两个业务 key 无条件加入集合。平台先生成的条件或其他插件先写入的同名条件保留原值和比较符；如果责任发生冲突，应先确定唯一生产者，不能用重复 `addFilterItem` 或 `clear()` 取代协调。`FilterInfo.getFilterItem/getValue` 读取同名首项，追加并非更新。

**边界**：本事件不等于查询入口，也不自动修改查询结果；最终取数仍须由报表查询插件按已确认字段/比较符消费条件；最小金额的字段名不会自动把默认比较符变成金额下限查询。`FilterInfo` 内的 `otherEntryFilter` 是另一张 Map，改用它也不能把本次校验对象变为 `custfilters`。示例不创建持久化字段、不写业务数据、不绕过方案权限。

**依据**：[官方报表表单插件指南](https://vip.kingdee.com/knowledge/720653325691249152?productLineId=29&isKnowledge=2&lang=zh-CN) 列出本事件；保存消费者合同另由本机 `bos-form-core-7.0.jar` 的 `ReportFilter` 确認，声明由本机随包 KingScript `.d.ts` 确认。官方未标最低版本，本机补丁号未确认，不能外推所有 7.0 环境。

### 21. loadOtherEntryFilter - 恢复插件负责的自定义标量

**方法签名**：`loadOtherEntryFilter(scheme: DynamicObject): void`

**触发与载荷合同**：`scheme` 是按方案 `formId` 的模型类型反序列化得到的 `DynamicObject`。本机 7.0 加载顺序为：平台自动赋值并清理无权限选项 → `updateView` → `afterSetModelValue` → `loadFlexFilter` → 本事件。平台自动集合来自过滤容器内 `FieldEdit.getFilterKeys()`，不能仅凭字段名称判断是否自动恢复。产品分类和最小金额若属于该集合，应保留平台恢复结果，不在此重复设置。

**业务能力与适配前提**：两个适配目标仍为产品分类 `kdec_product_category`、最小金额 `kdec_min_amount`。只有核实为已存在于模型、插件独占且不在平台自动恢复集合中的标量，才将实际字段 key 传入 `ownedScalarKeys`。未确认的基础资料/分录类型不能由这个 helper 代为加载或判断权限；它没有创建缺失字段的能力。

```typescript
/** 方案加载标量适配；仅恢复插件负责的已有字段，不执行基础资料权限判定。 */
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { IDataModel } from "@cosmic/bos-core/kd/bos/entity/datamodel";

/**
 * 恢复已核实的插件自定义标量；标准过滤字段保留平台已恢复/清理的结果。
 * 类型缺字段时不读写；存在且为 null 时清空旧值，0/空串不当成空值。
 * containsKey 只检查模型类型属性，不证明原始方案 JSON 是否出现过该键。
 */
export function restoreOwnedSchemeScalars(
  scheme: DynamicObject,
  model: IDataModel,
  ownedScalarKeys: string[]
): void {
  if (scheme == null) {
    return;
  }
  let sourceProperties = scheme.getDynamicObjectType().getProperties();
  let targetProperties = model.getDataEntityType().getProperties();
  for (let i = 0; i < ownedScalarKeys.length; i++) {
    let key = ownedScalarKeys[i];
    if (sourceProperties.containsKey(key) && targetProperties.containsKey(key)) {
      model.setValue(key, scheme.get(key));
    }
  }
}
```

在本事件中传入 `scheme`、当前模型及已核实的插件自定义标量 key 集合。类型缺字段时保留当前值；字段存在且当前 `scheme` 值为 `null` 时清空旧值；金额 `0` 和空字符串原样恢复，不能用 truthy 判断。字段集合中的 `containsKey` 只证明模型类型有此属性，无法区分原始 `custfilters` JSON 未出现该键、显式 `null` 或反序列化默认值；若业务要求旧方案缺键时采用不同策略，须另核实方案版本/原始载荷合同，不能从当前对象猜测。

**权限和事件责任**：平台校验不合法的标准字段时，会同时把 `scheme` 和 model 的该值设为 `null`，本事件收到的同一方案对象已清理；不能写成它仍必含原始无权限值。不要从另存快照、重新反序列化载荷或外部值恢复被清除的资料。非自动集合的自定义资料未经过这条自动校验路径，不得当成普通标量回填。`afterSetModelValue` 的日期更新或其他重算先于本事件；相同字段必须明确唯一写入责任，避免后续恢复覆盖前面的业务重设。

**依据**：[官方报表表单插件指南](https://vip.kingdee.com/knowledge/720653325691249152?productLineId=29&isKnowledge=2&lang=zh-CN) 列出本事件与 `afterSetModelValue`；上面的具体顺序、方案对象与模型同时清理来自本机 7.0 `ReportFilter.loadQuerySchemeData/setModelValue/toDynamicObject`，helper API 来自同版本 JAR 与随包声明。本机独立验证不等于真实平台保存、切换方案或权限验收。

### 22. preProcessExportData - 保留类型的分块导出加工

**方法签名**：`preProcessExportData(exportColumns: $.java.util.List, rowData: DynamicObjectCollection, numberFormatProvider: NumberFormatProvider): void`。

**触发与列快照**：普通 Excel 导出每取得一个非空数据块，初始化该块的 `NumberFormatProvider` 后调用本事件；默认块大小为10000。首块回调结束后复制当前导出列，作为这个 sheet 的写出列快照。后续块仍调用本事件，但不重建该快照。固定删列能在首块生效；同一 sheet 内所有插件必须保持列结构、类型和脱敏策略一致，不能按当前块数据临时删列或切换列类型。这里不是整个导出只执行一次的初始化事件。

**业务场景**：保留金额数值与显示格式、状态中文、供应商联系方式脱敏、内部列剔除，以及基础资料名称和导出说明信息。先核真实结果属性与导出列，按以下责任实现：

| 能力 | 实际处理与前提 |
|---|---|
| 金额两位小数、千分位 | 保留原 `BigDecimal` 和数值列。真实 decimal writer 使用 `DecimalProp` 精度，金额还受币别精度影响；确认实际字段精度为2后使用原数值格式链。仅改 provider 或 `ReportColumn.setScale(2)` 不足以保证最终两位；`setScale(...).toString()` 不生成千分位，也不创建可见的导出列。 |
| 状态 A/B/C 显示暂存/已提交/已审核 | 在真实 `ComboProp` 中维护对应显示项，保留原状态编码。writer 会再次按编码查枚举；先把 A 改成中文，中文找不到项时会写成空串。普通文本结果列若要自行转换，须另核文本列与字段合同，不能套到枚举列。 |
| 联系方式脱敏 | 仅接管已确认 `TextProp` 导出列和实际存在的字符串结果属性。长文本保留首3末4，中间固定四星；非空且不超过7字符全部遮蔽；规范掩码重入不变。按字符屏蔽，不验证电话格式。缺属性或未知类型保持原值，不能据此宣称已脱敏。 |
| 内部列剔除 | 固定剔除 `kdec_internal_flag/kdec_row_id`，递归处理真实 `ReportColumnGroup`，清理本次删空的分组，保留原来已空的分组和未知列类型。调用者保证列树无环。 |
| 基础资料 ID 转名称 | 使用已配置显示属性、已装载资料数据的真实基础资料列，或取数层按已核关联产生独立文本名称列；仅原始ID、猜测 `.name` 或在块内逐行查询都不能保证正确名称。不得把资料对象/ID强行写成字符串。 |
| 添加导出说明行 | 保留为独立导出布局需求。标准过滤摘要与任意说明行不同：官方 BOS_V2.0.034 说明摘要来自设计器过滤条件，并放在标题下；本事件逐块追加数据行会重复且混入业务结果。本例未实现任意说明行，需目标版本的导出布局/writer扩展及一次性位置合同。 |

下面代码实现固定递归删列与字符串联系方式加工；金额、枚举和基础资料继续由真实类型消费者处理。示例字段必须先与项目元数据对应，不能用不存在的 `kdec_amount_str` 代替导出列合同。

```typescript
/**
 * 普通报表导出：固定剔除内部列，并加工已核实的文本联系方式。
 * 前提：金额结果/导出列为原 Decimal/Amount 类型，精度由真实属性/币别确认；
 * 状态为已维护 A/B/C 显示项的 ComboProp；不在回调中覆盖原金额或状态编码。
 * 每个非空导出块都会调用，不能用本块数据决定列结构，也不在块内查询基础资料。
 */
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { DynamicObjectCollection } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { NumberFormatProvider } from "@cosmic/bos-core/kd/bos/entity";
import { ReportColumn, ReportColumnGroup } from "@cosmic/bos-core/kd/bos/entity/report";
import { TextProp } from "@cosmic/bos-core/kd/bos/entity/property";

/** 固定递归删列；保留未知列类型与原有非空分组，返回是否有确认的联系方式文本列。 */
function prepareColumns(columns: $.java.util.List): boolean {
  let phoneTextColumn = false;
  for (let i = columns.size() - 1; i >= 0; i--) {
    const col = columns.get(i);
    if (col instanceof ReportColumnGroup) {
      const key = col.getFieldKey();
      if (key === "kdec_internal_flag" || key === "kdec_row_id") {
        columns.remove(i);
        continue;
      }
      const children = col.getChildren();
      const hadChildren = children != null && children.size() > 0;
      if (children != null) {
        if (prepareColumns(children)) phoneTextColumn = true;
        if (hadChildren && children.size() === 0) columns.remove(i);
      }
    } else if (col instanceof ReportColumn) {
      const key = col.getFieldKey();
      if (key === "kdec_internal_flag" || key === "kdec_row_id") {
        columns.remove(i);
      } else if (key === "kdec_phone" && col.getFieldProperty() instanceof TextProp) {
        phoneTextColumn = true;
      }
    }
  }
  return phoneTextColumn;
}

/** 按字符脱敏；长文本保留首3末4，短文本全掩码，规范掩码保持幂等。 */
function maskContact(contact: string): string {
  if (contact.length === 0 || /^.{3}\*{4}.{4}$/.test(contact)) return contact;
  if (contact.length <= 7) return "*".repeat(contact.length);
  return contact.substring(0, 3) + "****" + contact.substring(contact.length - 4);
}

class ExportDataProcessPlugin extends AbstractReportFormPlugin {
  /** 使用完整三参数合同；只处理当前块中已声明的字符串；这是按字符屏蔽，不验证电话号码格式。 */
  preProcessExportData(exportColumns: $.java.util.List, rowData: DynamicObjectCollection,
                       numberFormatProvider: NumberFormatProvider): void {
    super.preProcessExportData(exportColumns, rowData, numberFormatProvider);
    const phoneTextColumn = prepareColumns(exportColumns);
    if (!phoneTextColumn || rowData == null || rowData.size() === 0) return;
    const properties = rowData.getDynamicObjectType().getProperties();
    if (!properties.containsKey("kdec_phone")) return;
    for (let i = 0; i < rowData.size(); i++) {
      const row = rowData.get(i);
      const phone = row.get("kdec_phone");
      if (typeof phone === "string") {
        const masked = maskContact(phone);
        if (masked !== phone) row.set("kdec_phone", masked);
      }
    }
  }
}
let plugin = new ExportDataProcessPlugin();
export { plugin };
```

**消费者边界**：`GridExcelExporter` 经列 writer 格式化后区分数值与文本；普通金额可成为 numeric 单元格，超大数字路径会转为文本以避免精度损失，不能承诺所有金额都为 numeric。保留 `NumberFormatProvider` 的第三参数和原引用，不在事件中改共享字段精度/枚举对象或逐行查资料。页面 `packageData` 的显示横线、链接规则不在这条导出路径执行。

依据：[KingScript 报表表单指南](https://vip.kingdee.com/knowledge/720653325691249152)、[官方报表插件基类及分批导出说明](https://vip.kingdee.com/knowledge/225997720761664000)、[过滤条件导出摘要](https://vip.kingdee.com/knowledge/81346787155731456)。前两篇未标最低版本；本机7.0 `NormalExcelExport → IExporter → GridExcelExporter → ColExcelExporter/RptDecimalColExcelExporter/RptComboColExporter` 及随包声明确认这里的消费合同。实际项目字段、完整平台导出和打印仍需验证；本例没有交付任意说明行或无元数据来源的基础资料名称转换。

### 23. afterSetModelValue - 加载方案后重设值

**方法签名**：`afterSetModelValue(scheme: any): void`

**触发时机**：加载过滤方案后给 model 设值之后，由 `ReportFilter.loadQuerySchemeData` 调用

**业务场景**：加载方案后根据业务逻辑覆盖某些值 —— 日期自动更新为最新期间

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";

class SchemeValueResetPlugin extends AbstractReportFormPlugin {

  /**
   * 加载方案设值后，可以重新设置值
   * 方案中保存的日期自动更新为当前月份
   */
  afterSetModelValue(scheme: any): void {
    super.afterSetModelValue(scheme);

    // 无论方案保存的是什么日期，始终覆盖为当前月份
    let now = new Date();
    let firstDay = new Date(now.getFullYear(), now.getMonth(), 1);
    let lastDay = new Date(now.getFullYear(), now.getMonth() + 1, 0);

    this.getModel().setValue("kdec_startdate", firstDay);
    this.getModel().setValue("kdec_enddate", lastDay);

    // 根据方案中的报表类型，动态调整其他字段
    let reportType = scheme.getString("kdec_report_type");
    if ("summary" === reportType) {
      // 汇总模式下隐藏明细相关过滤条件
      this.getView().setVisible(false, "kdec_detail_filter_panel");
    } else {
      this.getView().setVisible(true, "kdec_detail_filter_panel");
    }
  }
}

let plugin = new SchemeValueResetPlugin();
export { plugin };
```

**要点**：
- 在方案值设置到 model 之后触发
- 本机 7.0 中其后还会依次执行 `loadFlexFilter`、`loadOtherEntryFilter`；本事件不是所有自定义值恢复后的最终阶段。同一字段只设一个恢复/重算责任，见第21节。
- 可以覆盖方案值（如强制更新日期为当前）
- 可以根据方案内容动态调整界面状态

### 24. setTreeReportList - 树形报表数据与展开操作

**方法签名**：`setTreeReportList(event: TreeReportListEvent): void`。目标7.0事件只提供 `setTreeReportList(boolean)` 和 `setTreeExpandColId(string)`，没有 `setIdFieldKey/setParentIdFieldKey/setTreeFieldKey/setExpandLevel/setShowExpandAll`。

**业务场景**：按组织 → 部门 → 员工展示费用数据，并由工具栏全部展开或收起。树形开关、查询结果的父子结构、展示展开列和工具栏操作分别有自己的合同；只设置开关不会把普通明细自动分层或汇总。

**查询结果合同**：沿用实际查询插件和权限范围，将其已经确认的层级关系投影为以下结果列，不在本事件临时造组织、部门或员工。官方树形支持文档以查询插件取数为支持范围，配置式数据源需另核目标版本。

| 结果列 | 本机7.0的实际消费与本例责任 |
| --- | --- |
| `rowid` | 节点身份，非空、同一结果内唯一，使用稳定字符串并避开根哨兵 `"0"`；组织、部门、员工跨实体时须采用已确认且不会碰撞的身份编码，不用显示名称当主键。 |
| `pid` | 父节点的 `rowid`；根节点严格输出字符串 `"0"`，不能把 `null`、空串或不存在的父键当根。部门指向所属组织，员工指向所属部门。 |
| `isgroupnode` | Boolean，`true` 表示有下级、`false` 表示叶子；不能直接把“是否叶子”为true的字段原样别名成此列，也不用字符串 `"false"` 代替Boolean。 |
| `kdec_name` | 本例已有可见、非合并列表、可由LightRender渲染的显示列，承载组织／部门／员工名称。它不是行身份或父键。 |

普通查询路径读取 `pid/rowid` 建立父子映射，从 `"0"` 的子列表递归编号后按 `fseq` 排列；插件仍应保证层级无环、父键完整、身份唯一和同级顺序稳定。该路径没有访问集或重复ID拒绝逻辑：重复ID会覆盖编号映射，环可能造成递归不能终止，孤儿及非 `"0"` 根不会被正常编号。不能指望平台替项目修复这些输入。分批取数另有消费者，不将此路径推定为所有分批模式的行为。

**表单和工具栏前提**：本例控件为 `reportlistap`，工具栏为 `toolbarap`；添加 `expand/collapse` 两个工具栏项并绑定已确认的 `donothing` 操作。下面只实现树形展示配置与点击路由，查询插件仍须交付上述三层数据。展开列已有非空配置时保留，需由项目统一不同插件的列选择。

```typescript
/** 使用目标7.0树形事件和报表控件操作；数据层级与权限由查询插件提供。 */
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { TreeReportListEvent } from "@cosmic/bos-core/kd/bos/report/events";
import { ReportList } from "@cosmic/bos-core/kd/bos/report";
import { ItemClickEvent } from "@cosmic/bos-core/kd/bos/form/control/events";

class TreeReportListPlugin extends AbstractReportFormPlugin {
  /** 监听本例已有工具栏；不在此创建元数据或业务数据。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    this.addItemClickListeners("toolbarap");
  }

  /** 启用树形报表，空配置时选择已核显示列，保留前插件的展开列。 */
  setTreeReportList(event: TreeReportListEvent): void {
    super.setTreeReportList(event);
    event.setTreeReportList(true);
    const current = event.getTreeExpandColId();
    if (current == null || current.length === 0) {
      event.setTreeExpandColId("kdec_name");
    }
  }

  /** 只响应本例两项操作；控件缺失表示本次展开/收起没有应用。 */
  itemClick(event: ItemClickEvent): void {
    super.itemClick(event);
    const key = event.getItemKey();
    if (key !== "expand" && key !== "collapse") return;
    const reportList = this.getControl("reportlistap") as ReportList;

let plugin = new TreeReportListPlugin();
export { plugin };
```

**消费与未交付边界**：
- `ReportList`将事件值缓存并输出为 `istreevirtualviewgrid/teci`。前端树模型固定使用 `rowid/pid`，节点是否有下级直接消费 `isgroupnode`；展开请求根父键为 `"0"`，子请求取父行真实 `rowid`。任意 `kdec_row_id/kdec_parent_id` 不会因不存在的setter自动映射。
- `setTreeExpandColId`只选择展开控件所在列。列隐藏、合并列表、序号列或渲染类型不满足时，已核前端可能回退行键列而显示空标签；不能承诺设置任意字段即显示名称。保留先前非空配置也不证明该列可用。
- 全展开与收起使用 `ReportList.expandAllNode()/collapseAllNode()`，不是事件内“显示按钮”开关。本机方法会先refresh，再发控件指令并维护展开状态；实际指令目标固定为 `reportlistap`，不能仅换getControl的key便声称任意命名控件都适配。两方法已见本机7.0声明/JAR，官方专文标V7.0.1，目标部署仍须核实际补丁及工具栏挂载。
- 原需求“默认展开到第2层”仍保留为待接入能力：本机事件与已核树初始化没有该配置入口；此例**没有实现默认两级展开**。全展开也不等于两级；不能挪用树形单据体的层级或节点操作来冒充报表能力。若该交互是验收条件，需另取目标报表实际支持的初始化/节点展开合同后实现。
- 官方旧树形支持文档说明Excel按所有层级展开后的顺序输出且没有树层级展示；该说明绑定BOS_V2.0.035，不声称已验证当前7.0导出。页面层级、工具栏、真实三层数据与权限、默认层级、导出均未做平台验收。

依据：[树形报表支持](https://vip.kingdee.com/knowledge/87203604209182976)（BOS_V2.0.035）、[一键展开和收起](https://vip.kingdee.com/knowledge/665606949383170304)（V7.0.1）；入口、固定字段、根键与消费边界由本机7.0 JAR、随包声明和真实前端资源补充。官方旧示例的 `isleaf as isgroupnode` 不作为叶子语义证明，按实际业务字段含义和消费者确认是否需要转换。

### 25. beforeCreateFilterInfo - 过滤信息加载事件

**方法签名**：`beforeCreateFilterInfo(event: CreateFilterInfoEvent): void`。

**真实合同**：目标7.0只有 `cancel=true` 且 `filterInfo` 非空才采用插件Map；其余情况重新生成默认Map。自定义结构整体替换，不会与默认项逐项合并。此事件没有 `setFilterType/setDateFormat/setScale/setCanFilter`。

**业务场景**：日期列提供日期选择与区间，金额列提供数值比较且输入两位小数，备注/行ID禁止过滤，其余列保留原能力。本节和第26节的金额策略是不同业务场景：若同时使用第26节的“禁止金额过滤”，金额列不会进入本事件；须先按真实需求统一策略，不能叠加后声称金额筛选已启用。

**前置条件**：日期/金额列已有正确字段类型、列头能力与过滤消费者。下面整表提供目标7.0的标准日期7项和数字6项比较符，接入前确认项目未另有限制比较符的元数据/插件策略；不能用该整表绕过它们。若只需默认日期组件或默认数值比较，保留默认生成即可；输入精度另由编辑器承担。

```typescript
/** 为日期/金额列提供完整过滤载荷；保留已接管结构与真实列编辑器配置。 */
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { CreateFilterInfoEvent, SortAndFilterEvent } from "@cosmic/bos-core/kd/bos/report/events";
import { ReportColumn } from "@cosmic/bos-core/kd/bos/entity/report";
import { LocaleString } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { ArrayList, HashMap } from "@cosmic/bos-script/java/util";

// 目标7.0事件source的列访问桥接；AbstractProcessor不在随包模块导出中。
type ColumnSource = { getColumn?: () => ReportColumn };
type CompareSpec = [string, string, string, number];

class ColumnFilterInfoPlugin extends AbstractReportFormPlugin {
  /** 备注/行ID禁止过滤；允许列的自动配置及取数责任由既有报表保证。 */
  setSortAndFilter(allColumns: $.java.util.List): void {
    super.setSortAndFilter(allColumns);
    for (let i = 0; i < allColumns.size(); i++) {
      const event = allColumns.get(i) as SortAndFilterEvent;
      if (event.getColumnName() === "kdec_remark" || event.getColumnName() === "kdec_row_id") {
        event.setFilter(false);
        event.setDisableFilter(true);
      }
    }
  }

  /** 不合并残缺Map；仅在尚无前插件结构且取得对应真实列编辑器时完整替换。 */
  beforeCreateFilterInfo(event: CreateFilterInfoEvent): void {
    super.beforeCreateFilterInfo(event);
    const fieldKey = event.getFieldKey();
    if (fieldKey !== "kdec_bizdate" && fieldKey !== "kdec_amount") return;

    // 前插件已接管或已放入结构时不抢占；空Map也不取消别人的cancel。
    const previous = event.getFilterInfo();
    if (event.isCancel() || (previous != null && !previous.isEmpty())) return;
    const source = event.getSource() as ColumnSource | null;
    if (source == null || typeof source.getColumn !== "function") return;
    const column = source.getColumn();
    if (!(column instanceof ReportColumn) || column.getFieldKey() !== fieldKey) return;

    // 重新生成的是当前列配置，不调用createFilterInfo，避免重入事件。
    // editor缺失/类型不符时不抢占，平台仍按真实列元数据生成默认过滤。
    const columnInfo = column.createColumn();
    const originalEditor = columnInfo.get("editor") as $.java.util.Map | null;
    if (originalEditor == null) return;
    const editorType = String(originalEditor.get("type"));
    if (fieldKey === "kdec_bizdate" && editorType !== "date" && editorType !== "datetime") return;
    if (fieldKey === "kdec_amount" && editorType !== "number") return;
    const editor = new HashMap();
    editor.putAll(originalEditor);

    let specs: CompareSpec[];
    if (fieldKey === "kdec_bizdate") {
      // 日期比较项包含快捷期间、单日等于和双端区间。
      specs = [
        ["13", "今天", "TODAY", -1],
        ["10", "本周", "THISWEEK", -1],
        ["63", "本月", "THISMONTH", -1],
        ["92", "上月", "LASTMONTH", -1],
        ["24", "过去三个月", "LASTTHREEMONTH", -1],
        ["67", "等于", "", 0],
        ["1", "从…到…", "", 0]
      ];
      // 日期/长日期以及mask/df均继承原editor，不把长日期截成日期。
    } else {
      specs = [
        ["67", "等于", "", 0],
        ["83", "不等于", "", 0],
        ["21", "大于", "", 0],
        ["36", "小于", "", 0],
        ["19", "小于等于", "", 0],
        ["65", "大于等于", "", 0]
      ];
      // sc为已核前端SCALE键，只限制列头输入小数位；不改变原金额值。
      editor.put("sc", 2);
    }
    const items = new ArrayList();
    for (const spec of specs) {
      const item = new HashMap();
      item.put("id", spec[0]);
      item.put("name", new LocaleString(spec[1]));
      item.put("value", spec[2]);
      item.put("inputCtlType", spec[3]);
      items.add(item);
    }
    const replacement = new HashMap();
    replacement.put("filterItems", items);
    replacement.put("editor", editor);
    event.setFilterInfo(replacement);
    event.setCancel(true);
  }
}

let plugin = new ColumnFilterInfoPlugin();
export { plugin };
```

**载荷与能力边界**：
- `filterItems` 每项包含 `id/name/value/inputCtlType`。本机日期比较符是13/10/63/92/24/67/1；金额是67/83/21/36/19/65。来源为目标7.0 `FilterMetadata.xml`、`DateProcessor` 和 `NumberProcessor`，不是可以跨版本自由替换的编号。日期的1表示“从…到…”，67是等于；92是上月，24是过去三个月。
- 金额组件每次输入一个数值，通过大于/小于/大于等于等表达单端范围；不能将它宣称为双端金额区间。需要上下界同时成立时使用已确认的过滤面板范围条件及真实取数逻辑，不添加未经消费的第二个值。
- 日期控件类型来自真实列 `editor.type`，mask/显示格式也来自列编辑器；本例保留日期与长日期区别。要固定日期显示为 `yyyy-MM-dd`，应先在已确认的日期列格式中设置并核实际编辑器输出，不在该事件上调用虚构格式setter或截掉长日期时间。
- 数字列 `setScale` 影响列显示，不保证列头输入精度；目标列生成器默认编辑器 `sc=10`，前端筛选器读 `editor.sc`。本例复制完整编辑器，仅金额改 `sc=2`；保留原pc/min/max等其他属性，不舍入原始金额、不改数据查询口径。输入精度效果仍需目标页面验证。
- `getSource()` 是已核目标7.0的 `AbstractProcessor`，但该类未随KingScript模块导出。结构类型只承接其真实 `getColumn()` 桥接，并核返回列身份；不是新增平台API或导入一个不存在的模块。只调用列的 `createColumn()` 取编辑器，不递归调用过滤生成器。
- 缺桥接、错列、无编辑器或类型不符时不接管，平台继续默认生成；这代表本次定制未应用，不能称两位小数/指定组件已经实现。已有cancel或非空Map均保留；前插件单独放Map但未设cancel仍可能被默认生成忽略，应该由该插件修正，不能擅自抢占。
- 禁止筛选通过同类中的 `SortAndFilterEvent` 明确否决；该策略须协调为最后执行，后续插件仍可覆盖。它保留原业务目的，具体顺序与取数责任沿第26节；Map不负责启用一个尚未开启的列。

依据：[官方报表基类示例](https://vip.kingdee.com/knowledge/225997720761664000)展示 `filterInfo` 载荷，[KingScript 报表指南](https://vip.kingdee.com/knowledge/720653325691249152)说明列比较符事件用途。前者未设cancel的片段不能直接等同本机7.0行为；本节按真实消费者补足完整替换条件。未验证真实KingScript桥接、页面、过滤取数与日期区域设置。

### 26. setSortAndFilter - 设置过滤排序列

**方法签名**：`setSortAndFilter(allColumns: $.java.util.List): void`，元素为 `SortAndFilterEvent`。

**触发与消费**：`ReportList.sortAndFilter` 派发后，目标7.0 `TableHeadFilter.afterSortAndFilterEvent` 才决定列能力和接管缓存。存在查询插件且 `setSort(true)` / `setFilter(true)` 时先进入插件接管分支，查询插件必须实际消费排序或过滤条件；这不是打开平台自动能力的开关。

**业务场景**：编号、日期及其他列沿用自动排序/过滤，金额与成本只允许排序，备注禁用两者。报表控件须已开启对应自动能力，列类型、数据源绑定和结果行数还须满足平台条件；这些前提不满足时，本例不会伪造一个可用的箭头或漏斗。字段名是本例结果列合同，接入时核对实际输出列。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { SortAndFilterEvent } from "@cosmic/bos-core/kd/bos/report/events";

/** 对明确禁止的列能力作最终否决；其余保留平台自动判断或已确认的前插件接管。 */
function applyReportColumnPolicy(allColumns: $.java.util.List): void {
  for (let i = 0; i < allColumns.size(); i++) {
    const event = allColumns.get(i) as SortAndFilterEvent;
    const key = event.getColumnName();
    if (key === "kdec_amount" || key === "kdec_cost" || key === "kdec_remark") {
      // 先退出插件过滤接管，再禁止自动过滤；仅disable不能压过已置true的接管分支。
      event.setFilter(false);
      event.setDisableFilter(true);
    }
    if (key === "kdec_remark") {
      event.setSort(false);
      event.setDisableSort(true);
    }
  }
}

/** 控件已启用自动列头能力；本策略须最后执行，后续插件仍可重新接管。 */
class SortAndFilterPlugin extends AbstractReportFormPlugin {
  setSortAndFilter(allColumns: $.java.util.List): void {
    super.setSortAndFilter(allColumns);
    applyReportColumnPolicy(allColumns);
  }
}

const plugin = new SortAndFilterPlugin();
export { plugin, applyReportColumnPolicy };
```

**自动、接管与禁用**：
- 对允许自动处理的列不写 `setSort/setFilter`，也不把已有disable清为false；保留控件配置和前插件已确认的选择。金额排序同样保留。未知列/缺少某目标列无需新建事件。
- 指定禁止项同时设 `setSort/filter(false)` 与 `setDisableSort/Filter(true)`。只设false仍可能被自动路径重新开启；只设disable仍可能被先前true的插件接管分支绕过。
- 同一事件列表按插件顺序传递。本策略对上述禁止项拥有最终否决权，须排在其他处理之后或合并为统一处理器；平台没有不可覆盖的禁用锁，后续插件仍可再设true。
- 要接管时，查询插件须将同一次请求的 `FilterInfo.getHeadFilters()/getTableHeadFilterItems()` 和 `ReportQueryParam.getSortInfo()` 按已核字段映射应用到真实查询；未接管条件由平台对结果做二次过滤。排序/过滤责任不能只在界面插件改标记，不能解析QFilter字符串、漏掉权限过滤或把结果缓存当全库快照。

依据：[官方插件基类](https://vip.kingdee.com/knowledge/225997720761664000)说明设置后须自行过滤；[官方日期漏斗场景](https://vip.kingdee.com/knowledge/601888823231700992)展示取数插件消费列头条件。两文未给本机补丁保证；上述分支顺序来自本机7.0 SDK。未验证真实页面配置、插件顺序、数据库或KingScript绑定。

### 27. getComboItems - 获取下拉值事件

**方法签名**：`getComboItems(fieldKey: string, items: $.java.util.List): void`，元素为原生 `ValueMapItem`。

**触发边界**：本机7.0 `EnumProcessor` 先取 `ComboReportColumn.getComboItems()`；普通列再取 `FilterField` 枚举（包括按实体字段创建，以及 `fieldProperty` 的 `IFieldHandle` 回退）。仅完全没有 `FilterField` 时才调用插件。已有来源即使为空也不回退到本事件；最终空列表会关闭该列过滤。

**业务场景**：为已配置并由取数插件正确消费列头条件的普通动态 `ReportColumn` 增补状态和付款方式筛选项。列类型须是本机工厂识别的 `combofield`，并且没有上述元数据枚举来源；不把 `enum` 当作真实类型编码。本例 A–D、cash/transfer/check 仅是已约定的项目存储值，不是平台通用字典。

```typescript
/** 仅增补本项目无元数据枚举来源的动态报表列；不修改字段元数据或真实过滤值。 */
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { ValueMapItem } from "@cosmic/bos-core/kd/bos/entity";
import { LocaleString } from "@cosmic/bos-core/kd/bos/dataentity/entity";

class ComboItemsPlugin extends AbstractReportFormPlugin {
  /** 原列表由平台及前序插件传入；同值原项优先，重复调用不会重复追加本例选项。 */
  getComboItems(fieldKey: string, items: $.java.util.List): void {
    super.getComboItems(fieldKey, items);
    let choices: string[][];
    if (fieldKey === "kdec_bill_status") {
      choices = [["A", "暂存"], ["B", "已提交"], ["C", "已审核"], ["D", "已关闭"]];
    } else if (fieldKey === "kdec_pay_method") {
      choices = [["cash", "现金"], ["transfer", "银行转账"], ["check", "支票"]];
    } else {
      return;
    }
    // 同值已有项优先；保留原对象、多语言名称、图标、顺序与未知值。
    for (let n = 0; n < choices.length; n++) {
      const value = choices[n][0];
      let exists = false;
      for (let i = 0; i < items.size(); i++) {
        const current = items.get(i) as ValueMapItem;
        if (current != null && current.getValue() != null && String(current.getValue()) === value) {
          exists = true;
          break;
        }
      }
      if (!exists) {
        const item = new ValueMapItem();
        item.setValue(value);
        item.setName(new LocaleString(choices[n][1]));
        items.add(item);
      }
    }
  }
}
const plugin = new ComboItemsPlugin();
export { plugin };
```

**来源与接入**：
- [官方 KingScript 报表指南](https://vip.kingdee.com/knowledge/720653325691249152)确认事件用途为列头枚举集合调整，正文未限定具体版本。优先级、空来源不回退及载荷强转由目标7.0 `EnumProcessor/ReportColumnProcessorFactory/ReportViewPluginProxy` 确认。
- 原生消费者读 `ValueMapItem.getValue(): String` 和 `getName(): LocaleString`，序列化到 `comboItems`；普通 `{value, caption}` 对象不是该事件载荷。显示中文不能代替实际存储值。
- 代理按插件顺序传递同一列表。父方法本身不生成元数据默认项；本例保留已有对象、未知值、顺序、名称与多语言，仅补缺少值，不 `clear()`。原有重复项不擅自合并，后续插件仍可覆盖结果。
- 上游必须提供有效 `ValueMapItem`；保留已有项不表示 null/错误对象能被平台消费。缺值项不会被本例当成某个合法编码，仍须由上游字典校验处理。
- 若来源是 `ComboReportColumn` 或实体/字段元数据，应在该已确认的来源维护选项；不要靠清空此回调覆盖一个根本不会触发的事件。列头是否启用、绑定与取数处理仍按第26节，本文不承诺动态列自动过滤或真实页面已验。

### 28. setFloatButtomData - 格式化已有合计值

官方[报表表单插件KingScript指南](https://vip.kingdee.com/knowledge/720653325691249152)确认该方法名与合计行用途；正文未注明版本，以下事件字段及消费限制以本地7.0实现为准。

**真实签名**：`setFloatButtomData(summaryEvents: $.java.util.List): void`，目标 7.0 的拼写是 **Buttom**。`SummaryEvent` 提供 `getColumnName/getSrcSummaryValue/setFormatSummaryValue`；没有本例旧写法中的 `getFieldKey/setSummaryType/setCaption/setSummaryValue`。

**消费时机**：`ReportServiceImpl.getSummary` 已按数值合计列执行 `groupBy().sum()`；`ReportList` 只为已具有合计值的 `DecimalReportColumn` 且 `summary == 1` 构造事件，回调后只取回 `formatSummaryValue`。此事件不能设置聚合算法或创造不存在的列/事件，异步总计 `isAsyncTotal` 分支还会跳过这里的同步派发。

**业务场景**：保留金额和数量合计、加权均价、非空单号结果行计数及综合利润率。加权均价为 `sum(amount)/sum(qty)`；本例综合利润率明确采用 `(sum(amount)-sum(cost))/sum(amount)`，不能平均各行百分比或填固定 `28.5%`。金额、成本、数量必须取相同过滤范围，且可按同一币种/单位相加；否则先在取数层分别分组或按项目既有规则换算，不在格式化事件中暗做换算。

接入已有查询插件时，在**最终明细输出仍有 `kdec_billno`** 的位置调用 `withBillNumberCount(data)`；已有 `getColumns` 中只追加一次 `billNumberCountColumn()`。该贡献列按非null单号返回1/0，平台对它求和：重复单号多行分别计，空字符串仍非null，不把它称为去重单据数。若已经按供应商/物料聚合，须在聚合前生成贡献并按原组求和带到结果，不能在分组后补1再冒充明细行数。

本例要求现有输出别名 `kdec_amount/kdec_qty/kdec_cost/kdec_price/kdec_profit_rate` 与相应数值列一致，并提前启用 `summary=1`，这样价格/利润率列才有事件供覆盖显示；`kdec_billno_count` 是本例新增的**结果列**，不是新建业务表字段。成本合计缺失或分母为0时，派生值显示“—”，不补0。两个小数位与 `HALF_UP` 仅是本例展示口径，不改原始合计或存储金额。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { SummaryEvent } from "@cosmic/bos-core/kd/bos/report/events";
import { DataSet } from "@cosmic/bos-core/kd/bos/algo";
import { DecimalReportColumn, ReportColumn } from "@cosmic/bos-core/kd/bos/entity/report";
import { LocaleString } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { BigDecimal, RoundingMode } from "@cosmic/bos-script/java/math";

interface SummaryFields {
  amount: string;
  qty: string;
  price: string;
  cost?: string;
  profitRate?: string;
  count?: string;
}

/** 接入既有query的最终明细输出；按非null单号计结果行，重复单号各行分别计数。 */
function withBillNumberCount(data: DataSet, billField: "kdec_billno" | "billno" = "kdec_billno"): DataSet {
  if (billField !== "kdec_billno" && billField !== "billno") throw new Error("未知单号别名");
  return data.addField("CASE WHEN " + billField + " IS NULL THEN 0 ELSE 1 END", "kdec_billno_count");
}

/** 在既有getColumns中只添加一次；这是数值贡献的sum列，不把文本billno当数值合计列。 */
function billNumberCountColumn(): DecimalReportColumn {
  const column = new DecimalReportColumn();
  column.setFieldKey("kdec_billno_count");
  column.setDateIndex("kdec_billno_count");
  column.setFieldType(ReportColumn.TYPE_DECIMAL);
  column.setCaption(new LocaleString("非空单号结果行数"));
  column.setScale(0);
  column.setSummary(1);
  return column;
}

/** 源汇总为空/无法无损解读时保持未知，不把缺值或已丢精度的JS浮点补成0。 */
function decimalSummary(value: unknown): BigDecimal | null {
  if (value == null) return null;
  if (typeof value === "number" && !Number.isSafeInteger(value)) return null;
  const text = String(value);
  if (!/^[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(?:[eE][+-]?[0-9]+)?$/.test(text)) return null;
  try { return new BigDecimal(text); } catch (_) { return null; }
}

/** 两遍读取本次源合计，再改展示值；金额/数量/成本必须同一范围、币种和单位口径。 */
function formatReportTotals(events: $.java.util.List, fields: SummaryFields): void {
  const totals = new Map<string, BigDecimal | null>();
  const needed = new Set<string>([fields.amount, fields.qty]);
  if (fields.cost != null) needed.add(fields.cost);
  if (fields.count != null) needed.add(fields.count);
  for (let i = 0; i < events.size(); i++) {
    const event = events.get(i) as SummaryEvent;
    const key = event.getColumnName();
    if (!needed.has(key)) continue;
    if (totals.has(key)) throw new Error("汇总列标识重复：" + key);
    totals.set(key, decimalSummary(event.getSrcSummaryValue()));
  }
  const amount = totals.get(fields.amount);
  const qty = totals.get(fields.qty);
  const cost = fields.cost == null ? null : totals.get(fields.cost);
  const zero = new BigDecimal("0");
  for (let i = 0; i < events.size(); i++) {
    const event = events.get(i) as SummaryEvent;
    const key = event.getColumnName();
    if (key === fields.amount || key === fields.qty || key === fields.count) {
      const value = totals.get(key);
      if (value != null) event.setFormatSummaryValue(value.toPlainString());
    } else if (key === fields.price) {
      event.setFormatSummaryValue(amount == null || qty == null || qty.compareTo(zero) === 0
        ? "—" : amount.divide(qty, 2, RoundingMode.HALF_UP).toPlainString());
    } else if (fields.profitRate != null && key === fields.profitRate) {
      event.setFormatSummaryValue(amount == null || cost == null || amount.compareTo(zero) === 0
        ? "—" : amount.subtract(cost).multiply(new BigDecimal("100"))
          .divide(amount, 2, RoundingMode.HALF_UP).toPlainString() + "%");
    }
  }
}

/** 格式化同步合计事件；求和配置和计数贡献必须已由取数/列定义提供。 */
class SumReportFormPlugin extends AbstractReportFormPlugin {
  setFloatButtomData(events: $.java.util.List): void {
    super.setFloatButtomData(events);
    formatReportTotals(events, {
      amount: "kdec_amount", qty: "kdec_qty", price: "kdec_price",
      cost: "kdec_cost", profitRate: "kdec_profit_rate", count: "kdec_billno_count"
    });
  }
}
const plugin = new SumReportFormPlugin();
export { plugin, SumReportFormPlugin, formatReportTotals, decimalSummary, withBillNumberCount, billNumberCountColumn };
```

**验证与范围**：两遍扫描使价格/利润率事件在金额、数量之前出现时仍可计算。只读 `srcSummaryValue`，金额/数量的原平台格式在缺值时保留，未知列不修改。此处是同步前端合计展示，不修改 DataSet 中的单价/利润率，也不能据此前端显示推断导出/打印值已经改变；异步合计、二次过滤、分批与导出须分别核对真实消费者及范围，不缓存旧统计值复用。

### 29. setCellStyleRules - 自定义单元格样式规则

**方法签名**：`setCellStyleRules(cellStyleRules: $.java.util.List): void`，元素为原生 `CellStyleRule`。

**触发时机**：创建表格列时，由 `ReportList.getCellStyleRules` 派发并序列化规则。

**业务场景**：亏损标红、超预算标黄、逾期未付款标橙、利润率超过30%标绿，并使合计行不参与这些规则。第五个目的由每条规则共同的明细条件实现，不是另加一条客户名称等于“合计”的加粗规则。

**必需的项目合同**：在既有事件中保留父规则，再调用下面的 `appendBusinessCellStyles`。调用方传入两个已经确认并实际输出到客户端原始行变量的标记字段：`detailField` 为1表示业务明细、0表示总计/小计等非明细；`budgetComparableField` 为1表示本行金额与预算均非空、同币种和单位且可比较，否则为0。它们是项目输出合同，不是平台内置字段或待补的空解析器；没有真实字段及赋值实现时不能声称已接入。

利润、金额、预算、利润率须为JSON数值或null，不是带千分位/百分号的文本；逾期和已付须为Boolean或null。利润率用百分数点（30表示30%），保留原门槛30。真实数据若是比例小数，先确认转换口径，不直接改成0.3。金额的精确比较仍应由取数端保证，前端样式不作为财务校验或金额计算结果。

```typescript
/** 为已有报表事件追加真实CellStyleRule；明细/可比较标记必须由项目结果包提供。 */
import { CellStyleRule } from "@cosmic/bos-core/kd/bos/report/events";

interface BusinessStyleContract {
  detailField: string;
  budgetComparableField: string;
  profitRateUnit: "percentage-points";
}

/** 接收已核字段标识，避免把条件字符串或操作符当成字段插入表达式。 */
function styleFlag(key: string): string {
  if (typeof key !== "string" || !/^[A-Za-z_][A-Za-z0-9_]*$/.test(key) || /^(true|false|and|or|not|in)$/.test(key)) {
    throw new Error("样式标记须为已确认的表达式字段标识");
  }
  return "(" + key + " == 1)";
}

/**
 * 保留已有规则，追加亏损/超预算/逾期/高利润率四条；每条均排除非明细行。
 * detail=1仅表示业务明细；budgetComparable=1须同时确认金额/预算非空、同单位且可比较。
 * 数值为原始JSON number或null，布尔为true/false或null；利润率30表示30个百分点。
 */
function appendBusinessCellStyles(rules: $.java.util.List, contract: BusinessStyleContract): void {
  if (contract.profitRateUnit !== "percentage-points") {
    throw new Error("须确认利润率按百分数点输出，不能擅自将阈值30改为0.3");
  }
  const detail = styleFlag(contract.detailField);
  const comparable = styleFlag(contract.budgetComparableField);
  const specs: string[][] = [
    ["kdec_profit", "#FF4444", "#FFFFFF", "kdec_profit < 0"],
    ["kdec_amount", "#FFCC00", "", comparable + " && (kdec_amount > kdec_budget_amount)"],
    ["kdec_due_date", "#FF8800", "#FFFFFF", "kdec_is_overdue == true && kdec_paid == false"],
    ["kdec_profit_rate", "#22CC22", "#FFFFFF", "kdec_profit_rate > 30"]
  ];
  for (const spec of specs) {
    const rule = new CellStyleRule();
    rule.setFieldKey(spec[0]);
    rule.setBackgroundColor(spec[1]);
    if (spec[2] !== "") rule.setForeColor(spec[2]);
    rule.setDegree(100);
    rule.setCondition(detail + " && (" + spec[3] + ")");
    rules.add(rule);
  }
}

export { appendBusinessCellStyles, BusinessStyleContract };
```

**真实消费与范围**：
- [官方单元格背景色说明](https://vip.kingdee.com/knowledge/142314532835535104)使用 `CellStyleRule/setForeColor/setBackgroundColor/setDegree/setCondition`，条件与表达式计算器一致。原文未标具体版本；本机7.0序列化为 `fieldKey/style:{fc,bc,dg}/cond`，没有 `fontWeight`。`degree` 范围为0–100，本例100；已核本机前端的样式转换函数未消费dg，不承诺调整透明度已在页面生效。
- 本机前端先经 `analysClientAction` 归一化，再交 `expr-eval`；它不是任意JavaScript。`&&` 能在此链转换为逻辑运算，但不能使用任意函数、对象访问或将 `x != null` 当作JS空值守卫；此引擎把null视为未定义变量。数值与null比较还可能隐式转为0，因此黄色规则先判断取数端提供的可比较标记，不能把未知预算当0。
- 保留父规则并追加本例规则，同一单元格后命中的规则可覆盖前面的属性。数据包自带样式、单元格规则、行/列样式存在各自优先级；本例不清除其他插件的规则，也不承诺它们不会命中合计。黄色规则未设前景时原生DTO仍为null；若按已核载荷传入客户端，null也可能覆盖此前前景，不能把未调用setter等同于继承原色；最终传输序列化须按目标页面核对。
- 标记需进入实际表达式数据包。原生汇总由独立 `floatBottomData` 下发，未保证含项目标记；缺变量可能警告并跳过规则，不能据此宣称正式总计路径已验。要无警告地排除所有汇总行，项目还须保证该数据包标记为0。客户端 `rowPinned` 仅在求值之后覆盖背景，前景仍可能保留，不能把固定行当成自动排除。
- 本例处理页面条件样式。真实字段/类型、合计包、分批、固定行、后续插件和前端加载版本需项目核对；Excel导出行样式属于另一个事件，不能承诺此规则自动用于导出或打印。

### 30. setExcelName - 自定义报表导出名称

**目标签名**：`setExcelName(list: $.java.util.List): void`；实际消费者为 `kd.bos.report.export.AbstractReportExport.getFilename(String)`，注意方法名的 `n` 为小写。

**触发与命名权**：本机7.0导出器先准备默认“标题-时间-用户名”，再创建**空**字符串List传给插件。代理按顺序共享此List，最后只消费第0项；追加多项不会生成多个文件名。空List保留默认名，非空List的首项即使命名为空串也会覆盖默认，null首项还会在取长度时异常。本例只在List仍为空时提供名称，不清空或修复其他插件的项；已有命名冲突由插件责任和顺序解决。

**业务能力与前提**：保留“销售报表+查询月份范围+组织名称”，同月仅写一次月份，跨月写起止月份；两端日期都有值才附加范围，无组织则不附加组织。`kdec_startdate/kdec_enddate` 须为项目真实日期字段，`kdec_org` 须为含name的基础资料，且与本次导出所用条件一致。只支持整月标签的命名意图；若导出有日/时精度过滤，月份名称不能代替完整条件说明。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { SimpleDateFormat } from "@cosmic/bos-script/java/text";

/**
 * 为尚未命名的导出追加一个不含扩展名的名称。
 * 已有列表属于前插件；候选为空白或超出平台150个UTF-16单元时保持空列表，由平台生成默认名。
 * 本函数不清空、截断或修复其他插件的项；调用方负责文件名内容与真实导出结果范围一致。
 */
export function appendExportBaseName(list: $.java.util.List, baseName: string): boolean {
  if (!list.isEmpty() || baseName.trim().length === 0 || baseName.length > 150) return false;
  list.add(baseName);
  return true;
}

/**
 * 项目须确认日期与组织字段：日期为平台映射的Date，组织为带name的DynamicObject。
 * 两端日期都有值才附加月份范围；查询条件与实际导出数据是否一致仍由项目流程保证。
 */
class ExcelNamePlugin extends AbstractReportFormPlugin {
  setExcelName(list: $.java.util.List): void {
    super.setExcelName(list);
    if (!list.isEmpty()) return;
    const startDate = this.getModel().getValue("kdec_startdate") as Date | null;
    const endDate = this.getModel().getValue("kdec_enddate") as Date | null;
    const org = this.getModel().getValue("kdec_org") as DynamicObject | null;
    let fileName = "销售报表";
    if (startDate != null && endDate != null) {
      const format = new SimpleDateFormat("yyyy年MM月");
      const startText = format.format(startDate);
      const endText = format.format(endDate);
      fileName += "_" + (startText === endText ? startText : startText + "至" + endText);
    }
    const orgName = org == null ? null : org.getString("name");
    if (orgName != null && orgName.trim().length > 0) fileName += "_" + orgName;
    appendExportBaseName(list, fileName);
  }
}

const plugin = new ExcelNamePlugin();
export { plugin };
```

**长度、日期和文件边界**：

- 真实消费者检查首项Java `String.length()`，超过150个UTF-16单元直接报错；JavaScript字符串的length也是UTF-16单元数，表情等补充字符占两个。helper拒绝空白或过长候选，保持空List走平台默认，不截断可能承载业务含义的日期/组织名称。返回false表示本插件未写入自定义名称；默认名称不保证包含原定月份/组织。
- 普通及大数据Excel路径在自定义名称后追加 `.xlsx`，拆文件时还可能追加 `_序号`；150限制针对插件提供的基础名，不代表最终含序号/扩展名或路径的总长度。因此本事件只给基础名，不能先拼后缀或把List后续项当备用名；Sheet名称由独立规则决定，此处不修改Sheet。
- 本机脚本初始化将全局 `Date` 绑定为 `ScriptDate`，存在getFullYear/getMonth及java.util.Date解包能力，不能据Java日期体系就断言这些旧写法不存在。本例复用真实 `SimpleDateFormat` 与声明映射的Date，未虚构 `java/util` 的Date导出；运行时默认时区会影响月份边界，跨时区业务须使用项目确认的日期口径。
- 附录采购名称保留“运行时当前年月”含义，不冒充查询日期范围。页面当前模型与导出快照是否同源、异步过程的时区/条件变化、用户自定义名称字符和实际下载结果仍需项目验证。这里验证的是命名入口，不代表完成Excel导出或整篇附录可编译。

**依据**：[官方报表基类说明](https://vip.kingdee.com/knowledge/225997720761664000)明确仅取第一个元素，[KingScript报表指南](https://vip.kingdee.com/knowledge/720653325691249152)确认事件用途；两篇未声明本入口的最低版本。本机7.0导出器、代理、随包声明和ScriptDate桥接补充首项、150单元、后缀与日期合同。

### 31. setMergeColums - 自定义报表融合列

**目标签名**：`setMergeColums(columns: $.java.util.List): void`。平台使用 `Colums` 这一拼写，比 `Columns` 少一个 n。

**触发与数据合同**：创建报表列时，`ReportList` 创建列名列表，`ReportViewPluginProxy` 按插件顺序传递同一列表，最后下发 `mergeColumns`。本例保留客户名称、区域、部门三列的视觉融合，并保留前插件的列名和顺序。列必须实际存在于本次结果中；名称列只按自身值比较，不代表客户或部门主键。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";

class MergeColumnPlugin extends AbstractReportFormPlugin {

  /** 在共享列清单中幂等增补；不清空前插件配置，不改变结果行或业务排序。 */
  setMergeColums(columns: $.java.util.List): void {
    super.setMergeColums(columns);
    for (const field of ["kdec_customer_name", "kdec_region", "kdec_dept_name"]) {
      if (!columns.contains(field)) columns.add(field);
    }
  }
}

let plugin = new MergeColumnPlugin();
export { plugin };
```

**融合行为与业务边界**：

- 三列各自融合相邻同值单元格，区域/部门不会先按客户分组。同名不同客户也可能融合；业务若要求客户之间分开，须以真实客户分组键、稳定排序及行载荷合同控制边界，不能仅凭客户名称推断身份。
- 本机前端按严格相等比较；数组载荷只比较第0项，`1` 与 `"1"` 不同，两个 `null` 可以融合。不会替插件排序、聚合或删除数据，不能因视觉融合扣减第32节总数。
- 虚拟加载使用最近的前一、当前、后一连续数据块，按真实 `rowKey` 首尾连续关系衔接；快速跳转可重置窗口。可跨已接续块边界，不保证全结果任意跨页永久融合。过滤、排序或重新查询改变输入后按新顺序重算。
- 官方还提供 `PackageDataEvent.getNoMergeKey()`。本机消费者将清单送入行的 `cprop.nomerge`，该标记只阻止**当前行向前**融合；下一行仍可能与它融合。要让小计行两侧均隔离，需真实小计标识、对应列和下一行边界合同，不能用显示文本猜小计，也不能把一次标记当永久不融合锁。此处不添加缺少业务标识的打包插件。
- Excel 合并另走 `exportInitialize(ReportExportInitializeEvent)` 与 `MergeColumnRule`，分组字段和合并字段分别配置；页面列清单不会自动变成导出规则。导出按分组值决定合并，须保证组内被合并字段值一致；见[导出融合场景](报表表单插件-场景拆分/mergeColumnsAndLimitData.md)。页面、Excel和打印的最终效果须分别验证。

**依据**：[官方页面行融合](https://vip.kingdee.com/knowledge/311516534692807680) 标记 `BOS_V_5.0`；[官方导出合并](https://vip.kingdee.com/knowledge/494615674082175744) 标记 `BOS_V6.0.1`；[KingScript报表指南](https://vip.kingdee.com/knowledge/720653325691249152)说明事件用途但未标最低版本。具体签名和上述连续块、比较、标记消费来自本机7.0声明/JAR及前端资源；未据此确认项目部署版本、真实行标识或页面/导出验收。

### 32. resetDataCount - 重设报表总行数

**目标签名**：本机7.0随包声明为可选 `resetDataCount?(): number`，Java入口为可空 `Integer resetDataCount()`。这是不同层的声明合同，不能用 `any` 掩盖差异，也不能将 `number | null` 写成目标声明已允许的覆写。

**触发与影响**：`ReportList.getData` 先取本块行数据并打包，之后读取模型总数并调用该事件。非null返回值只覆盖本次响应的 `datacount` 并置 `resetDataCount=true`，不会回改已返回的rows、模型行数或queryId。它不仅是底部文字：前端用它初始化虚拟行数并判断加载终点，错误总数可能让后续数据不再请求。

`ReportListModel.getRowData` 先按起点/长度/树范围获取RowSet，转换集合后才派发 `processRowData`，不会按处理后集合重新计算全结果总数。因此官方增删行用途确实存在，但本块 `collection.size()` 仍不能给出完整最终计数。

**本例的处理**：第31节仅改变视觉融合，没有增删分页结果行；附录也没有完整最终计数合同，因此保持**不覆写此可选事件**。不因小计/合计或树叶节点猜测总数，不返回固定99、不拿第15节物化缓存计数充当分页总数，也不新增返回估值的解析器。已有项目实现了完整的同次最终计数时，仍可通过此真实入口返回一个 `number`；此处未提供缺少该合同的可粘贴覆写插件。

**默认数与插件顺序**：

- Java基类返回null。代理按顺序保留最后一个非null返回值；后插件返回null不能撤销前插件覆盖。因而“不覆写”只表示本插件不贡献覆盖值，不能承诺清除别的插件设置。若需撤销错误覆盖，应修正其责任插件及顺序。
- `ReportList.getTotalRecords()` 读取该控件模型的默认总数，其中 `getRowCount()` 应用按pageId/ctrlId保存的 `ReportResultLimit`；它不读取本次插件覆盖后的datacount。默认数、模型结果计数、完整明细数和分组数的口径不能直接互换，数值在无截断等条件下可能相同；不能无条件作为纠正数返回。
- 本机 `ReportTaskResult` 的行数和结果ID还会随二次过滤切换。Java中有方法不表示KingScript随包声明已导出这些方法；不能虚构结构类型后宣称获得同次最终计数。
- 响应 `queryId` 来自模型结果ID；模型查询时另存的 `reportQueryId` 请求UUID并非这个ID，不能以名称相近替代绑定。

**接入自定义计数前必须成立的项目合同**：

1. 计数属于本次同一 `pageId/ctrlId/queryId` 的**完整最终分页结果**，并绑定本次过滤、权限、排序、分组、结果限制和查询代次；不能累计各块回调次数或复用上次查询数字。
2. 真实增加/删除结果行的逻辑与分页起点、请求长度、返回rows和最终终点一致。需明确合计是否属于分页行、树级别/父节点范围以及大数据是否全部完成；仅改datacount不会修复错位或漏取的rows。
3. 返回值为有限非负整数且不超过Java `Integer` 上界2147483647；不以0表达“未知”。普通平面分页还应检查数值不少于本块 `startIndex + rows.length`（前提是每个返回项都是实际分页行）。这些检查只能发现矛盾，不能推导正确总数。
4. 在过滤/排序/重新查询、快速翻块、零行、有合计、限行、多插件及项目真实模式下验证完整结果与请求终点。当前样例未提供这个合同，不能把上述条件当作已经实现的取数适配器。

**本机消费者的可复核区别**：

| 模式或状态 | 已确认消费 | 实施含义 |
|---|---|---|
| 普通虚拟分页 | 当datacount不大于请求末端时，将其作为successCallback的lastRow；原rows仍传入 | 压低数值可能提前结束，抬高会延后结束；不能只看页脚 |
| 服务端模式且datacount为0 | 可直接successCallback([],0)，阻止后续取数 | 不能用0作尚未完成/尚未取得总数的占位 |
| 大数据 | 非isLast时终点为-1，isLast才使用datacount；首块还有特殊处理 | 不把普通分页判定套到尚未完成的大数据结果 |
| 树形 | 本级返回数不足pagerows时，按startIndex加本级实际rows长度结束 | 全树叶节点总数不是每个节点范围的通用分页数 |
| 查询代次 | 已有相同queryId时不重建dataSource | 旧查询数不可跨代复用，同ID改数也不保证重置初始状态 |

**依据与验证边界**：[KingScript报表指南](https://vip.kingdee.com/knowledge/720653325691249152)说明此事件用于 `processRowData` 增减行后的总数修正，但未提供项目最终计数合同。本机7.0的ReportList、模型/代理及前端资源补充上述响应与分页行为；已确认签名不等于KingScript可空返回桥接已验。真实查询、取数适配、页面分页、权限范围和部署版本仍须项目验证。

## 附录：完整的报表插件组合示例

### 业务场景

采购价格分析报表：按供应商、物料维度统计采购均价及波动，支持左树选择组织、列头过滤排序、合计行、条件样式、自定义导出名。

### 报表查询插件

```typescript
import { AbstractReportListDataPlugin } from "@cosmic/bos-core/kd/bos/entity/report";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class PurchasePriceAnalysisDataPlugin extends AbstractReportListDataPlugin {

  query(queryParam: any, selectedObj: any): any {
    let filters: QFilter[] = [];

    // 左树选中的组织
    if (selectedObj != null) {
      filters.push(new QFilter("org", QCP.equals, selectedObj.toString()));
    }

    // 过滤面板条件
    let filterItems = queryParam.getFilter().getFilterItems();
    for (let item of filterItems) {
      if ("kdec_startdate" === item.getPropName()) {
        filters.push(new QFilter("bizdate", QCP.ge, item.getValue()));
      } else if ("kdec_enddate" === item.getPropName()) {
        filters.push(new QFilter("bizdate", QCP.le, item.getValue()));
      } else if ("kdec_supplier.id" === item.getPropName()) {
        filters.push(new QFilter("supplier", QCP.in, item.getValue()));
      }
    }

    this.setProgress(0);

    // 查询采购明细
    let dataSet = QueryServiceHelper.queryDataSet(
      this.getClass().getName(),
      "pm_purorderbill",
      "supplier.name as kdec_supplier_name, "
        + "billentry.material.name as kdec_material_name, "
        + "billentry.priceandtax as kdec_price, "
        + "billentry.qty as kdec_qty, "
        + "billentry.amountandtax as kdec_amount",
      filters.length > 0 ? filters : null,
      null
    );
    this.setProgress(50);

    // 按供应商+物料分组统计
    let resultDataSet = dataSet.copy()
      .groupBy(["kdec_supplier_name", "kdec_material_name"])
      .sum("kdec_qty", "kdec_total_qty")
      .sum("kdec_amount", "kdec_total_amount")
      .avg("kdec_price", "kdec_avg_price")
      .min("kdec_price", "kdec_min_price")
      .max("kdec_price", "kdec_max_price")
      .count("kdec_order_count")
      .finish();
    this.setProgress(100);

    return resultDataSet;
  }
}

let plugin = new PurchasePriceAnalysisDataPlugin();
export { plugin };
```

### 报表表单插件

开始日期使用第14节同一verifyQuery校验。完成统计须按第15节接入取数成功出口，本组合不在beforeQuery/afterQuery提前报告完成；现有取数未提供该物化统计合同。

列头排序/过滤使用控件的自动能力，本组合不声明插件接管。须启用控件对应设置，并满足数据源绑定、列类型和行数限制；若项目要接管，先按第26节在取数插件落实条件与排序映射。此处查询示例未实现该接管合同，不能仅将事件全部设为true。

列定义须把 `kdec_total_amount/kdec_total_qty/kdec_avg_price` 设为数值合计列（`summary=1`）；下面沿用第28节同一纯格式化逻辑，均价由金额合计除数量合计，不平均组均价。此附录已有查询按供应商/物料分组，`kdec_order_count` 的 `.count()` 是分组内明细行计数，不据此宣称去重单据数。

```typescript
import { AbstractReportFormPlugin } from "@cosmic/bos-core/kd/bos/report/plugin";
import { RequestContext } from "@cosmic/bos-core/kd/bos/context";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";
import { ArrayList } from "@cosmic/bos-script/java/util";
import { SimpleDateFormat } from "@cosmic/bos-script/java/text";

import { ReportQueryParam, FilterItemInfo } from "@cosmic/bos-core/kd/bos/entity/report";
import { SummaryEvent, CellStyleRule } from "@cosmic/bos-core/kd/bos/report/events";
import { BigDecimal, RoundingMode } from "@cosmic/bos-script/java/math";

/**
 * 为尚未命名的导出追加一个不含扩展名的名称。
 * 已有列表属于前插件；候选为空白或超出平台150个UTF-16单元时保持空列表，由平台生成默认名。
 * 本函数不清空、截断或修复其他插件的项；调用方负责文件名内容与真实导出结果范围一致。
 */
export function appendExportBaseName(list: $.java.util.List, baseName: string): boolean {
  if (!list.isEmpty() || baseName.trim().length === 0 || baseName.length > 150) return false;
  list.add(baseName);
  return true;
}

interface SummaryFields {
  amount: string;
  qty: string;
  price: string;
  cost?: string;
  profitRate?: string;
  count?: string;
}

/** 源汇总为空/无法无损解读时保持未知，不把缺值或已丢精度的JS浮点补成0。 */
function decimalSummary(value: unknown): BigDecimal | null {
  if (value == null) return null;
  if (typeof value === "number" && !Number.isSafeInteger(value)) return null;
  const text = String(value);
  if (!/^[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(?:[eE][+-]?[0-9]+)?$/.test(text)) return null;
  try { return new BigDecimal(text); } catch (_) { return null; }
}

/** 两遍读取本次源合计，再改展示值；金额/数量/成本必须同一范围、币种和单位口径。 */
function formatReportTotals(events: $.java.util.List, fields: SummaryFields): void {
  const totals = new Map<string, BigDecimal | null>();
  const needed = new Set<string>([fields.amount, fields.qty]);
  if (fields.cost != null) needed.add(fields.cost);
  if (fields.count != null) needed.add(fields.count);
  for (let i = 0; i < events.size(); i++) {
    const event = events.get(i) as SummaryEvent;
    const key = event.getColumnName();
    if (!needed.has(key)) continue;
    if (totals.has(key)) throw new Error("汇总列标识重复：" + key);
    totals.set(key, decimalSummary(event.getSrcSummaryValue()));
  }
  const amount = totals.get(fields.amount);
  const qty = totals.get(fields.qty);
  const cost = fields.cost == null ? null : totals.get(fields.cost);
  const zero = new BigDecimal("0");
  for (let i = 0; i < events.size(); i++) {
    const event = events.get(i) as SummaryEvent;
    const key = event.getColumnName();
    if (key === fields.amount || key === fields.qty || key === fields.count) {
      const value = totals.get(key);
      if (value != null) event.setFormatSummaryValue(value.toPlainString());
    } else if (key === fields.price) {
      event.setFormatSummaryValue(amount == null || qty == null || qty.compareTo(zero) === 0
        ? "—" : amount.divide(qty, 2, RoundingMode.HALF_UP).toPlainString());
    } else if (fields.profitRate != null && key === fields.profitRate) {
      event.setFormatSummaryValue(amount == null || cost == null || amount.compareTo(zero) === 0
        ? "—" : amount.subtract(cost).multiply(new BigDecimal("100"))
          .divide(amount, 2, RoundingMode.HALF_UP).toPlainString() + "%");
    }
  }
}

/** 必填开始条件须是本例唯一非空项；日期类型、格式及区间有效性由真实过滤元数据和业务校验负责。 */
function hasRequiredStartDate(queryParam: ReportQueryParam): boolean {
  const filter = queryParam.getFilter();
  if (filter == null) return false;
  const items = filter.getFilterItems("kdec_startdate");
  if (items == null || items.size() !== 1) return false;
  const value: unknown = (items.get(0) as FilterItemInfo).getValue();
  return value != null && !(typeof value === "string" && value.trim() === "");
}

class PurchasePriceAnalysisFormPlugin extends AbstractReportFormPlugin {

    queryParam.getFilter().addFilterItem("kdec_enddate", now);

  // 过滤面板基础资料选择前过滤

      filters.add(new QFilter("status", QCP.equals, "C"));

  }

  /** 保留已有规则；价格波动按同币种同单位的原始数值输出，大于50时红底白字。 */
  setCellStyleRules(cellStyleRules: $.java.util.List): void {
    super.setCellStyleRules(cellStyleRules);
    const rule = new CellStyleRule();
    rule.setFieldKey("kdec_price_range");
    rule.setBackgroundColor("#FF4444");
    rule.setForeColor("#FFFFFF");

    cellStyleRules.add(rule);
  }

  /** 仅按供应商名称的相邻值视觉融合；不代表供应商身份或再次分组，详见第31节。 */
  setMergeColums(columns: $.java.util.List): void {
    super.setMergeColums(columns);
    if (!columns.contains("kdec_supplier_name")) columns.add("kdec_supplier_name");
  }

  /** 保留前插件名称；当前月份来自脚本运行时，不将其等同查询日期范围。 */
  setExcelName(list: $.java.util.List): void {
    super.setExcelName(list);
    if (!list.isEmpty()) return;
    appendExportBaseName(list, "采购价格分析报表_" + new SimpleDateFormat("yyyyMM").format(new Date()));
  }
```

## 注意事项

1. **报表查询插件和表单插件成对注册**：取数插件注册在报表列表节点，表单插件注册在页面根节点
2. **报表数据只读**：使用 `QueryServiceHelper` 而非 `BusinessDataServiceHelper`
3. **大数据量使用 DataSet**：通过 `QueryServiceHelper.queryDataSet` 获取 DataSet，利用 `groupBy`、`join`、`union` 进行数据加工
4. **无状态设计**：插件类中不要定义类属性，所有数据使用局部变量
5. **遵守 SDK 限流**：单次查询不超过 50,000 行，查询字段不超过 100 个
6. **条件样式的 condition**：使用设计器表达式及目标前端支持的语法，见第29节。附录价格波动保留原数值阈值50，要求原始JSON数值或null；总计排除须另接已确认的明细标记，不从供应商/物料名称猜测。
7. **进度条**：耗时查询中使用 `setProgress` 给用户反馈
