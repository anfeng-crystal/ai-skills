# 调度任务开发指南

## 摘要
金蝶云苍穹调度任务提供定时和周期性执行业务逻辑的能力，通过实现 AbstractTask 接口开发执行程序，配合调度作业和调度计划完成任务注册和调度管理。支持 Cron 表达式配置和代码动态创建。

## 适用版本
- 金蝶云苍穹 V5.0+

## 核心概念

### 调度体系架构

| 概念 | 说明 | 对应实体 |
|------|------|----------|
| 调度执行程序 | 定义任务的执行逻辑（Java类） | `sch_taskdefine` |
| 调度作业 | 配置执行程序和运行参数 | `sch_job` |
| 调度计划 | 配置触发时间（Cron表达式、起止时间） | `sch_schedule` |

### 执行流程

1. 开发执行程序（Java类继承 `AbstractTask`）
2. 注册调度执行程序
3. 创建调度作业（关联执行程序，配置参数）
4. 创建调度计划（关联作业，配置 Cron 和时间范围）
5. 启用调度计划

## 详细内容

### 一、开发执行程序

#### 1.1 基本接口

```java
package com.example.schedule;

import kd.bos.schedule.executor.AbstractTask;
import kd.bos.context.RequestContext;
import kd.bos.logging.Log;
import kd.bos.logging.LogFactory;

import java.util.Map;

/**
 * 调度任务执行程序示例
 * 继承 AbstractTask，实现 execute 方法
 */
public class DailyReportTask extends AbstractTask {

    private static final Log logger = LogFactory.getLog(DailyReportTask.class);

    @Override
    public void execute(RequestContext ctx, Map<String, Object> param) throws KDException {
        logger.info("开始执行日报生成任务...");

        try {
            // 获取运行参数
            String reportType = (String) param.get("reportType");
            String dateRange = (String) param.get("dateRange");

            // 执行业务逻辑
            generateDailyReport(reportType, dateRange);

            logger.info("日报生成任务执行完成");
        } catch (Exception e) {
            logger.error("日报生成任务执行失败", e);
            throw e;
        }
    }

    private void generateDailyReport(String reportType, String dateRange) {
        // 具体业务逻辑
        // 如：查询数据、生成报表、发送通知等
    }
}
```

#### 1.2 带数据处理的任务

```java
package com.example.schedule;

import kd.bos.schedule.executor.AbstractTask;
import kd.bos.context.RequestContext;
import kd.bos.dataentity.entity.DynamicObject;
import kd.bos.orm.query.QFilter;
import kd.bos.orm.query.QCP;
import kd.bos.servicehelper.QueryServiceHelper;
import kd.bos.servicehelper.SaveServiceHelper;
import kd.bos.servicehelper.BusinessDataServiceHelper;

import java.util.Date;
import java.util.Map;

/**
 * 定时数据清理任务
 * 定期清理过期的临时数据
 */
public class DataCleanupTask extends AbstractTask {

    @Override
    public void execute(RequestContext ctx, Map<String, Object> param) throws KDException {
        // 获取参数：保留天数
        int retentionDays = 30;
        if (param.containsKey("retentionDays")) {
            retentionDays = Integer.parseInt(param.get("retentionDays").toString());
        }

        // 计算截止日期
        java.util.Calendar cal = java.util.Calendar.getInstance();
        cal.add(java.util.Calendar.DAY_OF_MONTH, -retentionDays);
        Date cutoffDate = cal.getTime();

        // 查询需要清理的数据
        QFilter dateFilter = new QFilter("createtime", QCP.less_than, cutoffDate);
        QFilter statusFilter = new QFilter("billstatus", QCP.equals, "C"); // 已关闭

        DynamicObject[] expiredData = BusinessDataServiceHelper.load(
            "your_temp_entity",
            "id,billno,createtime",
            new QFilter[]{dateFilter, statusFilter}
        );

        if (expiredData.length > 0) {
            // 分批处理，每批100条
            int batchSize = 100;
            for (int i = 0; i < expiredData.length; i += batchSize) {
                int end = Math.min(i + batchSize, expiredData.length);
                DynamicObject[] batch = java.util.Arrays.copyOfRange(expiredData, i, end);
                // 执行删除或归档操作
                kd.bos.servicehelper.operation.DeleteServiceHelper.delete(
                    "your_temp_entity", batch
                );
            }
        }
    }
}
```

### 二、注册调度执行程序

#### 2.1 通过界面注册

路径：【开发平台】→ 搜索 `sch_taskdefine`（调度执行程序）→ 列表预览

1. 点击【新增】
2. 填写编码和名称
3. 输入执行类的完整类名（如 `com.example.schedule.DailyReportTask`）
4. 可选：定义运行参数
5. 保存

#### 2.2 运行参数配置

在调度执行程序中定义参数，在调度作业中赋值：

| 配置位置 | 说明 |
|----------|------|
| 调度执行程序（sch_taskdefine） | 定义参数名称和类型 |
| 调度作业（sch_job） | 从调度作业**列表**进入，配置参数值 |

> **注意**：从调度计划点击进入调度作业**不能**修改参数，必须从调度作业列表进入。

### 三、创建调度作业和计划

#### 3.1 界面配置方式

1. 进入【调度作业】列表，新增调度作业
2. 选择已注册的执行程序
3. 配置运行参数值
4. 进入【调度计划】，新增调度计划
5. 关联调度作业
6. 配置 Cron 表达式和起止时间
7. 启用调度计划

#### 3.2 代码动态创建方式

```java
import kd.bos.schedule.api.JobInfo;
import kd.bos.schedule.api.JobType;
import kd.bos.schedule.api.PlanInfo;
import kd.bos.servicehelper.DispatchServiceHelper;
import kd.bos.servicehelper.QueryServiceHelper;
import kd.bos.servicehelper.SaveServiceHelper;
import kd.bos.servicehelper.BusinessDataServiceHelper;
import kd.bos.orm.query.QFilter;
import kd.bos.orm.query.QCP;

import java.util.*;

/**
 * 调度任务辅助类
 * 通过代码创建和管理调度作业、调度计划
 */
public class ScheduleHelper {

    /**
     * 创建调度作业
     * @param data 单据数据（包含编号、名称、参数等）
     * @return 调度作业ID
     */
    public Object createJob(DynamicObject data) {
        Map<String, Object> param = new HashMap<>();
        // 设置执行程序的参数（在 execute 方法中通过 param 获取）
        param.put("billId", data.get("id"));

        String billno = data.getString("billno");
        String name = data.getString("name");
        String taskClassname = "com.example.schedule.DailyReportTask";
        long runByUserId = Long.parseLong(
            ((DynamicObject) data.get("creator")).getPkValue().toString()
        );

        JobInfo job = new JobInfo();
        job.setNumber(billno);                    // 作业编码
        job.setName(name);                        // 作业名称
        job.setRunByUserId(runByUserId);          // 负责人
        job.setJobType(JobType.BIZ);              // 作业类型：业务
        job.setTaskClassname(taskClassname);       // 执行程序类名
        job.setParams(param);                     // 运行参数
        job.setAppId("your_app_id");              // 应用ID
        job.setRunConcurrently(false);            // 串行执行

        // 调用平台服务创建调度作业
        Object jobId = DispatchServiceHelper.invokeBOSService(
            "JobDispatcher", "createJob", job
        );
        return jobId;
    }

    /**
     * 创建调度计划
     * @param jobId 关联的调度作业ID
     * @param data 单据数据（包含计划时间、Cron表达式等）
     */
    public void createSchedule(Object jobId, DynamicObject data) {
        PlanInfo planInfo = new PlanInfo();
        planInfo.setJobId(jobId.toString());
        planInfo.setNumber(data.getString("billno"));
        planInfo.setName(data.getString("name"));

        // 设置调度计划开始时间
        Date startTime = (Date) data.get("starttime");
        Calendar startCal = Calendar.getInstance();
        startCal.setTime(startTime);
        planInfo.setStartTime(startCal);

        // 设置调度计划结束时间
        Date endTime = (Date) data.get("endtime");
        Calendar endCal = Calendar.getInstance();
        endCal.setTime(endTime);
        planInfo.setEndTime(endCal);

        // 设置 Cron 表达式
        String cronExpression = (String) data.get("cron_plan");
        planInfo.setCronExpression(cronExpression);

        // 创建调度计划
        DispatchServiceHelper.invokeBOSService(
            "JobDispatcher", "createPlan", planInfo
        );
    }

    /**
     * 更新调度作业
     */
    public void updateJob(Object jobId, DynamicObject data) {
        DynamicObject jobData = BusinessDataServiceHelper.loadSingle(jobId, "sch_job");
        jobData.set("name", data.getString("name"));
        SaveServiceHelper.save(new DynamicObject[]{jobData});
    }

    /**
     * 更新调度计划
     */
    public void updateSchedule(Object scheduleId, DynamicObject data) {
        DynamicObject scheduleData = BusinessDataServiceHelper.loadSingle(
            scheduleId, "sch_schedule"
        );
        scheduleData.set("name", data.getString("name"));
        scheduleData.set("starttime", data.get("starttime"));
        scheduleData.set("endtime", data.get("endtime"));
        scheduleData.set("plan", data.get("cron_plan"));
        SaveServiceHelper.save(new DynamicObject[]{scheduleData});
    }
}
```

#### 3.3 在操作插件中创建调度任务

```java
/**
 * 在单据保存操作后，自动创建/更新调度任务
 */
public class CreateScheduleOnSavePlugin extends AbstractOperationServicePlugIn {

    @Override
    public void onPreparePropertys(PreparePropertysEventArgs e) {
        super.onPreparePropertys(e);
        e.getFieldKeys().add("id");
        e.getFieldKeys().add("billno");
        e.getFieldKeys().add("name");
        e.getFieldKeys().add("starttime");
        e.getFieldKeys().add("endtime");
        e.getFieldKeys().add("cron_plan");
        e.getFieldKeys().add("enable_schedule");
    }

    @Override
    public void afterExecuteOperationTransaction(AfterOperationArgs e) {
        super.afterExecuteOperationTransaction(e);

        DynamicObject[] dataEntities = e.getDataEntities();
        ScheduleHelper helper = new ScheduleHelper();

        for (DynamicObject data : dataEntities) {
            if (data.getBoolean("enable_schedule")) {
                String number = data.getString("billno");
                QFilter numberFilter = new QFilter("number", QCP.equals, number);

                Object jobId;
                // 检查是否已存在调度作业
                if (QueryServiceHelper.exists("sch_job", new QFilter[]{numberFilter})) {
                    jobId = QueryServiceHelper.queryPrimaryKeys(
                        "sch_job", new QFilter[]{numberFilter}, "id desc", 1
                    ).get(0);
                    helper.updateJob(jobId, data);
                } else {
                    jobId = helper.createJob(data);
                }

                // 检查并创建/更新调度计划
                QFilter jobFilter = new QFilter("job", QCP.equals, jobId);
                if (QueryServiceHelper.exists("sch_schedule", new QFilter[]{jobFilter})) {
                    Object scheduleId = QueryServiceHelper.queryPrimaryKeys(
                        "sch_schedule", new QFilter[]{jobFilter}, "id desc", 1
                    ).get(0);
                    helper.updateSchedule(scheduleId, data);
                } else {
                    helper.createSchedule(jobId, data);
                }
            }
        }
    }
}
```

### 四、Cron 表达式

苍穹调度任务使用标准 Cron 表达式（6位）：

```
秒 分 时 日 月 周
```

| 位置 | 取值范围 | 特殊字符 |
|------|----------|----------|
| 秒 | 0-59 | , - * / |
| 分 | 0-59 | , - * / |
| 时 | 0-23 | , - * / |
| 日 | 1-31 | , - * / ? |
| 月 | 1-12 | , - * / |
| 周 | 1-7 | , - * / ? |

常用示例：

| 表达式 | 说明 |
|--------|------|
| `0 0 8 * * ?` | 每天上午8点执行 |
| `0 0 8,12,18 * * ?` | 每天8点、12点、18点执行 |
| `0 0 8 ? * 2,3,4,5,6` | 周一至周五每天8点执行 |
| `0 0 8 1 * ?` | 每月1日上午8点执行 |
| `0 0 */2 * * ?` | 每2小时执行一次 |
| `0 30 9 * * ?` | 每天上午9:30执行 |

> **注意**：日和周不能同时指定，其中一个必须为 `?`

## 注意事项

1. **禁止使用多线程替代**：苍穹开发规范要求使用调度任务而非多线程实现异步执行，调度中心做了分布式管理
2. **串行与并行**：`setRunConcurrently(false)` 设置串行执行，避免同一任务并发冲突
3. **分批处理**：大数据量操作必须分批处理，避免内存溢出和长事务
4. **错误处理**：在 execute 方法中捕获异常并记录日志，避免任务静默失败
5. **参数配置入口**：修改运行参数必须从调度作业列表进入，不能从调度计划跳转
6. **时间设置**：注意开始时间和结束时间的校验，结束时间应大于开始时间+1小时
7. **日志输出**：使用 `kd.bos.logging.Log` 记录任务执行日志，便于排查问题
