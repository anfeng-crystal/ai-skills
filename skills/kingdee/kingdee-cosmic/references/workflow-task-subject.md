# 工作流任务主题的显示与配置来源

用于流程任务主题的长日期格式、下拉字段标题、移动端主题来源，以及钉钉撤销重提后仍显示旧主题的诊断；单据字段数据丢失、时区换算和其他第三方同步场景需另外取证。

## 配置与取证

1. 核对单据源字段实际是否保存时分秒、目标审批节点和消息中心展示的任务。源值本身无时间信息时，格式化不能恢复不存在的时间。
2. 官方配置入口为“流程服务云 → 工作流服务 → 设计中心 → 流程设计”，选中对应审批节点，打开“节点信息 → 任务信息 → 任务主题”。在任务主题表达式中使用“取长日期”函数处理目标日期字段。
3. “取长日期”是已核对的设计器函数名称，不是 Java/KingScript API。具体参数、字段标识和表达式语法从目标设计器函数说明及字段定义确认，不猜 `formatDate`、`toString` 或 XML 配置键。
4. 按已授权范围调整后，用包含非零时分秒的样例进入目标节点，在“消息中心 → 待办任务”核对主题；同时比较源字段值、有效流程定义和任务记录。空值、午夜值按业务需要核验，避免只凭 `00:00:00` 判断配置成功。

沿用 [工作流与布局变更](workflow-metadata-change.md) 的生效定义、授权和验收要求；只读排查不修改流程。本文来源没有承诺既有任务会自动刷新主题，也没有给出第三方待办、时区或空值的完整合同，不把本地表达式检查作为这些场景的运行证明。

## 版本冲突

- 2026-09-30 问答“流程单据主题取长日期字段缺少时分”标注 V7.0.1 及以上。
- 该问答推荐的“审批任务主题如何设置长日期格式”标注 V7.0.4 及以上；其链接的场景指引“审批任务主题支持长日期”也明确要求 V7.0.4 及以上。

配置方向一致，但资料未解释版本差异。目标为 V7.0.1～V7.0.3、仅知“7.0”或特定补丁时，先核目标设计器是否提供该函数及对应版本说明，不直接断言支持或要求升级。V7.0.4+ 是两篇资料共同标注的范围，也不能替代目标环境的实际生效验证。

## 下拉字段显示值与标题

直接把下拉字段放入主题时，可能显示存储值（编码），而非下拉标题；先对照字段的值/标题定义和任务主题，不把显示问题当作单据数据错误修改。

- 审批节点任务主题需要下拉标题时，官方问答给出的入口是“流程服务云 → 工作流服务 → 设计中心 → 流程设计”，选中对应审批节点，在任务主题设置中插入“枚举函数”。精确参数、字段标识及函数可用性从目标设计器确认，不猜 `.name`、`.caption` 或手写枚举映射。
- 单据流程属性中的单据主题与审批节点任务主题属于不同配置入口；先确定当前显示取哪一处。单据流程属性文档只描述直接引用字段显示下拉值的现象，不据此认定该入口也提供相同函数配置。
- “下拉值而非标题”的说明标注 V6.0.1+；给出“枚举函数”的问答未标适用版本，不能将前者版本移给后者。也不套用长日期函数的 V7.0.1/V7.0.4 边界。
- 按已授权范围修改后，以存储值和标题明显不同的样例验证目标节点、消息中心待办主题及源字段；既有任务是否刷新、多语言标题和通知消息模板需按目标场景另外核实。

## 移动端主题的配置优先级

V6.0.1+ 官方说明区分移动流程助手的待办列表和打开待办后的审批处理页面；两处显示不一致时，先识别具体位置。

| 显示位置 | 取值规则 |
|---|---|
| 移动审批处理页面 | 仅由单据流程属性的“移动审批页面任务主题”控制；未配置时默认显示“单据编号：xxx” |
| 移动待办列表 | 节点主题优先；节点未配置则取单据流程属性中的主题；仍未配置则默认显示“单据编号：xxx” |

诊断列表主题与审批页主题时，分别读取节点主题和单据流程属性，不能用修改节点主题来承诺改变审批页。沿用入口中的 analyzer 全景要求，核对目标移动/派生页面与实际生效定义；纯配置功能查询可先读本说明。

按授权验收时，用两处明显不同的主题值，提交到目标审批节点，分别检查移动待办列表与打开后的处理页面；需要验证回退时再覆盖未配置场景。上述规则不自动延伸到钉钉、企业微信或其他第三方待办，也不证明旧任务会刷新。

## 钉钉撤销重提后仍显示旧主题

针对 V6.0.1+ 的“已推送钉钉待办 → 撤销单据 → 修改主题相关信息 → 再提交”场景，官方问答说明：钉钉会保留首次推送的流程信息，重提时可能继续显示原主题，即使苍穹已推送新主题。该结论限定于文档所述钉钉待办场景，不能推广到所有消息渠道或所有版本的钉钉接口。

排查时区分单据源值、苍穹当前任务主题、实际发送给钉钉的主题和钉钉显示值。沿用已有只读取证授权，核对对应任务/流程和推送记录；只看到钉钉旧标题不能证明苍穹未重算，只有确认发出的主题已更新后才可用此限制解释现象。若苍穹发出的仍是旧主题，继续查生效定义、任务记录和配置来源。

官方给出的绕行方案为撤销后删除原单、重新制单并提交，也建议联系钉钉技术人员讨论优化。**这不是只读排查的自动执行步骤**：如需采用，先明确目标单据、关联数据与审批/编号影响、恢复办法及业务授权；已有授权确实覆盖时按其执行，不新增无关确认。不能在生产中为验证标题直接删单，不能声称删除缓存、刷新移动页面或修改节点主题必然修复此限制。

按授权验收时比对新单据/新流程与钉钉新待办的对应关系和主题；本文不承诺旧钉钉任务会原地更新，也不提供绕过第三方接口合同的调用。
