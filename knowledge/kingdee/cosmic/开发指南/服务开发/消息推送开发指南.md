# 消息推送开发指南

> 来源: 基于平台API和社区资料整理
> 日期: 2026-04-12
> 标签: 消息推送, MessageCenterServiceHelper, 消息中心, 待办, 通知

---

## 摘要
金蝶云苍穹消息推送通过 MessageCenterServiceHelper 等服务类实现，支持系统消息、工作流待办、自定义通知等多种类型。开发者可在插件中调用消息服务向指定用户发送消息，支持 PC 端消息中心和移动端推送。

## 适用版本
- 金蝶云苍穹 V5.0+

## 核心概念

### 消息类型

| 类型 | 说明 | 场景 |
|------|------|------|
| 系统消息 | 平台级通知 | 系统公告、维护通知 |
| 工作流消息 | 审批待办/已办 | 流程审批通知 |
| 自定义消息 | 业务自定义 | 订单提醒、到期预警 |
| 待办任务 | 需要用户处理 | 单据处理提醒 |

### 核心服务类

| 类 | 包路径 | 用途 |
|------|--------|------|
| `MessageCenterServiceHelper` | `kd.bos.servicehelper.workflow` | 创建待办/消息 |
| `SysMsgServiceHelper` | `kd.bos.servicehelper` | 系统消息发送 |

## 详细内容

### 一、通过消息中心发送消息

#### 1.1 创建待办任务

```java
import kd.bos.servicehelper.workflow.MessageCenterServiceHelper;
import kd.bos.workflow.api.AgentExecution;

import java.util.*;

/**
 * 创建待办任务示例
 * 向指定用户发送待办提醒
 */
public void createTodoTask(Long targetUserId, String title, String content,
                           String billFormId, Object billId) {
    Map<String, Object> taskInfo = new HashMap<>();
    taskInfo.put("title", title);           // 消息标题
    taskInfo.put("content", content);       // 消息内容
    taskInfo.put("formId", billFormId);     // 关联的表单标识
    taskInfo.put("billId", billId);         // 关联的单据ID
    taskInfo.put("senderId", RequestContext.get().getCurrUserId()); // 发送人

    List<Long> receiverIds = new ArrayList<>();
    receiverIds.add(targetUserId);

    // 调用消息中心服务创建待办
    MessageCenterServiceHelper.createTask(taskInfo, receiverIds);
}
```

#### 1.2 在操作插件中发送通知

```java
/**
 * 单据审核后自动发送通知
 */
public class AuditNotifyPlugin extends AbstractOperationServicePlugIn {

    @Override
    public void afterExecuteOperationTransaction(AfterOperationArgs e) {
        super.afterExecuteOperationTransaction(e);

        DynamicObject[] dataEntities = e.getDataEntities();
        for (DynamicObject data : dataEntities) {
            // 获取单据创建人
            DynamicObject creator = data.getDynamicObject("creator");
            if (creator != null) {
                Long creatorId = creator.getLong("id");
                String billNo = data.getString("billno");

                // 发送审核通过通知
                sendNotification(
                    creatorId,
                    "单据审核通过",
                    String.format("您的单据 %s 已审核通过", billNo),
                    this.billEntityType.getName(),
                    data.getPkValue()
                );
            }
        }
    }

    private void sendNotification(Long userId, String title, String content,
                                  String formId, Object billId) {
        Map<String, Object> msgInfo = new HashMap<>();
        msgInfo.put("title", title);
        msgInfo.put("content", content);
        msgInfo.put("formId", formId);
        msgInfo.put("billId", billId);

        List<Long> receivers = Collections.singletonList(userId);
        MessageCenterServiceHelper.createTask(msgInfo, receivers);
    }
}
```

### 二、批量消息发送

```java
/**
 * 批量通知示例：向部门所有人发送消息
 */
public void notifyDepartment(Long deptId, String title, String content) {
    // 查询部门下所有用户
    QFilter deptFilter = new QFilter("entryentity.dpt.id", QCP.equals, deptId);
    DynamicObjectCollection users = QueryServiceHelper.query(
        "bos_user", "id", new QFilter[]{deptFilter}
    );

    List<Long> userIds = new ArrayList<>();
    for (DynamicObject user : users) {
        userIds.add(user.getLong("id"));
    }

    if (!userIds.isEmpty()) {
        Map<String, Object> msgInfo = new HashMap<>();
        msgInfo.put("title", title);
        msgInfo.put("content", content);

        // 批量发送
        MessageCenterServiceHelper.createTask(msgInfo, userIds);
    }
}
```

### 三、定时消息提醒

结合调度任务实现定时提醒：

```java
/**
 * 定时任务：合同到期提醒
 * 每天检查即将到期的合同，发送提醒
 */
public class ContractExpiryReminderTask extends AbstractTask {

    @Override
    public void execute(RequestContext ctx, Map<String, Object> param) {
        // 查询7天内到期的合同
        Calendar cal = Calendar.getInstance();
        Date today = cal.getTime();
        cal.add(Calendar.DAY_OF_MONTH, 7);
        Date sevenDaysLater = cal.getTime();

        QFilter[] filters = new QFilter[]{
            new QFilter("expiry_date", QCP.large_equals, today),
            new QFilter("expiry_date", QCP.less_equals, sevenDaysLater),
            new QFilter("billstatus", QCP.equals, "C")
        };

        DynamicObject[] contracts = BusinessDataServiceHelper.load(
            "contract_bill",
            "id,billno,name,expiry_date,owner",
            filters
        );

        for (DynamicObject contract : contracts) {
            DynamicObject owner = contract.getDynamicObject("owner");
            if (owner != null) {
                String billNo = contract.getString("billno");
                Date expiryDate = contract.getDate("expiry_date");

                Map<String, Object> msgInfo = new HashMap<>();
                msgInfo.put("title", "合同即将到期提醒");
                msgInfo.put("content",
                    String.format("合同 %s 将于 %tF 到期，请及时处理", billNo, expiryDate));
                msgInfo.put("formId", "contract_bill");
                msgInfo.put("billId", contract.getPkValue());

                MessageCenterServiceHelper.createTask(
                    msgInfo,
                    Collections.singletonList(owner.getLong("id"))
                );
            }
        }
    }
}
```

## 注意事项

1. **发送时机**：消息发送应放在 `afterExecuteOperationTransaction` 中（事务外），避免事务回滚后消息已发出
2. **批量优化**：大量消息应批量发送，避免循环单条发送
3. **接收人校验**：发送前检查接收人 ID 是否有效
4. **内容安全**：消息内容不要包含敏感信息（密码、密钥等）
5. **消息模板**：推荐使用消息模板而非硬编码内容，便于多语言和统一管理
6. **频率控制**：避免高频重复发送消息，对定时任务发送的消息做去重处理
