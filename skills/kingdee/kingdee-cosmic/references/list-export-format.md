# 单据列表与模板导出的文件格式

用于标准单据的“按导出模板导出”和“按列表导出”格式选择、行数与数值展示排查。报表自定义导出、附件下载、接口取数和 Excel 导入模板仍按各自合同处理。

## 先查平台配置

- 核对目标版本、单据入口及实际使用的导出方式。在“单据 → 更多 → 导入导出个性化设置 → 导出文件格式为csv”下，按模板导出与按列表导出有各自开关；官方说明两项默认关闭。只启用其中一项不能证明另一入口也输出 CSV。
- 标准格式切换可由该配置满足时先沿用平台能力；确有定制数据或行为要求时，再核对实际导出扩展点及目标 SDK。不要仅为改扩展名新增导入插件或自建导出实现。

## 版本、容量与数据格式

| 项目 | 官方说明及使用边界 |
|---|---|
| CSV 功能版本 | 原文标注“苍穹V5.0.011以上”；目标版本及入口仍需核对，不能把新版界面存在当作旧环境已支持 |
| 大数据量 | 原文说明 CSV 超百万行不拆分文件，单文件最大导出 1000 万行；这是该功能的产品上限，不是目标环境吞吐、内存或耗时保证 |
| 数值输出 | 原文标注 V8.0.2 优化 CSV 数值字段格式化：常规数值形式并保留小数精度；不能据此承诺更早版本具有相同行为 |
| 脱敏 | 原文说明 CSV 与 XLSX 使用相同脱敏逻辑；切换格式不改变本次导出的权限与字段范围 |

核验长编码、前导零、数值精度或公式样式内容时，分别检查导出文件原始字段文本与目标阅读器的解析结果。Excel 打开 CSV 可能再次格式化；页面显示异常不单独证明平台已导错。需要保留标识字符串时使用阅读器受支持的文本列导入方式，不静默改业务值。实际 CSV 编码、分隔符和转义从目标文件确认，不猜固定方言。

## 验证与输出

在授权范围内以代表性数据核对实际入口、有效开关、文件类型、记录数及关键字段原文；需要验证两种入口时分别执行。不为核验格式例行导出海量数据；文件生成成功也不能代替内容核对。报告目标版本、入口、实际格式、抽查结果和未验证的容量边界。官方资料中的设置步骤不自动授权修改业务环境配置或扩大导出范围。
