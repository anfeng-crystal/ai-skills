## 一、平台架构 - 云服务体系

| 云服务 | 核心模块 |
|--------|---------|
| **开发服务云** | 开发平台、开发平台（专业版）、模型资产管理、定制开发平台、无代码开发平台、BOTP、前端服务、性能测试与分析、余额模型、AI基础服务 |
| **系统服务云** | 调度中心、日志管理、智能搜索、第三方服务设置、分布式管理 |
| **基础服务云** | 许可管理、组织人员、管控策略、权限管理、基础资料、打印、登录认证、系统门户、CA认证、导入导出、监控预警、附件水印、编码规则、参数配置、隐私中心 |
| **集成服务云** | 集成管理、数据流、事件网格、数据库复制、资源中心 |
| **流程服务云** | 工作流服务、业务流服务、消息中心、业务事件中心 |
| **开放服务云** | OpenAPI |
| **数据服务云** | 轻分析、智能数据洞察、轻数仓存储 |
| **AI服务云** | Agent平台、金蝶ChatBI、对话机器人、视觉识别服务、AI基础服务 |
| **RPA服务云** | RPA平台（私有云/公有云） |
| **云基础平台(GPaaS)** | 云基础平台、轻轨线(CI/CD) |

## 二、开发平台核心能力

### 2.1 开发工具链
- **开发者工具**：下载安装、离线登录
- **金蝶云·苍穹开发助手 IDEA 插件**：工程创建（**Gradle工程**）、代码规范扫描
- **环境管理**：安装(Windows/Mac)、初始化、许可申请导入、开发商标识
- **协同开发**：轻量级环境、多维数据库配置

### 2.2 设计器使用
- **PC 页面开发**：单据与列表、基础资料、报表、动态表单、参数、卡片、轻量卡片、布局
- **移动页面开发**：独立的移动端页面设计
- **页面属性**：动态表单属性、单据属性、列表属性、报表属性

### 2.3 控件体系
- **通用字段**：文本、整数、小数、长整数、大文本、多语言、多行文本、日期(各类)、步进器、复选框、单选、多选、下拉列表、附件、图片、手写签名、地理位置、富文本、颜色选择
- **业务字段**：单据类型、基础资料(多选/辅助/属性)、用户、员工头像、组织、城市、物料、计量单位、数量、币种、金额、单价、多类别基础资料、行政区划、地址、邮箱、手机、弹性域、单据状态
- **单据体**：标准/子/树形/卡片/子卡片分录
- **通用控件**：按钮、标签、超链接、图片、树控件、附件面板、二维码、IFrame、Ajax、HTML、SpreadJS、进度条、搜索、富文本编辑器、轮播图、时间轴、评分、穿梭框、WebOffice、地图、锚点、音视频、Markdown、倒计时、Listbox、智能助手
- **容器控件**：Flex面板、高级面板、页签、字段布局、分割容器、轮播容器、过滤面板、移动页签、嵌入页面、栅格容器
- **导航控件**：工具栏、树形菜单、向导、移动端工具栏、底部导航栏、浮动菜单
- **表格控件**：报表、列表、移动表格、轻量级表格
- **图表控件**：条形图、通用图、ECharts V5

### 2.4 自定义控件开发
- 规范篇 → 入门篇 → 进阶篇 → API篇 → 高级技巧篇
- 脚手架使用指南
- 标准产品开发全流程
- 二开环境迁移与部署
