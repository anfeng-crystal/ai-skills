## 2、事件方法

### 按模板导出时，删除每个采购申请单中金额小于500的分录行

依据：[官方引出插件示例](https://vip.kingdee.com/knowledge/720677930401126656?productLineId=29&isKnowledge=2&lang=zh-CN)（更新于 2026-07-30）。示例处理 `afterQueryOfExport` 返回的待导出数据；不调用数据库删除或单据保存。原文未标适用版本，事件类型和脚本导入仍按目标声明核对。

从尾到头遍历可变分录集合，避免移除一行后后续行前移、正向索引继续增加而漏掉相邻待删除行。保留原规则：金额为空、等于 500 或大于 500 的行不移除，保留行顺序不变；使用现有 `size/get/remove(row)`，不把 Java 集合替换为原生数组。

```kingscript
/**
 * 系统按条件查询出待导出的数据后，即将执行导出流程时，触发当前事件
 * 用户可修改查询完毕的数据，如移除部分数据不作导出，或按自定义规则修改部分数据
 * @param e 
 */
afterQueryOfExport(e: AfterQueryOfExportEvent): void {
    // 按模板导出时，删除每个采购申请单中金额小于500的分录行 

    // 获取待导出的采购申请单
    let queryValues = e.getQueryValues();
    // 遍历所有采购申请单
    for (let queryValue of queryValues) {
        let rows = queryValue.getDynamicObjectCollection("entryentity");
        // 倒序遍历，删除时未处理行的索引不受后方行移除影响
        for (let i = rows.size() - 1; i >= 0; i--) {
            let row = rows.get(i);
            if (row.get("kdtest_amount") != null && row.get("kdtest_amount").compareTo(new BigDecimal(500)) < 0) {
                // 移除金额小于500的分录行
                rows.remove(row);
            }
        }
    }
    e.setQueryValues(queryValues);
}
```
