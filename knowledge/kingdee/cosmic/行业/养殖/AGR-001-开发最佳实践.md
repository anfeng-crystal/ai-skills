# AGR-001 养殖批次档案 - 开发最佳实践

> 归档时间：2026-04-12 | 需求：AGR-001 | 评分：8.98/10

## 新增验证模式

### 1. 子分录行内金额计算
```java
// propertyChanged 中获取分录行索引
case "agr_vaccine_count":
case "agr_vaccine_unit_cost":
    int rowIndex = e.getChangeSet()[0].getRowIndex();
    Integer count = (Integer) this.getModel().getValue("agr_vaccine_count", rowIndex);
    BigDecimal unitCost = (BigDecimal) this.getModel().getValue("agr_vaccine_unit_cost", rowIndex);
    this.getModel().setValue("agr_vaccine_amount", unitCost.multiply(new BigDecimal(count)), rowIndex);
```
**要点**：分录字段 getValue/setValue 必须传 rowIndex。

### 2. 分录金额汇总回写单据头（通用方法）
```java
public static BigDecimal sumEntryAmount(DynamicObject bill, String entryKey, String amountKey) {
    DynamicObjectCollection entries = bill.getDynamicObjectCollection(entryKey);
    BigDecimal total = BigDecimal.ZERO;
    for (DynamicObject row : entries) {
        BigDecimal amount = row.getBigDecimal(amountKey);
        if (amount != null) total = total.add(amount);
    }
    return total;
}
```
**可复用**：任何有分录金额汇总需求的场景。

### 3. addWarningMessage vs addErrorMessage
- `addErrorMessage` — 阻断操作（保存失败）
- `addWarningMessage` — 弹出提醒但不阻断（用户确认后仍可继续）

适用于：死亡率预警、库存偏低预警等非阻断场景。

### 4. BigDecimal 精度与除法
```java
new BigDecimal(deathCount).divide(new BigDecimal(inCount), 4, BigDecimal.ROUND_HALF_UP)
```
**必须**指定 scale 和 roundingMode，否则无限小数会抛 ArithmeticException。

### 5. 多字段联动刷新策略
当多个字段变化都影响同一汇总字段时，采用"各自触发 → 最终统一刷新"链路：
```
防疫数量变 → calcVaccineRowAmount → refreshVaccineCost → refreshTotalCost
饲料重量变 → calcFeedRowAmount   → refreshFeedCost   → refreshTotalCost
入栏成本变 → refreshTotalCost
```
避免遗漏：每条路径最终都调用 refreshTotalCost。
