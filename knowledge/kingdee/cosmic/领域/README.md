# 领域知识库索引

本目录按技术领域组织知识文档。

## 目录说明

| 子目录 | 说明 | 对应 Skill |
|--------|------|-----------|
| `前端开发/` | 表单设计、页面布局、移动端适配、打印模板 | kd-frontend |
| `后端开发/` | 插件开发、数据操作、服务接口 | kd-plugin / kd-data / kd-service |
| `集成与运维/` | 环境搭建、中间件配置、第三方系统对接 | kd-integration |
| `通用规范/` | 开发规范、文档标准、安全规范 | 全体 |

## 文档命名规范

`[领域]_[行业/场景]_[功能/组件]_[文档类型].md`

文档类型：guide（指南）/ api（接口）/ practice（实践）/ faq（问答）/ example（示例）
