## 1. 等额本息公式实现（BigDecimal 精确计算）
```java
// 月利率 = 年利率 / 100 / 12 (10位中间精度)
BigDecimal monthlyRate = annualRate.divide(new BigDecimal("1200"), 10, RoundingMode.HALF_UP);
// (1+r)^n 用循环避免浮点误差
BigDecimal power = BigDecimal.ONE;
for (int i = 0; i < n; i++) power = power.multiply(onePlusR);
// M = P × r × (1+r)^n / [(1+r)^n - 1]
BigDecimal monthly = P.multiply(monthlyRate).multiply(power)
    .divide(power.subtract(BigDecimal.ONE), 2, RoundingMode.HALF_UP);
```
