> 归档时间：2026-04-12 | 需求：RTL-001 | 评分：9.19/10

## kd-frontend 核心模式

### 1. afterBindData 中根据状态控制控件可用性
```java
@Override
public void afterBindData(EventObject e) {
    String status = this.getModel().getValue("status_field").toString();
    boolean editable = "A".equals(status);
    this.getView().setEnable(editable, "entryKey");
    if ("C".equals(status)) {
        this.getView().setEnable(false, "field1", "field2");
    }
}
```

### 2. processRowData 状态列颜色标记
```java
String status = row.get("status_field").toString();
switch (status) {
    case "A": row.put("status_field", "<font color='green'>正常</font>"); break;
    case "B": row.put("status_field", "<font color='orange'>冻结</font>"); break;
    case "C": row.put("status_field", "<font color='gray'>注销</font>"); break;
}
```

### 3. processRowData 金额千分位 + 颜色
```java
BigDecimal balance = (BigDecimal) row.get("balance");
String formatted = String.format("%,.2f", balance);
String color = balance.compareTo(BigDecimal.ZERO) <= 0 ? "red" : "green";
row.put("balance", "<font color='" + color + "'>" + formatted + "</font>");
```

## kd-plugin 新增模式

### 4. 分录交易流水 running balance 计算
```java
BigDecimal runningBalance = BigDecimal.ZERO;
for (int i = 0; i <= rowIndex; i++) {
    DynamicObject row = entries.get(i);
    String type = row.getString("txn_type");
    BigDecimal amount = row.getBigDecimal("txn_amount");
    if ("recharge".equals(type)) {
        runningBalance = runningBalance.add(amount);
    } else {
        runningBalance = runningBalance.subtract(amount);
    }
}
this.getModel().setValue("after_balance", runningBalance, rowIndex);
```
