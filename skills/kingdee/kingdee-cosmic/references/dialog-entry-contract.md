# 动态表单回填分录

- 从父页“新增/编辑”入口确认打开参数、行定位、动态表单字段、返回 Map/对象、关闭回调与分录写值。弹窗确认只回填内存还是持久化主单据，以任务明确语义为准，不能预先保存。
- 字段改名/删除/类型变化后同步初始化、收集返回值、回写数组和 DTO。必需字段缺失应在交付前核对失败，不能用通配 `containsProperty` 跳过所有缺失来掩盖版本错误；共享插件的可选字段仅按实际页面差异处理。
- 基础资料本地回填按目标字段和 SDK 所需类型；发送外部 ID/编码时使用确认的映射。布尔在表单与分录间保持布尔，到外部协议边界再转换；金额单位与整数/小数约束不擅自取整。
- 手填字段不能被来源带出覆盖。新增初值与再次编辑已有值分别核对；取消不能新增行或改变原行，编辑不能回写到其它行。
- 先检查按钮 `CommitValidate` 或已有平台校验是否覆盖必录。缺值时不返回、不关闭；通过后才回填。不要未经 SDK 核实调用猜测的 `validate()`，也不要复制元数据必录清单维护第二套校验。
- 本地编译不证明目标仍在运行该版本；字段不存在异常先核对实际插件版本和运行期字段，再按已授权部署链交付配套版本。
