# PPT 排版规范

仅在处理演示文稿时读取。通过当前可用的 `pptx`、`presentations` 或同等基础技能生成和编辑文件；本规范决定版式与验收要求，不指定生成库或宿主专用命令。语言、受众和用途按用户要求确定，用户模板、品牌规范和明确要求优先于以下默认值。

## 用途与内容结构

- 先区分现场放映、屏幕阅读、打印留档。现场汇报使用更大的正文和更低的单页信息密度；阅读型材料可保留更多解释，仍需完整可读。
- 新建汇报先确定每页要回答的问题，再选择版式。用已有事实组织结论、依据、问题、下一步与待决策事项；没有对应内容时不凑章节，不把所有页面强行改成结论句。
- 纯美化保留原文含义、必需字段、页数、顺序、备注、来源和对象。只有获得内容重组授权才合并、拆页或把详细证据移入附录；不得把用户要求出现在页面上的信息只放到备注中。
- 用户指定 N 页时，封面、目录、章节页和结束页均计入 N 页。一页材料不默认增加封面，短汇报可省略目录及章节过渡页，结束页按实际需要呈现决策或行动，不强行增加“谢谢”。

## 画布、母版与对齐

| 项目 | 无模板时的默认值 | 检查要点 |
| --- | --- | --- |
| 画布 | 16:9 宽屏，约 33.87 × 19.05 cm | 已有模板保持比例，不直接拉伸 4:3 页面 |
| 安全边距 | 左右 1.2–1.5 cm，上下约 0.9–1.2 cm | 标题、正文和页脚均不贴边；品牌模板可另定 |
| 标题区 | 固定顶部基准，同类页面高度一致 | 标题一至两行，长标题不挤压正文 |
| 内容区 | 一个主内容区，或确有比较关系的双栏 | 等宽、对齐、间距由逻辑关系决定，不默认卡片网格 |
| 页脚 | 固定页码及必要的项目/期间信息 | 不编造 Logo、密级、版本与出具日期 |

有模板时先检查主题、母版、布局和占位符，再填充内容。复用可用布局，不用重复粘贴的手工页眉代替母版。仅作为内容来源的文件不自动作为视觉模板。换模板后检查继承字体、主题色、背景和隐藏对象是否残留旧样式。

标题、图表、正文、图注共享可见对齐线；同级对象采用一致间距。留白用于区分信息组，不靠大块空框补齐版面。不为每页换一种布局，重复页面也避免机械地套用同一套多卡片结构。

## 字体、字号与文字

字体优先用实际可用的微软雅黑；缺失时选思源黑体或 Noto Sans CJK SC，或采用目标环境已安装的企业指定字体。中文、英文与数字统一字重和视觉基线；替换字体后重新检查断行与对象尺寸，不假定收件人装有同款字体。

| 文字类型 | 默认字号 | 用法 |
| --- | --- | --- |
| 封面标题 | 36–44 pt，加粗 | 简洁写明项目和汇报主题；长名称可自然分行 |
| 页面标题 | 28–34 pt，加粗 | 已知结论可直接写结论，背景/流程页用清楚的主题名 |
| 二级标题/关键数字 | 22–28 pt | 只突出与本页问题有关的指标，注明单位与期间 |
| 现场放映正文 | 20–24 pt | 以目标屏幕查看，不能依靠观众放大阅读 |
| 屏幕阅读正文 | 18–22 pt | 稠密内容优先重排或按授权拆分 |
| 图表与表格标签 | 通常 16–20 pt | 投影场景取较大值，不能只放大标题 |
| 来源/页码 | 10–12 pt | 仅非核心辅助信息；影响结论的限定条件放入正文 |

- 正文默认左对齐；短封面标题可以居中，长段落不两端拉伸。行距从 1.15–1.3 倍起调，段落之间留出可辨识间距，不用空格和回车对齐。
- 列表仅用于真正并列的内容，通常不超过两级；不是每句话都加圆点。重点通过位置、字号和少量加粗建立，不整段高亮。
- 每页有一个主要阅读方向。文字过密时先调整内容分组、文本框和布局；获准重组后再精炼或拆页，不能默默删字或把正文缩成小字。
- 自动缩小字体只作为工具行为检查项，不作为解决溢出的默认办法。检查长中文标题、英文缩写、数字、负号、百分号、括号和引用编号是否断裂或被裁切。

## 配色与图形语言

- 默认白色或极浅灰背景，正文 `#222222`，辅助文字 `#5B6573`，主色深蓝 `#24476A`，浅色块 `#EAF0F5`，细分隔线 `#D8DEE5`。同一稿保持颜色角色一致。
- 默认一个主色加灰阶。业务状态需要额外颜色时配文字标签，不仅靠红绿区别；没有已确认阈值时不制造风险颜色。
- 深色封面或章节页按品牌需要使用，正文页优先保证阅读和打印；同页避免大面积强饱和色、渐变、阴影、厚描边及装饰图标堆叠。
- 一个页面采用完整构图，不默认加入按钮、标签胶囊、导航栏或仪表盘卡片。图片、图标与装饰图形按基础技能支持的方式处理；不能为追求装饰丢失业务证据。

## 表格、图表与项目进度

- 表格只承载必须横向核对的字段，表头浅底深字，数据区以白底和细分隔线为主。文本左对齐、金额/数量右对齐、短状态可居中，单位与精度一致。
- 跨页表重复字段名与口径；每页保留足够字号。字段太多时按业务关系拆分或用附录承载，前提是用户允许调整结构；不得把整张 Excel 截图缩小塞进页面。
- 图表采用可编辑原生图表或基础技能支持的等价可编辑对象，引用实际数据。条形图比较类别，折线图展示连续时间，柱形图比较期间；不使用 3D 效果，不默认双轴。
- 标明期间、单位、图例与口径，突出关键系列，其余弱化。条形/柱形轴通常从零开始，缩小坐标范围须清晰显示刻度。结论只能来自真实数据，不能把缺失值当零。
- 里程碑/甘特图明确计划与实际、时间刻度、基准日期、责任及状态定义；已完成、延期和待确认不能靠颜色暗示。装饰箭头不得形成不存在的依赖关系。
- 流程与架构图按真实关系组织，连接线端点明确，标签不重叠。需要可编辑图时保留对象与连线，不以扁平截图交付。

## 图片、对象与可编辑性

- 优先使用用户提供的原始图片、Logo 和图表。按比例缩放；裁剪不得裁掉关键对象、刻度、文字或标识。引用图片按任务要求保留来源，不能凭空添加企业背书。
- 关键文字、数据表格及用户要求可编辑的图表/流程保持可编辑，不把整页渲染成图片再放回 PPTX。
- 背景、形状、文字、图表的层级明确；检查遮挡、透明对象、组合后错位和超出画布的对象。合理的图片叠放属于设计，意外遮挡须修复。
- 编辑旧稿时核对备注、隐藏页、超链接、动画、嵌入媒体和外部依赖。原稿需要这些能力而当前工具不能保留时，说明具体受影响对象并选择保真路径，不静默删除或声称已验收。
- 新稿默认不增加动画；演示需要时采用少量一致的出现/淡入效果。动画、媒体和超链接须在可交互环境检查，静态渲染不证明放映正常。

## 渲染与视觉验收

1. 对照源内容核对页数、顺序、文字、关键数据、单位、来源、表格字段与备注；检查原生对象，确认可编辑性未丢失。
2. 渲染最终 PPTX。先查看全稿缩略图，检查字号层级、配色、页面节奏、对齐和空白是否一致；缩略图不能代替逐页检查。
3. 查看每一页完整预览，放大检查文字断行、溢出、缺字、对比度、对象遮挡、图表刻度、表格边界、图片清晰度和页脚位置。使用基础技能的溢出/重叠检查器辅助定位，不能以静态检查通过替代看图。
4. 按实际用途检查：放映稿在适合目标屏幕的比例下阅读，阅读稿检查正文与证据完整性，打印稿检查所需单页或讲义布局。仅预览时不宣称已在 PowerPoint/WPS 真实放映。
5. 修复后重新导出与渲染受影响页面；修改母版、主题字体、画布或全稿布局时重新检查全部页面。缺少可靠渲染能力时按主流程标记未完成视觉验收。

通过条件：必需内容完整、正文可读、无意外裁切或遮挡、图表口径准确、对象符合可编辑要求、风格一致；动画/媒体与目标客户端未实测的部分单独说明。
