# RTL-001 会员储值卡管理

## 基本信息
- **行业**: 零售
- **需求编号**: RTL-001
- **业务场景**: 门店会员注册并开通储值卡，充值、消费扣款、余额查询
- **覆盖 Skill 重点**: kd-frontend（列表分组汇总、状态列颜色、金额格式化）、kd-plugin（afterBindData、beforeF7Select）、kd-review（代码审查模式验证）

## 业务背景
零售连锁企业常设会员储值卡体系，用于促进客户粘性和资金沉淀。会员开卡后可多次充值，消费时按卡余额扣款，支持查看充值/消费流水。

## 业务规则
1. 储值卡编号自动生成：`VIP` + 年月日 + 4位流水号
2. 充值金额 ≥ 100 元，单笔充值上限 50000 元
3. 消费扣款不得超过卡余额
4. 卡状态流转：正常(A) → 冻结(B) → 注销(C)；已注销不可恢复
5. 冻结状态下禁止充值和消费
6. 分录记录所有充值/消费流水，包含：交易类型、金额、交易时间、操作员
7. 列表页需按门店分组汇总余额，余额≤0显示红色，正常显示绿色
8. 会员等级（普通/银卡/金卡/钻石）根据累计充值自动计算

## 单据结构
| 字段 | 标识 | 类型 | 说明 |
|------|------|------|------|
| 卡号 | card_no | 文本 | 自动生成，不可编辑 |
| 会员姓名 | member_name | 文本 | 必填 |
| 手机号 | phone | 文本 | 必填，11位 |
| 所属门店 | store | 基础资料F7 | 必填 |
| 卡状态 | card_status | 下拉 | A正常/B冻结/C注销 |
| 当前余额 | balance | 金额 | 自动计算 |
| 累计充值 | total_recharge | 金额 | 自动汇总 |
| 累计消费 | total_consume | 金额 | 自动汇总 |
| 会员等级 | member_level | 文本 | 自动计算 |
| 开卡日期 | open_date | 日期 | 默认当天 |

### 交易流水分录
| 字段 | 标识 | 类型 | 说明 |
|------|------|------|------|
| 交易类型 | txn_type | 下拉 | recharge/consume |
| 交易金额 | txn_amount | 金额 | >0 |
| 交易时间 | txn_time | 日期时间 | 默认当前 |
| 操作员 | operator | 文本 | 当前用户 |
| 交易后余额 | after_balance | 金额 | 自动算 |

## 前端特性需求（kd-frontend 重点）
1. **列表分组汇总**：按门店分组，小计显示各门店会员数和余额汇总
2. **状态列颜色**：正常→绿色，冻结→橙色，注销→灰色
3. **金额格式化**：余额字段千分位显示，负数红色
4. **表单控件联动**：卡状态为冻结/注销时，充值按钮灰化

## 技术要求
- 表单插件：AbstractBillPlugIn（afterBindData 设置控件状态、propertyChanged 计算余额和等级）
- 列表插件：processRowData 控制颜色 + formatColumnText 格式化金额
- 操作插件：充值/扣款前校验卡状态和余额
- 常量类 + Helper 类
