# 金蝶云苍穹插件开发综合指南

> 来源: 金蝶云苍穹官方文档及社区资料整理
> 标签: 插件开发, 表单插件, 列表插件, 操作插件

---

## 摘要

本文综合介绍金蝶云苍穹各类插件的开发方法，包括表单插件、列表插件、操作插件、转换插件等，涵盖事件执行顺序、常用接口及开发技巧。

## 适用版本

- 金蝶云苍穹 V5.0+
- 金蝶云星空 V8.0+

## 插件类型概览

| 插件类型 | 基类 | 用途 |
|---------|------|------|
| 表单插件 | `AbstractFormPlugin` | 处理动态表单界面交互 |
| 单据插件 | `AbstractBillPlugIn` | 处理单据界面业务逻辑 |
| 列表插件 | `AbstractListPlugin` | 处理列表界面交互 |
| 操作插件 | `AbstractOperationServicePlugIn` | 处理保存、提交等操作 |
| 转换插件 | `AbstractConvertPlugIn` | 处理单据转换（下推/上拉）|
| 打印插件 | `AbstractPrintServicePlugin` | 处理打印数据加工 |
| 引入插件 | `IImportPlugin` | 处理引入数据加工 |

## 一、表单插件 (AbstractFormPlugin)

### 1.1 事件执行顺序

```
setPluginName
  → preOpenForm
  → loadCustomControlMetas
  → setView
  → initialize
  → registerListener
  → getEntityType
  → createNewData / afterLoadData（互斥）
  → afterCreateNewData / afterLoadData
  → beforeBindData
  → afterBindData
```

### 1.2 核心事件

| 事件 | 触发时机 | 用途 |
|-----|---------|------|
| `preOpenForm` | 显示界面前 | 修改显示参数、取消显示 |
| `registerListener` | 用户与界面交互时 | 注册控件监听 |
| `afterCreateNewData` | 新建数据包后 | 设置默认值（新增模式）|
| `afterLoadData` | 加载数据后 | 处理已存在单据（修改/查看模式）|
| `afterBindData` | 数据绑定后 | 设置控件状态（锁定性、可见性）|
| `beforeDoOperation` | 执行操作前 | 业务校验 |
| `afterDoOperation` | 执行操作后 | 后续处理 |
| `beforeClosed` | 界面关闭前 | 清理资源 |

### 1.3 常用方法

```java
// 获取模型和视图
IDataModel model = this.getModel();
IFormView view = this.getView();

// 字段操作
model.setValue("fieldKey", value);
Object value = model.getValue("fieldKey");

// 控件操作
Control control = this.getView().getControl("controlKey");
this.getView().setVisible(true, "fieldKey");
this.getView().setEnable(false, "fieldKey");

// 获取当前用户
String userId = RequestContext.get().getUserId();
long orgId = RequestContext.get().getOrgId();
```

## 二、列表插件 (AbstractListPlugin)

### 2.1 事件执行顺序

**页面加载时：**
```
beforeCreateListDataProvider
  → filterColumnSetFilter
  → filterContainerInit
  → beforeCreateListColumns
  → setFilter
  → packageData
```

**点击查询时：**
```
filterColumnSetFilter
  → filterContainerInit
  → filterContainerSearchClick
  → filterContainerAfterSearchClick
  → beforeCreateListColumns
  → beforeCreateListDataProvider
  → setFilter
  → packageData
```

### 2.2 核心事件

| 事件 | 触发时机 |
|-----|---------|
| `billListHyperLinkClick` | 超链接点击 |
| `beforeCreateListColumns` | 列创建前（可动态添加/删除列）|
| `beforeCreateListDataProvider` | 构建取数器前（可自定义取数）|
| `setFilter` | 生成过滤条件后（可追加条件）|
| `beforePackageData` | 包装数据前 |
| `packageData` | 包装数据时（单元格填值）|
| `filterContainerSearchClick` | 查询点击时 |
| `filterContainerAfterSearchClick` | 最终查询条件解析后 |

## 三、操作插件 (AbstractOperationServicePlugIn)

### 3.1 事件执行顺序

```
onPreparePropertys（准备字段）
  → onAddValidators（添加校验器）
  → beforeExecuteOperationTransaction（事务前校验）
  → beginOperationTransaction（开启事务）
  → [数据库操作]
  → endOperationTransaction（提交数据库后）
  → [事务提交]
  → afterExecuteOperationTransaction（事务提交后）
  → setContext
  → initializeOperationResult
  → onReturnOperation
```

### 3.2 核心事件

| 事件 | 触发时机 | 注意事项 |
|-----|---------|---------|
| `onPreparePropertys` | 准备字段 | 添加需要用到的字段 |
| `beforeExecuteOperationTransaction` | 事务前 | 最终业务校验，勿直接跨库更新 |
| `beginOperationTransaction` | 开启事务后 | 可在事务中执行额外操作 |
| `afterExecuteOperationTransaction` | 事务提交后 | 发送通知、触发外部接口 |

## 五、开发技巧

### 5.1 插件间传递参数

**表单插件 → 操作插件：**
```java
// 表单插件中设置
public void beforeDoOperation(BeforeDoOperationArgs e) {
    e.Option.setVariableValue("customParam", "value");
}

// 操作插件中获取
public void beforeExecuteOperationTransaction(BeforeExecuteOperationTransaction e) {
    Object param = this.Option.getVariableValue("customParam");
}
```

### 5.2 服务插件消息提示

```java
// 操作插件中设置操作结果
OperateResult result = new OperateResult();
result.Message = "操作成功！";
result.Number = billNo;
this.OperationResult.OperateResult.Add(result);
```

### 5.3 异常处理

```java
// 普通错误（中断操作）
throw new KDException("单据编号不能为空");

// 交互式提示
throw new KDInteractionException("确认删除该单据吗？");
```

## 六、注意事项

1. **afterCreateNewData vs afterLoadData**
   - 互斥触发，只会执行其中一个
   - `afterCreateNewData`：新增模式触发，适合设置默认值
   - `afterLoadData`：修改/查看模式触发，数据来自数据库

2. **操作插件事务**
   - 不要在 `beginOperationTransaction` 中直接跨库更新
   - 跨库操作需使用 KDTX 框架保证数据一致性
   - 不要用 `e.setCancelOperation(true)` 取消操作（不会回滚），应抛出异常

3. **列表插件缓存**
   - `beforeCreateListDataProvider` 和 `beforePackageData` 中不要修改基础资料引用属性
   - 会打乱缓存数据，只适合非基础资料字段修改
