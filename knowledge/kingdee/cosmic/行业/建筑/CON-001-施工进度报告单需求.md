# 需求单

## 基本信息
- **需求编号**: CON-001
- **所属行业**: 建筑
- **业务场景**: 施工进度报告单
- **优先级**: P1(高)
- **提出时间**: 2026-04-12
- **需求来源**: 建筑施工现场管理 + 苍穹**进度百分比计算+审批流集成+附件上传+锁行**能力验证

## 核心功能目标
开发一个「施工进度报告单」，由施工员按周/阶段填报各工序的完成进度和实际成本，项目经理审批。重点验证**进度百分比计算+分录锁行+审批流+成本对比分析**。

## 业务角色
| 角色 | 职责 |
|------|------|
| 施工员 | 填写进度报告 |
| 项目经理 | 审批进度报告 |
| 成本会计 | 查看成本对比 |

## 详细业务规则

### 单据头
| 字段标识 | 字段名 | 类型 | 必录 | 说明 |
|---------|--------|------|------|------|
| billno | 单据编号 | 文本 | 是 | 自动生成 |
| billstatus | 单据状态 | 下拉 | 是 | A-暂存 B-已提交 C-已审批 D-已驳回 |
| con_project | 工程项目 | 基础资料 | 是 | |
| con_report_date | 报告日期 | 日期 | 是 | 默认当天 |
| con_reporter | 填报人 | 用户 | 是 | 默认当前用户 |
| con_period | 报告期间 | 文本 | 是 | 如：2026年第15周 |
| con_overall_progress | 整体进度(%) | 小数 | 否 | 自动计算：分录加权平均 |
| con_plan_cost | 计划总成本 | 金额 | 否 | 分录计划成本汇总 |
| con_actual_cost | 实际总成本 | 金额 | 否 | 分录实际成本汇总 |
| con_cost_variance | 成本偏差(%) | 小数 | 否 | =(实际-计划)/计划×100 |

### 分录：工序进度明细
| 字段标识 | 字段名 | 类型 | 必录 | 说明 |
|---------|--------|------|------|------|
| con_procedure | 工序名称 | 基础资料 | 是 | |
| con_weight | 权重(%) | 小数 | 是 | 所有行权重之和应=100% |
| con_plan_progress | 计划进度(%) | 小数 | 是 | |
| con_actual_progress | 实际进度(%) | 小数 | 是 | 0-100 |
| con_progress_deviation | 进度偏差(%) | 小数 | 否 | =实际-计划 |
| con_row_plan_cost | 计划成本 | 金额 | 是 | |
| con_row_actual_cost | 实际成本 | 金额 | 是 | |
| con_row_cost_deviation | 成本偏差(%) | 小数 | 否 | =(实际-计划)/计划×100 |
| con_remark | 备注 | 文本 | 否 | |

### 业务规则
1. **整体进度自动计算**：Σ(实际进度 × 权重) / 100
2. **进度偏差自动计算**：实际进度 - 计划进度
3. **成本偏差自动计算**：(实际成本 - 计划成本) / 计划成本 × 100
4. **权重校验**：保存时校验所有行权重之和 = 100%（允许 ±0.01 误差）
5. **实际进度范围校验**：必须在 0-100 之间
6. **进度不回退**：实际进度不得小于上一次报告的实际进度
7. **审批后锁定**：已审批状态的分录行不可编辑（lockRow）
8. **成本预警**：成本偏差超过 20% 时弹出预警

## 验收标准
- [ ] Gradle 工程编译通过
- [ ] 整体进度加权平均计算正确
- [ ] 进度偏差和成本偏差自动计算
- [ ] 权重之和校验 = 100%
- [ ] 进度 0-100 范围校验
- [ ] 成本偏差预警
- [ ] 审批后行锁定
