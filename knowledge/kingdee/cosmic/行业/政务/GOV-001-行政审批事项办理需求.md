# GOV-001 行政审批事项办理

## 基本信息
- **行业**: 政务
- **需求编号**: GOV-001
- **业务场景**: 行政审批事项申请→受理→审批→办结→归档，含超时预警和办结率统计
- **覆盖 Skill 重点**: kd-optimization（超时预警计算、办结率统计查询优化）、kd-knowledge（知识库分类归档验证）

## 业务背景
政务服务中心受理群众各类行政审批事项（营业执照、建设许可、食品经营许可等），需在法定时限内办结。超时预警、按时办结率是政务考核的核心指标。

## 业务规则
1. 事项编号自动生成：`GOV` + 年月 + 4位流水号
2. 每类事项有法定办理时限（工作日）
3. 状态流转：待受理(A) → 已受理(B) → 审批中(C) → 已办结(D) → 已归档(E) / 已退回(F)
4. 受理后自动计算预计办结日期 = 受理日期 + 法定时限（跳过周末）
5. 距预计办结日期≤3个工作日，显示黄色预警；超期显示红色预警
6. 办结后评分（群众评价1-5分）
7. 分录记录每个处理节点（处理人、处理时间、处理意见、处理结果）

## 单据结构
| 字段 | 标识 | 类型 | 说明 |
|------|------|------|------|
| 事项编号 | gov_no | 文本 | 自动生成 |
| 申请人 | applicant_name | 文本 | 必填 |
| 联系电话 | contact_phone | 文本 | 必填 |
| 事项类别 | item_category | 下拉 | 营业执照/建设许可/食品许可/其他 |
| 法定时限(工作日) | legal_days | 整数 | 根据类别自动填充 |
| 受理日期 | accept_date | 日期 | 受理时填写 |
| 预计办结日期 | due_date | 日期 | 自动计算 |
| 实际办结日期 | finish_date | 日期 | 办结时填写 |
| 办理状态 | gov_status | 下拉 | A/B/C/D/E/F |
| 群众评价 | rating | 整数 | 1-5分 |
| 是否超期 | is_overdue | 布尔 | 自动判定 |

## 技术要求
- Helper：工作日计算（跳过周末）、超期判定、办结率统计
- 表单插件：事项类别→法定时限自动填充、受理→预计办结日期计算、超期自动标记
- 操作插件：状态流转校验、评分范围校验
- 列表插件：超期红色标记、即将到期黄色、正常绿色
