# 平台数据导入模板回填

适用于用户导出的基础资料、树形资料或单据数据模板，不是元数据 ZIP。表格工具负责值写入，本 skill 负责平台导入合同；不直接修改 bundled/cache 表格 Skill。

## 先确认输入

- 原模板只读，输出到独立文件。解析实际工作表、技术字段行、显示标题、数据起始行、隐藏字典页、下拉校验、批注、命名范围和包内关系；不要按通用报表样式重建模板。
- 按技术字段绑定列，不能只按中文标题或列号猜；失败结果文件常在最左侧多“错误原因”列，不能当原模板直接继续填写。
- 把用户确认的来源版本、代码值/接口值、状态及使用状态作为合同。创建人等自动字段可按平台规则留空；数据状态是否允许空、暂存或已审核须单独确认，不能与所有系统字段一起留空，也不把一次任务的“已审核”推广到所有导入。

## 写入与兼容性

- 只改数据区及必要的维度/引用范围，保留原工作簿结构、技术表头、隐藏信息、校验、批注、关系文件和命名空间。编码按文本存储，保留前导零及完整字符，不自动缩短/重编号。
- 优先在原模板副本中写值。所用库重写包结构时，比对实际 XML 和 ZIP 成员；Excel/openpyxl 能打开或渲染正常不证明平台导入器能解析。
- 检查字符串序列化、命名空间前缀、sharedStrings 索引和样式引用。若需要将生成的数据行合回模板，使用模板的有效编码形式，不能拼接带未声明前缀、来自另一包的字符串/样式索引。不要断言合法 `inlineStr` 对所有版本不可用；格式差异必须由目标解析结果裁决。
- 有解析验证授权时，先上传核对平台识别到的工作表/行数，再执行另有授权的正式导入。仅消失一条错误提示不足以证明全量解析成功。

## 树形引用与容量

- 核对键唯一、父键存在、根节点规则、无环及层级；父项排在前面不证明同批子项能引用新建父项。没有目标平台同批解析成功证据时，按层级生成批次，上级已落库且状态可引用后再导下级。
- 状态过滤与批次可见性分别取证；“找不到上级”不等于源编码错误，先核对已落库父项、审核/可用状态、F7/引用过滤与批次事务。
- 长度检查同时覆盖输入字段及平台生成的长编码、长名称、层级路径。按实际祖先链和分隔规则算最大长度，比较有效继承元数据及物理列限制；留空派生列不代表平台不会生成它。
- 字段超长错误只给出 `varchar(N)` 时，不能直接认定是哪列。结合异常列/参数和当前物理定义定位；结构已改则重新查证，不沿用旧失败文件推断现状。

## 失败与补导

- 区分解析失败、值/状态不合法、缺父项、长度错误、编码重复与同批回滚；按错误类别和层级汇总，避免输出整份业务数据或 SQL 参数。
- 部分成功后，按业务键只读核对目标实际记录，重新算差集；补导只含未成功项，并重新验证父项依赖。不能盲重传全量或删除成功记录重来；添加与更新模式按实际模板合同分别处理。
- 交付记录源行数、候选行数、去重/排除数、各批次行数、状态、依赖、静态/解析/导入验证边界。用户确认导入通过后冻结业务结果，不继续改其编码或结构。

## 引入后字段为空或未显示

- 按同一业务键和技术字段分别核对原模板值、平台解析结果、目标记录实际存储值和页面展示值，并记录缺失证据；页面为空或导入提示成功都不能单独证明值未落库。证据不足时保留待查原因，不先重写模板或认定规则、插件故障。
- 原模板与解析值正确时，将相关表单业务规则、导入及保存插件列为排查线索。由 [kingdee-metadata-analyzer](../../kingdee-metadata-analyzer/SKILL.md) 核对目标环境的有效规则、触发条件和实际挂载，再结合执行证据定位变化阶段；仅需 Java 导入扩展时读 [引入插件参考](../../kingdee-cosmic/references/base/plugin/plugin-import.md)，普通模板填写不要求开发插件。
- 官方案例通过临时关闭业务规则恢复了引入，但不构成生产关闭规则的授权。仅在已授权测试范围对定位到的精确规则做可回滚对照，保留原配置，并验证引入以及正常手工录入、保存场景；修复不得破坏原有正常行为。

依据：[单据引入模板维护数据后字段未显示引入信息](https://vip.kingdee.com/knowledge/892940022872684032)（页面显示更新于 2026-09-30，原文未标适用版本）。案例说明业务规则可能干预引入，未提供当前目标环境的根因或存储结果证据。

## 本地预检

`python3 scripts/validate_import_workbook.py --template <原模板.xlsx> --candidate <候选.xlsx> --contract <合同.json>` 只读检查 ZIP/表头/结构变化、字符串格式、必填/值域/长度、重复键和父项依赖；不联网、不写工作簿，不计算平台派生字段，不代替实际解析。

合同示例（行号、字段及状态须从本次模板确认）：

```json
{
  "sheet": "sheet1", "header_row": 3, "data_start_row": 5,
  "key_field": "number", "parent_field": "parent.number",
  "existing_keys": [], "allow_same_batch_parent": false,
  "fields": {
    "number": {"required": true, "max_length": 30, "text": true},
    "name.zh_CN": {"required": true, "max_length": 50},
    "status": {"required": true, "choices": ["已审核"]}
  }
}
```

仅检查填充模板时，可不指定 `parent_field`；有目标现存键时通过 `existing_keys` 提供。此脚本用于新增导入，重复现存键会失败；更新导入需另按目标更新合同核验，不能用空 `existing_keys` 绕过冲突。
`static_passed` 只表示所提供合同范围内未发现问题；格式变化输出 `review_required`。退出码 0/1/2 分别为静态通过/错误/需审核，所有结果均标明平台解析未执行。
