# 需求单

## 基本信息
- **需求编号**: AGR-001
- **所属行业**: 养殖
- **业务场景**: 养殖批次档案管理
- **优先级**: P1(高)
- **提出时间**: 2026-04-12
- **需求来源**: 畜禽养殖核心业务 + 苍穹**树形基础资料+子分录+值更新服务+WebAPI**能力验证

## 核心功能目标
开发一个「养殖批次档案」，记录每批次动物从进苗到出栏的全生命周期数据，包括入栏信息、防疫记录（子分录）、生长记录（子分录）、出栏信息。重点验证**多子分录操作 + 值更新服务 + 金额汇总计算**。

## 业务角色
| 角色 | 职责 |
|------|------|
| 养殖员 | 录入饲养/防疫记录 |
| 场长 | 审批出栏、查看统计 |
| 兽医 | 录入防疫记录 |

## 前置条件与依赖
- 基础资料：养殖场(树形)、栏舍、品种、疫苗、饲料
- 编码规则：批次号自动生成（PC+年月+序号）

### 业务规则
1. **养殖场-栏舍联动**：选择养殖场后过滤栏舍
2. **防疫金额自动计算**：数量×单价=金额
3. **饲料金额自动计算**：重量×单价=金额
4. **成本自动汇总**：累计防疫成本 = 防疫分录金额之和；累计饲料成本 = 饲料分录金额之和；总成本 = 入栏成本 + 饲料成本 + 防疫成本
5. **出栏数量校验**：出栏数量 ≤ 入栏数量 - 累计死亡数
6. **出栏日期校验**：出栏日期不得早于入栏日期
7. **死亡率预警**：累计死亡数/入栏数量 > 10% 时弹出警告
