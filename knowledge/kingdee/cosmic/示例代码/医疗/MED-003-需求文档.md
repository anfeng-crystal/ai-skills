# MED-003 需求文档 — 医疗随访移动端

## 1. 需求概述
实现医护人员通过手机端进行患者随访录入和查看的功能，覆盖移动端表单插件和列表插件。

## 2. 核心功能

### 2.1 随访单移动端表单（FollowUpMobileFormPlugin）
- 根据患者病情等级自动带出建议随访周期天数
- 等级映射：危重→7天，重症→14天，普通→30天，康复→90天
- 提交前校验必填项：随访结果、生命体征、下次随访日期

### 2.2 随访记录移动端列表（FollowUpMobileListPlugin）
- 按随访状态着色：逾期(overdue)→红色，今日到期(today)→橙色
- 手机端快捷查看待随访患者

## 3. 字段规格
| 字段 | 类型 | 说明 |
|------|------|------|
| patient_level | String | 病情等级：critical/serious/normal/recovered |
| suggest_followup_days | Integer | 建议随访天数（自动填充） |
| followup_result | String | 随访结果（必填） |
| vital_signs | String | 生命体征（必填） |
| next_followup_date | Date | 下次随访日期（必填） |
| followup_status | String | 状态：overdue/today/pending/completed |

## 4. 插件类型
- AbstractMobFormPlugin（移动端表单插件）
- AbstractMobListPlugin（移动端列表插件）

## 5. 验收标准
1. 选择危重级别后，建议随访天数自动变为7
2. 提交空随访结果时，弹出提示"请填写随访结果"
3. 逾期状态行显示红色，今日到期显示橙色
