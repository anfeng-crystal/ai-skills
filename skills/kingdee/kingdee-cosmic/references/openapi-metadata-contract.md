# 元数据到 API 合同

用于从实体/分录元数据生成服务端 DTO、映射和 Controller。注解及版本规则沿用 [开放平台自定义 API](base/plugin/plugin-openapi.md)；本页不另建控制器框架，也不将表单元数据全部变成对外接口。

## 输入与生成范围

复用已确认的目标环境元数据或匹配版本的本地包，记录实体、完整字段路径、分录归属和继承后的有效定义。仅有名称或局部 schema 时，缺失属性保持未知；不能由字段后缀推断基础资料、主键或数据类型。

按用户需求选择查询、创建、修改或状态操作。只需查询时不顺带生成提交、审核、反审核和删除接口。优先复用项目已有 DTO、Controller 和转换器；没有同类实现时只实现本次合同，不为一个实体生成通用基础框架。

## 字段映射

先建立小型映射表：`接口字段/方向 → 实体.分录.字段 → 真实类型与引用目标 → 转换/校验 → 来源与未确认项`。请求和响应分别确定字段范围，隐藏字段、系统字段和全部元数据属性不自动获得对外读写资格。

| 字段类别 | 需要确认的合同 |
|---|---|
| 基础资料/组织/币种 | 输入使用本地主键、业务编码还是外部编码；引用目标及组织/租户范围；沿用项目已存在的解析方式，不统一强制某个 DTO 类 |
| 金额/小数 | 单位、精度、scale 和舍入要求；确认 precision 在该元数据中表示总位数还是整数位数，再生成边界校验；用高精度类型，不擅自取整 |
| 日期/时间 | 日期、年月或时间戳语义，格式、时区和空值策略；不能仅凭 Java 类型统一格式 |
| 枚举/布尔 | 保存值、显示值和接口值的显式映射；不把编码、名称及真假值互换 |
| 分录/嵌套对象 | 完整路径、行标识、顺序以及创建/更新/删除行语义；同名字段按所属实体区分 |

表单必录、默认值和接口必填分别判断：创建、部分更新和查询可能不同。明确缺省、显式 `null`、空字符串、零和 `false` 的含义，不用默认值覆盖调用方意图。

精度语义尚未确认时，只暂缓依赖它的数值边界校验或存储转换；继续已具备证据的只读响应映射和其他字段实现，不为未知属性阻断整个本地任务。

## 校验与业务执行

按目标依赖和 Java 类型选择约束：字符非空、对象非空、集合长度和数值范围各守类型；不要给日期对象套字符串长度规则。需要嵌套校验时，核对目标绑定入口与级联行为；直接调用 Java 方法通过不等于 HTTP 绑定校验生效。

查询字段、过滤字段和排序字段使用已确认的允许范围；未知请求键按接口合同拒绝或明确忽略，不直接透传到 DynamicObject 或扩展字段容器。动态扩展字段只有在项目确有该合同且完成允许范围、类型和权限校验时才接入。

沿用平台业务操作和权限上下文，不把 DTO 校验当授权。保存/提交等结果来自真实业务服务；批量操作记录逐项成功、失败和可重试状态，外部调用超时后先核实际状态，不能把统一响应包装或返回 ID 当作落库证明。

## 验证与交付

按本次接口覆盖正常映射、缺省与空值、精度边界、嵌套分录、无权限和实际失败返回。先完成本地映射/编译检查；已授权平台验证时，再确认 HTTP 参数绑定、业务结果和目标环境实际元数据。未获运行证据的层级明确列出，生成代码不自动授权注册或发布接口。
