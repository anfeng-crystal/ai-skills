## kd-data 核心模式

### 1. BusinessDataServiceHelper 三种加载方式
```java
// 1. 加载单个完整对象（含子分录）
DynamicObject obj = BusinessDataServiceHelper.loadSingle(id, "entity_name");

// 2. 加载单个指定字段
DynamicObject obj = BusinessDataServiceHelper.loadSingle(id, "entity_name", new QFilter[]{});

// 3. 批量加载
DynamicObject[] objs = BusinessDataServiceHelper.load("entity_name", "id,field1,field2",
    new QFilter[]{new QFilter("id", QCP.in, ids)});
```

### 2. QueryServiceHelper 查询 vs 计数
```java
// 轻量查询（仅需要的字段）
DynamicObjectCollection result = QueryServiceHelper.query("entity", "field1,field2", filters);

// 计数（不需要数据，只要数量）
int count = QueryServiceHelper.queryCount("entity", filters);
```
**原则**：只需要数量用 queryCount，需要数据才用 query，且只 select 必要字段。

### 3. SaveServiceHelper 批量保存
```java
DynamicObject[] bills = BusinessDataServiceHelper.load(...);
for (DynamicObject bill : bills) {
    bill.set("status", newValue);
}
SaveServiceHelper.save("entity_name", bills);
```
