# 字段与页面联动

用于同一业务值跨接口、字段、控件、弹窗、分录和保存目标的变更。复用已有映射，小改动不另建大清单。

## 一份映射贯穿各层

- 每个受影响值确认来源、主/子层级、存储类型、引用对象、消费者，以及需要的编辑/显隐/必录、初值和单位。不适用属性不配置；接口必传、非 null、页面必录和布尔为 true 分别判断，详见[属性适用性](property-applicability.md)。
- 手填文本保持手填；基础资料存本地引用，外部 ID/编码按确认映射提取。中文名称或参数名含 Id 不足以判断类型。表单与分录保持布尔，报文边界再转换，false 不等于缺值。
- 隐藏、只读与删除是不同动作。业务匹配/发送仍需要的字段保留存储和赋值；明确废弃的字段则同步去除控件、规则、脚本、插件数组、回填和 DTO 引用，不能仅隐藏。
- 字段改名、删除和类型改变列出旧/新 Key，检查所有消费者。动态表单与分录分别核对本模型支持的类型、引用/多选结构及校验；必要字段缺失不能静默跳过。

## 页面合同

- 先确定一行代表业务记录还是字段配置。批改记录以记录为行、可编辑值为列，并带入每条原值；字段选择向导必须有需求依据。
- 只读/隐藏、标题标识、对齐、按钮文字/顺序/样式和尺寸按当前需求落实。复用平台原生控件及动作，不把只读等同于必须加锁图标，也不因改位置重做按钮样式。
- 同时核对元数据尺寸、打开参数和父容器约束；只改一处不能证明生效。表头、内容、编辑态和底部按钮分别核对；多行、长文本、滚动及窄窗口不能遮挡按钮。
- 打开参数、初始化、返回值、父页回调与再次编辑使用同一映射；原生选值过滤与保存匹配分别归属。Java 时序交 `kingdee-cosmic` 的[弹窗合同](../../kingdee-cosmic/references/dialog-entry-contract.md)，页面扩展和交互验证交相应 Skill。

## 配套交付

- 在线人工修订按实际属性合并，仍以可信导出为基线，不以旧候选覆盖新配置。字段和 Java 同改时记录配套版本、导入/部署顺序及回滚范围；旧插件仍读旧字段时不能声明可验收。
- 用户自行导入、部署后自行测试等分工属于任务合同；完成授权内的静态检查与准备，保留指定交接。真实父页验收不能用动态表单单独预览替代，但也不因此代做用户保留的测试。
- 用户要求只留最终版时，交付目录仅保留最终候选，将必要的可信原包/回滚材料放入明确的备份位置；清理本轮过期候选，不删除无关资产。
- 导入失败先区分上传、解析、运行期构建与业务运行；仅有 null 提示时查同次最内层异常和节点，不猜删字段。候选重生成后核对变化是否影响旧证据，不沿用不适用的通过结论，也不否定仍有效的用户验收。
