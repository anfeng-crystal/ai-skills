## 工具方法（非事件）

### 1. getOperationResult - 获取操作结果

**签名**：`OperationResult getOperationResult()`

**说明**：获取当前操作的执行结果对象，包含成功/失败状态、错误信息、成功的主键ID集合等。

**业务场景**：审核操作完成后，根据操作结果判断是否需要触发后续流程。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";

class AuditResultPlugin extends AbstractOperationServicePlugIn {

  afterExecuteOperationTransaction(e: AfterOperationArgs): void {
    super.afterExecuteOperationTransaction(e);

    // 获取操作结果
    let operationResult = this.getOperationResult();

    if (operationResult.isSuccess()) {
      // 获取审核成功的单据主键集合
      let successPkIds = operationResult.getSuccessPkIds();
      console.log("审核成功的单据数量：" + successPkIds.size());

      // 获取操作返回消息
      let message = operationResult.getMessage();
      console.log("操作结果消息：" + message);
    } else {
      // 获取所有错误信息
      let errorInfos = operationResult.getAllErrorOrValidateInfo();
      for (let i = 0; i < errorInfos.size(); i++) {
        let errorInfo = errorInfos.get(i);
        console.log("错误信息：" + errorInfo.getMessage());
      }
    }
  }
}

let plugin = new AuditResultPlugin();
export { plugin };
```

### 2. getOperationContext - 获取操作上下文

**签名**：`OperationContext getOperationContext()`

**说明**：获取操作的上下文信息，包含当前用户、组织、操作标识等运行时环境数据。

**业务场景**：保存操作时，根据当前登录用户所属组织来设置不同的审批策略。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";

class OrgStrategyPlugin extends AbstractOperationServicePlugIn {

  beforeExecuteOperationTransaction(e: BeforeOperationArgs): void {
    super.beforeExecuteOperationTransaction(e);

    // 获取操作上下文
    let context = this.getOperationContext();

    // 获取当前用户ID
    let currentUserId = context.getUserId();
    // 获取当前操作的组织ID
    let orgId = context.getOrgId();
    // 获取操作标识
    let operationKey = context.getOperationKey();

    console.log("当前用户：" + currentUserId
      + "，组织：" + orgId
      + "，操作：" + operationKey);

    let validExtDatas = e.getValidExtDataEntities();
    for (let i = 0; i < validExtDatas.size(); i++) {
      let extData = validExtDatas.get(i);
      let dataEntity = extData.getDataEntity();

      // 根据组织设置不同的审批策略
      if (orgId == 100001) {
        dataEntity.set("kdec_approvestrategy", "fast_approve");
      } else {
        dataEntity.set("kdec_approvestrategy", "standard_approve");
      }
    }
  }
}

let plugin = new OrgStrategyPlugin();
export { plugin };
```

### 3. setOperationContext - 设置操作上下文

**签名**：`void setOperationContext(OperationContext operationContext)`

**说明**：由框架在操作初始化时调用，设置操作上下文。一般不需要在插件中主动调用，但在特殊场景（如手动构造操作调用链）中可使用。

**业务场景**：在自定义调度任务中手动执行操作时，需要设置操作上下文来模拟用户操作环境。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { RequestContext } from "@cosmic/bos-core/kd/bos/context";

class ContextAwarePlugin extends AbstractOperationServicePlugIn {

  // 说明：setOperationContext 通常由框架自动调用，
  // 在插件中一般通过 getOperationContext 获取已设置的上下文
  beginOperationTransaction(e: BeginOperationTransactionArgs): void {
    super.beginOperationTransaction(e);

    // 实际开发中，读取上下文获取用户信息
    let context = this.getOperationContext();
    let userId = context.getUserId();

    let dataEntities = e.getDataEntities();
    for (let dataEntity of dataEntities) {
      // 记录操作人信息
      dataEntity.set("kdec_operator", userId);
      dataEntity.set("kdec_operatetime", new Date());
    }
  }
}

let plugin = new ContextAwarePlugin();
export { plugin };
```

### 4. getDataEntities - 获取数据实体数组

**签名**：`DynamicObject[] getDataEntities()`

**说明**：获取当前操作涉及的所有数据实体数组，是操作插件中访问单据数据的核心方法。

**业务场景**：提交操作时，遍历所有待提交的采购订单，汇总计算总金额并记录日志。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { DynamicObject, DynamicObjectCollection } from "@cosmic/bos-core/kd/bos/dataentity/entity";

class SubmitAmountSummaryPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("billentry.amount");
  }

  afterExecuteOperationTransaction(e: AfterOperationArgs): void {
    super.afterExecuteOperationTransaction(e);

    // 获取所有参与操作的数据实体
    let dataEntities = this.getDataEntities();

    let totalAmount = BigDecimal.ZERO;
    for (let dataEntity of dataEntities) {
      let billno = dataEntity.getString("billno");
      let entries = dataEntity.getDynamicObjectCollection("billentry") as DynamicObjectCollection;

      let billAmount = BigDecimal.ZERO;
      for (let i = 0; i < entries.size(); i++) {
        let entry = entries.get(i) as DynamicObject;
        let amount = entry.get("amount") as BigDecimal;
        if (amount != null) {
          billAmount = billAmount.add(amount);
        }
      }
      totalAmount = totalAmount.add(billAmount);
      console.log("单据 " + billno + " 金额合计：" + billAmount.toString());
    }

    console.log("本次提交总金额：" + totalAmount.toString());
  }
}

let plugin = new SubmitAmountSummaryPlugin();
export { plugin };
```

### 5. setDataEntities - 设置数据实体数组

**签名**：插件基类 `void setDataEntities(DynamicObject[] dataEntities)` 仅设置插件自己的字段，不等于过滤实际操作范围。

**业务场景**：批量审核采购订单时跳过零金额单据，仍让有效单据进入既有审核流程，并返回每张被排除单据的原因。零金额、缺失金额、负数分别处理：零金额为跳过提示；缺失金额因无法判断而单列错误；非零负数不被本规则静默排除，仍由现有业务校验决定可否审核。

目标7.0 `BeforeOperationArgs.getValidExtDataEntities()` 返回真实可变列表，执行器在前事件后重新读取它并传入事务；直接 `clear/addAll` 确实收窄执行集合，但事件另有构造时缓存的 `getDataEntities()` 数组，二者会不一致。Java `e.setDataEntities` 能同步数组并按原对象身份收窄列表；随包TS没有暴露该setter及 `isCancel`，必须由已核实的项目Java桥接接入。不能换成 `this.setDataEntities`，也不能往数组中放未校验的新对象。

```typescript
import { AbstractOperationServicePlugIn, PreparePropertysEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { BeforeOperationArgs } from "@cosmic/bos-core/kd/bos/entity/plugin/args";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { ExtendedDataEntity } from "@cosmic/bos-core/kd/bos/entity";
import { OperateErrorInfo } from "@cosmic/bos-core/kd/bos/entity/operate/result";
import { ErrorLevel } from "@cosmic/bos-core/kd/bos/entity/validate";
import { BigDecimal } from "@cosmic/bos-script/java/math";

/** 项目桥接合同：实际Java BeforeOperationArgs的两个方法未在随包TS公开。 */
interface AuditSubsetBridge {
  validate(): void;
  isCancelled(e: BeforeOperationArgs): boolean;
  // 调用真实Java e.setDataEntities；只传入原有同一对象子集，禁止改权限或重建数据包。
  replaceValidSubset(e: BeforeOperationArgs, bills: DynamicObject[]): void;
  // 核实采购订单实体与持久主键，返回精确字符串，禁止Number化长ID。
  billKey(bill: DynamicObject): string | null;
}

/** 批量审核只排除零金额；空金额单列为无法判断，负数仍交既有业务校验。 */
export function createZeroAmountFilter(bridge: AuditSubsetBridge): AbstractOperationServicePlugIn {
  bridge.validate();
  class ZeroAmountFilter extends AbstractOperationServicePlugIn {
    onPreparePropertys(e: PreparePropertysEventArgs): void {
      super.onPreparePropertys(e);
      e.getFieldKeys().add("billno");
      e.getFieldKeys().add("kdec_totalamount");
    }

    beforeExecuteOperationTransaction(e: BeforeOperationArgs): void {
      super.beforeExecuteOperationTransaction(e);
      if (e.getOperationKey() !== "audit") return;
      bridge.validate();
      const cancelled = bridge.isCancelled(e);
      if (typeof cancelled !== "boolean") throw new Error("取消状态桥接无效");
      if (cancelled) return;
      const result = this.getOperationResult();
      if (result == null) throw new Error("操作结果未初始化");
      const rows = e.getValidExtDataEntities();
      const keep: DynamicObject[] = [];
      const excluded: { row: ExtendedDataEntity; missing: boolean }[] = [];
      const seen = new Set<string>();
      // 所有身份、金额先检查完毕，再缩小范围，避免遍历中途留下半批决策。
      for (let i = 0; i < rows.size(); i++) {
        const row = rows.get(i) as ExtendedDataEntity;
        const bill = row.getDataEntity();
        const key = bridge.billKey(bill);
        if (key == null || key.length === 0 || seen.has(key)) throw new Error("有效审核集合身份缺失或重复");
        seen.add(key);
        const amount = bill.get("kdec_totalamount") as BigDecimal | null;
        if (amount == null) excluded.push({ row, missing: true });
        else if (amount.compareTo(BigDecimal.ZERO) === 0) excluded.push({ row, missing: false });
        else keep.push(bill);
      }
      if (excluded.length === 0) return;
      // 保留前序取消，且不允许桥接把已校验范围扩充为新对象。
      const cancelledBeforeWrite = bridge.isCancelled(e);
      if (typeof cancelledBeforeWrite !== "boolean") { e.setCancel(true); throw new Error("取消状态桥接无效"); }
      if (cancelledBeforeWrite) return;
      try {
        bridge.replaceValidSubset(e, keep.slice());
        const actual = e.getDataEntities();
        const valid = e.getValidExtDataEntities();
        if (actual.length !== keep.length || valid.size() !== keep.length) throw new Error("审核范围同步失败");
        for (let i = 0; i < keep.length; i++) {
          if (actual[i] !== keep[i] || (valid.get(i) as ExtendedDataEntity).getDataEntity() !== keep[i]) throw new Error("审核范围对象不一致");
        }
        for (const item of excluded) {
          const info = new OperateErrorInfo(
            item.missing ? "PUR_AUDIT_AMOUNT_MISSING" : "PUR_AUDIT_ZERO_SKIPPED",
            item.missing ? ErrorLevel.Error : ErrorLevel.Info,
            item.row.getBillPkId()
          );
          info.setDataEntityIndex(item.row.getDataEntityIndex());
          info.setMessage(item.row.getDataEntity().getString("billno") + (item.missing ? "：金额缺失，未执行审核" : "：零金额，已跳过审核"));
          result.addErrorInfo(info);
        }
      } catch (error) {
        // setter或结果记录部分失败时终止本次操作，不在未知子集上继续审核。
        e.setCancel(true);
        throw error;
      }
    }
  }
  return new ZeroAmountFilter();
}
```

`AuditSubsetBridge` 不是平台API。`validate` 须核注册实体/操作、金额字段类型、取消状态读取、真实Java setter及Java/脚本对象身份一致性，不能空实现；工厂返回实例由项目入口导出为 `plugin`。缩小范围前保留先前取消与既有校验失败，先完成整组判断；桥接后检查事件两份视图，记录逐单Info跳过或缺金额Error，不重置已有操作结果、不绕过审核或权限校验。`PUR_AUDIT_ZERO_SKIPPED` 是本项目专用提示码，最终汇总必须按Info级别和此码共同识别。

本规则收窄的是当前事件给事务的已校验集合，不能宣称同步了插件基类字段、服务原始数组或外围 `MsOperationFacade` 的输入。后续插件仍可能修改范围；取消或异常后也不提供此前外部副作用回滚承诺。启用分页、分组、插件组合时需核本例是否被调用及最终调用范围，不能用事件内子集代替完整请求结果。

### 6. setOperationResult - 设置操作结果

**签名**：`void setOperationResult(OperationResult operationResult)`

**说明**：由框架调用初始化操作结果对象。在插件中一般通过 `getOperationResult()` 获取结果并追加错误信息，而非直接替换整个结果对象。

**业务场景**：在操作执行后，向操作结果中追加自定义成功提示信息。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";

class CustomResultPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
  }

  afterExecuteOperationTransaction(e: AfterOperationArgs): void {
    super.afterExecuteOperationTransaction(e);

    // 获取操作结果并追加自定义消息
    let result = this.getOperationResult();

    if (result.isSuccess()) {
      let dataEntities = e.getDataEntities();
      let billNos = new StringBuilder();
      for (let dataEntity of dataEntities) {
        billNos.append(dataEntity.getString("billno")).append(", ");
      }
      let message = "以下单据已成功处理：" + billNos.toString();
      result.setMessage(message);
    }
  }
}

let plugin = new CustomResultPlugin();
export { plugin };
```

### 7. setContext - 设置上下文

**签名**：`default void setContext(MainEntityType billEntityType, Map<String, Object> operateMeta, ...)`

**说明**：由框架调用，传入单据实体类型、操作元数据等上下文信息。一般不需要在插件中主动调用。

**业务场景**：通过操作上下文获取当前实体类型标识，实现一个插件同时服务多个单据实体的通用逻辑。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { InitOperationArgs } from "@cosmic/bos-core/kd/bos/entity/plugin/args";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class MultiEntityPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("kdec_totalamount");
  }

  beforeExecuteOperationTransaction(e: BeforeOperationArgs): void {
    super.beforeExecuteOperationTransaction(e);

    // 通过操作上下文获取当前实体标识
    let context = this.getOperationContext();
    let entityNumber = context.getEntityNumber();

    // 根据不同实体执行不同校验逻辑
    let validExtDatas = e.getValidExtDataEntities();
    for (let i = 0; i < validExtDatas.size(); i++) {
      let extData = validExtDatas.get(i);
      let dataEntity = extData.getDataEntity();

      if (entityNumber == "pm_purorderbill") {
        // 采购订单：校验金额不超过预算
        let amount = dataEntity.get("kdec_totalamount") as BigDecimal;
        let budget = new BigDecimal("1000000");
        if (amount != null && amount.compareTo(budget) > 0) {
          e.setCancelMessage("采购订单金额超过预算上限100万");
          e.setCancel(true);
          return;
        }
      } else if (entityNumber == "sm_salorderbill") {
        // 销售订单：校验客户信用额度
        console.log("执行销售订单信用额度校验");
      }
    }
  }
}

let plugin = new MultiEntityPlugin();
export { plugin };
```

### 8. getOption - 获取操作选项

**签名**：`OperateOption getOption()`

**说明**：获取操作选项对象，可用于在事件之间传递自定义变量（通过 `setVariableValue`/`getVariableValue`），也可以读取调用方传入的自定义参数。

**业务场景**：提交操作时在 `beginOperationTransaction` 中生成关联单据，将关联单据ID通过 `Option` 传递给 `rollbackOperation`，以便失败时回滚。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { BusinessDataServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { SaveServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper/operation";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { OperateOption } from "@cosmic/bos-core/kd/bos/dataentity";
import { RequestContext } from "@cosmic/bos-core/kd/bos/context";

class OptionPassingPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("kdec_supplier");
  }

  beginOperationTransaction(e: BeginOperationTransactionArgs): void {
    super.beginOperationTransaction(e);

    let dataEntities = e.getDataEntities();
    let createdIds = new StringBuilder();

    for (let dataEntity of dataEntities) {
      // 生成关联的收货通知单
      let noticeObj = BusinessDataServiceHelper.newDynamicObject("kdec_receivenotice") as DynamicObject;
      noticeObj.set("billstatus", "A");
      noticeObj.set("kdec_sourcebillno", dataEntity.getString("billno"));
      noticeObj.set("creator", RequestContext.get().getCurrUserId());

      let result = SaveServiceHelper.saveOperate(
        "kdec_receivenotice", [noticeObj], OperateOption.create()
      );

      if (result.isSuccess()) {
        let pkIds = result.getSuccessPkIds();
        pkIds.forEach(function(pkId: any) {
          createdIds.append(pkId).append(",");
        });
      }
    }

    // 通过 Option 传递已创建的关联单据ID，供 rollbackOperation 使用
    this.getOption().setVariableValue("created_notice_ids", createdIds.toString());
  }

  rollbackOperation(e: RollbackOperationArgs): void {
    super.rollbackOperation(e);

    // 从 Option 获取需要回滚的关联单据ID
    let createdIdsStr = this.getOption().getVariableValue("created_notice_ids") as string;
    if (createdIdsStr != null && createdIdsStr.length > 0) {
      console.log("事务回滚，需要清理已创建的收货通知单：" + createdIdsStr);
      // 执行关联单据的删除补偿
    }
  }
}

let plugin = new OptionPassingPlugin();
export { plugin };
```

### 9. setOperateProgress - 设置操作进度

**签名**：`default void setOperateProgress(OperateProgress progress)`

**说明**：设置操作执行进度对象，用于批量操作时向前端报告处理进度。

**业务场景**：批量审核大量采购订单时，设置进度条让用户了解审核进展。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";

class BatchAuditProgressPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("billentry.amount");
  }

  beginOperationTransaction(e: BeginOperationTransactionArgs): void {
    super.beginOperationTransaction(e);

    let dataEntities = e.getDataEntities();
    let total = dataEntities.length;
```

### 15. onAddValidators - 添加自定义校验器

**签名**：`default void onAddValidators(AddValidatorsEventArgs e)`

**触发时机**：系统预置校验器加载完毕，执行校验前。

**说明**：添加自定义校验器对单据数据进行校验，校验失败的单据将被剔除，不进入后续事务处理。校验器继承 `AbstractValidator`，支持批量校验，一条失败不影响其他数据。

**业务场景**：采购申请单提交时，校验每个分录行的数量必须大于零，且物料不能重复。

```typescript
import { AbstractOperationServicePlugIn, AddValidatorsEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { AbstractValidator, ErrorLevel, ValidationErrorInfo } from "@cosmic/bos-core/kd/bos/entity/validate";
import { RowDataModel } from "@cosmic/bos-core/kd/bos/entity/formula";
import { DynamicObjectCollection } from "@cosmic/bos-core/kd/bos/dataentity/metadata/dynamicobject";
import { LocaleString } from "@cosmic/bos-core/kd/bos/dataentity/entity";

class ReqSubmitValidatePlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("kdec_reqentry.kdec_material");
    e.getFieldKeys().add("kdec_reqentry.kdec_qty");
  }

  onAddValidators(e: AddValidatorsEventArgs): void {
    super.onAddValidators(e);

    // 添加自定义校验器
    let ValidatorClass = this.getValidatorClass();
    e.addValidator(new ValidatorClass());
  }

  getValidatorClass() {
    class ReqEntryValidator extends AbstractValidator {
      validate(): void {
        let extDataEntities = this.getDataEntities();

        for (let rowExtData of extDataEntities) {
          let dataEntity = rowExtData.getDataEntity();
          let entries = dataEntity.get("kdec_reqentry") as DynamicObjectCollection;

          // 校验1：分录不能为空
          if (entries == null || entries.size() == 0) {
            let msg = new LocaleString(rowExtData.getBillNo() + " 采购分录不能为空");
            let info = new ValidationErrorInfo(
              "", rowExtData.getBillPkId(),
              rowExtData.getDataEntityIndex(), rowExtData.getRowIndex(),
              "REQ_ENTRY_EMPTY",
              this.getValidateContext().getOperateName(),
              msg.toString(), ErrorLevel.Error
            );
            this.getValidateResult().addErrorInfo(info);
            continue;
          }

          // 校验2：每行数量必须大于零
          let materialSet = new HashSet();
          for (let i = 0; i < entries.size(); i++) {
            let entry = entries.get(i);
            let qty = entry.get("kdec_qty") as BigDecimal;

            if (qty == null || qty.compareTo(BigDecimal.ZERO) <= 0) {
              let msg = new LocaleString(
                rowExtData.getBillNo() + " 第" + (i + 1) + "行数量必须大于零"
              );
              let info = new ValidationErrorInfo(
                "", rowExtData.getBillPkId(),
                rowExtData.getDataEntityIndex(), i,
                "REQ_QTY_INVALID",
                this.getValidateContext().getOperateName(),
                msg.toString(), ErrorLevel.Error
              );
              this.getValidateResult().addErrorInfo(info);
            }

            // 校验3：物料不能重复
            let materialObj = entry.getDynamicObject("kdec_material");
            if (materialObj != null) {
              let materialId = materialObj.getLong("id");
              if (materialSet.contains(materialId)) {
                let msg = new LocaleString(
                  rowExtData.getBillNo() + " 第" + (i + 1) + "行物料重复"
                );
                let info = new ValidationErrorInfo(
                  "", rowExtData.getBillPkId(),
                  rowExtData.getDataEntityIndex(), i,
                  "REQ_MATERIAL_DUP",
                  this.getValidateContext().getOperateName(),
                  msg.toString(), ErrorLevel.Error
                );
                this.getValidateResult().addErrorInfo(info);
              }
              materialSet.add(materialId);
            }
          }
        }
      }
    }
    return ReqEntryValidator;
  }
}

let plugin = new ReqSubmitValidatePlugin();
export { plugin };
```

### 17. beginOperationTransaction - 事务内执行

**签名**：`default void beginOperationTransaction(BeginOperationTransactionArgs e)`

**触发时机**：数据库事务已开启，数据提交入库前。

**说明**：在事务范围内处理关联数据同步。不支持跨库写操作；批量处理数据时一条失败则全部失败（事务回滚）。如有向第三方系统同步数据的需求，需在 `rollbackOperation` 中做补偿。

**业务场景**：采购申请单提交时，在同一事务内自动生成对应的采购订单。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { BusinessDataServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { SaveServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper/operation";
import { DynamicObject, DynamicObjectCollection } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { OperateOption } from "@cosmic/bos-core/kd/bos/dataentity";
import { OperationResult, OperateErrorInfo } from "@cosmic/bos-core/kd/bos/entity/operate/result";
import { KDException, ErrorCode } from "@cosmic/bos-core/kd/bos/exception";
import { RequestContext } from "@cosmic/bos-core/kd/bos/context";
import { QFilter } from "@cosmic/bos-core/kd/bos/orm/query";

class ReqSubmitCreateOrderPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("kdec_supplier");
    e.getFieldKeys().add("kdec_department");
    e.getFieldKeys().add("kdec_reqentry.kdec_material");
    e.getFieldKeys().add("kdec_reqentry.kdec_qty");
    e.getFieldKeys().add("kdec_reqentry.kdec_price");
    e.getFieldKeys().add("kdec_orderno");
  }

  beginOperationTransaction(e: BeginOperationTransactionArgs): void {
    super.beginOperationTransaction(e);

    // 获取人民币币种
    let currencyObj = BusinessDataServiceHelper.loadSingle(
      "bd_currency", [new QFilter("number", "=", "CNY")]
    );

    let orderDojs: DynamicObject[] = [];
    let dataEntities = e.getDataEntities();

    for (let dataEntity of dataEntities) {
      // 创建采购订单
      let orderDoj = BusinessDataServiceHelper.newDynamicObject("pm_purorderbill") as DynamicObject;
      orderDoj.set("billstatus", "A");
      orderDoj.set("creator", RequestContext.get().getCurrUserId());
      orderDoj.set("kdec_supplier", dataEntity.get("kdec_supplier"));
      orderDoj.set("kdec_department", dataEntity.get("kdec_department"));
      orderDoj.set("kdec_currency", currencyObj);
      orderDoj.set("kdec_sourcebillno", dataEntity.getString("billno"));

      // 复制分录数据
      let reqEntries = dataEntity.getDynamicObjectCollection("kdec_reqentry") as DynamicObjectCollection;
      let orderEntries = orderDoj.getDynamicObjectCollection("billentry") as DynamicObjectCollection;

      for (let i = 0; i < reqEntries.size(); i++) {
        let reqEntry = reqEntries.get(i) as DynamicObject;
        let orderEntry = orderEntries.addNew() as DynamicObject;
        orderEntry.set("seq", i + 1);
        orderEntry.set("kdec_material", reqEntry.get("kdec_material"));
        orderEntry.set("kdec_qty", reqEntry.get("kdec_qty"));
        orderEntry.set("kdec_price", reqEntry.get("kdec_price"));

        let qty = reqEntry.get("kdec_qty") as BigDecimal;
        let price = reqEntry.get("kdec_price") as BigDecimal;
        if (qty != null && price != null) {
          orderEntry.set("kdec_amount", qty.multiply(price).setScale(2, BigDecimal.ROUND_HALF_UP));
        }
      }

      orderDojs.push(orderDoj);
    }

    // 保存采购订单
    let result = SaveServiceHelper.saveOperate(
      "pm_purorderbill", orderDojs, OperateOption.create()
    );

    if (result.isSuccess()) {
      // 将生成的订单编号回写到申请单
      let successPkIds = result.getSuccessPkIds();
      let orderIds = new StringBuilder();
      successPkIds.forEach(function(pkId: any) {
        orderIds.append(pkId).append(",");
      });
      this.getOption().setVariableValue("created_order_ids", orderIds.toString());

      for (let idx = 0; idx < dataEntities.length; idx++) {
        dataEntities[idx].set("kdec_orderno", orderDojs[idx].getString("billno"));
      }
    } else {
      let errorInfos = result.getAllErrorOrValidateInfo();
      let errMsg = "生成采购订单失败";
      if (errorInfos.size() > 0) {
        let errorInfo = errorInfos.get(0) as OperateErrorInfo;
        errMsg = errMsg + "：" + errorInfo.getMessage();
      }
      let errorCode = new ErrorCode("kdec_req.create_order_fail", errMsg);
      throw new KDException(errorCode, []);
    }
  }
}
```

### 18. endOperationTransaction - 事务结束

**签名**：`default void endOperationTransaction(EndOperationTransactionArgs e)`

**触发时机**：数据已入库，事务尚未提交。

**说明**：在同一事务范围内进行关联数据同步更新。此时主单据数据已写入数据库，可以基于已入库的数据进行关联操作。

**业务场景**：采购入库单保存后，在同一事务内更新库存台账的库存数量。

```typescript
import { AbstractOperationServicePlugIn } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { BusinessDataServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { SaveServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper/operation";
import { DynamicObject, DynamicObjectCollection } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { OperateOption } from "@cosmic/bos-core/kd/bos/dataentity";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class InStockUpdateInventoryPlugin extends AbstractOperationServicePlugIn {

  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    e.getFieldKeys().add("billno");
    e.getFieldKeys().add("kdec_warehouse");
    e.getFieldKeys().add("stockentry.kdec_material");
    e.getFieldKeys().add("stockentry.kdec_qty");
  }

  endOperationTransaction(e: EndOperationTransactionArgs): void {
    super.endOperationTransaction(e);

    let dataEntities = e.getDataEntities();

    for (let dataEntity of dataEntities) {
      let warehouseObj = dataEntity.getDynamicObject("kdec_warehouse");
      let entries = dataEntity.getDynamicObjectCollection("stockentry") as DynamicObjectCollection;

      for (let i = 0; i < entries.size(); i++) {
        let entry = entries.get(i) as DynamicObject;
        let materialObj = entry.getDynamicObject("kdec_material");
        let inQty = entry.get("kdec_qty") as BigDecimal;

        if (materialObj == null || inQty == null) continue;

        let materialId = materialObj.getLong("id");
        let warehouseId = warehouseObj.getLong("id");

        // 查询现有库存记录
        let filters = [
          new QFilter("kdec_material", QCP.equals, materialId),
          new QFilter("kdec_warehouse", QCP.equals, warehouseId)
        ];
        let inventoryObj = BusinessDataServiceHelper.loadSingle("kdec_inventory", filters);

        if (inventoryObj != null) {
          // 更新库存数量
          let currentQty = inventoryObj.get("kdec_stockqty") as BigDecimal;
          let newQty = currentQty.add(inQty);
          inventoryObj.set("kdec_stockqty", newQty);
          inventoryObj.set("kdec_lastindate", new Date());
          SaveServiceHelper.saveOperate("kdec_inventory", [inventoryObj], OperateOption.create());
        } else {
          // 新建库存记录
          let newInventory = BusinessDataServiceHelper.newDynamicObject("kdec_inventory") as DynamicObject;
          newInventory.set("kdec_material", materialObj);
          newInventory.set("kdec_warehouse", warehouseObj);
          newInventory.set("kdec_stockqty", inQty);
          newInventory.set("kdec_lastindate", new Date());
          newInventory.set("billstatus", "A");
          SaveServiceHelper.saveOperate("kdec_inventory", [newInventory], OperateOption.create());
        }
      }
    }
  }
}

let plugin = new InStockUpdateInventoryPlugin();
export { plugin };
```

### 19. rollbackOperation - 回滚通知与外部补偿

**签名**：`void rollbackOperation(RollbackOperationArgs e)`。

**业务场景**：采购订单审核时同步外部ERP；如果对应主事务最终回滚，可靠识别并撤销本次尝试实际造成的外部变化，避免误删以前已成功业务。

不能把这个钩子当作所有事务最终回滚后的可靠通知。目标7.0 `callOperationTransaction` 的异常路径先 `markRollback`，再调用rollback，之后才 `TXHandle.close`；提交监听器 `OpTXCommitListener.onRollbacked()` 为空，close及外层后续失败不保证补发。审核状态恢复、规则回滚还先于插件回滚，它们失败也可能阻断本钩子。这里收到的数组是执行器原事务入参数组的引用，不是“已同步成功清单”，也不保证等于后续插件修改后的实际事务范围。

仅在同步循环结束后把逗号分隔单号写进option，会丢失中途失败前已完成的远端操作；单号也不是外部尝试身份。真实 `OperateOption` 单键覆盖，非null参数可被共享，单参 `getVariableValue` 缺键会抛异常，不能依赖null分支恢复。内存或随主事务回滚的记录同样不是持久账本。

下例保留审核内同步入口，先登记尝试、每笔HTTP前持久登记，再立即保存成功回执。超时或回执保存失败只表示结果待核对，不能假定远端没有执行。回滚事件只提示协调器加快扫描；协调器必须独立追踪所有已登记尝试，包括没有收到此钩子的尝试。确认最终事务已回滚且外部副作用归属本次尝试，才执行幂等补偿；UNKNOWN不删除，已提交但外部未确认也保留恢复记录。

```typescript
import { AbstractOperationServicePlugIn, PreparePropertysEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { InitOperationArgs, BeginOperationTransactionArgs, RollbackOperationArgs } from "@cosmic/bos-core/kd/bos/entity/plugin/args";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";

interface SyncTicket { ticketId: string; attemptId: string; billKey: string; externalKey: string; }
interface AppliedProof { ticketId: string; externalObjectId: string; effectId: string; }
type RemoteState = { state: "UNKNOWN" | "NOT_APPLIED" } | { state: "APPLIED"; proof: AppliedProof };

/** 项目持久协调合同；每个已登记尝试必须由恢复任务独立扫描，不能依赖回滚事件。
 * 记录须在主事务失败后仍可恢复；prepare在HTTP前持久化完整载荷/指纹、事务关联及外部幂等键。
 * 外部幂等、权属校验、锁与最终事务证明都是真实接入职责，不能用option/内存/打印模拟。
 */
interface ExternalAuditCoordinator {
  validate(): void;
  billKey(bill: DynamicObject): string | null;
  startAttempt(e: BeginOperationTransactionArgs): string;
  prepare(attemptId: string, bill: DynamicObject): SyncTicket;
  sync(ticket: SyncTicket, bill: DynamicObject): AppliedProof;
  recordApplied(ticket: SyncTicket, proof: AppliedProof): void;
  // 仅加快扫描，不作为最终回滚证明，不执行外部删除。
  hintRollback(ticket: SyncTicket): void;
  recordFailure(ticket: SyncTicket, phase: string, error: unknown): void;
  // 返回恢复范围内已登记且未完成的尝试，包含无回滚通知的记录。
  pendingTickets(): SyncTicket[];
  acquire(ticket: SyncTicket): string | null;
  release(ticket: SyncTicket, lease: string): void;
  transactionOutcome(ticket: SyncTicket, lease: string): "COMMITTED" | "ROLLED_BACK" | "UNKNOWN";
  inspectRemote(ticket: SyncTicket, lease: string): RemoteState;
  // 只撤销proof指向的本attempt实际副作用；须支持幂等重试，不按单号直接删除旧对象。
  compensate(ticket: SyncTicket, proof: AppliedProof, lease: string): boolean;
  finish(ticket: SyncTicket, outcome: "KEPT" | "NO_EFFECT" | "COMPENSATED", lease: string): void;
}

/** 只接收可持久追溯的票据，避免adapter返回空键或错归尝试。 */
function checkedTicket(ticket: SyncTicket): SyncTicket {
  for (const value of [ticket.ticketId, ticket.attemptId, ticket.billKey, ticket.externalKey]) {
    if (typeof value !== "string" || value.length === 0) throw new Error("同步票据身份不完整");
  }
  return Object.freeze({ ...ticket });
}
function checkProof(ticket: SyncTicket, proof: AppliedProof): void {
  if (proof == null || proof.ticketId !== ticket.ticketId) throw new Error("外部副作用凭据不匹配");
  for (const value of [proof.ticketId, proof.externalObjectId, proof.effectId]) {
    if (typeof value !== "string" || value.trim().length === 0) throw new Error("外部副作用凭据不匹配");
  }
}

/** 保留审核内同步入口；先登记每笔尝试，回滚钩子只发恢复提示，绝不据此立即删除。 */
export function createExternalAuditPlugin(coordinator: ExternalAuditCoordinator): AbstractOperationServicePlugIn {
  coordinator.validate();
  class ExternalAuditPlugin extends AbstractOperationServicePlugIn {
    private prepared: { bill: DynamicObject; ticket: SyncTicket }[] = [];
    initialize(e: InitOperationArgs): void {
      super.initialize(e);
      this.prepared = [];
    }
    onPreparePropertys(e: PreparePropertysEventArgs): void {
      super.onPreparePropertys(e);
      for (const field of ["billno", "kdec_supplier.name", "kdec_totalamount"]) e.getFieldKeys().add(field);
    }
    beginOperationTransaction(e: BeginOperationTransactionArgs): void {
      super.beginOperationTransaction(e);
      if (e.getOperationKey() !== "audit") return;
      coordinator.validate();
      const bills = Array.from(e.getDataEntities());
      if (bills.length === 0) return;
      const keys = bills.map(bill => coordinator.billKey(bill));
      if (keys.some(key => key == null || key.length === 0) || new Set(keys).size !== keys.length) throw new Error("审核同步身份缺失或重复");
      const attemptId = coordinator.startAttempt(e);
      if (typeof attemptId !== "string" || !attemptId) throw new Error("同步尝试未登记");
      for (let i = 0; i < bills.length; i++) {
        const bill = bills[i];
        const ticket = checkedTicket(coordinator.prepare(attemptId, bill));
        if (ticket.attemptId !== attemptId || ticket.billKey !== keys[i]) throw new Error("同步票据不属于当前单据尝试");
        if (this.prepared.some(entry => entry.ticket.ticketId === ticket.ticketId || entry.ticket.externalKey === ticket.externalKey)) throw new Error("同步票据或外部幂等键重复");
        this.prepared.push({ bill, ticket });
        // prepare已持久登记：HTTP或回执记录抛错时仍可按externalKey恢复，不假定远端未执行。
        const proof = coordinator.sync(ticket, bill);
        checkProof(ticket, proof);
        coordinator.recordApplied(ticket, proof);
      }
    }
    rollbackOperation(e: RollbackOperationArgs): void {
      super.rollbackOperation(e);
      const rollbackBills = e.getDataEntitys();
      if (rollbackBills == null) return;
      for (const entry of this.prepared) {
        if (!Array.from(rollbackBills).some(bill => bill === entry.bill)) continue;
        try {
          coordinator.hintRollback(entry.ticket);
        } catch (error) {
          // 单笔通知失败不阻止余项；恢复扫描本来就独立于通知，且保留原事务异常。
          try { coordinator.recordFailure(entry.ticket, "rollback-hint", error); } catch (_) { /* 持久扫描仍负责恢复，不能称通知成功。 */ }
        }
      }
    }
  }
  return new ExternalAuditPlugin();
}

/** 由已授权项目恢复任务调用；只有最终主事务回滚且本尝试副作用归属明确才补偿。 */
export function reconcileExternalAttempts(coordinator: ExternalAuditCoordinator): { ticketId: string; outcome: string }[] {
  coordinator.validate();
  const report: { ticketId: string; outcome: string }[] = [];
  for (const rawTicket of coordinator.pendingTickets()) {
    let ticket: SyncTicket;
    try { ticket = checkedTicket(rawTicket); }
    catch (_) { report.push({ ticketId: "[无效票据]", outcome: "需修复记录" }); continue; }
    let lease: string | null = null;
    let phase = "acquire";
    try {
      lease = coordinator.acquire(ticket);
      if (lease == null) { report.push({ ticketId: ticket.ticketId, outcome: "其它任务处理中" }); continue; }
      if (typeof lease !== "string" || lease.length === 0) throw new Error("恢复锁凭据无效");
      phase = "transaction-outcome";
      const tx = coordinator.transactionOutcome(ticket, lease);
      if (tx === "COMMITTED") {
        phase = "inspect-committed-remote";
        const remote = coordinator.inspectRemote(ticket, lease);
        if (remote.state === "APPLIED") {
          checkProof(ticket, remote.proof);
          phase = "finish-kept";
          coordinator.finish(ticket, "KEPT", lease);
          report.push({ ticketId: ticket.ticketId, outcome: "已提交，保留已确认外部结果" });
        } else report.push({ ticketId: ticket.ticketId, outcome: "已提交但外部结果未确认，保留待恢复" });
      } else if (tx === "ROLLED_BACK") {
        phase = "inspect-remote";
        const remote = coordinator.inspectRemote(ticket, lease);
        if (remote.state === "NOT_APPLIED") {
          phase = "finish-no-effect";
          coordinator.finish(ticket, "NO_EFFECT", lease);
          report.push({ ticketId: ticket.ticketId, outcome: "已确认无外部副作用" });
        } else if (remote.state === "APPLIED") {
          checkProof(ticket, remote.proof);
          phase = "compensate";
          if (coordinator.compensate(ticket, remote.proof, lease) !== true) throw new Error("补偿结果未确认");
          phase = "finish-compensated";
          coordinator.finish(ticket, "COMPENSATED", lease);
          report.push({ ticketId: ticket.ticketId, outcome: "补偿已确认" });
        } else report.push({ ticketId: ticket.ticketId, outcome: "远端结果未知，继续核对" });
      } else report.push({ ticketId: ticket.ticketId, outcome: "最终事务结果未知，继续核对" });
    } catch (error) {
      report.push({ ticketId: ticket.ticketId, outcome: phase + "失败，保留待恢复" });
      try { coordinator.recordFailure(ticket, phase, error); }
      catch (_) { report.push({ ticketId: ticket.ticketId, outcome: "诊断记录失败，需核查恢复服务" }); }
    } finally {
      if (typeof lease === "string" && lease.length > 0) {
        try { coordinator.release(ticket, lease); }
        catch (_) { report.push({ ticketId: ticket.ticketId, outcome: "恢复锁释放失败，需核查" }); }
      }
    }
  }
  return report;
}
```

`ExternalAuditCoordinator` 是必须实现的项目合同，不是苍穹API，也不是可空实现的示例服务。接入前须核实：真实采购订单与audit挂载；持久记录不随主事务消失；完整单号、供应商、金额载荷与指纹，sync使用prepare固化载荷或核验指纹一致；尝试到最终事务的可靠关联；外部幂等键与作用范围；恢复锁、已完成票据拒绝再领取和最终状态单调性。`inspectRemote` 的NOT_APPLIED必须是已确认终态，不能把超时、暂不可见或404直接当作未执行。`proof`必须证明externalObjectId/effectId属于本票据造成的变化；仅相同单号或同一目标对象存在不够。

由项目入口导出工厂实例为 `plugin`，由独立的已授权恢复任务调用协调函数并展示其报告。补偿/记录/锁释放失败分别报告并继续其他票据；主回滚钩子的通知失败不覆盖原事务异常，持久扫描仍负责恢复，不能称通知或补偿已成功。HTTP认证、URL、权限与持久化方式由项目提供，不能补造；缺少此合同就不能声称已实现可靠外部同步与补偿。真实事务、网络超时、外层回滚、并发恢复及KingScript引用桥接需要项目验收，离线示例不代替这些验证。

依据：[官方操作插件事件说明](https://vip.kingdee.com/knowledge/225566067572376064)给出通用时机；上述目标边界依据7.0 `EntityOperateService`、`OpTXCommitListener`、`StatusConvertOperateService`、`Audit`、`RollbackOperationArgs` 和 `OperateOptionPrivate` 的实际消费路径。没有证实普通审核必然自动分组或重放回滚，不能把这些假设写成平台事实。

### 20. afterExecuteOperationTransaction - 事务后处理

**签名**：`default void afterExecuteOperationTransaction(AfterOperationArgs e)`

**触发时机**：操作执行完毕，事务已提交。

**说明**：适合做日志记录、消息通知等非事务性操作。此时数据已确认写入数据库。

**业务场景**：采购申请单提交成功后，向审批人发送消息通知。

### 21. onReturnOperation - 返回操作结果

**签名**：`void onReturnOperation(ReturnOperationArgs e)`；`e.getOperationResult()` 返回 `IOperationResult`。

**业务场景**：批量操作后显示单据级成功、失败、跳过及可读明细，保留调用方实际结果和原有后继操作。

此事件不能当作所有路径的最终合并点。目标7.0 `EntityOperateService.excute(DynamicObject[])` 派发返回事件后仍可能执行 `mergeSubOpResult`：非null子消息覆盖原消息、成功PK取交集、错误与校验追加。事件无论成功与否都可能触发；如果在此留阶段快照，须立即复制成独立数据并明确标注“事件阶段”，不得把同一个可变结果引用当最终快照。

真正的全请求汇总应在调用方收到全部最终结果后，结合操作前保留的完整请求ID计算。相同单据可有多条校验信息，空PK可为全局错误，Info也不一定是失败；成功列表可能重复。不以信息条数当失败单据数，也不把未分类请求补成成功。下面的只读汇总器保留所有明细、原消息和原成功标志，成功/失败/跳过冲突单列；未知级别、无法归属、范围外信息均显式呈现。

```typescript
import { OperationResult, OperateErrorInfo, IOperateInfo } from "@cosmic/bos-core/kd/bos/entity/operate/result";
import { ErrorLevel } from "@cosmic/bos-core/kd/bos/entity/validate";

interface SummaryDetail {
  key: string | null;
  category: "failure" | "skip" | "info" | "unknown";
  title: string;
  message: string;
}
interface FinalOperationSummary {
  success: string[]; failure: string[]; skipped: string[]; unknown: string[]; conflicts: string[];
  duplicateRequestKeys: string[]; invalidRequestCount: number;
  globalDetails: SummaryDetail[]; outsideDetails: SummaryDetail[]; details: SummaryDetail[];
  outsideSuccessKeys: string[]; invalidSuccessCount: number;
  platformSuccessFlag: boolean; originalMessage: string; text: string;
}

/** 在调用方收到最终OperationResult后执行；不在onReturnOperation内冒充最终结果。
 * keyOf必须无损核验请求、返回PK的同一实体身份；null表示无法归属，不可用序号或金额代替PK。
 * 函数只读取原结果，返回独立摘要；不改消息、错误、成功标志、交互或后继操作。
 */
export function summarizeFinalOperation(
  requestIds: unknown[], result: OperationResult, keyOf: (id: unknown) => string | null
): FinalOperationSummary {
  const requested = new Map<string, { success: boolean; failure: boolean; skip: boolean; unknown: boolean }>();
  const duplicateRequestKeys: string[] = [];
  let invalidRequestCount = 0;
  for (const id of requestIds) {
    const key = keyOf(id);
    if (key == null || key.length === 0) { invalidRequestCount++; continue; }
    if (requested.has(key)) duplicateRequestKeys.push(key);
    else requested.set(key, { success: false, failure: false, skip: false, unknown: false });
  }
  const outsideSuccessKeys = new Set<string>();
  let invalidSuccessCount = 0;
  const successIds = result.getSuccessPkIds();
  for (let i = 0; i < successIds.size(); i++) {
    const key = keyOf(successIds.get(i));
    if (key == null || key.length === 0) { invalidSuccessCount++; continue; }
    const row = requested.get(key);
    if (row) row.success = true; else outsideSuccessKeys.add(key);
  }
  const details: SummaryDetail[] = [], globalDetails: SummaryDetail[] = [], outsideDetails: SummaryDetail[] = [];
  const infos = result.getAllErrorOrValidateInfo();
  for (let i = 0; i < infos.size(); i++) {
    const info = infos.get(i) as IOperateInfo;
    const key = keyOf(info.getPkValue());
    let category: SummaryDetail["category"] = "unknown";
    // 实际校验信息继承OperateErrorInfo；其它IOperateInfo无法证明级别时保留未知。
    if (info instanceof OperateErrorInfo) {
      const level = info.getLevel();
      if (level != null && level.getValue() === ErrorLevel.Info.getValue()) {
        category = info.getErrorCode() === "PUR_AUDIT_ZERO_SKIPPED" ? "skip" : "info";
      } else if (level != null && [ErrorLevel.Warning.getValue(), ErrorLevel.Error.getValue(), ErrorLevel.FatalError.getValue()].includes(level.getValue())) {
        category = "failure";
      }
    }
    const detail: SummaryDetail = { key: key || null, category, title: info.getTitle(), message: info.getMessage() };
    details.push(detail);
    if (key == null || key.length === 0) { globalDetails.push(detail); continue; }
    const row = requested.get(key);
    if (!row) { outsideDetails.push(detail); continue; }
    if (category === "failure") row.failure = true;
    if (category === "skip") row.skip = true;
    if (category === "unknown") row.unknown = true;
  }
  const success: string[] = [], failure: string[] = [], skipped: string[] = [], unknown: string[] = [], conflicts: string[] = [];
  for (const [key, row] of requested) {
    const count = Number(row.success) + Number(row.failure) + Number(row.skip);
    if (count > 1) conflicts.push(key);
    else if (row.unknown || count === 0) unknown.push(key);
    else if (row.success) success.push(key);
    else if (row.failure) failure.push(key);
    else skipped.push(key);
  }
  const text = "操作结果：成功 " + success.length + " 单，失败 " + failure.length
    + " 单，跳过 " + skipped.length + " 单，未知 " + unknown.length + " 单，冲突 " + conflicts.length
    + " 单；全局信息 " + globalDetails.length + " 条，范围外信息 " + outsideDetails.length
    + " 条，范围外成功ID " + outsideSuccessKeys.size + " 个，无效成功ID " + invalidSuccessCount
    + " 个，重复请求 " + duplicateRequestKeys.length + " 项，无效请求 " + invalidRequestCount + " 项"
    + (details.length ? "\n明细：\n" + details.map(d => "[" + d.category + "] " + (d.key || "无单据归属") + "：" + d.message).join("\n") : "");
  return { success, failure, skipped, unknown, conflicts, duplicateRequestKeys, invalidRequestCount,
    globalDetails, outsideDetails, details, outsideSuccessKeys: [...outsideSuccessKeys], invalidSuccessCount,
    platformSuccessFlag: result.isSuccess(), originalMessage: result.getMessage(), text };
}
```

此函数是项目调用方工具，不是新平台事件。`requestIds` 必须来自本次完整原请求，不是事件当前子集；`keyOf` 须对原请求和结果使用同一实体的无损主键合同，无效值返回null，不用JS Number转换长整型ID。若调用方自行分批，先合并各批最终结果，再调用一次；不能从一次 `onReturnOperation` 推断请求总范围。`instanceof` 与Java枚举/集合桥接也要在实际KingScript宿主核实。摘要中的“成功”只代表最终结果载荷对该PK的报告，不自行证明外层事务提交或远端副作用完成；存在全局信息仍保留逐单可确认结果，不把一个全局错误虚构成每张单据的失败。

通过项目已有的返回/页面展示通道展示 `text` 与 `originalMessage`，同时保留原错误细节。标准前端单错误分支优先显示该错误，多结果页面只有 `messageType==1` 才传递非空message；只 `setMessage` 不能保证汇总可见。也不要仅为汇总强设自定义结果页：这可能阻止保存后提交、提交后关闭等后继操作。没有可用调用方集成点时，明确只能提供事件阶段信息，不能把此示例直接注册后声称完整最终汇总已生效。

依据：[KingScript操作插件指南](https://vip.kingdee.com/knowledge/720652815630194944)、[自定义结果页面及后继操作边界](https://vip.kingdee.com/knowledge/734099201797243392)；具体合并与显示语义核对目标7.0 `OperationResult`、`AbstractOperationResult`、`EntityOperateService`、`AbstractFormView` 与随包声明。

### 22. beforeSaveAuditLog - 保存审计日志前

**签名**：`void beforeSaveAuditLog(BeforeSaveAuditLogArg e)`。

**业务场景**：采购订单审核时，把对应单据的单号、供应商、金额追加到已有审核状态变化的审计描述，保留原字段变化与审计身份。

目标7.0执行器按成功数据逐单构建 `EntityModifyInfo`，触发本事件后继续序列化原来的同一载荷。参数仅携带当前审计修改信息，不能循环插件全部单据替它描述；基类 `getDataEntities()` / `getOperationContext()` 在该执行路径没有注入，不能作为数据来源。先在 `afterExecuteOperationTransaction` 从事件的成功数据采集只读快照，再按 `getKeyID()` 精确唯一匹配。这里的成功只是该执行器当前阶段事实，不能据此宣称外层事务最终提交。

`getModifyInfo()` 不是描述字符串；随包TS没有 `setDescription` 或 `setModifyInfo`。Java即使替换参数中的modifyInfo，后续消费者仍拿原局部引用。修改原载荷上真实审核状态变化的 `FieldModifyInfo.caption`，即可保留old/new并进入JSON和文本内容；新增 `FieldModifyInfo(null, 描述)` 会伪造字段变化，修改 `getFields()` 返回列表也不能写回原Map。头实体caption本身不保证显示在文本日志里。

下例只注册到采购订单 `audit`，并接入真实状态转换与主键合同。空金额写“未提供”，不写0；重复身份、无成功快照、没有唯一真实状态变更、删除/子实体载荷均保持原日志。日志开关关闭、未配置监控字段或没有变动时，执行器可能根本不触发此事件，不能通过本钩子补造一条日志。

```typescript
import { AbstractOperationServicePlugIn, PreparePropertysEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { InitOperationArgs, AfterOperationArgs, BeforeSaveAuditLogArg } from "@cosmic/bos-core/kd/bos/entity/plugin/args";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";

/** 项目接入合同：仅注册采购订单audit；核实体、主键、真实审核状态及展示值。 */
interface PurchaseAuditContract {
  statusField: string;
  validate(): void;
  // 验证采购订单实体和持久主键，返回与EntityModifyInfo.keyID完全一致的字符串；不得Number化长ID。
  billKey(bill: DynamicObject): string | null;
  // 仅真实且不同的旧、新状态构成已确认的审核转换时返回true，不能猜测B/C。
  isAuditTransition(oldValue: unknown, newValue: unknown): boolean;
}

/** 用真实已有审核状态变化的caption携带上下文，不新增或伪造字段变更。 */
export function createPurchaseAuditPlugin(contract: PurchaseAuditContract): AbstractOperationServicePlugIn {
  contract.validate();
  if (!contract.statusField || contract.statusField.includes(".")) throw new Error("须指定已核实的头审核状态字段");
  const statusField = contract.statusField;
  class PurchaseAuditPlugin extends AbstractOperationServicePlugIn {
    private contexts = new Map<string, string>();
    private ambiguous = new Set<string>();
    private enhanced = new Set<$.kd.bos.log.api.FieldModifyInfo>();

    /** 每次操作初始化清理缓存；不把上次成功单据带入本次审计。 */
    initialize(e: InitOperationArgs): void {
      super.initialize(e);
      this.contexts.clear();
      this.ambiguous.clear();
      this.enhanced.clear();
    }

    onPreparePropertys(e: PreparePropertysEventArgs): void {
      super.onPreparePropertys(e);
      for (const field of ["billno", "kdec_supplier.name", "kdec_totalamount", statusField]) e.getFieldKeys().add(field);
    }

    /** 只从真实成功事件数据采集快照，插件基类getDataEntities并未由该执行器注入。 */
    afterExecuteOperationTransaction(e: AfterOperationArgs): void {
      super.afterExecuteOperationTransaction(e);
      this.contexts.clear();
      this.ambiguous.clear();
      this.enhanced.clear();
      if (e.getOperationKey() !== "audit") return;
      contract.validate();
      const bills = e.getDataEntities();
      for (const bill of bills) {
        const key = contract.billKey(bill);
        if (key == null || key.length === 0) continue;
        if (this.contexts.has(key) || this.ambiguous.has(key)) {
          this.contexts.delete(key);
          this.ambiguous.add(key);
          continue;
        }
        const supplier = bill.getDynamicObject("kdec_supplier");
        const amount: unknown = bill.get("kdec_totalamount");
        // 空金额与0有不同含义；文本按原值展示，不补造缺失业务事实。
        const billNo = bill.getString("billno");
        const supplierName = supplier == null ? "[未设置]" : supplier.getString("name");
        const text = "审核采购订单【" + (billNo || "[单号为空]") + "】"
          + "，供应商：" + (supplierName || "[名称为空]")
          + "，金额：" + (amount == null ? "[未提供]" : String(amount));
        this.contexts.set(key, text.replace(/[\r\n\t]/g, " "));
      }
    }

    /** 按本次审计keyID唯一定位，原位修改消费者持有的同一字段；不替换modifyInfo。 */
    beforeSaveAuditLog(e: BeforeSaveAuditLogArg): void {
      super.beforeSaveAuditLog(e);
      const info = e.getModifyInfo();
      if (info == null || info.getParent() != null || info.getFlag() === "-") return;
      const key = info.getKeyID();
      const context = this.contexts.get(key);
      if (context == null || this.ambiguous.has(key)) return;
      const fields = info.getFields();
      let change: $.kd.bos.log.api.FieldModifyInfo | null = null;
      for (let i = 0; i < fields.size(); i++) {
        const candidate = fields.get(i) as $.kd.bos.log.api.FieldModifyInfo;
        if (candidate.getFieldName() !== statusField) continue;
        if (change != null) return;
        change = candidate;
      }
      if (change == null || change.getEntity() !== info || this.enhanced.has(change)) return;
      if (contract.isAuditTransition(change.getOldValue(), change.getNewValue()) !== true) return;
      const oldCaption = change.getCaption();
      if (oldCaption == null || oldCaption.length === 0) return;
      change.setCaption(oldCaption + "（" + context + "）");
      this.enhanced.add(change);
    }
  }
  return new PurchaseAuditPlugin();
}
```

`PurchaseAuditContract` 是项目接入合同，不是平台API；`validate` 必须验证实际实体、审核操作挂载、字段类型、状态对与主键转换，不能空实现。`billKey` 对跨实体或无效主键返回null；长整型主键用原始字符串合同，不经JavaScript Number。把工厂返回实例由项目入口导出为 `plugin` 后注册。示例不查询数据库、不写业务字段，也不主动保存审计日志；日志最终写入、界面显示、桥接对象身份及外层事务边界仍须项目验证。平台或其他插件后续改变载荷，不能由这里的快照保证不变。 原生摘要会截为最多510字符（超长时507字符加省略号），完整JSON另存修改内容；writeLogWithoutError还会吞掉异常，事件处理或序列化完成不证明日志落库，也不能把本钩子当业务拒绝校验。

依据：[官方审计事件机制](https://vip.kingdee.com/knowledge/211543323638015488)给出4.0历史机制；上面的逐单载荷、引用与渲染边界以目标7.0 `EntityOperateService.writeLog/writeAuditLog/buildContent`、`EntityModifyInfo`、`FieldModifyInfo` 及随包声明为准，不能用历史页面推定全部版本。

### 23. validatePrefix - 校验提示前缀与编号规则分工

**签名**：`validatePrefix(e: ValidatePrefixArgs): void`，参数来自 `@cosmic/bos-core/kd/bos/entity/plugin/args`。

**真实责任**：本机7.0在创建 `ValidateContext` 时传入 `ValidatePrefixArgs`，插件指定的 `propName` 被放入校验上下文。`AbstractValidator.addMessage/addErrorMessage` 读取该字段值，组成校验提示的前缀。参数不是编号规则，也没有 `setCancel/setCancelMessage`；仅记录日志不会使单据校验失败。字段名须存在并已加载；空配置交给平台默认处理。非空自定义字段取不到值时，消费者不会退回默认单号，因此不能把任意展示文字当字段名。

**业务场景**：采购订单既要用单号定位校验提示，又要求单号以本单组织编码为前缀。下面分别配置消息字段和注册真正的业务校验器，保留系统及前插件校验器。逐单读取单头 `org.number`，不以当前登录组织代表批量单据组织；本例按字面、区分大小写的 `startsWith` 校验，不能由前缀合法推断完整编号唯一或替代编码规则。

**接入前提**：`billno/org/org.number` 必须是项目已核字段，org是单头组织引用；目标操作在执行校验前已经有正式编号。若保存操作要在校验之后才分配编号，本例不能直接挂到该时点，应沿实际编号生成合同选择校验时机。列表加载路径预声明字段；直接传入模型数据包仍须保证数据已加载。未查库、不创建或更新单号。

```typescript
/**
 * 采购订单组织编号前缀校验：仅校验既有编号，不生成编号或承诺编号唯一。
 * 挂到已核采购订单操作；org 是本单单头组织基础资料，number 是其编码。
 * 目标操作在校验前必须已有正式 billno；保存前尚未编号的操作不得直接挂此例。
 */
import { AbstractOperationServicePlugIn, AddValidatorsEventArgs, PreparePropertysEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { ValidatePrefixArgs } from "@cosmic/bos-core/kd/bos/entity/plugin/args";
import { AbstractValidator, ErrorLevel, ValidationErrorInfo } from "@cosmic/bos-core/kd/bos/entity/validate";

/** 逐单头校验本单组织编码与编号；不查询登录组织，不写业务数据。 */
class OrgBillPrefixValidator extends AbstractValidator {
    /** 以实际操作实体定位单头；在平台提取校验行之前完成。 */
    initializeConfiguration(): void {
        super.initializeConfiguration();
        this.setEntityKey(this.getValidateContext().getEntityNumber());
    }

    /** 只读取单头字段，不依赖完整分录，允许大单分录分页路径。 */
    isSupportSplitPageMode(): boolean {
        return true;
    }

    /** 原始字符串按字面区分大小写；缺失值不能作为空前缀放行。 */
    validate(): void {
        const rows = this.getDataEntities();
        if (rows == null) return;
        for (let i = 0; i < rows.length; i++) {
            const row = rows[i];
            const data = row.getDataEntity();
            const billno = data.getString("billno");
            const org = data.getDynamicObject("org");
            const orgNumber = org == null ? null : org.getString("number");
            let message: string | null = null;
            let fieldKey = "billno";
            if (orgNumber == null || orgNumber.trim().length === 0) {
                fieldKey = "org";
                message = "本单组织及其编码不能为空，无法校验单据编号前缀";
            } else if (billno == null || billno.trim().length === 0) {
                message = "单据编号不能为空，无法校验组织编码前缀";
            } else if (!billno.startsWith(orgNumber)) {
                message = "单据编号必须以本单组织编码 " + orgNumber + " 为前缀";
            }
            if (message != null) {
                const display = billno == null || billno.length === 0 ? "[空编号]" : billno;
                // 直接构造的错误不经过 AbstractValidator.addMessage，需要自行提供完整提示。
                this.getValidateResult().addErrorInfo(new ValidationErrorInfo(
                    fieldKey, row, "ORG_BILL_PREFIX", "组织编号前缀校验",
                    display + "：" + message, ErrorLevel.Error
                ));
            }
        }
    }
}

/** 消息前缀配置与业务校验分别接真实事件，不改已有校验器或编号规则。 */
class BillNoValidatePlugin extends AbstractOperationServicePlugIn {
    /** 列表操作加载单头字段；模型直传路径仍要求这些字段已在本次包中。 */
    onPreparePropertys(e: PreparePropertysEventArgs): void {
        super.onPreparePropertys(e);
        e.getFieldKeys().add("billno");
        e.getFieldKeys().add("org");
        e.getFieldKeys().add("org.number");
    }

    /** 仅配置平台提示前缀所读字段；保留前插件已指定的非空字段。 */
    validatePrefix(e: ValidatePrefixArgs): void {
        super.validatePrefix(e);
        const existing = e.getPropName();
        if (existing == null || existing.trim().length === 0) e.setPropName("billno");
    }

    /** 附加本例校验，保留平台及前插件已注册的其它校验器。 */
    onAddValidators(e: AddValidatorsEventArgs): void {
        super.onAddValidators(e);
        e.addValidator(new OrgBillPrefixValidator());
    }
}

let plugin = new BillNoValidatePlugin();
export { plugin };
```

**消息与批量边界**：此声明未公开 protected `addErrorMessage`，因此业务校验使用真实 `ValidationErrorInfo(fieldKey, ExtendedDataEntity, errorCode, title, message, ErrorLevel)` 重载，保留每单身份、数据包索引与行定位，再加入 `ValidateResult`。直接构造错误不会经过平台的消息前缀拼装，所以本例自己构造完整提示，不指望 `validatePrefix` 替它补单号。`ErrorLevel.Error` 交平台校验流程处理无效单据；是否整体回滚、继续处理有效单据取决于目标操作及其选项，不能把错误集合当作已验事务结果。这里没有删除预置校验器，也不使用虚构的事件取消方法。

依据：[官方操作事件总览](https://vip.kingdee.com/knowledge/225566067572376064)、[onAddValidators注册与逐单校验](https://developer.kingdee.com/knowledge/225568330919027968)、[KingScript操作插件指南](https://vip.kingdee.com/knowledge/720652815630194944)。官方文档说明操作校验入口和生命周期，未声明最低产品版本；`validatePrefix` 的确切语义以本机7.0随包声明及 `EntityOperateService.createValidateContext → ValidateContext → AbstractValidator` 消费链为准。实际项目字段、正式编号生成时点、页面提示及操作事务尚未验收。

## 完整生命周期综合案例

以下是一个完整的操作插件，展示所有生命周期方法在同一个业务流程中的协作：

**场景**：采购申请单自定义提交操作，包括字段预加载、数据校验、金额计算、生成采购订单、库存预留、消息通知、异常回滚等完整流程。

```typescript
import { AbstractOperationServicePlugIn, AddValidatorsEventArgs } from "@cosmic/bos-core/kd/bos/entity/plugin";
import { AbstractValidator, ErrorLevel, ValidationErrorInfo } from "@cosmic/bos-core/kd/bos/entity/validate";
import { BusinessDataServiceHelper, QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { SaveServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper/operation";

import { MessageCenterServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper/workflow";

import { RequestContext } from "@cosmic/bos-core/kd/bos/context";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";

class ReqBillFullLifecyclePlugin extends AbstractOperationServicePlugIn {

  // ========== 1. 字段预加载 ==========
  onPreparePropertys(e: $.kd.bos.entity.plugin.PreparePropertysEventArgs): void {
    super.onPreparePropertys(e);
    let fields = e.getFieldKeys();
    fields.add("billno");
    fields.add("kdec_supplier");
    fields.add("kdec_supplier.name");
    fields.add("kdec_department");
    fields.add("kdec_totalamount");
    fields.add("kdec_reqentry.kdec_material");
    fields.add("kdec_reqentry.kdec_qty");
    fields.add("kdec_reqentry.kdec_price");
    fields.add("kdec_reqentry.kdec_amount");
    fields.add("kdec_orderno");
  }

  // ========== 2. 自定义校验器 ==========
  onAddValidators(e: AddValidatorsEventArgs): void {
    super.onAddValidators(e);
    let ValidatorClass = this.getValidatorClass();
    e.addValidator(new ValidatorClass());
  }

  getValidatorClass() {
    class ReqValidator extends AbstractValidator {
      validate(): void {
        let extDataEntities = this.getDataEntities();
        for (let rowExtData of extDataEntities) {
          let dataEntity = rowExtData.getDataEntity();
          let entries = dataEntity.get("kdec_reqentry") as DynamicObjectCollection;
          if (entries == null || entries.size() == 0) {
            let msg = new LocaleString(rowExtData.getBillNo() + " 分录不能为空");
            let info = new ValidationErrorInfo(
              "", rowExtData.getBillPkId(),
              rowExtData.getDataEntityIndex(), rowExtData.getRowIndex(),
              "ENTRY_EMPTY", this.getValidateContext().getOperateName(),
              msg.toString(), ErrorLevel.Error
            );
            this.getValidateResult().addErrorInfo(info);
          }
        }
      }
    }
    return ReqValidator;
  }

  // ========== 3. 事务前：金额计算（耗时逻辑放事务外） ==========
  beforeExecuteOperationTransaction(e: BeforeOperationArgs): void {
    super.beforeExecuteOperationTransaction(e);

    let validExtDatas = e.getValidExtDataEntities();
    for (let i = 0; i < validExtDatas.size(); i++) {
      let extData = validExtDatas.get(i);
      let dataEntity = extData.getDataEntity();

      // 重新计算分录金额
      let entries = dataEntity.getDynamicObjectCollection("kdec_reqentry") as DynamicObjectCollection;
      let totalAmount = BigDecimal.ZERO;
      for (let j = 0; j < entries.size(); j++) {
        let entry = entries.get(j) as DynamicObject;
        let qty = entry.get("kdec_qty") as BigDecimal;
        let price = entry.get("kdec_price") as BigDecimal;
        if (qty != null && price != null) {
          let amount = qty.multiply(price).setScale(2, BigDecimal.ROUND_HALF_UP);
          entry.set("kdec_amount", amount);
          totalAmount = totalAmount.add(amount);
        }
      }
      dataEntity.set("kdec_totalamount", totalAmount);
    }
  }

  // ========== 4. 事务内：生成采购订单 ==========
  beginOperationTransaction(e: BeginOperationTransactionArgs): void {
    super.beginOperationTransaction(e);

    let dataEntities = e.getDataEntities();
    let orderDojs: DynamicObject[] = [];

    for (let dataEntity of dataEntities) {
      let orderDoj = BusinessDataServiceHelper.newDynamicObject("pm_purorderbill") as DynamicObject;
      orderDoj.set("billstatus", "A");
      orderDoj.set("creator", RequestContext.get().getCurrUserId());
      orderDoj.set("kdec_sourcebillno", dataEntity.getString("billno"));
      orderDojs.push(orderDoj);
    }

    let result = SaveServiceHelper.saveOperate("pm_purorderbill", orderDojs, OperateOption.create());

    if (result.isSuccess()) {
      let ids = new StringBuilder();
      result.getSuccessPkIds().forEach(function(pkId: any) {
        ids.append(pkId).append(",");
      });
      this.getOption().setVariableValue("order_ids", ids.toString());
    } else {
      let errorCode = new ErrorCode("req.submit.fail", "生成采购订单失败");
      throw new KDException(errorCode, []);
    }
  }

  // ========== 5. 数据入库后：关联数据更新 ==========
  endOperationTransaction(e: EndOperationTransactionArgs): void {
    super.endOperationTransaction(e);
    console.log("数据已入库，执行关联更新");
  }

  // ========== 6. 事务回滚：补偿处理 ==========
  rollbackOperation(e: RollbackOperationArgs): void {
    super.rollbackOperation(e);

    let orderIds = this.getOption().getVariableValue("order_ids") as string;
    if (orderIds != null && orderIds.length > 0) {
      console.log("事务回滚，需删除已生成的采购订单：" + orderIds);
    }
  }

  // ========== 7. 事务后：发送通知 ==========
  afterExecuteOperationTransaction(e: AfterOperationArgs): void {
    super.afterExecuteOperationTransaction(e);

    let userId = RequestContext.get().getCurrUserId();
    let dataEntities = e.getDataEntities();
    let messageInfos = new ArrayList();

    for (let dataEntity of dataEntities) {
      let messageInfo = new MessageInfo();
      messageInfo.setMessageTitle(new LocaleString("采购申请已提交：" + dataEntity.getString("billno")));
      messageInfo.setMessageContent(new LocaleString("请及时审批"));
      let receivers = new ArrayList();
      receivers.add(userId);
      messageInfo.setUserIds(receivers);
      messageInfo.setMessageType(MessageInfo.TYPE_MESSAGE);
      messageInfo.setSenderId(userId);
      messageInfo.setEntityNumber("kdec_reqbill");
      messageInfo.setBizDataId(dataEntity.getPkValue());
      messageInfos.add(messageInfo);
    }

    if (messageInfos.size() > 0) {
      MessageCenterServiceHelper.batchSendMessages(messageInfos);
    }
  }

  // ========== 8. 返回结果：汇总信息 ==========
  onReturnOperation(e: ReturnOperationArgs): void {
    super.onReturnOperation(e);

    let result = this.getOperationResult();
    if (result.isSuccess()) {
      result.setMessage("提交成功，已生成关联采购订单并发送审批通知");
    }
  }
}

let plugin = new ReqBillFullLifecyclePlugin();
export { plugin };
```
