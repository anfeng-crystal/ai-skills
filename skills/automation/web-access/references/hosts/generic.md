# 通用宿主适配

当宿主没有明确的浏览器插件或原生联网工具时，按下面的降级顺序执行：

1. 本机 shell 能完成的轻量 HTTP/抓取
2. 宿主自带的任意搜索/抓取能力
3. 本 skill 的 `check-deps.mjs`、`find-url.mjs`、`cdp-proxy.mjs`

## 最小判断
- 公开页面文本：优先不用真实浏览器
- 需要可视确认、现有登录态、前端运行时值：升级到 CDP
- 支付等写操作先核对已有任务授权；目标、范围和动作已获授权时不重复确认，缺少授权或范围变化时先取得相应授权
- 不绕过验证码、访问控制或企业安全策略；必须由用户本人验证或接管的步骤只暂停对应步骤或来源，继续其他独立且已授权的工作

- 区分“搜索结果”“浏览器结果”“推断结论”
