## AfterAddControlListener

### afterAddControl

**签名**：`afterAddControl(event: AfterAddControlEvent): void`
**触发控件**：FormDesigner / AbstractGrid
**场景**：表单设计器动态添加控件后，自动设置新增控件的默认属性。

```typescript
  registerListener(e: $.java.util.EventObject): void {
  let grid = this.getView().getControl("kdec_entrygrid") as any;
  grid.addAfterAddControlListener(this);
}

afterAddControl(event: any): void {
  // 新增控件后，自动设置默认宽度和锁定性
  let controlKey = event.getControlKey();
  if (controlKey != null) {
    this.getView().setEnable(false, controlKey);
    this.getView().showTipNotification("已添加控件：" + controlKey);
  }
}
```

## CellClickListener

### cellClick

**签名**：`cellClick(evt: CellClickEvent): void`
**触发控件**：Button、表单控件基类
**场景**：单据体中的按钮列，点击后弹出对应行的物料详情。

```typescript
  registerListener(e: $.java.util.EventObject): void {
  let grid = this.getView().getControl("kdec_entrygrid") as any;
  grid.addCellClickListener(this);
}

cellClick(evt: any): void {
  let fieldKey = evt.getFieldKey();
  let row = evt.getRow();

  if (fieldKey === "kdec_btn_detail") {
    let materialObj = this.getModel().getValue("kdec_material", row) as DynamicObject;
    if (materialObj != null) {
      let param = new BillShowParameter();
      param.setFormId("bd_material");
      param.setPkId(materialObj.get("id"));
      param.getOpenStyle().setShowType(ShowType.Modal);
      this.getView().showForm(param);
    }
  }
}
```

### cellDoubleClick

**签名**：`cellDoubleClick(evt: CellClickEvent): void`
**触发控件**：AbstractGrid
**说明**：不推荐使用，建议使用 `cellClick` 替代。
**场景**：双击单据体单元格，快速打开行编辑弹窗。

```typescript
cellDoubleClick(evt: any): void {
  let fieldKey = evt.getFieldKey();
  let row = evt.getRow();

  if (fieldKey === "kdec_remark") {
    // 双击备注列，弹出大文本编辑窗口
    let currentValue = this.getModel().getValue("kdec_remark", row) as string;
    let param = new FormShowParameter();
    param.setFormId("kdec_text_editor");
    param.getOpenStyle().setShowType(ShowType.Modal);
    param.setCustomParam("initText", currentValue || "");
    param.setCustomParam("rowIndex", row);
    param.setCloseCallBack(new CloseCallBack(plugin, "editRemark"));
    this.getView().showForm(param);
  }
}
```

## ClickListener

### beforeClick

**签名**：`beforeClick(evt: BeforeClickEvent): void`
**触发控件**：Button、TextEdit（按钮+文本编辑风格）
**场景**：点击"查看源单"按钮前，校验源单编号是否为空。

```typescript
  registerListener(e: $.java.util.EventObject): void {
  let btn = this.getView().getControl("kdec_btn_viewsource") as any;
  btn.addClickListener(this);
}

beforeClick(evt: any): void {
  if (evt.getSource() instanceof Button && evt.getSource().getKey() === "kdec_btn_viewsource") {
    let sourceNo = this.getModel().getValue("kdec_source_billno") as string;
    if (sourceNo == null || sourceNo === "") {
      this.getView().showTipNotification("源单编号为空，无法查看");
      evt.setCancel(true);
    }
  }
}
```

**注意**：必须重写 `beforeClick`，即使方法体为空也需声明，否则可能报异常。

### click

**签名**：`click(evt: EventObject): void`
**触发控件**：Button、Container
**场景**：点击"查看源单"按钮，打开关联的采购订单详情页。

```typescript
click(evt: any): void {
  if (evt.getSource() instanceof Button) {
    let btn = evt.getSource() as Button;
    if (btn.getKey() === "kdec_btn_viewsource") {
      let sourceNo = this.getModel().getValue("kdec_source_billno") as string;
      let obj = BusinessDataServiceHelper.loadSingle(
        "pm_purorderbill",
        [new QFilter("billno", QCP.equals, sourceNo)]
      );
      if (obj != null) {
        let param = new BillShowParameter();
        param.setFormId("pm_purorderbill");
        param.setPkId(obj.get("id"));
        param.getOpenStyle().setShowType(ShowType.Modal);
        this.getView().showForm(param);
      } else {
        this.getView().showErrorNotification("未找到源单：" + sourceNo);
      }
    }
  }
}
```

## EnterKeyListener

### enterKeyEvent

**签名**：`enterKeyEvent(event: EnterKeyEvent): void`
**触发控件**：输入框
**场景**：物料编码输入框回车后，自动查询并填充物料名称和规格。

```typescript
  registerListener(e: $.java.util.EventObject): void {
  let textEdit = this.getView().getControl("kdec_material_code") as any;
  textEdit.addEnterKeyListener(this);
}

enterKeyEvent(event: any): void {
  let inputValue = this.getModel().getValue("kdec_material_code") as string;
  if (inputValue != null && inputValue !== "") {
    let materialObj = QueryServiceHelper.queryOne(
      "bd_material",
      "id,name,modelnum",
      [new QFilter("number", QCP.equals, inputValue)]
    );
    if (materialObj != null) {
      this.getModel().setValue("kdec_material_name", materialObj.getString("name"));
      this.getModel().setValue("kdec_model", materialObj.getString("modelnum"));
    } else {
      this.getView().showTipNotification("未找到编码为 " + inputValue + " 的物料");
    }
  }
}
```

## EntryFilterChangedListener

### entryFilterChanged：本次客户端过滤的可见行合计

**签名与注册**：`entryFilterChanged(e: EntryFilterChangedEvent): void`，使用 `EntryGrid.addFilterChangedListener` 注册。保留过滤可见行金额 `BigDecimal` 合计、回填表头 `kdec_filter_total` 和提示。

**时点与行号**：本机7.0先派发回调，之后才从原入参第0项读取 `reset/rk`、更新 GridState 并执行标准合计。因此不能在回调里把旧 GridState 或 `getFilterEntryRows` 当成本次结果。普通单据体的 `rk` 由服务端绑定原模型绝对行号，前端过滤保留该值；它不是屏幕排序下标，也不是业务主键。`getFilterIndexByRowKeys` 输出过滤结果位置，不能用该结果再按原模型行号取值。

**适用合同**：启用“过滤刷新合计”，表格控件 `kdec_entrygrid` 实际绑定分录 `kdec_entryentity`，金额为已加载的Decimal字段。本例覆盖普通单据体客户端过滤及普通页码分页：有条件而零匹配的 `reset=false/rk=[]` 合计为0；清空条件的 `reset=true/rk=[]` 恢复当前页，只有非分页才恢复全部行。服务端跨页过滤排序、TableCache、子/树分录、滚动追加及保留多页数据不在本例范围，可选模式API缺失也不接管。项目须保证客户端快照到回调期间没有未同步的插删/移动；仅有行号无法发现行号被另一条记录复用。

```typescript
/**
 * 普通单据体客户端过滤：按本次事件的原模型行号，用 BigDecimal 更新表头合计。
 * 前提：启用过滤刷新合计；字段为 Decimal；本插件在所有可能修改载荷的监听器之后，
 * 且后续监听器不再改载荷、表头或分录结构。仅覆盖普通单据体的非分页/普通分页视图；
 * 后端过滤排序、表缓存、树形/子分录、滚动追加及保留多页数据须另行适配，不能按当前页冒充跨页结果。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { EntryGrid } from "@cosmic/bos-core/kd/bos/form/control";
import { EntryFilterChangedEvent } from "@cosmic/bos-core/kd/bos/form/control/events";
import { EntryProp, SubEntryProp, TreeEntryProp } from "@cosmic/bos-core/kd/bos/entity/property";
import { BigDecimal } from "@cosmic/bos-script/java/math";

/** 只读取事件，不替换其 List/Map，也不取消平台的标准合计。 */
class VisibleEntryAmountPlugin extends AbstractFormPlugin {
  /** 给普通单据体注册真实的过滤变化监听器。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const grid = this.getView().getControl("kdec_entrygrid") as EntryGrid;
    grid.addFilterChangedListener(this);
  }

  /** 先完整验证行范围和金额，再一次性更新表头，避免失效行导致部分金额写回。 */
  entryFilterChanged(e: EntryFilterChangedEvent): void {
    const grid = e.getSource() as EntryGrid;
    // 控件标识与模型分录标识可能不同；先核绑定，再以 getEntryKey 返回值读模型。
    const entryKey = grid.getEntryKey();
    if (grid.getKey() !== "kdec_entrygrid" || entryKey !== "kdec_entryentity") return;
    const model = this.getModel();
    const property = model.getProperty(entryKey);
    const state = grid.getEntryState();
    if (!(property instanceof EntryProp) || property instanceof SubEntryProp || property instanceof TreeEntryProp
        || grid.isServerFilterModle() || typeof model.isFilterAndSortModel !== "function"
        || model.isFilterAndSortModel(entryKey)
        || typeof model.useTableCache !== "function" || model.useTableCache()
        || state.isScrollLoad() || state.isKeepPageData()) {
      this.rejectTotal("当前单据体模式未配置可见范围适配");
      return;
    }
    if (!grid.isSumWithFilter()) {
      this.rejectTotal("未启用过滤刷新合计");
      return;
    }
    const args = e.getEntryFilterArgs();
    if (args == null || args.size() !== 1) {
      this.rejectTotal("过滤参数不完整");
      return;
    }
    const filter = args.get(0) as $.java.util.Map | null;
    if (filter == null || typeof filter.get !== "function") {
      this.rejectTotal("过滤参数格式不正确");
      return;
    }
    const reset: unknown = filter.get("reset");
    const keys = filter.get("rk") as $.java.util.List | null;
    if (typeof reset !== "boolean" || keys == null
        || typeof keys.size !== "function" || typeof keys.get !== "function") {
      this.rejectTotal("过滤行号或重置标记不正确");
      return;
    }
    const count = model.getEntryRowCount(entryKey);
    if (!Number.isSafeInteger(count) || count < 0) {
      this.rejectTotal("单据体行数不正确");
      return;
    }
    let start = 0;
    let end = count;
    if (grid.isNeedPaged()) {
      const page = state.getCurrentPageIndex();
      const pageRows = state.getPageRows();
      const pageSize = grid.getPageRow();
      if (!Number.isSafeInteger(page) || page < 1 || !Number.isSafeInteger(pageRows) || pageRows < 1
          || !Number.isSafeInteger(pageSize) || pageSize < 1) {
        this.rejectTotal("当前页范围不正确");
        return;
      }
      start = (page - 1) * pageRows;
      end = Math.min(start + pageSize, count);
      if (!Number.isSafeInteger(start) || start > count) {
        this.rejectTotal("当前页已失效");
        return;
      }
    }
    const rows: number[] = [];
    if (reset) {
      if (keys.size() !== 0) {
        this.rejectTotal("清空过滤的行号参数不正确");
        return;
      }
      // reset=true 表示恢复当前可见页；没有分页时才恢复全部模型行。
      for (let row = start; row < end; row++) rows.push(row);
    } else {
      const seen = new Set<number>();
      for (let i = 0; i < keys.size(); i++) {
        const row: unknown = keys.get(i);
        if (typeof row !== "number" || !Number.isSafeInteger(row) || row < start || row >= end) {
          this.rejectTotal("过滤行号已失效，请刷新单据体");
          return;
        }
        if (!seen.has(row)) {
          seen.add(row);
          rows.push(row);
        }
      }
    }
    let total = BigDecimal.ZERO;
    for (const row of rows) {
      const entity = model.getEntryRowEntity(entryKey, row);
      if (entity == null) {
        this.rejectTotal("过滤行已失效，请刷新单据体");
        return;
      }
      const amount: unknown = entity.get("kdec_amount");
      if (amount == null) continue;
      if (!(amount instanceof BigDecimal)) {
        this.rejectTotal("金额字段必须为 Decimal 类型");
        return;
      }
      total = total.add(amount);
    }
    // reset=false 且 rk=[] 是真实零命中；金额保持 BigDecimal，不经 JS Number 运算。
    model.setValue("kdec_filter_total", total);
    this.getView().showTipNotification("过滤后合计：" + total.toPlainString());
  }

  /** 拒绝不完整结果时保留原表头，提示刷新或补齐模式适配。 */
  private rejectTotal(reason: string): void {
    this.getView().showTipNotification("过滤合计未更新：" + reason);
  }
}
const plugin = new VisibleEntryAmountPlugin();
export { plugin };
```

**多插件与失败**：本插件只读事件，不更换List/Map、不修改取消状态。重复有效行号只算一次；非法、越界、缺失行或错类型金额拒绝整个更新，保留旧表头并提示，不能把部分合计当完成。所有可能修改载荷的监听器须在本例之前，后续不能再改载荷、分录结构或目标表头；前插件也不能仅以 `setEntryFilterArgs(newList)` 换引用而保留不同的原入参，因为标准消费者仍读原List。`setCancel(true)` 只跳过后续状态更新和标准summary，不撤销已完成的前端筛选；派发不会因取消提前停止，最终取消值由后续插件决定。

**生命周期边界**：这是过滤事件触发时的合计，初始无过滤、翻页、纯金额编辑等是否触发该事件各有条件，不能宣称已实现所有操作实时刷新。标准合计与自定义表头是不同通道，实际字段、监听器顺序、页面和KingScript引擎仍需项目验证。

依据：[官方过滤刷新合计](https://vip.kingdee.com/knowledge/674565559773554944)（更新时间2026-07-30 02:08，正文V4.0.1及以上）、[单据体](https://vip.kingdee.com/knowledge/224093028694948608)（2026-05-21 15:44）及[选项过滤](https://vip.kingdee.com/knowledge/713346495146910720)（2026-07-30 01:42，文本/多语言/基础资料选项过滤标V7.0.11，须跨页模式）。本机7.0服务端、模型和前端消费者补充上述行号及时点依据，不由文章版本推断部署补丁。

## EntryGridSetRowDataListener

### 赋值事件与库存行样式分工

`entryGridSetRowData(e: EntryGridSetRowDataEvent)` 属于按编号录入/粘贴的赋值处理链，真实载荷由 `getValues/getEntryType/getQFilters/setQFilters` 提供，用于输入值与资料解析；它不是逐行渲染回调，没有 `getRowData/getRowIndex` 行渲染接口。给数据包添加 `kdec_qty_color` 不会自动改变行背景，换成赋值后事件也不能覆盖初始加载与其它模型变化。

**库存告警场景**：普通、完整载入的非分页单据体中，`kdec_qty` 大于 `kdec_stock_qty` 时整行红色；两个字段属于该分录、为同一计量单位的Decimal，库存值由项目已有逻辑提供，本例不查库存、不改业务字段。数量或库存为空按“不标红”处理，恢复正常时撤销本例背景色。

**样式所有权**：以下示例独占该分录的全部动态行样式，`ownsRowStyle=true` 是接线合同。实际 `setRowBackcolor` 生成的行样式会整体替换前端 `s`，不是合并；若已有别的插件或界面规则写行样式，须由统一实现合成完整样式，本例设为false后不发送任何样式。空颜色只撤销本例独占背景色，不能恢复其他插件曾经的字体或颜色。也可按官方界面规则配置条件成立“设置行样式”、条件不成立“清除行样式”。

```typescript
import { AbstractBillPlugIn } from "@cosmic/bos-core/kd/bos/bill";
import { EntryGrid } from "@cosmic/bos-core/kd/bos/form/control";
import { AfterAddRowEventArgs, AfterDeleteEntryEventArgs, AfterDeleteRowEventArgs,
  AfterMoveEntryEventArgs, PropertyChangedArgs } from "@cosmic/bos-core/kd/bos/entity/datamodel/events";
import { BigDecimal } from "@cosmic/bos-script/java/math";
import { EventObject } from "@cosmic/bos-script/java/util";

/**
 * 普通、非分页单据体的库存行提示：数量大于库存时整行红色，否则移除本例背景色。
 * 本例独占该单据体全部动态行样式；如有其他插件或规则写行样式，须先统一合成样式。
 * 字段必须为同计量单位的Decimal；不查询库存、不更改业务字段，不支持大单/跨页模式。
 */
class InventoryRowStylePlugin extends AbstractBillPlugIn {
  private readonly gridKey = "kdec_entrygrid";
  private readonly qtyKey = "kdec_qty";
  private readonly stockKey = "kdec_stock_qty";
  // 集成合同：本例独占整行样式。合用时设为false，由统一样式实现接管。
  private readonly ownsRowStyle = true;

  /** 数据绑定后从当前模型计算；新建单据的默认行也在绑定后处理。 */
  afterBindData(e: EventObject): void { this.refreshInventoryRows(); }

  /** 一次重算完整单据体，兼容批量字段更新，不只读取changeSet的第0项。 */
  isSupportBatchPropChanged(): boolean { return true; }

  /** 只响应数量或库存值更新；样式发送不会回写字段。 */
  propertyChanged(e: PropertyChangedArgs): void {
    const key = e.getProperty().getName();
    if (key === this.qtyKey || key === this.stockKey) this.refreshInventoryRows();
  }

  /** 分录数量或次序改变后重算，防止旧行号的红色留到其他行。 */
  afterAddRow(e: AfterAddRowEventArgs): void { this.refreshInventoryRows(); }
  afterDeleteRow(e: AfterDeleteRowEventArgs): void { this.refreshInventoryRows(); }
  afterDeleteEntry(e: AfterDeleteEntryEventArgs): void { this.refreshInventoryRows(); }
  afterMoveEntryUp(e: AfterMoveEntryEventArgs): void { this.refreshInventoryRows(); }
  afterMoveEntryDown(e: AfterMoveEntryEventArgs): void { this.refreshInventoryRows(); }
  afterSetEntryTop(e: AfterMoveEntryEventArgs): void { this.refreshInventoryRows(); }
  afterSetEntryBottom(e: AfterMoveEntryEventArgs): void { this.refreshInventoryRows(); }

  /**
   * 仅普通完整载入模型使用行序号；分页/服务器过滤/临时表模式不发送不完整样式。
   * null数量或库存按“不标红”处理。空色只撤销本例独占的背景色，不能恢复他人样式。
   */
  private refreshInventoryRows(): void {
    if (!this.ownsRowStyle) return;
    const grid = this.getView().getControl(this.gridKey) as EntryGrid;
    const model = this.getModel();
    if (grid == null || grid.isSplitPage() || grid.isServerFilterModle()) return;
    const entryKey = grid.getEntryKey();
    if (entryKey == null || entryKey.length === 0) return;
    if (!model.useTableCache || !model.isFilterAndSortModel) return;
    if (model.useTableCache() || model.isFilterAndSortModel(entryKey)) return;
    const redRows: number[] = [];
    const clearRows: number[] = [];
    const count = model.getEntryRowCount(entryKey);
    for (let row = 0; row < count; row++) {
      const qty = model.getValue(this.qtyKey, row) as BigDecimal | null;
      const stock = model.getValue(this.stockKey, row) as BigDecimal | null;
      if (qty != null && stock != null && qty.compareTo(stock) > 0) redRows.push(row);
      else clearRows.push(row);
    }
    if (clearRows.length > 0) grid.setRowBackcolor("", clearRows);
    if (redRows.length > 0) grid.setRowBackcolor("red", redRows);
  }
}

const plugin = new InventoryRowStylePlugin();
export { plugin };
```

**入口与边界**：本机标准装配先注册内部 `DataModelChangeListener`，再注册表单插件；模型变化事件按注册顺序派发，内部增删/移位指令在本例样式指令之前。初始 `bindData` 先更新视图，再触发 `afterBindData`。本例在绑定完成、数量/库存变化、增删清空及上下移动/置顶置底后重算，不只处理批量变更的第0项；控件键只用于取控件，模型分录键取 `grid.getEntryKey()`。

代码拒绝分页、服务器过滤、TableCache、过滤排序模型以及缺少模式能力的情况。树/子分录、滚动追加、多页保留、异步块重载、移动端或定制监听器装配不在本例支持范围；其它插件随后刷新视图或写行样式仍会覆盖结果。局部验证不代表平台页面、真实库存与单位口径、权限或保存验收。

## FilterGridF7ClickListener

### 点击与客户范围过滤的分工

**真实点击签名**：`filterGridF7Click(evt: FilterGridF7ClickEvent): void`，注册为 `FilterGrid.addFilterGridF7ClickListener` **并不存在**；实际点击注册为 `addFilterGridF7ClickEvents`。点击事件可读 `getFieldName`、改变实体选择或取消，但没有自定义过滤集合。只把方法名改对仍不能完成客户范围限制。

**场景**：过滤面板选择客户时，按本次已解析的销售员业务范围限制候选。过滤入口是 `FilterGrid.addBeforeF7SelectListener` 注册 `kd.bos.form.field.events.BeforeFilterF7SelectListener`，回调为 `beforeF7Select(BeforeFilterF7SelectEvent)`。不要与普通 `BaseDataEdit` 的 `BeforeF7SelectEvent` 混用；在项目既有监听器的该回调中调用下方独立 helper。

本例明确交付过滤追加 helper；客户字段、引用实体及销售员范围由项目已有真实业务逻辑提供。`getCurrUserId()` 是用户身份，不能未经映射证明便当销售员ID；`kdec_salesman.id` 也不是所有客户实体通用字段。参数 `targetFieldName`、`targetRefEntityId` 必须来自已核页面与引用元数据，`scope` 必须是针对该引用实体、本次销售员范围的真实 `QFilter`，范围未取得传 `null`。既有范围中的大ID保持原始字符串或宿主整数，不转成JS Number。

```typescript
import { BeforeFilterF7SelectEvent } from "@cosmic/bos-core/kd/bos/form/field/events";
import { QFilter } from "@cosmic/bos-core/kd/bos/orm/query";

/**
 * 在 FilterGrid 的 beforeF7Select 中追加当前业务范围。
 * 字段和引用实体来自已核页面；scope 来自本次已解析的销售员或公司范围。
 * 无范围或引用实体不符时取消目标选择；不替换平台和前插件的过滤集合。
 */
export function appendVerifiedF7Scope(
  evt: BeforeFilterF7SelectEvent,
  targetFieldName: string,
  targetRefEntityId: string,
  scope: QFilter | null
): void {
  // 调用方必须提供非空真实字段；无关字段和已取消事件不改动。
  if (targetFieldName.length === 0 || evt.getFieldName() !== targetFieldName || evt.isCancel()) {
    return;
  }
  // 缺少业务范围不代表可查看全部；引用实体变化也不能沿用旧范围。
  if (targetRefEntityId.length === 0 || evt.getRefEntityId() !== targetRefEntityId || scope === null) {
    evt.setCancel(true);
    return;
  }
  evt.addCustomQFilter(scope);
}
```

当前7.0消费者把标准 `qfilters` 原List传入事件，在所有回调结束后还往该原List追加审核状态条件，再调用 `getMergeQFilters()`。因此不能复制后 `setQfilters` 换引用；也不要用 `setCustomQFilters` 替换前插件条件——该setter先清旧集合，传自身会把自身清空。`addCustomQFilter` 只追加本条件，merge依次保留custom与standard，不替代平台权限控制。

helper不清除已有cancel，不改原过滤集合引用、引用实体、单多选、行索引或选择状态。所有监听器会继续执行，后插件不得再清cancel、换集合或覆盖本次业务范围。标准选择回填来自控件原缓存；当前路径创建事件时 `selectedIds` 为空数组，不能把 `getSelectedIds()` 当完整当前选择或借改它控制回填。

仅针对实际走 `beforeF7Select` 的普通引用资料列表选择路径；RefBill提前分支、输入解析及其它入口需各自核实，不能把本helper当全入口访问控制。项目仍须在本次回调前取得当前销售员范围，在公司/身份切换后重新解析，不闭包捕获旧范围。未交付身份映射、真实业务查询、页面挂载或权限验收。

**依据**：[官方通用过滤控件用法](https://vip.kingdee.com/knowledge/324870422128784896)明确给出选前监听与 `addCustomQFilter`；当前7.0 JAR/声明另证实原List共享、回调后审核追加和setter清空行为。官方正文未标适用版本，本机7.0不推定部署补丁。

## FilterGridF7CloseCallBackListener

### filterGridF7CloseCallBack

**签名**：`filterGridF7CloseCallBack(evt: FilterGridF7CloseCallBackEvent): void`。注册为 `addFilterGridF7CloseCallBackListeners`。
**触发控件**：FilterGrid 的基础资料 F7 关闭分支；文本和 RefBill 分支另核。
**场景**：供应商选择返回时提示已提供的名称，保留过滤控件的标准回填。这里发生在标准加载转换和回填之前，提示不是“回填成功”通知；原例没有另一个表单目标字段，不追加任意字段写入或业务查询。

当前 7.0 消费者先把原 `ListSelectedRowCollection` 放入事件并通知所有监听器，再处理回填。正常分支继续使用原局部集合，`setRows(newRows)` 不能替换它；直接修改原集合会影响后续转换。`getValues()` 初始空，也不是已加载的供应商信息。

`cancel=true` 会走自定义 `setF7Value` 分支，仍会向客户端发指令：非空 `values` 才带 `value`。当前 PC FilterGrid 的 `setF7ValueCFReducer` 会把省略的 `value` 写成 `undefined` 并更新 `updatePostData` 标记，不代表真实提交完成；这不是“取消后保持原值”。`setValues(null)` 还会使服务端随后 `isEmpty()` 失败。只做信息提示时不修改 `cancel/values/rows/actionIds`，也不替换监听器列表。

```typescript
/**
 * 读取 FilterGrid 基础资料关闭回调中的供应商名称快照。
 * 依赖已核控件/字段及返回行清空标记桥；只提示，不接管标准回填或查询业务。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { FilterGrid } from "@cosmic/bos-core/kd/bos/form/control";
import { FilterGridF7CloseCallBackEvent, FilterGridF7CloseCallBackListener } from "@cosmic/bos-core/kd/bos/form/control/events";

/** 当前 Java 返回集合公开该方法；目标声明未导出，使用前检查宿主是否提供。 */
type ClearAwareRows = $.kd.bos.entity.datamodel.ListSelectedRowCollection & {
  isClearFlag?: () => boolean;
};

/** 保留过滤控件标准回填；提示只描述回调快照，不代表后续加载或回填成功。 */
class SupplierFilterClosePlugin extends AbstractFormPlugin implements FilterGridF7CloseCallBackListener {
  /** 在当前表单已核的 FilterGrid 上增补监听，不替换前插件。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const grid = this.getView().getControl("kdec_filtergrid") as FilterGrid;

    if (evt.getFieldName() !== "kdec_supplier_filter" || evt.isCancel()) return;

    if (rows == null || rows.isEmpty()) return;

    const names: string[] = [];
    for (let i = 0; i < rows.size(); i++) {
      const row = rows.get(i);
      if (row == null) return;
      const name = row.getName();
      if (typeof name !== "string" || name.trim().length === 0) return;
      names.push(name);
    }
    this.getView().showTipNotification("本次关闭回调返回的供应商：" + names.join("、"));
  }
}
```

前插件取消/自定义值保持；其他监听器对行、清空标记或取消状态的更改仍影响各自阶段。提示只描述当前回调看到的快照，不能据此推定后续标准回填、权限或保存成功；若要求真正回填完成后通知，须另核已存在的完成入口。清空/取消和标准单多选回填不由本插件接管。

## ProgressListener

### onProgress

**签名**：`onProgress(evt: ProgressEvent): void`，监听接口真实名称为 `ProgresssListener`。
**触发控件**：ProgressBar
**场景**：读取已存在的物料导入任务快照，显示处理进度；任务明确提交成功后，只提示并刷新列表一次。

`onProgress` 是进度拉取回调。控件为每次请求新建初值为 0 的 `ProgressEvent`，监听器通过 `setProgress(int)` 与 `setText(String)` 提供本次结果；事件没有 `getTotal()`。处理条数达到总数，不等于事务或导入已经成功。

以下是快照消费者，**不包含真实导入任务、后台生产者或跨节点缓存传播实现**。业务适配层必须先发布当前任务身份 `materialImport.activeTaskId`，再以 `PageCache.put("materialImport.snapshot." + taskId, JSON字符串)` 发布完整快照。每个任务使用唯一 `taskId`，状态和计数单调推进，终态不可回退；`SUCCEEDED` 仅在业务提交成功后发布。快照包含 `taskId/state/completed/total/text`，状态为 `RUNNING/SUCCEEDED/FAILED/CANCELLED`，计数为非负安全整数且 `completed <= total`。这些键是本例业务合同，不是平台自动维护字段。

页面须有 `kdec_progressbar`、有效刷新间隔及已配置的 `refresh` 操作。绑定时可接续已发布任务；同页创建新任务后由业务适配层调用 `startWatching(taskId)`。先 `stop` 清理计时器身份，再归零、`start`，避免上一任务自动到100后无法重新启动。缺失或非法快照停止观察，生产者恢复后须显式重新启动。

```typescript
/**
 * 消费已存在的物料导入任务快照，向 kdec_progressbar 提供进度并在业务成功后刷新列表。
 * 业务适配层负责真实任务、权限、提交结果，以及向当前页面缓存发布快照；本插件不创建导入任务。
 * 使用目标 7.0 声明中的 ProgresssListener。页面须配置有效刷新间隔和 refresh 操作。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { ProgressBar } from "@cosmic/bos-core/kd/bos/form/control";
import { ProgressEvent, ProgresssListener } from "@cosmic/bos-core/kd/bos/form/control/events";

type ImportState = "RUNNING" | "SUCCEEDED" | "FAILED" | "CANCELLED";
interface ImportSnapshot {
  taskId: string;
  state: ImportState;
  completed: number;
  total: number;
  text: string;
}

/** 当前页面同时观察一个任务；终态提示按任务身份在页面缓存中去重。 */
export class MaterialImportProgressPlugin extends AbstractFormPlugin implements ProgresssListener {
  /** 每次注册阶段只注册一次，不在轮询回调中重复添加监听器。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    this.progressBar().addProgressListener(this);
  }

  /** 绑定后续接业务适配层已发布的任务；没有任务时保持停止状态。 */
  afterBindData(e: $.java.util.EventObject): void {
    super.afterBindData(e);
    const taskId = this.getView().getPageCache().get("materialImport.activeTaskId");
    if (taskId != null && taskId !== "") this.startWatching(taskId);
  }

  /**
   * 业务任务创建成功并发布初始快照后调用；同页新任务也从此入口切换。
   * taskId 必须是该业务任务的唯一身份，不能复用前一个任务的身份。
   */
  startWatching(taskId: string): void {
    if (taskId.trim() === "") throw new Error("任务标识不能为空");
    const cache = this.getView().getPageCache();
    cache.put("materialImport.watchedTaskId", taskId);
    const bar = this.progressBar();
    bar.stop();
    bar.setPercent(0, "正在读取导入进度");
    bar.start();
  }

  /** 回调用于提供本次进度；新事件的初始值不表示真实任务进度或任务完成。 */
  onProgress(evt: ProgressEvent): void {
    const bar = evt.getSource() as ProgressBar;
    if (bar.getKey() !== "kdec_progressbar") return;
    const cache = this.getView().getPageCache();
    const taskId = cache.get("materialImport.watchedTaskId");
    const snapshot = taskId == null || taskId === "" || cache.get("materialImport.activeTaskId") !== taskId
      ? null : this.readSnapshot(taskId);
    if (snapshot === null) {
      evt.setProgress(0);
      evt.setText("任务进度缺失或无效，已停止查询");
      bar.stop();
      return;
    }

    // 处理条数到达总数仍可能尚未提交成功，RUNNING 不提前发布100。
    const percent = snapshot.total === 0 ? 0 : Math.min(99, Math.floor(snapshot.completed / snapshot.total * 100));
    evt.setProgress(snapshot.state === "SUCCEEDED" ? 100 : percent);
    evt.setText(snapshot.text);
    if (snapshot.state === "RUNNING") return;

    bar.stop();
    const notifiedKey = "materialImport.notified." + snapshot.taskId;
    if (cache.get(notifiedKey) != null) return;
    // 先记录终态，避免刷新触发重绑或重复轮询时再次提示和刷新。
    cache.put(notifiedKey, snapshot.state);
    if (snapshot.state === "SUCCEEDED") {
      this.getView().showSuccessNotification("导入完成，共处理 " + snapshot.completed + " 条记录");
      this.getView().invokeOperation("refresh");
    } else if (snapshot.state === "FAILED") {
      this.getView().showErrorNotification("导入失败：" + snapshot.text);
    }
  }

  private progressBar(): ProgressBar {
    return this.getView().getControl("kdec_progressbar") as ProgressBar;
  }

  /**
   * 快照来自业务适配层以 put(key, JSON字符串) 发布的单条完整状态。
   * taskId、状态、计数须一致；成功只接受全部处理完毕且业务已提交成功的终态。
   */
  private readSnapshot(taskId: string): ImportSnapshot | null {
    const raw = this.getView().getPageCache().get("materialImport.snapshot." + taskId);
    if (raw == null || raw === "") return null;
    let decoded: unknown;
    try { decoded = JSON.parse(raw); } catch (_error) { return null; }
    if (decoded === null || typeof decoded !== "object" || Array.isArray(decoded)) return null;
    const value = decoded as Record<string, unknown>;
    if (value.taskId !== taskId || typeof value.text !== "string") return null;
    const state = value.state;
    if (state !== "RUNNING" && state !== "SUCCEEDED" && state !== "FAILED" && state !== "CANCELLED") return null;
    const completed = value.completed;
    const total = value.total;
    if (typeof completed !== "number" || typeof total !== "number" ||
        !Number.isSafeInteger(completed) || !Number.isSafeInteger(total) ||
        completed < 0 || total < 0 || completed > total) return null;
    if (state === "SUCCEEDED" && completed !== total) return null;
    return { taskId, state, completed, total, text: value.text };
  }
}

let plugin = new MaterialImportProgressPlugin();
export { plugin };
```

**边界**：

- `RUNNING` 最多显示99；仅合法 `SUCCEEDED` 显示100并触发完成提示、刷新。空任务总数0可显式成功；失败或取消停止轮询，不冒充导入成功。终态提示按当前页面缓存中的任务身份去重。
- 当前任务身份与快照身份同时核对，旧任务快照不能完成新任务。业务生产者仍须保证同一任务的更新顺序；本例不实现后台调度、进程间通信或事务结果采集。
- 本机PC消费者以 `percent == 100` 停止，移动消费者以 `parseInt(percent) === 100` 停止；101不等于完成。使用0—100整数，不能靠超范围值停止。刷新间隔默认不刷新，必须设置有效间隔并调用 `start()`。
- 真实任务、权限、字段、刷新结果和平台页面运行需项目验证；`PageCache.put` 可写字符串不证明后台任务已经接通。每次注册阶段只注册监听器，不在 `onProgress` 内重复注册。

依据：[官方进度条说明](https://vip.kingdee.com/knowledge/224163738101282560)与目标本机7.0 `ProgressBar/ProgressEvent`、PC及移动消费者。官方业务属性表标V4.0及以上，不据此推断全部API最低版本或实际部署补丁。

## ResponseListener

### afterReceiveResponse

**签名**：`afterReceiveResponse(evt: ResponseEvent): void`；**触发控件**：ClientAjax。

**场景与前提**：沿用原 `kdec_clientajax` 和 `kdec_external_code`，处理项目已经确认的对象响应合同：`success` 为布尔值，成功时 `code` 为字符串，失败时 `message` 可为字符串。三个业务键不是 SDK 固有格式；实际接口若不符合此合同，须按其真实定义调整，不能凭 SDK 推断外部业务成功。

当前 7.0 注册方法是 `addResponseListner`（目标 API 的原始拼写），不是新官方示例中的 `addResponseListener`。事件提供 `getMsg(): Object`，没有 `getResponseText`。PC/mobile 标准消费者先执行 `response.json()`，再把结果作为动作参数传回；服务端通用 JSON Object 解码为 Java LinkedHashMap，因此代码接受这一实际类型，也兼容桥接为自有属性对象的情况，不再无条件 `JSON.parse`。KingScript 桥的实际 Map/布尔值/字符串表现仍须在项目环境验证；无法识别的表示保留旧字段并提示合同不符，不强制转成字符串或把 truthy 值当成功。

```typescript
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { ClientAjax } from "@cosmic/bos-core/kd/bos/form/control";
import { ResponseEvent, ResponseListener } from "@cosmic/bos-core/kd/bos/form/control/events";
import { LinkedHashMap } from "@cosmic/bos-script/java/util";

/** 外部对象响应的约定字段回填；不发请求、不保存。 */
export class ExternalCodeResponsePlugin extends AbstractFormPlugin implements ResponseListener {
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const ajax = this.getView().getControl("kdec_clientajax") as ClientAjax;
    if (ajax != null) ajax.addResponseListner(this);
  }

  afterReceiveResponse(evt: ResponseEvent): void {
    const source = evt.getSource();
    if (!(source instanceof ClientAjax) || source.getKey() !== "kdec_clientajax" || evt.getType() !== "receive") return;
    const msg: unknown = evt.getMsg();
    let success: unknown;
    let code: unknown;
    let message: unknown;
    try {
      if (msg instanceof LinkedHashMap) {
        success = msg.get("success");
        code = msg.get("code");
        message = msg.get("message");
      } else if (msg != null && typeof msg === "object" && !Array.isArray(msg)) {
        const data = msg as Record<string, unknown>;
        const own = (key: string): unknown => Object.prototype.hasOwnProperty.call(data, key) ? data[key] : undefined;
        success = own("success");
        code = own("code");
        message = own("message");
      }
    } catch (_error) {
      this.getView().showErrorNotification("响应对象无法按约定读取，原外部编码已保留");
      return;
    }
    if (success === true && typeof code === "string") {
      this.getModel().setValue("kdec_external_code", code);
      this.getView().showSuccessNotification("响应已按约定回填外部编码");
    } else if (success === false) {
      this.getView().showErrorNotification(typeof message === "string" && message !== "" ? "接口返回错误：" + message : "接口返回业务失败，未提供错误说明");
    } else {
      this.getView().showErrorNotification("响应不符合约定的 success/code 格式，原外部编码已保留");
    }
  }

  /** 当前标准请求链未派发此方法；不据此报告请求已发送。 */
  afterSendRequest(_evt: ResponseEvent): void {}
}
const plugin = new ExternalCodeResponsePlugin();
export { plugin };
```

成功分支仅写回原字段，保留空字符串这一字符串合同值，不截断、数值转换或补造编码；模型规则若拒绝写入，异常继续向上传递，不显示成功。失败或无效载荷不清旧值、不修改共享响应。提示只表示本次回填，不表示外部业务、权限、保存或事务验收。

### afterSendRequest

**签名**：`afterSendRequest(evt: ResponseEvent): void`。接口存在默认空实现，但当前 ClientAjax 的 `request` 只下发客户端指令，标准 PC/mobile 路径未派发该回调，所以示例不再显示虚假的“已发送”。发送日志需要项目真实请求入口另行接入，当前未交付。

网络、HTTP 状态或 JSON 解析失败通常使 Promise 拒绝，未进入 `afterReceiveResponse`；不能用 `success=false` 分支声称覆盖通信失败。GET 的重定向/会话重载分支可能回传 undefined，GET JSON null 会在消费者后续访问中失败，而 JSON POST 可传回 null。示例只处理实际收到的响应，通信失败通知、取消/超时与请求关联协调均须按真实项目入口另行实现。未运行真实 HTTP、CORS、平台派发或 KingScript 桥。

## SearchEnterListener

### search / getSearchList / getComPlexSearchList

**签名**：`search(evt: SearchEnterEvent): void`、`getSearchList(evt: SearchEnterEvent): $.java.util.List`、`getComPlexSearchList(evt: SearchEnterEvent): $.java.util.List`。
**触发控件**：PC Search；通过 `addEnterListener` 注册 `SearchEnterListener`。复杂方法中间的 `P` 必须大写。

普通确认保留物料编号或名称模糊查询，按编号排序、最多20条；自动补全与复杂建议保留只按名称匹配、按编号排序、最多10条。以下保留编号名称和规格分类信息；项目须确认 `bd_material/id/number/name/modelnum/group.name` 的字段、关联投影及查询权限范围。基础资料查到结果不等于已经取得打开权限。

PC `showModel=1` 返回文本 `List`，模式3调用 `getComPlexSearchList`，其事件 `text` 是 JSON `{type,content,time}`；不能将整个JSON当关键词。已核本机全局消费者的 `type` 为字符串 `"1"/"2"/"3"`，分别对应入口、帮助、最近；响应List中的包装对象必须回显原 `type/content/time`，另提供 `titles/childs`。前端用原请求时间拒绝较旧响应，不得换成返回时的新时间。

```typescript
/**
 * PC 物料搜索：模式1返回文本建议，模式3返回与已核前端匹配的分组响应。
 * 依赖当前表单的 kdec_search 及真实 bd_material 字段；查询范围须由项目补齐权限过滤。
 * 复杂结果只展示，不在搜索回调打开页面或执行业务操作。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { Search } from "@cosmic/bos-core/kd/bos/form/control";
import { SearchEnterEvent, SearchEnterListener } from "@cosmic/bos-core/kd/bos/form/control/events";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { QFilter } from "@cosmic/bos-core/kd/bos/orm/query";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { ArrayList, HashMap } from "@cosmic/bos-script/java/util";

interface GlobalSearchRequest { type: "1" | "2" | "3"; content: string; time: number; }

/** 解析模式3真实请求；无有效时间戳时拒绝请求，不伪造新时间冒充原请求。 */
function parseGlobalSearchRequest(text: string): GlobalSearchRequest {
  let value: unknown;
  try { value = JSON.parse(text); } catch (_error) { throw new Error("全局搜索请求不是有效 JSON"); }
  if (value === null || typeof value !== "object") throw new Error("全局搜索请求格式无效");
  const obj = value as Record<string, unknown>;
  if ((obj.type !== "1" && obj.type !== "2" && obj.type !== "3") ||
      typeof obj.content !== "string" || typeof obj.time !== "number" ||
      !Number.isSafeInteger(obj.time) || obj.time < 0) throw new Error("全局搜索请求类型、内容或时间无效");
  return { type: obj.type, content: obj.content, time: obj.time };
}

/** 保留原请求类型、关键词和时间；入口始终保留一组，组内可为空。 */
function packGlobalSearchResult(request: GlobalSearchRequest, items: $.java.util.List): $.java.util.List {
  const response = new HashMap();
  response.put("type", request.type);
  response.put("content", request.content);
  response.put("time", request.time);
  const titles = new ArrayList();
  titles.add("物料");
  titles.add("帮助");
  response.put("titles", titles);
  const children = new ArrayList();
  if (request.type === "1") {
    const group = new HashMap();
    group.put("childs", items);
    children.add(group);
  }
  response.put("childs", children);
  const result = new ArrayList();
  result.add(response);
  return result;
}

class MaterialSearchPlugin extends AbstractFormPlugin implements SearchEnterListener {
  /** 仅注册本例搜索控件；搜索风格由页面元数据选择。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const search = this.getView().getControl("kdec_search") as Search;
    search.addEnterListener(this);
  }

  /** 普通文本确认后查询编号或名称，最多20条；不把全局项目点击当此事件。 */
  search(evt: SearchEnterEvent): void {
    const source = evt.getSource() as Search;
    if (source.getKey() !== "kdec_search" || source.getShowModel() === 3) return;
    const text = evt.getText();
    if (text == null || text.trim() === "") return;
    const rows = this.queryMaterials(text, "id,number,name", 20, true);
    this.getView().showTipNotification("搜索到 " + rows.size() + " 条物料（最多20条）");
  }

  /** 模式1的文本建议，保留编号与名称；空输入返回空列表清除旧建议。 */
  getSearchList(evt: SearchEnterEvent): $.java.util.List {
    const suggestions = new ArrayList();
    const source = evt.getSource() as Search;
    if (source.getKey() !== "kdec_search" || source.getShowModel() !== 1) return suggestions;
    const text = evt.getText();
    if (text == null || text.trim() === "") return suggestions;
    const rows = this.queryMaterials(text, "id,number,name", 10);
    for (let i = 0; i < rows.size(); i++) {
      const row = rows.get(i) as DynamicObject;
      suggestions.add(row.getString("number") + " - " + row.getString("name"));
    }
    return suggestions;
  }

  /** 模式3按请求封装响应；帮助和最近访问未配置数据，返回对应空结果。 */
  getComPlexSearchList(evt: SearchEnterEvent): $.java.util.List {
    const source = evt.getSource() as Search;
    if (source.getKey() !== "kdec_search" || source.getShowModel() !== 3) {
      throw new Error("本例复杂搜索仅用于 kdec_search 的 PC 全局搜索风格");
    }
    const request = parseGlobalSearchRequest(evt.getText());
    const items = new ArrayList();
    if (request.type === "1" && request.content.trim() !== "") {
      const rows = this.queryMaterials(request.content, "id,number,name,modelnum,group.name", 10);
      for (let i = 0; i < rows.size(); i++) {
        const row = rows.get(i) as DynamicObject;
        const item = new HashMap();
        const id = row.get("id");
        item.put("id", id == null ? "" : String(id));
        item.put("name", row.getString("number") + " - " + row.getString("name"));
        item.put("subName", "规格：" + (row.getString("modelnum") || "无") +
          " | 分类：" + (row.getString("group.name") || "未分类"));
        items.add(item);
      }
    }
    return packGlobalSearchResult(request, items);
  }

  /** 建议按名称模糊查询，普通搜索额外匹配编号；均按编号排序并限制返回条数。 */
  private queryMaterials(keyword: string, fields: string, limit: number, includeNumber: boolean = false): $.kd.bos.dataentity.entity.DynamicObjectCollection {
    let filter = new QFilter("name", "like", "%" + keyword + "%");
    if (includeNumber) filter = new QFilter("number", "like", "%" + keyword + "%").or(filter);
    return QueryServiceHelper.query("bd_material", fields, [filter], "number", limit);
  }
}

const plugin = new MaterialSearchPlugin();
export { plugin };
```

**返回协议与未交付项**：

- 入口结果使用包装 `childs` 的第0组，其内部 `childs` 才是物料项；显示读取 `name/subName`。旧的扁平 `id/title/subtitle` 不进入该显示合同。空入口结果仍保留一组 `childs:[]`，避免已核前端对顶层空组继续读取null。
- 图标目标尚未交付：此入口renderer没有已核图标槽，不伪造 `icon`。帮助/最近无数据合同，只返回相应空结果，未实现帮助或历史查询。
- 复杂项点击走独立 `itemClick(Map)`，不等于普通 `search(evt.text)`。本节只展示复杂结果，不实现其业务打开；双来源文本联想与快开见[配置搜索联想与快速打开](控件-场景拆分/configureSearchAndQuickFilter.md)。
- 本机Java `QCP.like` 为 `"like"`，对应7.0脚本声明未导出该成员，故使用已核运算符字符串；保留模糊匹配，不用 `any` 伪装为已声明成员。
- 同控件的多个监听器会分别发送自动补全结果，项目需明确谁负责列表；本例不保证多个返回结果自动合并。复杂包装合同来自已核本机PC前端，移动端的模式含义不同，不套用此例。

## SliderListener

### update (Slider)

**签名**：`update(e: SliderEvent): void`
**触发控件**：移动端 `Slider` 滑动输入条。
**场景**：已存在的单数值百分比滑条完成一次有效变更后，用原金额乘本次百分比，写回折后金额及折扣率。

**接入合同**：`kdec_discount_slider` 必须是已核实 `range=false` 的移动控件；`kdec_original_amount`、`kdec_discount_amount` 是已有金额字段，`kdec_discount_rate` 是已有百分数值字段，不能从控件ID推导模型字段。数值范围、步长和允许的业务值由真实页面及保存校验确定；默认0—100、步长1只是控件默认值。本例不把双值区间的右端擅自定义为折扣。

`SliderEvent.getValue()` 是两槽载荷，单值取第 **2** 槽 `values[1]`，第1槽不是本次折扣值。保留原公式：百分比先除100，以 **scale=4、HALF_UP** 得到系数，再乘原 `BigDecimal` 金额；不是减免比例 `1-rate`，不额外做两位金额舍入。更细步长是否接受四位系数精度须沿用项目财务合同。

```typescript
import { AbstractMobFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { Slider } from "@cosmic/bos-core/kd/bos/form/control";
import { SliderEvent, SliderListener } from "@cosmic/bos-core/kd/bos/form/control/events";
import { BigDecimal } from "@cosmic/bos-script/java/math";

/** 移动单值百分比滑条的金额联动；字段与模式须先按页面合同核实，不执行保存。 */
export class DiscountSliderPlugin extends AbstractMobFormPlugin implements SliderListener {
  /** 每次注册阶段只接入已存在的目标滑条，保留基类监听器。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const slider = this.getView().getControl("kdec_discount_slider") as Slider;
    if (slider != null) slider.addSliderListener(this);
  }

  /** 读取本次双槽快照；无效载荷或缺原金额时保留旧值，不改共享事件或滑条。 */
  update(e: SliderEvent): void {
    const source = e.getSource();
    if (!(source instanceof Slider) || source.getKey() !== "kdec_discount_slider") return;
    const values = e.getValue();
    if (values == null || values.length !== 2) return;
    const discountRate = values[1];
    if (typeof discountRate !== "number" || !Number.isFinite(discountRate)) return;
    const originalAmount = this.getModel().getValue("kdec_original_amount");
    if (!(originalAmount instanceof BigDecimal)) return;

    const rate = new BigDecimal(String(discountRate)).divide(
      new BigDecimal("100"), 4, BigDecimal.ROUND_HALF_UP
    );
    const discountAmount = originalAmount.multiply(rate);
    this.getModel().setValue("kdec_discount_amount", discountAmount);
    this.getModel().setValue("kdec_discount_rate", discountRate);
  }
}
const plugin = new DiscountSliderPlugin();
export { plugin };
```

**时点与边界**：当前移动端 `KDSlider` 在 `afterChange` 且值与旧快照不同时回发；拖动中的展示变化不是每帧服务端金额重算。`setSliderValue` 只同步控件数值，不自动调用本例；初始打开、仅修改原金额、程序设值后的金额一致性仍须由项目真实入口处理，不能宣称已实现完整实时联动。事件 `setValue` 只改共享事件，派发者不读回它来改控件；本例不调用它。其它监听器若改载荷或金额，须由接线方协调最终顺序。

两次模型赋值是本次表单计算，不是保存或原子事务；既有字段规则、权限、精度和保存校验继续生效。非法或缺失输入不写回，也不宣称计算完成。目标声明的 `number[]` 与 Java `Number[]` 已分别核对，实际 KingScript 数组/数值桥、字段挂载及页面联动仍需项目验收。

依据：[官方滑动输入条说明](https://vip.kingdee.com/knowledge/794244138563341568)（明确仅移动端，业务属性V4.0及以上）及当前本机7.0 `Slider/SliderEvent/SliderListener/SliderAp`、移动端 `KDSlider` 消费者；不据此推断实际部署补丁。

## TabBatchCloseListener

### tabBatchClose

**签名**：`tabBatchClose(evt: TabBatchCloseEvent): void`；`Tab` 位于 `kd.bos.form.container`，真实集合入口为 `getTabKeys()`。
**触发控件**：明确调用 `Tab.batchCloseTabs` 的自定义入口。当前 PC KDTabs 右键关闭发送 `closeTabs`、交 `TabCloseListener`，不是本事件，不能声称本例保护所有页签关闭。
**场景**：原目标是批量关闭前检查未保存数据并提示确认。普通提示没有实现该保护；当前已确认的安全处理是暂停这条直接批关入口，提示逐页走原关闭流程。完整“逐页检查、串行确认后批量关闭”尚未实现，不能把拦截提示当成功批关或未保存检查结果。

当前 7.0 `Tab.batchCloseTabs` 每通知一个监听器，就立即读取事件名单与 force 并消费，不等所有监听器统一决定。`force=false` 且名单非空直接发 `closeWindow`；`force=true` 虽尝试对子视图调用 close，随后仍无条件发送批量 `closeWindow`，即使子视图正在等确认也不能据此保证页面保留。`closeTabs(list)` 只是替换事件名单，`forceCloseTabs()` 只是置 force，事件没有 `cancel/getClosingTabs`。

只在已核**独占这一批关事件**的自定义 Tab 上挂载下面插件；先前监听器已经发出的关闭无法撤回，后续监听器重新放入名单或设 force 也会破坏拦截。多个处理者必须先统一协调，本例不删除或重排它们。替换为空名单并关闭 force 后，当前消费者不发送批关指令；不原地清空调用方共享列表。

```typescript
/**
 * 暂停已核独占 Tab.batchCloseTabs 入口，避免直接客户端批关跳过未保存校验。
 * 仅用于自定义入口；不替代门户右键关闭，不加载子视图、不发关闭指令或执行保存。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { Tab } from "@cosmic/bos-core/kd/bos/form/container";
import { TabBatchCloseEvent, TabBatchCloseListener } from "@cosmic/bos-core/kd/bos/form/control/events";
import { ArrayList } from "@cosmic/bos-script/java/util";

/** 只有本监听器独占该批关处理时才挂载；多个处理者须先统一协调。 */
class PreserveTabsOnBatchClosePlugin extends AbstractFormPlugin implements TabBatchCloseListener {
  /** 当前自定义Tab入口已核为本插件独占；不复用门户的标准右键关闭通道。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const tab = this.getView().getControl("kdec_tabcontrol") as Tab;
    tab.addTabBatchCloseListener(this);
  }

  /** 保留全部页面，提示回到原单页关闭入口；不假造跨页dirty或确认状态。 */
  tabBatchClose(evt: TabBatchCloseEvent): void {
    const requested = evt.getTabKeys();
    const count = requested == null ? 0 : requested.size();
    // 替换事件名单而非clear共享原List；同时撤销本入口的force，避免空名单仍发关闭命令。
    evt.closeTabs(new ArrayList());
    evt.setForce(false);
    if (count > 0) {
      this.getView().showTipNotification(
        "已暂停批量关闭（请求项 " + count + "），请逐页使用原关闭入口处理未保存内容。"
      );
    }
  }
}

const plugin = new PreserveTabsOnBatchClosePlugin();
export { plugin };
```

提示中的数量是请求项数，不推断去重后的页面数、脏页面数或成功关闭数。空/缺名单不提示，仍保持空名单和 force=false；不查询跨页业务数据，不触发保存、强制关闭或额外确认框。

普通 `BillView.close` 的标准链有 `BeforeClosedEvent`、`checkDataChange`、取消和未保存确认，符合条件时等待用户答复，完成关闭由其 `onClose/closeClientForm` 自己发送关闭及父回调。该保护依赖真实已加载模型、变更状态和页面插件，不能仅凭页签名判断。`getViewNoPlugin` 官方声明只允许访问页面数据，不可调用业务逻辑；不要照搬批关 force 分支来冒充完整插件校验，也不要省略跨页客户端指令打包合同。多个脏页面并发 close 的确认串行协调未核，所以本例不补造dirty生产者、确认缓存或逐页自动关闭循环。

此处保留全部页面，后续由用户沿目标页面原有单页关闭入口处理；原入口的权限、校验和保存语义不由本拦截器改写。真实挂载、入口覆盖、独占条件与完整批量关闭验收未完成。

依据：[官方事件](https://dev.kingdee.com/sdk/Cosmic%20V8.0.1/index.html?nav=class&package=kd.bos.form.control.events&name=TabBatchCloseEvent)、[官方监听器](https://dev.kingdee.com/sdk/Cosmic%20V8.0.1/index.html?nav=class&package=kd.bos.form.control.events&name=TabBatchCloseListener) 为 V8.0.1；本例方法与逐监听器消费、关闭指令/确认分支另核当前 7.0 JAR/声明及前端，不据此宣称平台保护已验收。

## TreeNodeQueryListener

### queryTreeNodeChildren

**签名**：`queryTreeNodeChildren(evt: TreeNodeEvent): void`
**触发控件**：TreeView
**场景**：在已有组织树节点展开时，按 `parent.id` 查询其下级组织并按 `number` 排序。

懒加载结果经 `TreeView.addNodes(List<TreeNode>)` 发送到控件；`TreeNodeEvent` 没有 `setChildNodes` 或 `getNodeText`。用真实 `TreeNode(parentId, id, text)` 并为待加载节点设置空 `children`。本机序列化键是 `parentid`；前端读取 `parentid` 定位父节点，由 `children` 决定可展开状态。普通对象的 `parentId/isParent` 不能替代这份载荷合同；不能据此宣称所有普通 Map 都会在 Java `addNodes` 中抛类型转换异常。

以下保留组织查询场景。`bos_org/id/number/name/parent.id`、可访问组织范围与根节点必须在目标项目确认；本例不创建虚构组织根节点。现有根节点须以真实组织主键作为标识，并以空 `children` 允许首次懒加载。

```typescript
/**
 * 组织树懒加载：对已有 kdec_org_tree 根节点，按 parent.id 查询孩子并按 number 排序。
 * bos_org 及字段、根节点初始化、数据范围和权限须由目标项目确认；本例只读查询并更新控件。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { TreeView } from "@cosmic/bos-core/kd/bos/form/control";
import { TreeNodeEvent } from "@cosmic/bos-core/kd/bos/form/control/events";
import { TreeNode } from "@cosmic/bos-core/kd/bos/entity/tree";
import { DynamicObject } from "@cosmic/bos-core/kd/bos/dataentity/entity";
import { QueryServiceHelper } from "@cosmic/bos-core/kd/bos/servicehelper";
import { QFilter, QCP } from "@cosmic/bos-core/kd/bos/orm/query";
import { ArrayList } from "@cosmic/bos-script/java/util";

/** 为项目已初始化、标识与组织主键一致的节点加载下一级组织。 */
class OrgTreeLazyLoadPlugin extends AbstractFormPlugin {
  /** 接线到既有组织树；根节点需要以空 children 标记可懒加载。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    (this.getView().getControl("kdec_org_tree") as TreeView).addTreeNodeQueryListener(this);
  }

  /** 空结果不伪造父节点更新，保留再次展开查询；节点唯一、无环由项目数据保证。 */
  queryTreeNodeChildren(evt: TreeNodeEvent): void {
    if ((evt.getSource() as TreeView).getKey() !== "kdec_org_tree") return;
    const value = evt.getNodeId();
    if (value == null || String(value) === "") return;
    const parentId = String(value);
    const children = QueryServiceHelper.query(
      "bos_org", "id,number,name", [new QFilter("parent.id", QCP.equals, parentId)], "number"
    );
    const childNodes = new ArrayList();
    for (let i = 0; i < children.size(); i++) {
      const child = children.get(i) as DynamicObject;
      const node = new TreeNode(parentId, child.getString("id"), child.getString("name"));
      node.setChildren(new ArrayList());
      childNodes.add(node);
    }
    if (childNodes.isEmpty()) return;
    (this.getView().getControl("kdec_org_tree") as TreeView).addNodes(childNodes);
  }
}
const plugin = new OrgTreeLazyLoadPlugin();
export { plugin };
```

**节点与空结果合同**：

- 本机PC前端在展开且 `children` 存在、长度为0时请求孩子；`children` 缺失或null视为叶子，空数组表示尚未加载。前端会重算 `isParent`，只设置 `leaf=true` 不保证停止懒加载。
- 所有节点标识须在本树内唯一，父键必须已存在，组织关系无环；本机追加按ID跳过已有节点，未知父键不追加。重复追加不等于刷新名称、移动节点或合并其业务状态，不能靠去重修复错误父子关系。
- 空查询结果不发追加命令，**本例未把空结果永久叶化**，再次展开仍可查询。若项目要永久叶化，需保有该节点完整状态，去掉其 `children` 后通过真实 `updateNode` 更新；不能只凭事件中的ID伪造节点并覆盖原名称、样式或孩子。
- 回调事件的 `getExpandedNode()` 并不保证有值；本机查询派发未填入完整节点。根初始化、权限、无环检查及真实页面加载需项目验证。

完整合成节点与点击、双击、勾选、拖拽反馈见[构建树并按需懒加载节点](控件-场景拆分/buildTreeViewAndLazyLoadNodes.md)。本节只负责组织树查询，其他独立示例不能未经项目适配直接组合成组织保存流程。

依据：[官方树形控件插件](https://vip.kingdee.com/knowledge/230366156979367424)、[懒加载事件说明](https://vip.kingdee.com/knowledge/230361122757940224)及目标本机7.0序列化与PC消费者。事件单页模板夹杂点击事件写法，签名以实际目标声明为准；官方正文更新时间不代表部署补丁。

## WizardStepsListener

**真实责任**：PC常规向导的 `update(e: StepEvent)` 收到用户点击的目标下标，`e.getValue()` 从0开始；事件来源是 `kd.bos.form.container.Wizard`。本机7.0没有示例原写的 `getCurrentStep/getTargetStep/setCancel`。前端步骤条由 `currentStepInfo` 控制，点击只派发请求；服务端调用 `setWizardCurrentStep(Map)`，前端收到 `currentStep/currentStatus` 后才更新步骤状态。校验失败时不发更新指令即可保持原步骤，修改 `e.setValue()` 也不等于取消。

**业务场景与前提**：保留原来的基本信息和明细检查。控件 `kdec_wizard` 须配置 `wizardType=normal`，恰好三个步骤项，下标0、1、2；`stepsOptions` 的配置优先于 `stepLength`。`billno/kdec_supplier/kdec_entryentity` 须是已核实的本表单字段。进入第二或第三步都检查单号与供应商，进入第三步还检查至少一行明细，防止从第一步直接跳第三步绕过检查。允许返回第一步，忽略范围外的下标。

```typescript
/**
 * PC 常规三步向导插件，控件标识为 kdec_wizard，步骤下标为 0、1、2。
 * 表单须提供 billno、kdec_supplier 和 kdec_entryentity；后两项对应供应商与明细分录。
 * 点击时校验目标步骤的前置数据，仅更新步骤条状态，不替代保存操作校验。
 */
import { AbstractBillPlugIn } from "@cosmic/bos-core/kd/bos/bill";
import { Wizard } from "@cosmic/bos-core/kd/bos/form/container";
import { StepEvent, WizardStepsListener } from "@cosmic/bos-core/kd/bos/form/control/events";
import { HashMap } from "@cosmic/bos-script/java/util";

/** PC 常规三步向导：校验目标步骤的前置数据，再更新步骤条状态。 */
export class ThreeStepWizardPlugin extends AbstractBillPlugIn implements WizardStepsListener {
  /** 注册常规向导步骤点击事件；控件须配置三个步骤项。 */
  registerListener(e: $.java.util.EventObject): void {
    super.registerListener(e);
    const wizard = this.getView().getControl("kdec_wizard") as Wizard;
    wizard.addWizardStepsListener(this);
  }

  /** 点击下标只表示用户请求；前置校验失败时不发送步骤更新指令。 */
  update(e: StepEvent): void {
    const wizard = e.getSource() as Wizard;
    if (wizard.getKey() !== "kdec_wizard") return;
    const targetStep = e.getValue();
    if (targetStep !== 0 && targetStep !== 1 && targetStep !== 2) return;

    // 进入第二或第三步前，累计检查基本信息，防止直接点击第三步绕过校验。
    if (targetStep >= 1) {
      const billNo = this.getModel().getValue("billno") as string | null;
      const supplier = this.getModel().getValue("kdec_supplier");
      if (billNo == null || billNo === "" || supplier == null) {
        this.getView().showErrorNotification("请先填写单据编号和供应商");
        return;
      }
    }
    // 进入第三步还须有至少一行明细；不替代保存操作的业务校验。
    if (targetStep >= 2 && this.getModel().getEntryRowCount("kdec_entryentity") === 0) {
      this.getView().showErrorNotification("请至少添加一行明细数据");
      return;
    }

    const currentStepMap = new HashMap();
    currentStepMap.put("currentStep", targetStep);
    currentStepMap.put("currentStatus", "process");
    wizard.setWizardCurrentStep(currentStepMap);
  }
}

let plugin = new ThreeStepWizardPlugin();
export { plugin };
```

**能力边界**：此例只更新常规步骤条，不负责切换内容页或保存数据；节点显示 `finish` 也不证明已持久化。真正保存时仍执行操作校验与权限检查。页签向导通过关联 `Tab.activeTab` 切换页签，不能把本例当作页签通用取消机制。实际元数据、插件引擎及页面行为尚未验收。

依据：[官方向导控件](https://vip.kingdee.com/knowledge/226992171080254208)，正文更新时间2025-09-03 18:17，常规/页签向导说明为V4.0+且仅PC；节点联动子页签V6.0.5、描述换行V8.0.1不是本例能力。文章部分位置混写Wizard包名，以上以本机7.0 JAR、声明与真实前端受控状态链为准，不能外推部署版本或补丁。

## BeforeCreateDataGridColumnListener

### beforeCreateDataGridColumns：按已核角色结果限制成本列展示

**真实签名**：`beforeCreateDataGridColumns(event: BeforeCreateDataGridColumnsEvent): void`。接口、事件和注册方法均为复数 `Columns`，注册入口为 `DataGrid.addBeforeCreateDataGridColumnsListener`，列集合由 `event.getDataGridColumns()` 获取。本节保留原检索标题，不能把单数类名或 `getColumns()` 直接用于当前7.0。当前声明在全局 `$` 命名空间公开事件类型，但 `grid/events` 模块未导出它，代码使用真实全局类型别名。

**场景**：根据当前已有角色/权限判断，向不可查看成本的用户隐藏成本价列。下方为独立helper，在真实建列回调中传入已核非空成本列key及本次权限结果；`bos_user.usertype = "admin"` 未确认，不能用它代替项目已有权限模型。本例不查询用户角色、不定义新角色，也不生成列或行数据。

```typescript
type BeforeCreateDataGridColumnsEvent = $.kd.bos.form.control.grid.events.BeforeCreateDataGridColumnsEvent;

/**
 * 在建列回调中限制成本列的展示，不删除列或改变行槽协议。
 * costColumnKey来自已核列定义；maySeeCost来自本次已有角色/权限判断。
 * 允许查看时保留原可见性，不能反向解除设计器或其它插件的限制。
 */
export function restrictCostColumnVisibility(
  event: BeforeCreateDataGridColumnsEvent,
  costColumnKey: string,
  maySeeCost: boolean
): void {
  if (maySeeCost || costColumnKey.length === 0) return;
  const columns = event.getDataGridColumns();
  for (let i = 0; i < columns.size(); i++) {
    const column = columns.get(i);
    if (column != null && column.getKey() === costColumnKey) {
      // 空字符串解析为可见状态位0；保留该列在数据索引中的位置。
      column.setVisible("");
    }
  }
}
```

当前7.0中，`DataGridColumn.setVisible` 接收字符串，并非普通控件的Boolean开关。空字符串转换为状态位0；`null` 返回默认63，不能拿null当隐藏。状态位为新增1、修改2、查看4、初始8、提交16、审核32。helper只把命中的成本列置为0，不用63强制显示已被设计器或前插件隐藏的列。

真实建列消费者先取得设计器列，再让所有监听器依次操作同一List，最后逐列创建前端定义。helper保留List、列对象、顺序、key和其它列属性；不能clear后仅放成本列，也不按角色删除列。`getDataIndex()` 仍为隐藏列分配行槽，现有供数及 [毛利率加工](#datagridbinddatalistener) 的完整行协议保持。后续建列插件不得重新放宽可见性。

**展示与权限边界**：隐藏列仍可能随rows和postCols发给浏览器。若成本属于不能下发的数据，必须由项目已有供数/授权逻辑保证不返回原值；本helper只限制列展示，不代表成本数据保密或权限验收。现有毛利率加工在服务端供数回调执行，但会保留原成本槽；若要求成本不下发，仍须在已核供数链中处理原值并保持行协议，不能由隐藏列推定已经完成。

`costColumnKey` 必须已存在于真实列定义，缺列/空key不代表隐藏成功。权限应在本次建列前获得；本例不保存可见性旧值，也不负责用户/角色切换后的复原。若权限变化，需要按真实页面生命周期重新生成列并应用所有原有规则，不能直接恢复63覆盖别人的限制。完整业务权限判断、动态重建与平台页面效果仍需项目集成验证。

**依据**：[官方数据表格文档](https://vip.kingdee.com/knowledge/372335960438452736)标明BOS_V5.0.010及以上，给出真实建列接口，并说明列定义全量替换。当前7.0消费者另核共享List、状态位序列化与隐藏列仍占槽；不由7.0推部署补丁。

## DataGridBindDataListener

### dataGridBindData：在已有供数之后加工毛利率

**签名**：`dataGridBindData(e: DataGridBindDataEvent): void`。在 `initialize` 中调用 `DataGrid.addBindDataListener` 注册。

**场景与接线**：轻量表格没有绑定实体。每次供数事件的 `data` 初始为空；本例须排在本页已核实的供数监听器之后，读取它已写入的 `e.getData()`，补充毛利率。仅挂本例不会自动取数，也不创建业务查询或供数器。后续监听器仍可能替换结果，项目须确认实际顺序。

**行协议**：当前 7.0 消费者使用 Java List 行，前两槽为 `rk`、`seq`，之后按 `e.getDataGridColumns()` 的实际顺序排列，隐藏列也占槽；不能按字段 Map 读写，也不能只改注册方法名。供数方须保证行键存在且唯一。三个目标列必须已建好，售价/成本槽为原始 `BigDecimal` 或 null，毛利率列 `kdec_profit_rate` 必须能够显示百分比文本（例如表格文本列）。

```typescript
/**
 * 供数监听器之后增补毛利率显示；输入是已经按当前 DataGrid 列打包的行。
 * 本插件不查询业务数据，不创建供数器，不改主键、序号、原价格和其他列。
 */
import { AbstractFormPlugin } from "@cosmic/bos-core/kd/bos/form/plugin";
import { DataGrid } from "@cosmic/bos-core/kd/bos/form/control/grid";
import { BigDecimal } from "@cosmic/bos-script/java/math";
import { ArrayList } from "@cosmic/bos-script/java/util";

type ReadableRow = { size(): number; get(index: number): unknown; toArray(): unknown };

/** 只接受有列表读取接口的数据行；Map、数组和不完整数据保持原样。 */
function isReadableRow(value: unknown): value is ReadableRow {
  if (value == null || (typeof value !== "object" && typeof value !== "function")) return false;
  const row = value as Partial<ReadableRow>;
  return typeof row.size === "function" && typeof row.get === "function" &&
    typeof row.toArray === "function";
}

/**
 * 按实际列序找三个业务槽位；复制完整行，仅替换毛利率槽。
 * 缺列、重复目标列或非法行保留原数据；null 价格和零售价显示为 0%。
 */
export function appendProfitRate(e: $.kd.bos.form.control.grid.events.DataGridBindDataEvent): void {
  const columns = e.getDataGridColumns();
  const data = e.getData();
  if (columns == null || data == null || data.isEmpty()) return;
  const keys = ["kdec_sell_price", "kdec_cost_price", "kdec_profit_rate"];
  const slots = [-1, -1, -1];
  for (let i = 0; i < columns.size(); i++) {
    const column = columns.get(i) as $.kd.bos.form.control.grid.column.DataGridColumn;
    if (column == null) return;
    const key = column.getKey();
    if (key === "rk" || key === "seq") return;
    const match = keys.indexOf(key);
    if (match < 0) continue;
    if (slots[match] !== -1) return;
    slots[match] = i + 2;
  }
  if (slots.some(slot => slot < 0)) return;
  const requiredSize = Math.max(...slots) + 1;
  const result = new ArrayList();
  let changed = false;
  for (let i = 0; i < data.size(); i++) {
    const original: unknown = data.get(i);
    if (!isReadableRow(original)) { result.add(original); continue; }
    const size = original.size();
    if (!Number.isSafeInteger(size) || size < requiredSize) { result.add(original); continue; }
    const sell = original.get(slots[0]);
    const cost = original.get(slots[1]);
    if ((sell != null && !(sell instanceof BigDecimal)) ||
        (cost != null && !(cost instanceof BigDecimal))) {
      result.add(original); continue;
    }
    let display = "0%";
    if (sell != null && cost != null && sell.compareTo(BigDecimal.ZERO) !== 0) {
      display = sell.subtract(cost).divide(sell, 4, BigDecimal.ROUND_HALF_UP)
        .multiply(new BigDecimal("100")).toPlainString() + "%";
    }
    const copy = new ArrayList();
    for (let slot = 0; slot < size; slot++) copy.add(original.get(slot));
    copy.set(slots[2], display);
    result.add(copy);
    changed = true;
  }
  if (changed) e.setData(result);
}

/** 与既有供数插件同表格挂载，并确保它先完成 e.setData。 */
export class ProfitRateDataGridPlugin extends AbstractFormPlugin {
  initialize(): void {
    super.initialize();
    const grid = this.getView().getControl("kdec_datagrid") as DataGrid;
    grid.addBindDataListener(this);
  }

  dataGridBindData(e: $.kd.bos.form.control.grid.events.DataGridBindDataEvent): void {
    appendProfitRate(e);
  }
}

const plugin = new ProfitRateDataGridPlugin();
export { plugin };
```

**保留与边界**：售价非零且两个价格非空时按 `(售价-成本)/售价` 保留4位、HALF_UP舍入后乘100并加 `%`；null或零售价显示 `0%`，不把财务数值转为 JS Number。每个有效行复制全部槽位，仅替换毛利率，原行、行数、顺序、rk、seq、价格、额外槽及 `postCols` 保留。缺列、重复目标列或保留键冲突时不接管；异常行或不符类型的价格保持原样，不能宣称这些行已计算。空供数保持空，供数权限、字段类型、监听器顺序及真实页面仍需项目验证。

依据：[官方轻量级表格控件](https://vip.kingdee.com/knowledge/373516397839800832)，更新时间2026-07-30 11:40，发布版本COSMIC.V5.0.011；本机7.0的 `DataGrid.getData/getDataIndex`、事件及 `DataGridRowBuilder` 消费者和随包声明。原生行协议按本机核实，不外推部署补丁。

## DataGridSelectRowListener

### dataGridSelectRow：最近一次单行选择信息回填

**真实签名**：`dataGridSelectRow(evt: DataGridSelectRowEvent): void`，注册入口是 `DataGrid.addSelectRowListener`。事件只有动作与 `getSelectedRow()`，没有 `getRowData()`；不能把返回载荷当成带 `number/name` 属性的DynamicObject。当前脚本模块没有导出该事件，示例使用真实全局声明类型别名。

**场景**：将最近一次单行选中的物料编号回填到原目标表单字段，并提示物料名称。下方独立helper在真实选择回调中调用；原例的 `kdec_selected_material` 只有确认其为本页可写文本字段后才作为 `targetFieldKey`。编号列、名称列必须是本次供数中已确认的纯文本列，不能凭显示标题或数据行序推定。

```typescript
import { IFormView } from "@cosmic/bos-core/kd/bos/form";
type DataGridSelectRowEvent = $.kd.bos.form.control.grid.events.DataGridSelectRowEvent;

/**
 * 将最近一次单行ADD_ROW的纯文本编号回填，并提示名称。
 * postCols必须是本次已显示数据最终下发的完整顺序；列key/目标字段须已核。
 * 其它选择动作或无效载荷保持旧值；不查询业务、不重跑供数、不代替权限校验。
 */
export function applyLastSelectedMaterial(
  evt: DataGridSelectRowEvent,
  view: IFormView,
  postCols: $.java.util.List,
  numberColumnKey: string,
  nameColumnKey: string,
  targetFieldKey: string
): boolean {
  const action = evt.getAction();
  if (action == null || action.toString() !== "ADD_ROW") return false;
  if (numberColumnKey.length === 0 || nameColumnKey.length === 0 ||
      numberColumnKey === nameColumnKey || targetFieldKey.length === 0) return false;
  const row = evt.getSelectedRow();
  if (row == null) return false;
  const values = row.getPostRowData();
  if (postCols == null || values == null || values.size() !== postCols.size()) return false;
  let numberIndex = -1;
  let nameIndex = -1;
  for (let i = 0; i < postCols.size(); i++) {
    const key: unknown = postCols.get(i);
    if (typeof key !== "string") return false;
    if (key === numberColumnKey) {
      if (numberIndex !== -1) return false;
      numberIndex = i;
    }
    if (key === nameColumnKey) {
      if (nameIndex !== -1) return false;
      nameIndex = i;
    }
  }
  if (numberIndex < 0 || nameIndex < 0) return false;
  const number: unknown = values.get(numberIndex);
  const name: unknown = values.get(nameIndex);
  // 格式化[display,raw]、对象和数值不能强转为物料文本；大编号保持原字符串。
  if (typeof number !== "string" || number.length === 0 ||
      typeof name !== "string" || name.length === 0) return false;
  view.getModel().setValue(targetFieldKey, number);
  view.showTipNotification("已选择：" + name);
  return true;
}
```

`RowSelectAct` 真动作是 `ADD_ROW/CLEAR_ROW/SELECT_ALL/CLEAR_ALL`。当前声明没有模块导出的枚举值，helper读取真实枚举继承的 `toString()` 名称，不猜数字序号或添加虚构导出。`CLEAR_ROW` 也携带被取消行的载荷，不能仅判断selectedRow非null就回填；页全选/全清没有行对象。helper对后三类动作保持旧字段，不宣称此字段代表当前完整已选集合。若需要取消后清空或多选汇总，须另核真实页面选中状态合同，不能把取消任意一行误当取消最近选择。

实际轻量前端按本次 `postCols.map(code => record[code])` 组装回传值；`getPostRowData()` 仅含这些值，顺序不是显示列序、也不是dataindex的原槽位。当前DataGrid派发使用两参数 `DataGridSelectedRow` 构造，事件自身的 `getPostCols()` 是空List，不能用它解码。调用方必须提供**本次已显示数据最终下发的postCols完整顺序**，其中包含已核编号/名称列；缺少这个既有供数合同就不能挂用helper，不新增空供数者、缓存或解析器来假装已经接线。

`postCols` 必须与当前显示批次一致，后续供数监听器不得改变其顺序或行值含义而仍沿用旧合同；长度相等并不能检测同长度重排或陈旧合同。缺列/重复目标列/非文本列key/短载荷/数组或未知值时，helper保持旧字段且不提示“已选择”。回传的格式化 `[display,raw]` 不会由前端自动解包，不能toString凑值。大编号保持字符串，`rk` 只是int行键，不拿它查询物料主键。

DataGrid没有保存当前完整选中集合；`getData()` 会重新触发全部供数监听器，不能在选择回调中用它补查所谓当前缓存行。隐藏列仍可能被postCols回传。这里的文本来自客户端，只用于本页信息展示；不凭它授予权限、打开任意实体或执行保存/删除等业务动作。真实物料查询、供数、字段与挂载、Java桥接及页面权限仍须项目验证。

**依据**：[官方数据表格文档](https://vip.kingdee.com/knowledge/372335960438452736)标明BOS_V5.0.010及以上，说明rk唯一、postCols回传及差量选择；当前7.0服务端与实际KDLightTable消费者进一步核实事件动作、空postCols和回传顺序。没有把旧ks示例等同于当前KingScript运行验收。

## DateClickListener

### resetDateFilter

**签名**：`resetDateFilter(e: ResetDateFilterEvent): void`
**触发控件**：`DateEdit/DateTimeEdit` 的年度日期过滤请求；通过控件 `addDateClickListener` 注册。
**场景**：业务日期的选择面板限制在项目已确认的当前会计期间，并保留本次事件已有的有效日期限制。会计期间起止必须来自已有业务依据；系统自然月不自动等于会计期间。

`setMinDate/setMaxDate` 属于控件，不属于本事件。当前7.0 `changeYear` 先设 `focusedYear`、调用全部监听器，再取事件列表发送 `setDateFilter`；不是每次选中日期都回调。`includeDates` **非null即优先**，即使空List也会压住 `excludeDates`。当前PC消费者对空数组不更新状态，空include不能表达全禁或清掉旧缓存。

下列完整合成函数接受项目已有的、按平台默认日期格式化时区解释的 `yyyy-MM-dd` 期间首末日（含两端）。调用方在已核的 `kdec_bizdate` 事件中传入真实起止；不造期间字段、查询或权限映射。函数按事件年份枚举，使用真实 `SimpleDateFormat.parse` 构造Java日期，再合成非空禁选集合：前include非空时按其补集保留限制；include为null时保留前exclude。原列表不就地修改，原include存在时原exclude按平台优先级不额外生效。

```typescript
import { ResetDateFilterEvent } from "@cosmic/bos-core/kd/bos/form/field/events";
import { ArrayList } from "@cosmic/bos-script/java/util";
import { SimpleDateFormat } from "@cosmic/bos-script/java/text";

/** 按既有期间合成当年日期选择限制；true仅表示写入事件，不表示客户端或保存验收。 */
export function restrictPickerToPeriod(
  e: ResetDateFilterEvent, periodStart: string, periodEnd: string
): boolean {
  const format = new SimpleDateFormat("yyyy-MM-dd");
  format.setLenient(false);
  /** 接受完整规范日期，避免宽松解析及按字符串比较非规范日期。 */
  const validKey = (s: string): boolean => {
    if (typeof s !== "string" || !/^\d{4}-\d{2}-\d{2}$/.test(s)) return false;
    try { return format.format(format.parse(s)) === s; } catch { return false; }
  };
  if (!validKey(periodStart) || !validKey(periodEnd) || periodStart > periodEnd) return false;
  const year = e.getFocusedYear();
  // 本例限默认公历切换后的完整年份；历史Julian月长不能套JS公历枚举。
  if (!Number.isInteger(year) || year < 1583 || year > 9999) return false;
  const priorInclude = e.getIncludeDates();
  if (priorInclude != null && priorInclude.isEmpty()) return false;

  /** 完整校验本次已有列表；null元素或非日期使本次不接管，原事件保持。 */
  const readKeys = (include: boolean): Set<string> | null => {
    try {
      const list = include ? e.getFmtIncludeDates() : e.getFmtExcludeDates();
      const keys = new Set<string>();
      if (list != null) {
        for (let i = 0; i < list.size(); i++) {
          const value = list.get(i);
          if (typeof value !== "string" || !validKey(value)) return null;
          keys.add(value);
        }
      }
      return keys;
    } catch { return null; }
  };
  const includeMode = priorInclude != null;
  const prior = readKeys(includeMode);
  if (prior == null) return false;
  const excluded = new ArrayList();
  try {
    for (let month = 1; month <= 12; month++) {
      const leap = year % 4 === 0 && (year % 100 !== 0 || year % 400 === 0);
      const days = month === 2 ? (leap ? 29 : 28) : ([4, 6, 9, 11].includes(month) ? 30 : 31);
      for (let day = 1; day <= days; day++) {
        const key = String(year) + "-" + String(month).padStart(2, "0") + "-" + String(day).padStart(2, "0");
        const wasExcluded = includeMode ? !prior.has(key) : prior.has(key);
        if (wasExcluded || key < periodStart || key > periodEnd) {
          const date = format.parse(key);
          if (format.format(date) !== key) return false;
          excluded.add(date);
        }
      }
    }
  } catch { return false; }
  // 空数组不能清客户端旧状态；不伪装成已解除全年限制。
  if (excluded.isEmpty()) return false;
  e.setExcludeDates(excluded);
  // Java setter接受null；目标TS未标nullable，断言只用于清掉已合成的优先include。
  e.setIncludeDates(null!);
  return true;
}
```

**接线与边界**：保留原业务日期控件 `kdec_bizdate`。项目在自己的已注册 `resetDateFilter` 中核事件来源为该控件后调用此函数；期间供数、字段挂载及原保存校验沿用项目，不把本函数当会计期间查询。仅当会计期间已经确认等于自然月时，原示例“本月首日—末日”的算法才可提供入参。本例不自动选择这种业务口径。

调用者必须是本次年度过滤的最终合成者，前置列表是本次完整限制；后续监听器不得覆盖。当前PC按年份缓存，期间或其它限制须在该页生命周期内稳定；已缓存年份不保证再请求，空include与未知旧缓存不能被本次事件重建，函数返回false时当前期间限制未生效。期间覆盖整年且无其它禁选也返回false，不声称清除了旧状态。跨年/闰年按请求年份计算；仅支持1583—9999的公历年份，按纯公历月长枚举，且要求JVM默认Calendar采用公历及项目已核的日期时区；这属于本函数的技术适用边界，不是业务期间规则。年份检查仍不保证时区可表达全部日期，枚举解析失败或格式回等不一致时保持事件并返回false；限制日期选择不等于手工输入、移动端或保存强校验。真实时区、KingScript日期桥、项目当前期间及页面验收仍未完成。

依据：[官方日期可选/不可选控制指南](https://vip.kingdee.com/knowledge/135431719481868032)、[日期字段](https://vip.kingdee.com/knowledge/220180664904104960)、当前本机7.0 `DateTimeEdit/ResetDateFilterEvent` 与PC `KDDatePicker` 消费者。官方通用字段概述“未增加其他插件事件”不能替代专项指南及目标类的实际年度过滤事件；V8.0.1逐分录行配置不外推本例。

## ListExpandListener

### expandClick 与显式明细显示控制

**签名**：`expandClick(evt: ListExpandEvent): void`
**触发控件**：标准 PC 列表的 `BillList`
**场景**：识别当前行的明细展示请求；需要程序展开或关闭时，另外发送明确的显示指令。

标准列表的 `AbstractListView` 已向 `BillList` 注册代理，将事件分发给 `AbstractListPlugin.expandClick`；本例直接重写，不再 `addListExpandListener(this)`，避免重复接入。嵌入动态表单、自定义视图装配和移动列表须另核接线，不能套用此注册前提。

`ListExpandEvent` 只有主键和行上下文，没有 `isExpanded` 或取消接口。当前 AgDataGrid 在 500ms 延迟渲染前即可通知，缓存命中也通知，销毁只清定时器；KDTable 的明细取数另走独立请求。因此这里提示“收到请求”，不能报告渲染或取数完成，也不能报告“已折叠”。`getRowIndex()` 在已核链路承载当前 `rowKey`；分页、滚动和重排会改变对应关系，不是可见数组下标、永久行号或业务主键。主键原值保持，不转 JavaScript Number。

```typescript
import { AbstractListPlugin } from "@cosmic/bos-core/kd/bos/list/plugin";
import { BillList } from "@cosmic/bos-core/kd/bos/list";
import { ListExpandEvent } from "@cosmic/bos-core/kd/bos/form/field/events";

/** 标准 PC 列表明细请求观察器；依赖列表视图自动接线，不执行取数、保存或明细控制。 */
export class ListDetailRequestPlugin extends AbstractListPlugin {
  /** 仅接收目标列表格式合法的行上下文；共享事件不修改，通知不代表明细已经显示。 */
  expandClick(evt: ListExpandEvent): void {
    const source = evt.getSource();
    if (!(source instanceof BillList) || source.getKey() !== "billlistap") return;
    const rowKey = evt.getRowIndex();
    if (!Number.isInteger(rowKey) || rowKey < 0 || rowKey > 2147483647
        || evt.getPkId() == null) return;
    this.getView().showTipNotification("收到列表行明细展示请求，行键：" + rowKey);
  }
}

/**
 * 发送本次明确的展开/关闭请求；调用方须提供同一当前列表快照中的有效 rowKey。
 * 数组为普通 JavaScript number[]，不能由主键、显示序号或旧分页索引推算。
 * 全量验证后复制并去重，不改调用方数组；非法或相互冲突的请求不发送。
 * 返回 true 仅表示调用了显示指令，不表示取数、渲染或业务验收完成。
 */
export function requestListDetails(
  list: BillList,
  expandRowKeys: number[],
  closeRowKeys: number[],
  closeOtherRows: boolean
): boolean {
  if (!(list instanceof BillList) || !Array.isArray(expandRowKeys)
      || !Array.isArray(closeRowKeys) || typeof closeOtherRows !== "boolean") return false;
  const expand: number[] = [];
  const close: number[] = [];
  for (const rowKey of expandRowKeys) {
    if (!Number.isInteger(rowKey) || rowKey < 0 || rowKey > 2147483647) return false;
    if (!expand.includes(rowKey)) expand.push(rowKey);
  }
  for (const rowKey of closeRowKeys) {
    if (!Number.isInteger(rowKey) || rowKey < 0 || rowKey > 2147483647
        || expand.includes(rowKey)) return false;
    if (!close.includes(rowKey)) close.push(rowKey);
  }
  if (expand.length === 0 && close.length === 0 && !closeOtherRows) return false;
  list.autoExpandOrCloseRowDetail(expand, close, closeOtherRows);
  return true;
}
```

`autoExpandOrCloseRowDetail` 下发 `expandOrCloseRowDetail`，载荷为 `[展开行键数组, 关闭行键数组, 是否关闭其它行]`。当前消费者先关再开，展开优先；本 helper 拒绝两个数组重叠，避免调用意图含糊。空数组配 `closeOtherRows=true` 是明确关闭全部请求，不是无操作。它不替调用方确认行键仍存在，也不建立权限或页面配置。

显示控制应由项目已有的明确入口调用，**不要在 `expandClick` 中自动再次展开**：程序展开也可能创建明细渲染器并引发通知。官方说明列表支持折叠第一个单据体，不支持多个单据体或子单据体；实际页面必须已配置相应明细。本文保留明细显示控制入口，但不提供业务行键生产者、控件配置、折叠回执、渲染完成事件或完整页面接线；KingScript 类型识别、数组桥及实际页面行为仍需目标环境验证。若要加工面板字段，另核 `setCellFieldValue` 的字段与显示合同，不把示例状态值当业务更新。
