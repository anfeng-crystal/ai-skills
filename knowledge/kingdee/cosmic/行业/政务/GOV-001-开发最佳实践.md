## 1. 工作日计算（跳过周末）
```java
public static Date calcDueDate(Date startDate, int workDays) {
    Calendar cal = Calendar.getInstance();
    cal.setTime(startDate);
    int added = 0;
    while (added < workDays) {
        cal.add(Calendar.DAY_OF_MONTH, 1);
        int dow = cal.get(Calendar.DAY_OF_WEEK);
        if (dow != Calendar.SATURDAY && dow != Calendar.SUNDAY) {
            added++;
        }
    }
    return cal.getTime();
}
```
**原则**：逐日推进，遇到周末跳过不计入，保证工作日精确。

## 2. 办结率统计优化（queryCount vs query）

```java
// 两次 queryCount 比 query + 遍历高效得多

```
**原则**：统计场景优先 queryCount，避免加载完整数据。
