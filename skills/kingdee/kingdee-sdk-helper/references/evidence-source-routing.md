# SDK/API 证据合同

同名类、产品/JDK 和目标构件的背景见[云端知识](https://chatgpt.com/space/page_4da965c745c88191a07bc024728e39f1)；不可访问时继续使用当前项目证据，不阻断本地核验。

## 来源能证明什么

| 来源 | 可确认范围 |
| --- | --- |
| 目标实际依赖 JAR、同版本声明/Javadoc、反射/编译 | 类、完整签名、可见性及编译兼容；行为需相应正文或实际实现/运行证据 |
| Skill SDK 索引及可核验的版本/来源 | 索引明确记录的类、签名、注释，不自动证明当前项目兼容 |
| 目标项目已编译源码 | 该项目的用法，不外推为标品或其他版本能力 |
| 官方产品/SDK 文档与示例 | 正文适用版本内的契约；无版本则记录缺口 |
| 普通用户社区、项目片段、论坛、反编译摘要 | 检索线索和候选，需回目标或适用官方证据复核 |
| 无来源或转载 | 不用于确认签名或行为 |

记录文件/标题、发布主体、来源版本/日期或提交版本。目标同版本的实际依赖优先解决签名冲突，编译只能证明类型；官方和用户社区按发布主体及正文分类，不按域名分类。缺版本不补造“全部支持”。

## 目标与调用语义

1. 复用用户目标与已核实依赖；`7.0` 不等于最新补丁，查询 8.0 资料不授权升级项目。版本不一致先查依赖解析；未知补丁但目标 JAR 足以证明当前调用时继续，只阻塞依赖未知事实的部分。
2. 对本次 API 核对声明者、完整重载、参数顺序/类型/含义、返回和异常。元数据内部身份、实体/表单编码、记录主键、业务编码及权限项不能因类型相同混用；参数名仅是线索，不能代替说明或调用证据。
3. 对事件/回调核对触发阶段、可用上下文、监听与回调标识、结果序列化及消费分支。按钮文案/选项名称不保证特定枚举返回；区分 SDK 声明、客户端发出值和服务端解释，不用只注入预期值的 mock 证明实际映射。
4. 查询参数与数据赋值须结合真实字段元数据；Java 的 String/Object 形参不能证明数据库或引用字段类型。基础资料单选、多选集合和显示文本分开判断。
5. 无版本参考卡、不同版本索引或新示例只作候选；用户要求其他版本独立示例时可以按该目标写，但不能修改当前项目目标。mock/桩、正则检查和异版编译均不能证明目标平台兼容。
6. 构建/运行兼容分别记录产品/补丁、部署形态、SDK JAR、构建 JVM 和运行 JVM；不从 SDK 主版本或 source/target 推断 JDK。按[官方 JDK 调整说明](https://vip.kingdee.com/knowledge/767850225473553920)与目标部署核对支持范围和计划，不能据公告或编译结果擅自切换项目 JDK。

## 官方与社区取文

- 普通社区可给检索词，不能直接确认默认值、事务语义或生产可用性。项目实现只属于该项目；跨项目复用先查依赖与元数据。
- 反编译只在来源、许可证和用途允许时用于定位，不复制实现，不把推断当官方契约。
- 需要联网时转 `web-access`，技术结论使用官方一手正文。专题目录、标题和搜索摘要只定位原文；记录实际 category/id/type 页面，空壳和登录墙不算正文。可复用授权浏览器会话，不提取 Cookie，不绑定宿主工具名。
- 区分“该版本未公开”“SDK 废弃”“脚本废弃”“内部封装”和“性能偏好”；废弃必须有同版本标记/Javadoc 或官方迁移公告，不能由未命中或存在另一重载推出。

从[开发者门户](https://dev.kingdee.com/index/home)或[苍穹帮助中心](https://developer.kingdee.com/knowledge/atlas?productLineId=29)定位版本化正文；[官网](https://www.kingdee.com/products/cosmic_platform.html)仅作入口导航。来源冲突时比较具体产品、认证/运行模式、补丁变更及适用范围，再对目标依赖；不能按搜索排名或页面新旧拼出新合同，未消歧则保留双方证据并标未确认。

## 输出证据状态

| 状态 | 含义 |
| --- | --- |
| `confirmed-project` | 目标实际依赖/声明或编译确认了所列签名/类型；运行行为另标依据 |
| `confirmed-index` | 索引有记录，目标兼容尚未确认 |
| `official-versioned` | 已读官方且有适用版本 |
| `official-unversioned` | 已读官方正文，适用版本未确认 |
| `candidate-community` | 社区/项目片段只提供候选 |
| `unconfirmed` | 缺证据或来源冲突 |

结论写到具体事实：签名、参数语义、行为、编译与运行各自的依据，不能用一个状态包办所有层次。
