# 界面控件开发指南

> 来源: 基于平台API和社区资料整理
> 日期: 2026-04-12
> 标签: 界面控件, 自定义控件, FlexPanel, 控件事件, 表单设计

## 摘要
金蝶云苍穹提供丰富的内置控件（文本、日期、F7、分录、标签页等）和自定义控件扩展机制。开发者通过表单插件中的控件事件实现交互逻辑，通过前端 React 技术实现完全自定义的 UI 控件。

## 适用版本
- 金蝶云苍穹 V5.0+

## 核心概念

### 控件分类

| 类别 | 控件 | 说明 |
|------|------|------|
| 数据字段 | 文本、数字、日期、多选、下拉列表 | 绑定实体字段 |
| 引用字段 | F7（基础资料）、用户、组织 | 引用其他实体 |
| 布局容器 | FlexPanel、标签页、折叠面板 | 页面布局 |
| 操作按钮 | 工具栏、按钮 | 触发操作 |
| 展示控件 | 标签、图片、轮播 | 数据展示 |
| 分录控件 | 分录、子分录 | 多行数据 |

### 控件事件

| 事件 | 触发时机 | 常用场景 |
|------|----------|----------|
| `valueChanged` | 字段值改变 | 联动计算、条件显隐 |
| `itemClick` | 按钮点击 | 自定义操作 |
| `beforeF7Select` | F7 弹出前 | 设置 F7 过滤条件 |
| `afterF7Select` | F7 选择后 | 携带关联字段 |
| `click` | 控件点击 | 通用点击响应 |
| `entryRowClick` | 分录行点击 | 分录行操作 |

## 详细内容

### 一、控件事件注册与监听

```java
/**
 * 控件事件处理示例
 */
public class ControlEventDemoPlugin extends AbstractBillPlugIn {

    @Override
    public void registerListener(EventObject e) {
        super.registerListener(e);
        // 注册按钮点击事件
        this.addItemClickListeners("bar_custom_btn");
        // 注册字段值变化事件
        this.addClickListeners("label_custom");
    }

    @Override
    public void itemClick(ItemClickEvent evt) {
        super.itemClick(evt);
        if ("bar_custom_btn".equals(evt.getItemKey())) {
            // 处理自定义按钮点击
            handleCustomAction();
        }
    }

    @Override
    public void propertyChanged(PropertyChangedArgs e) {
        super.propertyChanged(e);
        String fieldKey = e.getProperty().getName();

        if ("qty".equals(fieldKey)) {
            // 数量变化时自动计算金额
            calcAmount(e.getChangeSet()[0].getRowIndex());
        }

        if ("material".equals(fieldKey)) {
            // 物料变化时携带相关字段
            carryMaterialInfo(e.getChangeSet()[0].getRowIndex());
        }
    }

    @Override
    public void beforeF7Select(BeforeF7SelectEvent e) {
        String fieldKey = e.getProperty().getName();
        if ("material".equals(fieldKey)) {
            // 设置物料 F7 的过滤条件
            ListShowParameter showParam = (ListShowParameter) e.getFormShowParameter();
            showParam.getListFilterParameter().setFilter(
                new QFilter("enable", QCP.equals, true)
                    .and(new QFilter("status", QCP.equals, "C"))
            );
        }
    }

    private void calcAmount(int rowIndex) {
        BigDecimal qty = (BigDecimal) this.getModel().getValue("qty", rowIndex);
        BigDecimal price = (BigDecimal) this.getModel().getValue("price", rowIndex);
        if (qty != null && price != null) {
            this.getModel().setValue("amount", qty.multiply(price), rowIndex);
        }
    }

    private void carryMaterialInfo(int rowIndex) {
        DynamicObject material = (DynamicObject) this.getModel().getValue("material", rowIndex);
        if (material != null) {
            this.getModel().setValue("materialname", material.getString("name"), rowIndex);
            this.getModel().setValue("unit", material.getDynamicObject("baseunit"), rowIndex);
        }
    }

    private void handleCustomAction() {
        this.getView().showConfirm("确认执行此操作？", MessageBoxOptions.YesNo,
            new ConfirmCallBackListener("confirmAction", this));
    }
}
```

     * 编程方式新增分录行

        this.getModel().setValue("material", materialObj, newRowIndex);
        this.getModel().setValue("qty", 1, newRowIndex);
    }

    /**
     * 删除指定分录行
     */
    private void deleteEntryRow(int rowIndex) {
        this.getModel().deleteEntryRow("entryentity", rowIndex);
    }

    /**
     * 遍历分录并计算汇总
     */
    private BigDecimal calcEntryTotal() {
        DynamicObjectCollection entries =
            this.getModel().getEntryEntity("entryentity");
        BigDecimal total = BigDecimal.ZERO;
        for (DynamicObject entry : entries) {
            total = total.add(entry.getBigDecimal("amount"));

### 五、自定义控件开发（前端）

苍穹支持通过 React 开发完全自定义的前端控件：

1. 编写 React 组件
2. 打包为 JS/CSS 资源
3. 在设计器中注册自定义控件
4. 通过前后端消息机制通信

前端技术要求：
- React 框架
- 了解前端代码部署方法和结构
- 熟练使用 F12 调试
- 了解苍穹前端消息机制

## 注意事项

1. **事件注册位置**：控件事件必须在 `registerListener` 中注册，不能在 `initialize` 中
2. **界面控制时机**：界面控制逻辑放在 `afterBindData` 中，不要在 `initialize` 中设置可见性
3. **禁止大批量 setValue**：超过100行数据不要循环 `model.setValue`，应使用 `property.setValueFast`
4. **禁止在 beforeBindData/afterBindData 修改数据对象**：会导致数据库值与界面不一致
5. **updateView 调用**：禁止在循环中调用 `view.updateView()`，循环结束后局部刷新即可
6. **F7过滤时机**：在 `beforeF7Select` 中设置过滤条件
