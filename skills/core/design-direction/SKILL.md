# Design Direction

> Cross-platform Agent Skill · 提出有依据的设计推荐，让用户看稿、试调并选定方向。

## 触发条件与设计输入

以本次的受众、观看情境、核心内容和主要任务为依据。沿用用户指定的品牌、素材、模板及业务约束。改版先看原作，明确哪些内容和操作需要保留。用户只要文字评审时，指出具体画面、影响和建议。已有定稿并要求制作时，Web 前端开发交给 `frontend-development`，视觉成品还原交给 `visual-implementation`。

## 设计与推荐流程

网页与应用界面的整页选型、出稿和视觉评审，按[视觉设计方法](references/visual-craft.md)推敲与检查相关视觉取舍；局部调整只读涉及的部分。方法服务于实际任务与已选方向，不改变用户的决策时点、出稿范围或制作授权。

1. 整页选型先看用户指定的参考。没有指定时，选同媒介、用途相近且当前可用的成熟作品。查看目标尺寸的实际画面和关键操作。给出原页和可见的借鉴点，说明如何服务本题。控件行为可对照项目组件或成熟组件库的官方示例。
2. 方向未定时，先用真实参考或简要布局对照说明首屏重点、视觉气质和关键操作，给出推荐及理由。向用户确认会改变效果的取舍。待用户确认方向或明确委托自主决定，再生成素材或制作完整样稿。用户已明确方向或要求直接出稿时，按其要求推进。
3. 开放选型通常比较两至三种有实质差异的方向。各版使用同一内容、业务状态和目标尺寸。用实际内容排整页，先定视觉重心和阅读次序，再一起推敲构图、字体、图像、配色和留白。交稿前对照参考和实际画面，指出哪处搭配支撑本版的气质和主要任务。窄屏重新安排图文与操作次序。PPT 按放映尺寸和观看距离设计。
4. 按媒介判断节奏。静态作品看形态、疏密和尺度如何引导视线。涉及动画、媒体或操作时，看实际变化是否传达了预期关系。交付物使用面向受众的文案和所需署名。制作说明仅按用户要求加入。
5. 为各版命名，说明最重要的收益和取舍。推荐自己认为最适合的一版，指向画面中支持判断的细节。评审时指出值得保留和需要调整的关系，按问题决定修改范围。最终选择由用户作出。

方法参考见 [frontend-design 创意方法](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)、[GOV.UK Design System](https://design-system.service.gov.uk/patterns/check-answers/) 或 [CERN 演示设计](https://design-guidelines.web.cern.ch/presentations)。

## 设计输出与开发交接

交付 UI 设计时，按同一版本提供以下三项。静态视觉稿按约定的观看规格交付。

1. **交互稿**。在目标尺寸展示整页与关键状态，能操作主要流程并看到反馈。优先提供能在对话内体验的原型。
2. **中英双语设计规范**。按布局、组件、状态及动效标明位置和实现要求。术语首次出现时并列原语与贴合当前设计的中文含义。写明不同尺寸的排法，以及主要操作的触发、状态变化和结果。
3. **设计参数**。按[设计参数规范](references/design-parameters.md)登记影响整页和关键组件的值，局部设计登记相关项。交互界面的整页选型默认开放主要参数供用户试调。变化即时作用于真实稿面，并可恢复本版的基准值。

使用 A2UI 时，将真实组件的文字、颜色、位置及其他开放参数绑定到[共用编辑函数](scripts/a2ui-editor.mjs)。各版独立保存草稿，同版跨尺寸共享编辑值。编辑控件放在作品之外，保留作品自身操作。编辑能力由自动检查验证。改动组件绑定或渲染器时验证受影响的接入。[A2UI 接入](references/a2ui-review.md)

开发交接包含同版交互稿、双语规范、参数表、可编辑源、素材、目标规格、验收条件和待定项。在交接入口说明采用的设计版本和选定依据（用户确认，或用户授权后采用的方案与基准）。指出开发取值的来源，标明采用基准还是选定值，以及适用的尺寸或状态覆盖。小项目可直接引用现有规范、参数表和原型源码；已有设计系统时沿用项目约定的来源和格式。

为影响主要操作、完成和恢复的关键状态附最短复现路径，写清入口、必要前置条件、动作和可观察结果，例如文案、禁用状态、保留的选择或焦点位置。已有验收用例或可操作原型能说明时直接引用，也可在现有材料中补充。

## 选定边界与接入失败处理

用户指定的入口无法承载约定交互时，指出受影响的操作并由用户决定是否更换入口。

初始选择留空。用户明确选定时，记录方案版本及选定参数。后续试调另存草稿。只有已有制作授权时才进入成品实现。
