# ISCB 数据集成映射表达式

## Profile

- 本文件用于数据集成方案的直接赋值、过滤条件赋值和聚合运算字段。宏/聚合表达式与 `<%script%>` 内嵌脚本分别处理，不能仅凭编辑位置判定语法。
- 宏/聚合表达式使用 `check-script --mode mapping` 校验；不得送入 engine JAR 编译，也不得改写成 JavaScript 调用。内嵌脚本的覆盖边界见下节。
- 表达式以官方映射文档为基线；实际目标版本行为冲突时，记录版本反例并以目标平台验证结果修订。

## 直接赋值与过滤条件

| 表达式 | 结果/用途 | 约束 |
|---|---|---|
| `#{new_boid(BOSTYPE)}` | 生成 EAS/BOS BOID | `BOSTYPE` 替换为目标实体的 8 位十六进制值 |
| `#{new_int_id()}` | 生成苍穹长整型 ID | 用于 bigint 主键 |
| `#{new_string_id()}` | 生成 18 位字符串 ID | 用于 varchar 主键 |
| `#{new_uuid()}` | 生成 36 位 UUID | 用于字符串主键 |
| `#{now}` | 当前日期时间 | 直接赋值 |
| `#{today}` | 当前日期 | 直接赋值 |
| `#{now-TIMESPAN}` | 当前时间减指定范围 | `TIMESPAN` 实际写成下列 n+单位形式 |
| `#{now-<n>day}` | 当前时间减 n 天 | 过滤条件赋值 |
| `#{now-<n>hour}` | 当前时间减 n 小时 | 过滤条件赋值 |
| `#{now-<n>minute}` | 当前时间减 n 分钟 | 过滤条件赋值 |

生成 ID 的目标字段不得同时作为候选键；候选键使用稳定业务值。

## 直接赋值与固定比较值中的内嵌脚本

官方功能文档明确支持 `<%script%>`，例如固定比较值 `<%$上周%>`；该能力的发布记录为苍穹 V2.0、补丁 `V2.0.032（BIZ）`、上线日期 2020-07-21。使用前核对目标版本、补丁及当前编辑位置；该记录不证明每个旧项目已安装，也不把此语法扩展到聚合运算链。

- 内层是集成脚本，不能套用宏表达式“不得出现 return、分号”的约束；具体变量和语法仍按实际上下文取证。
- 当前 `check-script --mode mapping` 尚未实现 `<%...%>` 容器。其拒绝只说明本地校验覆盖不足，不能据此断言官方平台不支持；也不能忽略拒绝后声称映射静态通过。
- 如需本地预检，保留交付中的完整容器，把内层脚本单独作为输入；平台上下文可用 `check-script --mode platform <inner.iscb>` 做弱预检，普通 engine 片段仅做适用的 engine 校验。两者均不能代替目标版本编辑器对完整映射的实际验证；runtime 和真实环境动作仍遵守原授权合同。

来源：[支持数据集成方案直接赋值、过滤条件内输入脚本赋值](https://developer.kingdee.com/knowledge/specialDetail/136861720890670848?category=137198604132816640&id=63586477686239488&type=Knowledge&productLineId=29&lang=zh-CN)，官方知识正文更新于 2026-07-30；上述版本来自正文发布记录。

## 聚合运算

`::` 按从左到右组合运算，例如：

```text
split(;)::rtrim(省,市,自治区)::join(,)
default(1970-01-01)::date
```

| 运算 | 语义 |
|---|---|
| `count` | 统计源分录字段的非空值 |
| `join(s)` | 用分隔符 s 将 N 行合并为一个字符串 |
| `split(s)` | 用分隔符 s 将单值拆为 N 行 |
| `rtrim(s1,s2,...)` | 删除右侧命中的后缀 |
| `default(s)` | 值为 null 或空字符串时使用 s |
| `if(field=value)` | 条件成立保留源值，否则返回 null |
| `null_if(field=value)` | 条件成立返回 null，否则保留源值 |
| `to_eas_id(BOSTYPE)` | 按 BOSTYPE 将当前源值转换为 EAS/BOS ID |
| `date` / `decimal` / `int` / `long` | 转换目标类型 |

## 分录选择

| 表达式 | 语义 |
|---|---|
| `[n]` | 选择第 n 行；官方示例从 `[1]` 开始 |
| `[-n]` | 倒序选择；`[-1]` 是最后一行 |
| `[field=value]` | 选择字段等于指定值的分录行 |

选择器可作为独立聚合运算，也可与其他运算通过 `::` 组合。`[0]` 没有官方语义，不生成。

## 输出边界

- 用户要求脚本节点代码时，不输出本文件语法。
- 用户要求宏/聚合表达式时只输出表达式，不包 `return` 或分号；使用已确认的 `<%script%>` 能力时交付完整容器及其内层脚本，不把两种语法相互改写。
- 目标字段类型、候选键、BOSTYPE、过滤字段和分录基数不明时，给出待替换项，不宣称平台验证通过。
