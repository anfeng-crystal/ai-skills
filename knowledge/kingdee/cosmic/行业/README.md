# 行业知识库索引

本目录按行业场景组织知识文档。8 个行业按固定顺序轮转：

1. **医疗** — HIS对接、患者管理、药品管理、费用结算
2. **教育** — 学籍管理、排课系统、学分管理
3. **养殖** — 养殖批次、IoT采集、防疫管理
4. **建筑** — 项目进度、安全巡检、工程结算
5. **制造** — BOM管理、生产排程、质检管理
6. **零售** — 订单管理、库存预警、促销管理
7. **金融** — 交易管理、风控系统、对账结算
8. **政务** — 政务审批、电子签章、数据上报

## 文档命名规范

`[领域]_[行业]_[功能/组件]_[文档类型].md`

示例：`backend_healthcare_patient-registration_guide.md`
