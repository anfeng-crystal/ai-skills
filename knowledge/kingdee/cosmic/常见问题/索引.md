# 金蝶云苍穹常见问题

## 插件相关问题

### Q: 插件为什么不生效？

**可能原因：**
1. 插件未正确注册到元数据
2. 插件类路径错误
3. 容器未重启
4. 环境变量未配置

**排查步骤：**
1. 检查插件是否已上传到 AppStore
2. 检查容器环境变量是否配置了插件包
3. 重启容器服务
4. 查看服务器日志

```java

```

```java

// A: 创建
```

### Q: 如何判断是新增还是修改？

```java
@Override
public void afterCreateNewData(EventObject e) {
    // 新增时触发
}

// 或通过数据状态判断
DynamicObject data = this.getModel().getDataEntity();
Object pkValue = data.getPkValue();
if (pkValue == null || "0".equals(pkValue.toString())) {
    // 新增
} else {
    // 修改
}
```

```java
DynamicObjectCollection entries = this.getModel().getEntryEntity("entryKey");

```

### Q: 如何删除分录行？

## 性能问题

### Q: 查询数据很慢怎么办？

1. 检查是否缺少索引
2. 优化查询条件
3. 避免查询过多字段
4. 使用分页查询

```java
// 只查询需要的字段
DynamicObject[] results = QueryServiceHelper.query(
    "entityKey",
    "field1,field2,field3", // 指定字段
    new QFilter[]{filter}
);
```

### Q: 保存数据很慢怎么办？

1. 检查是否有大量分录
2. 检查是否有复杂的校验规则
3. 使用批量保存
4. 检查是否有循环触发插件

## 错误排查

### Q: NullPointerException

**常见原因：**
- DynamicObject 为 null
- 字段值为 null 时直接调用方法

**解决：**
```java
Object value = this.getModel().getValue("fieldKey");
if (value != null) {
    String str = value.toString();
}
```

### Q: ClassNotFoundException

**常见原因：**
- 插件包未正确上传
- 类路径错误
- 依赖缺失

### Q: 操作被锁定

**常见原因：**
- 单据已被其他用户锁定
- 事务未正确提交

**解决：**
- 检查事务控制
- 确保异常时回滚事务
