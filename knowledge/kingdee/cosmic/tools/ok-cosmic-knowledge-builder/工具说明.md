## 摘要
本工具用于从苍穹 JAR 和文档库生成 `ok-cosmic-knowledge.db`，供 `kingdee-cosmic` 的 API 查询脚本读取。

## 适用场景
- 苍穹 SDK、插件基类、服务助手或方法签名发生变化。
- 新项目需要建立独立的 `ok-cosmic-knowledge.db`。
- API 查询结果缺失、过旧或与当前本地依赖不一致。

## 前置条件
- 本机可执行 Java 8 或更高版本。
- 已确认项目对应的苍穹 JAR 库目录。
- 已确认输出知识库路径，优先输出到项目知识库目录。

## 固定规则
- 构建产物写入项目知识库目录，不写入 active skill 目录。
- `kingdee-cosmic` 只读取项目 `ok-cosmic.json` 中的 `graph.dbPath`。
- `ok-cosmic-docs.db` 作为文档增强输入库，不能替代项目最终的 `ok-cosmic-knowledge.db`。
- 多项目共存时，每个项目维护独立配置和独立知识库文件。

## 推荐命令
```bash
cd /Users/anfeng/AI/knowledge/kingdee/cosmic/tools/ok-cosmic-knowledge-builder
./setup-mac.sh -libpath=/path/to/cosmic/libs -docsdbpath=ok-cosmic-docs.db -dbpath=/path/to/project/ok-cosmic-knowledge.db
```

## 参数
| 参数 | 说明 |
|---|---|
| `-libpath` | 苍穹 JAR 库目录 |
| `-docsdbpath` | 文档增强数据库路径 |
| `-dbpath` | 输出 API 知识库路径 |
| `-jarthreads` | JAR 解析并发线程数 |
| `-verifyjar` | 校验用 JAR 文件路径 |
| `-verifyclass` | 校验用完整类名 |

## 输出
- `ok-cosmic-knowledge.db`：API 查询知识库。
- `class_node`：类、继承、类注释信息。
- `method_node`：方法签名、返回值、参数说明和方法注释信息。

## 失败条件
- Java 不可用或版本不满足要求。
- `setup.jar` 缺失。
- `-libpath` 指向错误目录或 JAR 不完整。
- 输出目录不可写。
- 生成后的数据库缺少 `class_node` 或 `method_node`。
