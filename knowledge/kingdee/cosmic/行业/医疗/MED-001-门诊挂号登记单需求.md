# 需求单

## 基本信息
- **需求编号**: MED-001
- **所属行业**: 医疗
- **业务场景**: 门诊挂号登记
- **优先级**: P1(高)
- **提出时间**: 2026-04-12
- **需求来源**: 医院门诊核心业务流程 + 苍穹单据标准开发模式

## 核心功能目标
开发一个「门诊挂号登记单」，实现患者挂号信息录入、科室号源管理、挂号费用结算的完整业务闭环，覆盖苍穹**单据表单+列表+操作插件+表单插件**的基本开发能力。

## 业务角色
| 角色 | 职责 |
|------|------|
| 挂号员 | 录入挂号信息、收费 |
| 门诊医生 | 查看挂号列表、接诊 |
| 门诊主任 | 审批加号/退号 |

## 前置条件与依赖
- 基础资料：科室、医生、号源类型（普通/专家/特需）
- 编码规则：挂号单号自动生成（GH+日期+序号）
- 环境：苍穹开发环境 + PostgreSQL

## 详细业务规则

### 单据头
| 字段标识 | 字段名 | 类型 | 必录 | 说明 |
|---------|--------|------|------|------|
| billno | 挂号单号 | 文本 | 是 | 编码规则自动生成 |
| billstatus | 单据状态 | 下拉 | 是 | A-暂存 B-已挂号 C-已接诊 D-已退号 |
| patient_name | 患者姓名 | 文本 | 是 | |
| patient_id | 身份证号 | 文本 | 是 | 18位，前端校验格式 |
| patient_phone | 联系电话 | 文本 | 是 | 手机号校验 |
| patient_gender | 性别 | 下拉 | 是 | 男/女 |
| patient_age | 年龄 | 整数 | 否 | 根据身份证自动计算 |
| dept | 挂号科室 | 基础资料 | 是 | 关联科室基础资料 |
| doctor | 就诊医生 | 基础资料 | 是 | 联动科室过滤 |
| register_type | 号源类型 | 下拉 | 是 | 普通/专家/特需 |
| register_date | 就诊日期 | 日期 | 是 | 默认当天，不得早于当天 |
| time_period | 就诊时段 | 下拉 | 是 | 上午/下午 |
| register_fee | 挂号费用 | 金额 | 是 | 根据号源类型自动带出 |
| pay_status | 支付状态 | 下拉 | 是 | 未支付/已支付/已退款 |
| remark | 备注 | 大文本 | 否 | |

### 业务规则
1. **科室-医生联动**：选择科室后，医生字段仅显示该科室下的医生
2. **费用自动计算**：号源类型切换时，挂号费自动赋值（普通=10元，专家=50元，特需=200元）
3. **年龄自动计算**：录入身份证号后，自动计算并回写年龄字段
4. **号源校验**：保存时校验当日该医生当前时段的剩余号源数量，不足则报错提示
5. **就诊日期校验**：不允许挂过去日期的号
6. **退号限制**：已接诊状态的挂号单不允许退号

### 审批流程
- 退号需门诊主任审批（金额>100元时）
- 加号需门诊主任审批

### 列表页功能
- 支持按科室、医生、日期、状态过滤
- 挂号员视图：显示所有挂号记录
- 医生视图：仅显示自己的患者
- 支持批量操作（批量确认接诊）
