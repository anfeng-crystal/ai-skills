## 摘要
本文沉淀苍穹二开前的配置优先门禁：能由元数据、界面规则、业务规则、工作流规则、模板配置完成的需求，不进入插件或 KingScript。

## 适用版本
- 金蝶云苍穹 V7/V8 方向能力。
- 当前项目本地依赖以 `/Users/anfeng/utils/cosmic/home/mservice-cosmic/lib` 与随包文档为准。
- 若官方社区文章和本地依赖存在差异，以当前项目依赖、随包文档和目标租户实际版本为准。

## 核心概念
| 概念 | 说明 |
|---|---|
| 元数据 | 单据、基础资料、动态表单、字段、单据体、布局、物理表、编码和引用关系等设计器配置。 |
| 界面规则 | 官方资料中按“前置条件 + 服务”组织，主要用于控制控件可见、锁定、启用、样式等界面行为。 |
| 业务规则 | 官方资料中同样按“前置条件 + 服务”组织，主要用于字段携带、值更新、简单单据内计算等。 |
| 插件兜底 | 配置无法覆盖时，才使用 Java 插件或 KingScript 处理复杂动态行为、跨对象聚合、事务编排和外部集成。 |

## 详细内容

### 配置可做事项
| 能力域 | 可优先配置的事项 | 边界 |
|---|---|---|
| 元数据 | 单据、基础资料、动态表单、字段、单据体、子分录、默认值、必录、编码、基础资料引用、组织字段 | 适合对象结构、字段建模、页面布局和基础校验；不要直接修改 `t_meta_*`。 |
| 基础资料 | 编码、名称、启用状态、审核状态、分组、组织隔离、引用缓存 | 基础资料编码字段用 `number`，单据编码字段用 `billno`。 |
| 界面规则 | 控制字段/控件可见、隐藏、锁定、启用、样式类服务 | 仅处理已有控件状态；运行期动态造控件或复杂前端通信需插件兜底。 |
| 业务规则 | 字段携带、值更新、简单计算、基于条件触发单据内服务 | 跨对象累计、复杂查库、大批量算法不放进业务规则硬做。 |
| 工作流规则 | 发起条件、跳过条件、流转线条件、参与人、自动审批、消息通知、节点业务规则检查 | 动态组织链、金额矩阵、复杂参与人和特殊节点逻辑用工作流插件或脚本兜底。 |
| 操作配置 | 保存、提交、审核、反审核、删除、关闭等标准操作和按钮权限 | 跨库保存、补偿任务、外部接口调用不放在标准操作配置中硬拼。 |
| 打印模板 | 静态版式、字段绑定、常规明细、常规样式 | 动态列、打印前重组数据包、按值调整输出元素样式需打印插件。 |
| 导入导出模板 | 标准引入引出模板、字段映射、常规 Excel 数据导入导出 | 自定义解析、复杂清洗、批量权限、导入后关联和反写需插件。 |

### 插件兜底事项
| 场景 | 兜底方式 | 必须说明的理由 |
|---|---|---|
| 运行期动态加控件、动态改变控件元数据、自定义前端通信 | 表单插件或自定义控件 | 界面规则只控制已有控件状态。 |
| F7 过滤依赖复杂组织权限、当前用户、分录行、外部服务 | 表单/列表插件 | 标准过滤配置无法表达完整上下文。 |
| 跨对象、跨期间、跨单据累计校验 | 操作插件或服务 | 业务规则不适合大批量查库聚合。 |
| 跨库保存、事务后通知、补偿任务 | 操作插件事务后事件或异步任务 | 避免在同一事务写多库。 |
| 自定义列表取数或第三方数据列表 | 列表插件数据提供器 | 设计器列表只覆盖标准实体列表。 |
| 报表自定义数据源 | 报表取数插件 | 普通列表分页已由设计器“显示分页”承担。 |
| 工作流复杂参与人、复杂条件路由 | 工作流插件或 KingScript | 标准参与人/条件规则无法表达动态算法。 |
| 打印动态列和运行期数据包 | 打印插件 | 静态模板无法表达运行期结构变化。 |
| 导入复杂解析、清洗、批量校验 | 引入插件 | 标准模板不处理复杂 Excel 结构和业务关联。 |

### 配置可达性判定表
| 字段 | 填写要求 |
|---|---|
| 需求 ID | 如 `BUILD-BILL-001`、`FIN-IO-005`、`HR-WF-003`。 |
| 业务域 | 建设、财务、HR、实施、工作流、打印等。 |
| 对象类别 | 单据、基础资料、动态表单、列表、操作、移动、工作流、KingScript、控件、打印、导入导出。 |
| 元数据可做 | 是、否、待官确。 |
| 界面规则可做 | 是、否、待官确。 |
| 业务规则可做 | 是、否、待官确。 |
| 工作流规则可做 | 是、否、待官确。 |
| 模板配置可做 | 打印、导入导出、过滤、权限等配置项。 |
| 必须插件原因 | 配置不可覆盖时必填。 |
| 官方来源 | URL 或本地随包文档路径。 |
| 验证方式 | 编译、smoke、平台联调、文档核验。 |

## 注意事项
- 配置能完成的，不要写插件。
- 不能把 PC 控件、PC 插件事件直接套到移动端，移动端能力必须单独确认。
- 报表列表设计器配置“显示分页”后已经具备分页能力，不要为了普通分页新增取数插件。
- 未从官方资料、本地知识库或随包文档确认的能力必须标记“待官确”。
- 插件内禁止直接 SQL、全量内存分页、空 `catch`、生产入口污染和跨库同事务写入。
