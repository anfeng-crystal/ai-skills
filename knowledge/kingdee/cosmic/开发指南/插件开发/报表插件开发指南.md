## 摘要

本文介绍金蝶云苍穹报表插件的开发方法，包括报表取数插件和报表界面插件的事件、常用接口及开发技巧。

## 适用版本

- 金蝶云苍穹 V5.0+

## 报表类型说明

苍穹平台支持多种报表类型：

| 报表类型 | 说明 | 适用场景 |
|---------|------|---------|
| **轻报表** | 基于元数据配置的简单报表 | 简单列表、简单统计 |
| **报表** | 基于插件开发的复杂报表 | 复杂查询、多表关联 |
| **报表取数插件** | 服务端取数逻辑 | 自定义取数逻辑 |
| **报表界面插件** | 客户端交互逻辑 | 过滤条件、界面控制 |

## 一、报表取数插件

### 1.1 插件基类

```java
public class ReportDataPlugin extends AbstractReportListDataPlugin {
    // 报表取数逻辑
}
```

### 1.2 核心事件

| 事件 | 触发时机 | 用途 |
|-----|---------|------|
| `query` | 查询数据时 | 对数据列进行操作 |
| `getColumns` | 获取列定义时 | 修改指定列的属性 |

### 1.3 代码示例

```java
public class ReportDataPlugin extends AbstractReportListDataPlugin {

    @Override
    public void query(QueryEventArgs e) {
        super.query(e);
        // 对查询结果进行处理
        // 可以修改查询条件、添加自定义过滤
    }

    @Override
    public void getColumns(GetColumnsEventArgs e) {
        super.getColumns(e);
        // 修改列属性
        // 如：设置列宽、格式、对齐方式等
        for (ReportColumn column : e.getColumns()) {
            if ("amount".equals(column.getKey())) {
                column.setFormat("#,##0.00");
                column.setAlign("right");
            }
        }
    }
}
```

## 二、报表界面插件

### 2.1 插件基类

```java
public class ReportFormPlugin extends AbstractReportFormPlugin {
    // 报表界面交互逻辑
}
```

### 2.2 核心方法与事件

| 方法/事件 | 触发时机 | 用途 |
|----------|---------|------|
| `filterContainerInit` | 初始化过滤容器时 | 设置过滤控件默认值 |
| `filterContainerBeforeF7Select` | 过滤容器内 F7 弹出前 | F7 弹出前处理 |
| `initDefaultQueryParam` | 初始化默认查询参数 | 设置默认过滤条件 |
| `processRowData` | 行数据处理时 | 对每页数据进行处理 |
| `packageData` | 打包数据给前端时 | 最终数据处理 |
| `formatDisplayFilterField` | 格式化显示的过滤字段 | 自定义过滤字段显示 |
| `verifyQuery` | 查询前条件验证 | 验证查询条件合法性 |
| `beforeQuery` | 查询前置处理 | 查询前的准备工作 |
| `afterQuery` | 查询后置处理 | 查询后的处理工作 |
| `afterCreateColumn` | 表格列创建完成后 | 列创建后的处理 |

### 2.3 代码示例

```java
public class ReportFormPlugin extends AbstractReportFormPlugin {

    @Override
    public void filterContainerInit(FilterContainerInitEventArgs e) {
        super.filterContainerInit(e);
        // 设置过滤控件默认值
        e.setFilterValue("dateRange", "thisMonth");
    }

    @Override
    public void initDefaultQueryParam(InitDefaultQueryParamEventArgs e) {
        super.initDefaultQueryParam(e);
        // 设置默认查询参数
        e.addQueryParam("status", "A");
    }

    @Override
    public void processRowData(ProcessRowDataEventArgs e) {
        super.processRowData(e);
        // 行数据处理
        // 参数说明：
        // e.getGridPK() - 表格控件标识
        // e.getRowData() - 一页数据
        // e.getQueryParam() - 查询参数

        List<Map<String, Object>> rowData = e.getRowData();
        for (Map<String, Object> row : rowData) {
            // 自定义行数据计算
            BigDecimal qty = (BigDecimal) row.get("qty");
            BigDecimal price = (BigDecimal) row.get("price");
            row.put("amount", qty.multiply(price));
        }
    }

    @Override
    public void verifyQuery(VerifyQueryEventArgs e) {
        super.verifyQuery(e);
        // 查询前验证
        if (e.getQueryParam().get("startDate") == null) {
            e.setErrorMessage("开始日期不能为空");
        }
    }

    @Override
    public void beforeQuery(BeforeQueryEventArgs e) {
        super.beforeQuery(e);
        // 查询前处理
    }

    @Override
    public void afterQuery(AfterQueryEventArgs e) {
        super.afterQuery(e);
        // 查询后处理
    }

    @Override
    public void packageData(PackageDataEventArgs e) {
        super.packageData(e);
        // 打包数据给前端前的最后处理
    }
}
```

## 三、复杂报表取数（QueryServiceHelper）

### 3.1 基础查询

```java
import kd.bos.servicehelper.QueryServiceHelper;

// 简单查询
DynamicObject[] data = QueryServiceHelper.query(
    "sal_order",                          // 实体标识
    "id,billNo,customerId,customerId.name,amount",  // 查询字段
    new QFilter[]{                        // 过滤条件
        new QFilter("billStatus", QCP.equals, "C"),
        new QFilter("createTime", QCP.greater_equal, "2024-01-01")
    }
);
```

### 3.2 多表关联查询

苍穹使用 `QueryServiceHelper` 的 `query` 方法支持多表关联，通过字段路径实现：

```java
// 查询销售订单，关联客户基础资料、物料基础资料
DynamicObject[] orders = QueryServiceHelper.query(
    "sal_order",                          // 主实体：销售订单
    "id,billNo," +                        // 订单字段
    "customerId,customerId.name,customerId.address," +  // 关联客户字段
    "entryEntity.seq," +                  // 单据体行号
    "entryEntity.materialId,entryEntity.materialId.name,entryEntity.materialId.specification," +  // 关联物料
    "entryEntity.qty,entryEntity.price,entryEntity.amount",  // 单据体金额字段
    new QFilter[]{
        new QFilter("billStatus", QCP.equals, "C"),
        new QFilter("customerId.name", QCP.like, "%张三%"),  // 关联字段过滤
        new QFilter("entryEntity.materialId.number", QCP.equals, "MAT001")
    }
);

// 遍历结果
for (DynamicObject order : orders) {
    String billNo = order.getString("billNo");
    String customerName = order.getString("customerId.name");

    // 获取单据体
    DynamicObjectCollection entries = order.getDynamicObjectCollection("entryEntity");
    for (DynamicObject entry : entries) {
        String materialName = entry.getString("materialId.name");
        BigDecimal qty = entry.getBigDecimal("qty");
    }
}
```

### 3.3 复杂条件构造（AND/OR组合）

```java
import kd.bos.orm.CondType;

// 构造复杂条件：(A AND B) OR (C AND D)
QFilter filterA = new QFilter("billStatus", QCP.equals, "C");
QFilter filterB = new QFilter("amount", QCP.greater, new BigDecimal("10000"));

QFilter filterC = new QFilter("billStatus", QCP.equals, "B");
QFilter filterD = new QFilter("creatorId.name", QCP.equals, "管理员");

// 先构造内部 AND 条件
QFilter andFilter1 = filterA.and(filterB);
QFilter andFilter2 = filterC.and(filterD);

// 再构造外部 OR 条件
QFilter finalFilter = andFilter1.or(andFilter2);

DynamicObject[] data = QueryServiceHelper.query(
    "sal_order",
    "id,billNo,billStatus,amount",
    new QFilter[]{finalFilter}
);
```

### 3.4 IN查询（批量条件）

```java
// 查询多个指定单据
List<String> billNos = Arrays.asList("SO2024001", "SO2024002", "SO2024003");

DynamicObject[] data = QueryServiceHelper.query(
    "sal_order",
    "id,billNo,amount",
    new QFilter[]{
        new QFilter("billNo", QCP.in, billNos)
    }
);

// 子查询 IN
DynamicObject[] customers = QueryServiceHelper.query(
    "bd_customer",
    "id",
    new QFilter[]{
        new QFilter("customerType", QCP.equals, "A")
    }
);
List<Object> customerIds = Arrays.stream(customers)
    .map(c -> c.get("id"))
    .collect(Collectors.toList());

DynamicObject[] orders = QueryServiceHelper.query(
    "sal_order",
    "id,billNo,customerId",
    new QFilter[]{
        new QFilter("customerId", QCP.in, customerIds)
    }
);
```

### 3.5 分组汇总查询

```java
// 使用 queryGroup 进行分组汇总
GroupBy groupBy = new GroupBy();
```

### 3.7 报表取数插件中动态构建查询

```java
public class CustomReportDataPlugin extends AbstractReportListDataPlugin {

    @Override
    public void query(QueryEventArgs e) {
        super.query(e);

        // 获取报表过滤条件
        Map<String, Object> filterParams = e.getQueryParams();

        // 构建动态条件
        List<QFilter> filters = new ArrayList<>();

        // 日期范围
        String startDate = (String) filterParams.get("startDate");
        String endDate = (String) filterParams.get("endDate");
        if (StringUtils.isNotEmpty(startDate)) {
            filters.add(new QFilter("createTime", QCP.greater_equal, startDate));
        }
        if (StringUtils.isNotEmpty(endDate)) {
            filters.add(new QFilter("createTime", QCP.less_equal, endDate));
        }

        // 客户多选
        List<String> customerIds = (List<String>) filterParams.get("customerIds");
        if (CollectionUtils.isNotEmpty(customerIds)) {
            filters.add(new QFilter("customerId", QCP.in, customerIds));
        }

        // 金额范围
        BigDecimal minAmount = (BigDecimal) filterParams.get("minAmount");
        BigDecimal maxAmount = (BigDecimal) filterParams.get("maxAmount");
        if (minAmount != null) {
            filters.add(new QFilter("amount", QCP.greater_equal, minAmount));
        }
        if (maxAmount != null) {
            filters.add(new QFilter("amount", QCP.less_equal, maxAmount));
        }

        // 模糊搜索（多字段匹配）
        String keyword = (String) filterParams.get("keyword");
        if (StringUtils.isNotEmpty(keyword)) {
            QFilter billNoFilter = new QFilter("billNo", QCP.like, "%" + keyword + "%");
            QFilter customerFilter = new QFilter("customerId.name", QCP.like, "%" + keyword + "%");
            filters.add(billNoFilter.or(customerFilter));
        }

        // 执行查询
        DynamicObject[] data = QueryServiceHelper.query(
            "sal_order",
            "id,billNo,customerId,customerId.name,amount,createTime",
            filters.toArray(new QFilter[0])
        );

        // 设置查询结果
        e.setQueryData(data);
    }
}
```

## 四、自定义SQL查询（DB.query）

### 4.1 执行原生SQL

当 QueryServiceHelper 无法满足复杂查询时，可以使用 DB 类执行原生 SQL：

```java
import kd.bos.db.DB;
import kd.bos.db.DBRoute;

// 简单SQL查询
String sql = "SELECT id, billNo, amount FROM sal_order WHERE billStatus = ?";
List<Map<String, Object>> result = DB.query(sql, new Object[]{"C"}, DBRoute.basedata);

// 遍历结果
for (Map<String, Object> row : result) {
    String id = (String) row.get("id");
    String billNo = (String) row.get("billNo");
    BigDecimal amount = (BigDecimal) row.get("amount");
}
```

### 4.2 复杂SQL（多表关联）

```java
// 多表关联SQL查询
String complexSql =
    "SELECT " +
    "  o.id, o.billNo, o.amount as orderAmount, " +
    "  c.name as customerName, c.address as customerAddress, " +
    "  e.qty, e.price, m.name as materialName " +
    "FROM sal_order o " +
    "INNER JOIN bd_customer c ON o.customerId = c.id " +
    "LEFT JOIN sal_order_entry e ON o.id = e.parent " +
    "LEFT JOIN bd_material m ON e.materialId = m.id " +
    "WHERE o.billStatus = ? " +
    "  AND o.createTime >= ? " +
    "  AND c.customerType = ? " +
    "ORDER BY o.createTime DESC";

List<Map<String, Object>> result = DB.query(
    complexSql,
    new Object[]{"C", "2024-01-01", "A"},
    DBRoute.basedata
);
```

### 4.3 分页SQL查询

```java
// 分页查询
int pageNo = 1;
int pageSize = 100;
int offset = (pageNo - 1) * pageSize;

String pageSql =
    "SELECT id, billNo, amount " +
    "FROM sal_order " +
    "WHERE billStatus = ? " +
    "ORDER BY createTime DESC " +
    "LIMIT ? OFFSET ?";

List<Map<String, Object>> result = DB.query(
    pageSql,
    new Object[]{"C", pageSize, offset},
    DBRoute.basedata
);

// 查询总记录数
String countSql = "SELECT COUNT(*) FROM sal_order WHERE billStatus = ?";
long totalCount = DB.queryCount(countSql, new Object[]{"C"}, DBRoute.basedata);
```

## 五、轻报表开发

### 3.1 创建步骤

1. **创建报表页面**
   - 打开开发平台
   - 新建 -> 报表 -> 轻报表
   - 配置报表基本信息

2. **配置数据源**
   - 选择实体（支持单个实体查询）
   - 配置实体关联关系（多表连接查询）

3. **配置查询字段**
   - 从实体中选择需要在报表显示的字段
   - 设置字段别名、格式

4. **配置过滤条件**
   - 添加快捷过滤字段
   - 配置常用过滤方案

### 3.2 多实体组合查询（连接查询）

对于需要多个实体关联的报表：

1. 在报表设计器中点击【增加子实体】
2. 选择关联的子实体
3. 配置主实体与子实体的关联关系
   - 选择关联字段
   - 配置连接类型（内连接、左连接等）
4. 从子实体中选择需要显示的字段

## 四、报表与单据的区别

| 特性 | 报表 | 单据 |
|-----|------|------|
| 数据编辑 | 只读，不支持编辑 | 支持增删改查 |
| 数据保存 | 不保存到数据库 | 保存到数据库 |
| 主要用途 | 数据展示、分析 | 业务数据录入 |
| 插件基类 | `AbstractReportFormPlugin` | `AbstractBillPlugIn` |
| 取数方式 | 查询实时数据 | 加载单条单据数据 |

## 五、常用开发技巧

### 5.1 动态设置过滤条件

```java
@Override
public void filterContainerInit(FilterContainerInitEventArgs e) {
```

### 5.2 自定义列显示格式

```java
@Override
public void processRowData(ProcessRowDataEventArgs e) {
    super.processRowData(e);

    List<Map<String, Object>> rowData = e.getRowData();
    for (Map<String, Object> row : rowData) {
        // 格式化金额
        BigDecimal amount = (BigDecimal) row.get("amount");
        if (amount != null) {
            row.put("amountFormatted", "¥" + amount.toString());
        }

        // 状态转义
        String status = (String) row.get("status");
        switch (status) {
            case "A":
                row.put("statusName", "创建");
                break;
            case "B":
                row.put("statusName", "审核中");
                break;
            case "C":
                row.put("statusName", "已审核");
                break;
        }
    }
}
```

### 5.3 查询前参数处理

```java
@Override

    }
```

## 六、注意事项

1. **数据权限**
   - 报表查询需考虑数据权限控制
   - 在 `beforeQuery` 中添加组织权限过滤

2. **性能优化**
   - 避免在 `processRowData` 中执行耗时操作
   - 大数据量报表考虑分页取数
   - 复杂查询建议使用视图或物化视图

3. **日期处理**
   - 注意报表查询的日期范围
   - 考虑设置合理的默认日期范围

4. **数据一致性**
   - 报表数据是实时查询的，可能与其他界面显示略有差异
   - 如需精确数据，考虑在 `afterQuery` 中进行校准
